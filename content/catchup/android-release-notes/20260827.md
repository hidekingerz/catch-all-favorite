## 今回の注目ポイント

前回キャッチアップ（2026-07-23）以降、リリースノート一覧の最新バージョンは引き続き **Android 17** で、Android 18 等の新バージョンは未掲載。今回は Android 17 リリースノートに新たに **9 セクション**（Architecture / Audio / Automotive / Connectivity / Display / Media / Performance / Permissions / Security）が追加された。プラットフォーム基盤の大きな変更として、ION メモリアロケータの廃止、Memory Limiter / mmd / PMGD といったメモリ管理系デーモンの追加、per-display のデスクトップウィンドウイング、VVC（Versatile Video Coding）デコード対応、Contact Picker とロケーションインジケータによるプライバシー強化、ハードウェアラップ鍵の Linux カーネル ioctl 化とロック画面レート制限 UX の改善などがある。AOSP ベンダー実装・OEM に影響する破壊的変更（ION 廃止）を含むため、対象ベンダーは早めの確認が必要。

## リリースノート一覧

### Android 17 — Architecture（アーキテクチャ）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#architecture
- **要約**:
  - **ION deprecation**: ION メモリアロケータがすべての Android バージョンでサポート終了。ION をサポートするカーネルは 2025 年 12 月にすべて EOL に達したため、ION を使用するベンダーコードは失敗するようになる。ION を使うベンダーコードはすべて削除する必要がある。

### Android 17 — Audio（オーディオ）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#audio
- **要約**:
  - **Audio Managed SCO rearchitecture**: Android 17 以降で Audio Managed SCO（同期接続指向）の再アーキテクチャを採用したデバイスでは、SCO ルーティングを従来の Bluetooth フレームワークではなく Android オーディオフレームワークが SCO 管理機能で管理する。

### Android 17 — Automotive（車載）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#automotive
- **要約**:
  - **Advanced windowing with Scalable UI**: Android 17 以降、Scalable UI により車内で高度・動的なマルチパネル UX を構築できる。WindowManager invariants の追加、セットアップウィザードの構成、システム/ナビゲーションバーのカスタマイズに対応。
  - **Software defined vehicle (SDV)**: Android 17 以降で SDV を利用可能。ソフトウェアで車両の構築・制御・管理・機能拡張を担い、ソフトウェア更新で進化するコネクテッドで適応可能なプラットフォームへ車両を変える。

### Android 17 — Connectivity（接続）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#connectivity
- **要約**:
  - **Autorouting OTT calls to premium network connections**: OTT の音声・ビデオ通話をプレミアムネットワーク接続（プレミアム 5G スライスや 4G PDN 接続など）へ自動ルーティングする機能。アプリのネットワークスタックを変更せずにシステムがトラフィックを誘導する。
  - **Ranging: Out-of-band 仕様更新**: OOB 仕様の v2・v3 を導入。v2 はアクティブセッション中に測距技術を動的に切り替える Technology transitioning などを追加。v3 は周辺デバイスの動き変化を通知する Motion Notification / Motion support を追加。

### Android 17 — Display（ディスプレイ）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#display
- **要約**:
  - **Desktop windowing**: Android 17 以降でディスプレイ単位のデスクトップウィンドウイングを有効化できる（System decorations support 等を含む）。
  - **Large screen app compatibility**: 大画面アプリ互換オーバーレイ向けに `config_isCameraCompatSimulateRequestedOrientationTreatmentEnabled` など複数の設定を追加。

### Android 17 — Media（メディア）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#media
- **要約**:
  - **VVC support**: Android 17 は動画符号化規格 VVC（Versatile Video Coding）のデコードをサポート。プラットフォームはフレームワークとパーサーを提供するが、実際の VVC デコードには SoC ベンダーまたは OEM がデコーダ（ソフト/ハード）を用意し、Android メディアサブシステムに登録・有効化する必要がある。

### Android 17 — Performance（パフォーマンス）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#performance
- **要約**:
  - **Gather general health information**: トレードインモードのシステムヘルス診断向けに、カメラジオメトリと UICC スロット情報を追加。
  - **Memory Limiter**: Linux cgroup v2 を使ってアプリプロセスのメモリ使用量を監視・制限するシステムサービス。個々のアプリの過剰なメモリ消費を防ぎ、システム全体のメモリ圧迫と重要プロセスの OOM kill を軽減する。
  - **Memory management daemon (mmd)**: ZRAM 関連の保守タスクの構成・管理を担うシステムデーモン。
  - **Process memory guardian daemon (PMGD)**: プロセス単位でメモリ使用を先回りして管理し、対象プロセスにメモリ上限を穏やかに適用することで、孤立したメモリリークやスパイクによるシステム全体の性能劣化を防ぐ。

### Android 17 — Permissions（権限）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#permissions
- **要約**:
  - **Contact Picker**: 連絡先の全権限を要求せずに、ユーザーが選択した連絡先情報のみをアプリが取得できる仕組み。選択したデータのみへの読み取り許可、検索・プロフィール切替・複数選択を備えた標準 UI、Android 17 以降を対象とするアプリでは従来の `Intent.ACTION_PICK` を自動的に引き継ぐ後方互換性を提供。
  - **Location indicators**: カメラ/マイクに続き、リアルタイムのロケーションインジケータをステータスバーに追加。非システムアプリがフォアグラウンドで位置情報にアクセスするとアイコンが表示され、常時ドット表示に遷移。タップでどのアプリが追跡しているか確認できる。

### Android 17 — Security（セキュリティ）
- **URL**: https://source.android.com/docs/whatsnew/android-17-release#security
- **要約**:
  - **Hardware-wrapped key improvements**: ハードウェアラップ鍵によるストレージ暗号化の実装を簡素化。KeyMint ではなく Linux カーネル ioctl を使って鍵を生成・インポート・準備する。fstab で `wrappedkey_v0` から `wrappedkey` へ切り替えるとオンディスクフォーマットが変わるため、新規発売デバイス限定。既存の `wrappedkey_v0` デバイスは継続利用する。
  - **Lock screen rate-limiting UX**: 既定のロック画面レート制限を強化しつつ、UX を改善（「1800 秒」ではなく「30 分」といった大きな時間単位表示、`g.co/android/unlock` への復旧ショートリンク、重複した誤入力へのフィードバック、PIN 入力パッドの一貫した無効化）。`LockPatternUtils#getLockoutAttemptDeadline(int)` は `getLockoutEndTime(int)` に改名。
  - **Policy compatibility**: 対象プロパティで発売するデバイスは `memfd_class` ポリシー機能を有効化し、`memfd_file` クラスオブジェクトをサポートするよう共有メモリ関連ポリシーを更新する必要がある。
  - **Secure element prewarming**: Weaver HAL にセキュアエレメントをプリウォームするメソッドを追加。ロック画面の PIN/パターン/パスワード入力開始時に呼び出され、検証レイテンシを最大 200 ミリ秒短縮できる。
