## 今回の注目ポイント

Android 17 のリリースノート（英語版）は既掲載の全セクションから変更がなかった。一方、Android 16 のリリースノートページには既存ダイジェスト未収録のセクションが多数あり、今回はそれらを補完する。特にアーキテクチャでは Generic Bootloader（GBL）の標準化と 16KB ページサイズ向けメモリ最適化、セキュリティでは KeyMint 4.0 の APEX モジュール検証用 `moduleHash` フィールド追加、仮想化では AVF/pKVM の保護 VM 向けデバイス割り当て・FF-A 対応が注目。メディアでは APV コーデック対応と AV1 への移行計画が進む。

---

## リリースノート一覧

### Android 16 — Architecture（アーキテクチャ）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#architecture
- **要約**: Android のブート処理を効率化する標準化された Generic Bootloader（GBL）を導入。16KB ページサイズ向けのメモリ最適化ではスレッドローカルストレージバッファを分離し、初期スレッドメモリページ内で約 8KB を解放。メモリ消費とページフォルトを削減する。

### Android 16 — Audio（オーディオ）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#audio
- **要約**: AIDL HAL における Configurable Audio Policy（CAP）サポートを実装し、Android 14〜15 で欠けていた AIDL 定義とフレームワークによる CAP 設定の読み込み機構を修正。Cuttlefish Auto ターゲットをこの CAP AIDL 実装を利用する形に移行した。

### Android 16 — Connectivity（接続）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#connectivity
- **要約**: Bluetooth デバイスが Android API レベルを GATT キャラクタリスティックとして読み取れる Android Information Service（AIS）GATT サービスを追加。IMS 実装向けにトラフィックセッション管理や EPS フォールバックトリガーの新システム API を提供。Ranging モジュールが UWB・Bluetooth channel sounding・Wi-Fi RTT の API を集約する。

### Android 16 — Display（ディスプレイ）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#display
- **要約**: デスクトップウィンドウイングで重なり合うウィンドウの配置・リサイズによる生産性向上を実現。デバイス状態ベースの自動回転設定をリファクタリングし従来版の既知問題に対応。クイック設定タイルは編集モードでタイルを見つけやすくするカテゴリ分けに対応した。

### Android 16 — Media（メディア）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#media
- **要約**: アプリ側フォールバック機能・スクリーンショット処理改善・一貫性向上により HDR サポートを強化。ストリームおよびユーザーごとに細かく設定できる標準化された画質・音質フレームワークを新設。Advanced Professional Video（APV）コーデックのプラットフォーム対応を開始し、AV1 への移行計画も進める。

### Android 16 — Performance（パフォーマンス）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#performance
- **要約**: 開発者や再販業者が工場出荷時リセット後のシステム健全性を評価できる Trade-in モードを追加。ファクトリーリセット後のデバイス評価のための診断機能を提供する。

### Android 16 — Security（セキュリティ）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#security
- **要約**: セルラー機能向けに Safety Center へ専用の Mobile Network Security セクションを追加。KeyMint 4.0 のアテステーションに APEX モジュールの整合性を検証する `moduleHash` フィールドを追加。プライベートスペースは新しいシステムアプリを使い、メインプロファイルから直接ファイルをインポートできるようになった。

### Android 16 — Virtualization（仮想化）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#virtualization
- **要約**: AVF がベンダー起動 VM 向けの LL-NDK サポート、早期ブート VM 機能、リサイズ可能ストレージを備えた改良版 Microdroid を獲得。pKVM は保護 VM 向けに TrustZone との FF-A 標準セキュア通信をサポート。デバイス割り当てにより保護 VM 内でプラットフォームデバイスへの直接ハードウェアアクセスが可能になる。
