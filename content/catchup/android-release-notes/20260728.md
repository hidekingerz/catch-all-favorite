## 今回の注目ポイント

リリースノート一覧の最新バージョンは引き続き **Android 17**（英語版ページ最終更新 2026-06-17 UTC）で、Android 18 等の新バージョンは未掲載。Android 17 の全セクションは既存キャッチアップ（2026-06-21 / 2026-07-23）で記録済みのため新着なし。一方で **Android 16 のバージョン別ページが 2026-07-13 UTC に更新**され（初回記録時 2026-03-13 から更新）、QPR2 に伴う新セクションが追加された。今回の新着は Android 16 の **Compatibility / Interaction / Permissions / Storage / Updates** の各セクションで、互換性テスト（Camera ITS・CDD・CTS Verifier）、プライベートスペースへのファイル取り込み、シームレスアプリ更新による凍結時間短縮、既定連絡先アカウント、クイック設定タイルの分類などが含まれる。

## リリースノート一覧

### Android 16 — Compatibility（互換性テスト）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#compatibility
- **要約**:
  - Camera Image Test Suite（ITS）の更新、および QPR2 更新を含む Android 16 版 Compatibility Definition Document（CDD）の公開。
  - CTS Verifier の Bluetooth MIDI テストは USB MIDI 周辺機器なしで Bluetooth MIDI ループバックテストを実行可能に。Android の位置情報機能を支える気圧計（barometer）計測テストを追加。
  - 接続性向けのマルチデバイステストを追加し、Better Together 連携機能向けの Wi-Fi AP 接続テストにも対応。

### Android 16 — Interaction（操作・インタラクション）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#interaction
- **要約**:
  - 編集モードでタイルを見つけやすくするため、クイック設定（Quick Settings）タイルにカテゴリ分類機能を追加。
  - 心拍数ベースセンサーが Android 16 での互換性のため `SENSOR_PERMISSION_READ_HEART_RATE` 権限を使用するように変更。
  - （ハプティクス・自動回転などの操作系項目は 2026-06-10 の初回記録で既出。上記は今回追加分）

### Android 16 — Permissions（権限）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#permissions
- **要約**:
  - デバイス移行時に連絡先を失わないための「既定の連絡先アカウント（default contacts account）」の概念を導入。
  - 連絡先アプリはクラウド同期オプションを促し、ローカルおよび SIM の連絡先をクラウドアカウントへ移すようユーザーに確認することが推奨される。

### Android 16 — Storage（ストレージ）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#storage
- **要約**:
  - Android 16 QPR2 で、メインプロファイルからプライベートスペースへ「ファイル追加（Add files）」ショートカット経由でファイルや写真を直接取り込めるようになった。
  - プライベートスペースの Downloads フォルダへの移動またはコピーが可能。

### Android 16 — Updates（アップデート）
- **URL**: https://source.android.com/docs/whatsnew/android-16-release#updates
- **要約**:
  - シームレスなアプリ更新（Seamless app updates）で、`dexopt`／`dex2oat` をインストールのより早い段階に移すことで凍結状態の継続時間を短縮。
  - アプリの利用不可時間を、従来の最大数秒から数十ミリ秒程度まで削減する。
