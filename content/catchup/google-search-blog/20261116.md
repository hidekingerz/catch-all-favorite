## 今回の注目ポイント

Search Analytics API に、これまで Search Console のパフォーマンスレポートでしか使えなかった 3 つの機能が追加された。(1) `brandedClassification` によるブランド/非ブランドクエリのグルーピング・フィルタリング、(2) `type` に `webMultimodal` を指定して Google Lens・Circle to Search（Android）・画像アップロード経由のパフォーマンスデータを取得、(3) 新しい `filterLists` フィールドによる複数国・複数デバイスの一括フィルタリング。レポート自動化や独自ツールを構築しているサイト運用者・開発者向けの更新で、EMEA・LATAM・DACH といった地域グループを 1 回のリクエストで集計でき、複雑なキーワード正規表現リストの保守が不要になる。

### New filtering and reporting capabilities in the Search Analytics API
- **URL**: https://developers.google.com/search/blog/2026/11/search-analytics-api-update?hl=ja
- **公開日**: 2026-11-16
- **要約**: Search Analytics API に、Search Console のパフォーマンスレポートが既に提供していた 3 つの機能が追加された。(1) **ブランドクエリ**: `brandedClassification` でブランド/非ブランドのパフォーマンスをグルーピング・フィルタして比較できる（対象プロパティのみ。それ以外のプロパティではレスポンスに行が返らない）。(2) **ウェブマルチモーダル**: `type` に `webMultimodal` を指定すると、Google Lens・Circle to Search（Android）・Google 検索での画像アップロード経由のパフォーマンスデータを取得できる。一括データエクスポートが有効なプロパティでは BigQuery でも利用可能。(3) **複数国・複数デバイスのフィルタリング**: 新しい `filterLists` フィールドにより、複数の国やデバイスを 1 回のリクエストでフィルタできる。これによりレポート作成を自動化でき、EMEA・LATAM・DACH などの地域グループを複雑なキーワード正規表現リストを保守せずに 1 回の呼び出しで集計できる。
