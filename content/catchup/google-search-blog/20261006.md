## 今回の注目ポイント

Search Central の YouTube チャンネルに蓄積された多数の動画を、学習の目的別に 2 つのプレイリストへ再編した「ラーニングパス」が公開された。シリーズ単位（Search for Beginners / Ask Googlebot / Search Console Training / Search Off the Record など）では体系的に学びにくいという課題に応えるもので、(1) 初心者向けの「Search fundamentals for beginners」、(2) 開発者・技術 SEO 担当者向けの「Technical SEO fundamentals」の 2 本を提供する。これから SEO を学ぶ人も、大規模サイトの技術的な運用を担う人も、順を追って知識を積み上げられる。

## 記事一覧

### New learning paths: curated YouTube playlists for Search fundamentals and Technical SEO
- **URL**: https://developers.google.com/search/blog/2026/10/seo-learning-paths?hl=ja
- **公開日**: 2026-10-06
- **要約**: Search Central YouTube チャンネルの既存動画を目的別にまとめた 2 つのラーニングパス（プレイリスト）を公開した。従来のシリーズ構成は深掘りや episodic な更新には向くが、ゼロから順を追って学ぶには分かりにくいという声に応えたもの。(1) **Search fundamentals for beginners**（[プレイリスト](https://www.youtube.com/playlist?list=PLbrFcZbKqjoI)）: サイト所有者・マーケター・コンテンツ制作者・SEO 初心者向け。Google のクロール／インデックス／配信の仕組み、検索結果での最適化、Google Search Console と Google トレンドによる計測を扱う。トピックは「検索の仕組み（クロール・インデックス・配信の入門と検索結果の構造）」「Search Console 入門（セットアップ理解・パフォーマンスレポート分析・Search Console Insights）」「市場とコンテンツのインサイト（SEO 向けの Google トレンド活用・トレンドトピックの発見）」。(2) **Technical SEO fundamentals**（[プレイリスト](https://www.youtube.com/playlist?list=PLeMjPeaUGn9U)）: 開発者・技術 SEO 専門家向け。高レベルの基礎は省き、サイトのヘルス・クロールバジェット最適化・レンダリング・大規模デバッグに焦点。トピックは「クロールディレクティブとアーキテクチャ（robots.txt・クロール統計レポート・クロールバジェット管理の深掘り）」「大規模なインデックス登録とデバッグ（インデックス問題のトラブルシュート・URL 検査ツールの活用・重複コンテンツ管理）」「配信・レンダリング・API（ブラウザによる HTML 解析の理解・ページ重量・Search Console の一括データエクスポートと API によるワークフロー自動化）」。両プレイリストは Search Central チャンネルの[プレイリスト一覧](https://www.youtube.com/@GoogleSearchCentral/playlists)で公開中。投稿者は Daniel Waisberg（Search advocate）。
