## 今回の注目ポイント

前回収録（v2.1.311 / 2026-10-26）以降の新着は **v2.1.312**（2026-10-27）の1バージョン。目立つのは安全性寄りの修正で、**巨大な CLAUDE.md / ルールファイル / @-include ファイルを先頭だけ見て上書きしてしまう問題を修正**し、Write ツールが全体の読み込みまたはインプレース編集を促すようになった。また **Bash の `cd` でリポジトリの深い階層に移動するとディレクトリ単位・`paths:` 指定のスキルが見つからなくなる問題**を修正。挙動変更として、Bedrock/Vertex/Foundry/Mantle で未知のモデル名（カスタムデプロイ名や推論プロファイル ARN）に短いシステムプロンプトを使うようになり（`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` で従来通り）、フック実行数の上限（セッションあたり同時24・タイムアウト超過は12まで）が導入された。クラウドセッション・VS Code・Claude Tag（Slack）・Code Review にも多数の修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.312

### v2.1.312（2026-10-27）

**新機能・改善**
- Claude apps ゲートウェイに `oidc.user_id_claim` を追加。`sub` 以外の id_token クレーム（例: Microsoft Entra ID の `oid`）でユーザーを識別できる
- クリックで送信: フルスクリーンで、キューに入れたメッセージ下の「to send now」ヒントをクリックすると即座に送信される（キーと同じ動作）
- プロンプトの effort インジケーターを改善。タスク途中の変更は「次のメッセージまで待つ場合がある」と表示し、該当しなくなると注記が消える
- クラウドセッションの WebFetch エラーを改善。解決できないホストは「許可ネットワークドメイン外の可能性」と説明し、許可すべきホスト名を示す

**重要な修正（安全性・挙動）**
- サブディレクトリの非常に大きな CLAUDE.md・ルールファイル・@-include ファイルを、先頭だけ見て上書きしてしまう問題を修正。Write が全体の読み込みかインプレース編集を促すようになった
- Bash で `cd` によりリポジトリの深い階層へ移動すると、ディレクトリ単位・`paths:` 指定のスキルが見つからない問題を修正
- VS Code 拡張からのサインイン後、セッション残り全体で managed settings と組織ポリシーが取得されない問題を修正
- 端末でセッションを再開した直後の最初の返信が、次回再開時に欠落することがある稀な問題を修正
- 無効な名前のコマンドが全コマンドの読み込みを止め、`claude -p` が無出力になりうる問題を修正
- 古いセッションファイルの掃除と同時実行時に Read ツールが PDF ページで「pdftoppm failed」で失敗する問題を修正
- effort レベルを新たに選んだ際、スピナー・OpenTelemetry の `effort` 値・トランスクリプトが、モデルが適用する前のレベルを表示していた問題を修正（適用中のレベルを表示するように）
- vim モードの `d`/`c`/`y` を、残り行数より大きい `gj`/`gk` カウントと組み合わせると削除/コピーしてしまう問題を修正（Vim 同様カーソル移動のみに）

**挙動変更**
- Bedrock/Vertex/Foundry/Mantle で、Claude Code が認識しないモデル名（カスタムデプロイ名・推論プロファイル ARN 等）に短いシステムプロンプトを使用（Sonnet/Haiku をフロントするものも含む）。`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` で従来のフルプロンプトを維持
- フラグ付きメッセージ後の自動モデル切り替えを、認識しないモデル名にも適用。`CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` で無効化
- 使用量上限メッセージの表記を「session limit」から「5-hour limit」に変更
- CLI から開始したクラウドセッションの名前・ブランチ名をサーバ側から取得
- プロンプト/エージェントのフックを、セッションあたり同時24（サブエージェント含む）＋イベントのタイムアウトを超えて待機したものを12までに制限。`timeout` 1秒未満は1秒として扱う
- サブエージェントの `autoCompactWindow` が `CLAUDE_CODE_AUTO_COMPACT_WINDOW` で設定したウィンドウを下げられるように（従来は無効。上げることはできない）
- OpenTelemetry の `mcp_server.name` が、公式 Anthropic マーケットプレイスのプラグインが宣言する固定 URL のリモート MCP サーバについて実名を報告（従来は `custom`）
- `claude_code.safety_event` の OpenTelemetry イベント送信を停止

**VS Code**
- 組織設定の読み込み失敗・起動時拒否でセッションが終了コードのみで終わる問題を修正。タブに理由を表示し Retry / Sign in again を提示
- 使用量上限のリセットを時刻表示（「Resets at 3:10 PM」）にし、「5-hour limit」と表記

**クラウドセッション**
- クラウドで実行する routine の作成/編集時、モデルピッカーに effort レベルを追加
- クラウド環境設定のセットアップスクリプト欄に、カラー・行番号・Copy ボタン付きの Bash エディタを追加
- リポジトリ追加ステップの表示を、生 JSON ではなく処理結果の短い表に改善
- 送信失敗後に未変更メッセージを再送すると二重実行されることがある問題を修正
- 環境作成失敗のエラーがダイアログ外のトーストにのみ出る問題を修正（ダイアログ内に表示）
- Routines ページの Edit が編集ダイアログを開かず routine ページに遷移する問題を修正

**Remote Control / Claude Tag（Slack）/ Code Review**
- Remote Control: アーカイブ解除したセッションが、コンピュータ再接続まで working 表示になる問題を修正（idle 表示に）
- Claude Tag: Slack の再試行通知に使用モデル名やレート制限到達を表示（従来は汎用 API エラー）
- Claude Tag: 旧プライベート Slack チャンネルが公開化し新 ID を得た際、チャンネルの on/off とエージェント設定がワークスペース既定に戻る問題を修正
- Claude Tag: 環境のネットワークアクセスが None のチャンネルで Claude が返信しない問題を修正
- Claude Tag: 同一チャンネルの別スレッドに回答中、ファイルを誤ったスレッドに投稿することがある問題を修正
- Code Review: GitHub の push イベント遅延時に古いコミット（または何も）をレビューする問題を修正（PR の現在のコミットをレビュー）
