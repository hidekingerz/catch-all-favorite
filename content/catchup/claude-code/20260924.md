## 今回の注目ポイント

- 新バージョン **v2.1.282**（2026-09-24）が1件リリース。大量のバグ修正が中心だが、いくつか設定・挙動の変更を含む。
- ワイド端末での表示を制御する **`maxProseWidth`** 設定が追加。プロース（本文）の幅だけを制限し、表やコードブロックは端末幅いっぱいを維持する。
- **テレメトリ設定の可視化と無効化**: プロジェクト/ローカル設定にあるテレメトリ関連変数を起動時通知・`/status`・`claude doctor` で一覧表示。さらにプロジェクト/ローカル設定の OpenTelemetry 系変数（`CLAUDE_CODE_ENABLE_TELEMETRY` / `OTEL_LOG_*` 等）は無視するよう変更。
- **auto mode のサーバーサイド分類器**: 直接 Anthropic API 接続でテレメトリがオフの場合、既定でサーバーサイド分類器を使用（`CLAUDE_CODE_AUTO_MODE_SERVER=0` でオプトアウト）。
- スキル名前空間の厳格化: `anthropic-skills` / `claude-ai` 名前空間の許可ルールや読み込み挙動が claude.ai 同期スキルのみを対象とするよう変更。
- vim モード・レンダリング・managed 設定・Cloud sessions・Claude Tag（Slack）に多数の修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.282（v2.1.281 以前は既出のため対象外）

### v2.1.282（2026-09-24）

- **バージョン**: v2.1.282（2026-09-24）
- **内容**:

**新機能・設定追加**
- `maxProseWidth` 設定を追加。ワイド端末で Claude の本文幅を制限しつつ、表やコードブロックは全幅を維持。
- 起動時通知および `/status`・`claude doctor` に、プロジェクト設定ファイル内で無視された/テレメトリを無効化したテレメトリ変数の一覧を追加。
- `allowClaudeInChromeWithManagedMcp` managed 設定を追加。排他的な `managed-mcp.json` と併存して `claude --chrome` を実行可能に（Chrome がブロックされた際のエラーがこの設定名を明示）。
- Claude apps gateway に `store.readiness_grace_seconds` を追加。DB フェイルオーバー等の短時間の Postgres 障害中も `/readyz` が ready を維持。
- フルスクリーンモードの `/feedback` 下書きリストにスクロールバーを追加（マウスオーバー時に表示）。

**主なバグ修正**
- 履歴に API が復号できない Web 検索結果（サードパーティゲートウェイ経由の応答等）を含む会話で毎リクエストが 400 エラーになる問題を修正。
- `--continue` / `--resume` の継続・再開セッションが以前のメッセージを変形して再送し、Claude の過去の推論を API が破棄しうる問題をさらに修正。
- 作業中に `/model`・`/rename`・`/artifacts` 等の即時スラッシュコマンドを使うと過去の extended thinking が破棄される問題を修正。
- 会話中に提供済みの組み込みツールを除外した `--tools` リストで再起動すると、継続・再開会話が過去の extended thinking を失う問題を修正。
- 毎ターン "Invalid `data` in `redacted_thinking` block" API エラーで失敗する問題を修正（thinking ブロックを破棄して1回リトライ）。
- 要約リクエストが拒否された際に compaction が失敗する問題を修正（フォールバックモデルでリトライ）。
- thinking オフ・effort が high 超のセッションで安全性関連のモデル切替後にターンが失敗する問題（"Effort 'xhigh' isn't available with thinking turned off"）を修正。
- Fable の使用クレジットプロンプト未応答が SDK ホストセッション（Claude Desktop 等）でモデルを切り替える問題を修正（ターンを終了、Remote Control クライアントに切替通知）。
- 他プロセスがサインイン更新中に閉じられた/killされた後、最大1分間 "another Claude Code process is refreshing it" ログインエラーでリクエストが失敗する問題を修正。
- リポジトリ symlink 経由で macOS の `/Network` 等に到達する CLAUDE.md/ルールの読み込みを修正。
- 設定ファイルでパターン途中に `:*` を含む Bash 権限ルールがスキップされる問題を修正（全ソースで有効化、起動時警告付き）。
- managed 設定の boolean ロックキー（`disableClaudeAiConnectors` / `allowManagedPermissionRulesOnly` 等）の誤入力値が無視される問題、および managed `permissions`/`autoMode`/`worktree`/`attribution` がネスト値1つの不正で全体無視される問題を修正。
- Bedrock/Vertex 等のツール入力検証エラーが不明・欠落・誤記のパラメータを1つしか示さない問題を修正（同一呼び出し内の他の不正も列挙）。
- 端末の bracketed paste モードがセッション中にリセットされた後、複数行の貼り付けが1行ずつ送信される問題を修正。
- `SessionStart` フックを持つプロジェクトで起動時にプロンプトの例文が点滅・消失する問題、フルスクリーン開始時の空白画面フラッシュ等のレンダリング修正。
- vim モード多数修正: `>>` の空行インデント、count 付き `r`、`2J`、最終行の count（`2dd`/`2>>`）、`dd`/`dj`/`dG`/行 `p`/`P` 後のカーソル位置、`.` リピート時の count 無視、履歴/キュー復元時のカーソル位置ずれ 等。
- `claude remote-control --debug` が "Unknown argument: --debug" で失敗する問題を修正。
- `/install-github-app` がキャンセル後もブランチを push・API キーシークレットを保存する問題を修正。
- プラグインアンインストールが失敗時に保存オプション/シークレットを誤削除する問題を修正。
- 大規模セッションの再開時間を改善（未 compaction のものを含む）。
- `/artifacts` の表示改善（列揃え、PgUp/PgDn・Home/End・マウスホイール・クリック対応）。
- `claude-api` スキルの更新（拒否課金ドキュメントへのリンク、Managed Agents リソースを `ant apply` でバージョン管理する推奨）。

**挙動変更（要注意）**
- auto mode を、直接 Anthropic API 接続かつテレメトリオフの場合に既定でサーバーサイド分類器を使用（`CLAUDE_CODE_AUTO_MODE_SERVER=0` でオプトアウト）。
- managed 設定/`--settings` で `allowUnsandboxedCommands: false`、または managed `allowManagedDomainsOnly: true` の場合、`sandbox.excludedCommands` のプロジェクト/ローカル設定エントリを無視。
- プロジェクト/ローカル設定で、export 有効化・エンドポイント設定・コンテンツキャプチャを行う OpenTelemetry 変数（`CLAUDE_CODE_ENABLE_TELEMETRY` / `OTEL_LOG_*` 等）を無視。
- Windows/WSL の managed 設定で、admin ポリシー（HKLM / `managed-settings.json`）が存在するが不正・読取不能な場合、ユーザー書込可の HKCU・WSL `/etc/claude-code` を適用しない。
- `Skill(anthropic-skills:*)` / `Skill(claude-ai:*)` 許可ルールを claude.ai 同期スキルのみに限定。`anthropic-skills`/`claude-ai` 名前空間のスキルフォルダ・コマンド・ワークフローは読み込まなくなり、同名 MCP サーバーはスキル/プロンプトを一覧しない（ツールは動作）。
- `/effort` とプロンプト入力の `ultracode` 視覚効果をプレーン化。

**VSCode**
- 長い返信のストリーム遅延を修正（返信全体の再パースを廃止）、dictation マイクボタンがスクロールバーを覆う問題、Remote Control セッションの Web エントリからの起動、拡張ホスト再起動後のサインイン画面ハング等を修正。

**Cloud sessions**
- Settings › Connectors › GitHub に Claude GitHub App の状態を追加。GitHub 以外の Git サーバーのリポジトリメニューに「Open repository」「Open compare page」を追加。実行中の cloud session に別 GitHub owner のリポジトリを追加可能に。半時間オフセットのタイムゾーン（インド等）での毎時ルーチン次回実行時刻のずれを修正。Routines ページとサイドバーの読み込み速度を改善。

**Claude Tag（Slack）**
- Enterprise Grid 組織全体インストールでの auto-join チャネルパターン無視、ワークスペース間共有チャネルでの無応答、リタイア済みモデルへの毎回フォールバック、テーブル入りキャプション、Agents & tools ビューのスレッド一覧、ワーカー再起動後のコスト/トークン集計過大表示等を修正。ボーダー付きカードを既定でワイド表示に、新規接続ワークスペースは現行の既定モデルに追従するよう変更。
