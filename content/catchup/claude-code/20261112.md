## 今回の注目ポイント

- **Code Mode（実験的・オプトイン）** が追加された。Claude が自分のツールを呼ぶために JavaScript を書く方式で、`https://code.claude.com/docs/en/code-mode` から有効化（または組織単位で無効化）できる。
- **プラグインのバージョン管理が強化**。`plugin.json` に `engines["claude-code"]` を書くと、対応バージョン範囲外のプラグインはインストール／更新／読み込みがされなくなり、インストール・更新時は範囲に収まる最新版が選ばれる。`claude plugin validate` に TypeScript フックモジュールの型チェックも追加（`--strict` で失敗扱い）。
- **セキュリティ・権限まわりの修正が多数**。Write/Edit が `Read` の deny ルール対象パスに書き込めてしまう問題、誤ったフォルダ基準で `rm` を判定して危険削除プロンプトを飛ばす問題、Bash の allow ルールのワイルドカード／`sudo` ラッパーすり抜け、サンドボックスが symlink 経由の書き込み権限を誤って認める問題などを修正。`--permission-mode auto` は auto が使えないとき、より緩い挙動ではなく確認を行う Manual で起動するようになった。`/security-review` は実行前に確認するようになった。
- **未知のモデル ID の既定コンテキストウィンドウを 200K → 1M に変更**（`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で 200K 維持）。他ベンダーの小さいウィンドウのモデルでは、埋まると `/clear` まで毎ターン失敗し得る点に注意。
- そのほか、`.docx` を Artifact tool のアセットアップロードに対応、各セッション間で確認なしに送れるメッセージ数を約20→100,000に変更、`subagentStatusLine` 設定の削除、プラグインの `agent` 設定の非推奨化など、サインイン／バックグラウンドセッション／Remote Control／VS Code／Claude Code on the web／Claude Tag／Code Review にわたる多数の追加・修正を含む大型リリース。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.323（v2.1.320 は欠番。v2.1.321〜322 は 2026-11-10 分で収録済み）

### v2.1.323（Code Mode・プラグイン engines・権限強化ほか大型アップデート）
- **バージョン**: v2.1.323（2026-11-12）
- **内容**:
  - **新機能（Added）**: 実験的な **Code Mode**（Claude がツール呼び出しのために JavaScript を書く。docs から有効化／組織で無効化）。`plugin.json` の `engines["claude-code"]` によるバージョン範囲ゲーティング。`claude plugin validate` へのプラグイン TypeScript フックの型チェック追加と、mod の `engine.create` が追加／保留／置換する `$` noun の検証。Claude Desktop のサードパーティプロバイダ向け `CLAUDE_CODE_AUTO_MODE_MODEL`（managed settings）。使用クレジットが無効／枯渇したときのオプションメニュー。`claude -p`／SDK セッションでフックが長引く際の30秒ごとの進捗ハートビート。**`.docx` を Artifact tool のアセットアップロードに対応**。diff パネルの `/diff to close` ヒント。`CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES`／`CLAUDE_CODE_RESUME_HINT_COMMAND` など環境変数の追加。
  - **セキュリティ・権限修正（Fixed）**: Write/Edit が `Read` deny ルール対象パスに書き込める問題。誤ったフォルダ基準で `rm` を判定し危険削除プロンプトを飛ばす問題（bypass／allow ルール下）。`Bash(ls*)` のような末尾ワイルドカードや `sudo`／`env` ラッパー経由でプロンプトを飛ばす問題、`sandbox.excludedCommands` の抜け、セッション中にサンドボックスがオフになり得る問題。`.git`／`.claude` 等の機微パスに書く Bash への「don't ask again」が次回プロンプトを止めない問題。`plansDirectory` 設定時にプロジェクト外へ plan を書く問題。
  - **主な修正（Fixed）**: `/compact` の再実行や `/context` 後に未応答メッセージを要約で消す問題。再開セッションが前の中断メッセージに次の発言を結合する問題。巨大ファイル変更後のメモリスパイク、`/proc` 特殊ファイルや named pipe での Edit/Bash のメモリ枯渇・ハング。非ストリーミング要求がストリーミングなら回復するエラー（画像・thinking ブロック・beta ヘッダ拒否）で失敗する問題。サインイン／バックグラウンドセッションのアカウント取り違え、MCP ツール呼び出しが再サインインを促さずトークンエラーで終わる問題など、認証・プロファイル周りを広範に修正。WebFetch が空のテーブルセルを落として列がずれる問題、Remote Control のネットワーク切替後の切断表示なども修正。
  - **変更（Changed）**: **未知モデル ID の既定コンテキストを 200K→1M**（`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で従来維持）。`--permission-mode auto` が auto 不可時に Manual 起動。`/security-review` を実行前に確認。各マシン上のセッション間で確認なしに送れるメッセージ数を約20→100,000に。`git worktree add/move/remove` や未起動ワークツリーでのコミットをサンドボックスで読み取り専用失敗に。mod が Claude Code 自身の確認文言を書き換えられない／言い換えられない制限。組織設定・ポリシー要求が `ALL_PROXY` のみのプロキシを使わない変更。MCP v1 クライアント削除（`MCP_SDK_GENERATION=v1` は互換モードで v2 を実行）。
  - **削除・非推奨（Removed / Deprecated）**: `subagentStatusLine` 設定を削除（サブエージェント行は常に既定表示）。プラグインの `agent` 設定を非推奨化（起動時・`claude plugin list`・`validate` で警告）。
  - **クライアント別**: `[VSCode]` 未信頼フォルダでの初回セッション前の trust プロンプト追加、実行中 Bash/PowerShell のライブ出力をチャットに表示、CRLF ファイルの複数行編集で diff タブが開かない問題の修正など。`[Claude Code on the web]` セルフホスト／クラウドセッションの接続・再接続表示、巨大な GitHub Actions ログのダウンロード切れ、リポジトリピッカーの SSO 非表示時の案内などを改善。`[Claude Tag]` Compliance API（Enterprise ベータ）対応、管理設定の各種修正。`[Code Review]` 管理設定にリポジトリ別レビューコストの CSV ダウンロードを追加。
  - このリリースは200項目近くに及ぶ大型アップデート。全項目は changelog（GitHub Releases）を参照。
