## 今回の注目ポイント

- **サンドボックス化した Bash が既定で通常の権限フローを通るようになった。** これまでプロンプトなしで走っていたサンドボックス内コマンドが、既定では確認を求めるように変更。従来どおり無確認で走らせたい場合は `sandbox.autoAllowBashIfSandboxed: true` を設定する（管理設定でサンドボックスを有効化している場合は、最上位の管理ソースにこの設定を置く）。権限・サンドボックス・プラグイン周りの引き締めが非常に多いリリース。
- **読み取り専用 git コマンドの権限が厳格化。** プロジェクト外や未信頼のリポジトリでは読み取り専用 git も確認を求めるようになり、無確認で走らせるには `additionalDirectories` 設定ではなく `--add-dir` で明示する必要がある。
- **定期タスク／`/loop` が、`allowed-tools` やフックを宣言するスキルの実行前に確認するようになった。** 無人実行するには `permissions.allow` に `Skill(name)` を追加する。スラッシュコマンドの `allowed-tools` 付与が、そのターン中／後に起こされたバックグラウンドエージェントに及んでいた問題も修正。
- **zstd 圧縮レスポンスのデコード処理のセキュリティ問題を修正。** そのほか権限ルール（相対パスの deny/ask ルール、`cd` 後の挙動、大文字小文字差、特定の複合 Bash コマンド、allow ルールが別プログラムを走らせ得る問題）を広範に修正。
- **サインイン／認証・MCP・Code Mode の修正が多数。** バックグラウンドセッションが別サインインへ移る問題の追加修正、Bedrock でのトークンカウント送信、`claude auth status` 等のロック残留、MCP タスクの待機表示・再接続、Code Mode が `EnterWorktree` のワークツリーを無視する問題などを修正。VS Code に API キーを作らない Console サインインを追加。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.325（v2.1.324 はフィードに不在＝欠番。v2.1.323 以前は収録済み）

### v2.1.325（サンドボックス／権限の既定変更・セキュリティ・認証/MCP/Code Mode 修正ほか大型アップデート）
- **バージョン**: v2.1.325（2026-11-13）
- **内容**: このリリースは Added/Fixed/Changed の見出しを持たない一続きのリストで約80項目に及ぶ。主なものを機能カテゴリ別に整理する（全項目は changelog / GitHub Releases を参照）。

  - **セキュリティ**:
    - zstd 圧縮レスポンスのデコード方法のセキュリティ問題を修正。
    - サンドボックスがネイティブアップデータのダウンロードフォルダへ書き込めてしまう場合、ワークツリーの設定／フック、リンクされたワークツリーの共有 git フォルダを十分保護できない場合を修正。
    - アカウントのメール確認を強化（コマンドが走らせるスクリプト・ファイル書き込み・Web フェッチ・MCP 呼び出しの中でも、自分のメールをクライアント識別子として拒否）。
    - Claude Code 自身が使うために起動するプログラム（ネットワークブリッジ等）や ripgrep・ローカル git・サンドボックスランタイムのヘルパから、サインイントークン・API キー・mTLS クライアント鍵のパスフレーズを環境から外して実行するよう変更。

  - **サンドボックス・権限（挙動変更。影響大）**:
    - **サンドボックス化した Bash を既定で通常の権限フローに**。無確認継続は `sandbox.autoAllowBashIfSandboxed: true`。管理設定でサンドボックス有効化時も同様に最上位管理ソースへ設定。
    - **読み取り専用 git コマンド**を、プロジェクト外／未信頼リポジトリでは確認するよう変更。無確認実行は `--add-dir` で名指しする（`additionalDirectories` 設定では不可）。
    - **定期タスク・`/loop`** が `allowed-tools`／フックを宣言するスキルの実行前に確認。無人実行は `permissions.allow` に `Skill(name)` を追加。
    - Desktop/IDE/SDK ホストの「Always allow」は、ルール保存で再度そのコマンドを許可できる場合のみ提示（ルールに頼っていた定期タスクはユーザの応答を待てるように）。
    - 追加ディレクトリ内の `.claude` 設定・スキル・エージェント・コマンド・フックへのサンドボックス書き込みを、起動フォルダと同様に拒否。
    - 相対 deny/ask ルール（例 `Read(./.env)`）が `cd` 後にプロジェクトを覆わなくなる問題、`mcp__plugin_*_` で始まるルールが大文字小文字差でサーバ／ツールを取りこぼす問題、再起動後に届いた承認へ deny ルールが適用されない問題、一部 Bash コマンドに deny/ask が適用されない問題、確認なしで走れる複合コマンド、allow ルールが名指しと別プログラムを走らせ得る問題などを修正。
    - サブエージェントのプラン承認後にセッションが前の権限モードへ戻る問題、サブエージェントのプラン承認後に権限モードが戻る問題も修正。

  - **プラグイン・マーケットプレース**:
    - プラグイン MCP バンドル（`.mcpb`/`.dxt`）を `.mcpb-cache` ではなくプラグインディレクトリ配下へ展開（読み取り専用プラグインフォルダでも読み込めるように）。
    - 管理設定が宣言・有効化し `prependPlugins`/`appendPlugins` に列挙したリモートマーケットプレースのプラグインを組織のものとして扱う（`pluginDigests` は非推奨・無視）。
    - プラグインフォルダ内の危険なパス／リンクを読み込みスキップし `claude plugin validate` が報告。マーケットプレース追加の確認・推奨プロンプト・インストール警告に「プラグインは計算機上でコードを実行し、ファイルとシェルにアクセスし得る」と明記。
    - ネストしたスキル読み込みの変更（`--plugin-dir` プラグインの `.claude/skills` は上位から起動したセッションでは読み込まない）。マーケットプレース `ref` がブランチ/タグ上の任意コミットの完全 ID を受け付ける（旧版クライアントはクローン不可）。

  - **認証・サインイン・バックグラウンド**:
    - バックグラウンドセッションが起動シェルの API キー／トークンを使い（課金し）てしまう問題、バックグラウンドで別サインインへ移る複数ケースの拒否、移行拒否後に 2回目の Enter で作業が止まる問題を修正。
    - Bedrock でのトークンカウントが `allowedProviders` 非許可時にも会話を送る問題、AWS `credential_process`／Google Cloud 既定資格情報が `HOME` 未設定で失敗する問題、`claude auth status` 等がロックを残し次セッションが約1分ハングする問題を修正。
    - `/login` の Console アカウントサインインで Esc 時に既存ログインを置換する問題、サインイン失敗/キャンセル時に成功ページが出る問題、`/fast`・`/model` がサーバ未確認で組織制限を表示する問題を修正。`/login` が privacy 設定変更の許可を求めるよう変更。

  - **MCP**:
    - MCP サーバが一時的な更新拒否後に「要認証」のままになり `mcp_tool` フックがスキップされる問題、ヘッドレスでの elicitation 取り消し、SDK ホストからの呼び出しが再接続後に「Not connected」を返す問題を修正。
    - バックグラウンド MCP タスクが待機になった際にフッタ表示・`/tasks` から質問再表示、Esc は「後で回答」（サーバへ送信せず `/tasks` に残す）に変更。Claude にタスクがユーザ回答待ちであることを伝え `/tasks` へ誘導。
    - Desktop/SDK がフォルダ自身の MCP サーバ（`.mcp.json`・local）を誤って列挙/非接続にする問題、プラグイン再読み込みで削除後も `/mcp` に残る問題を修正。

  - **Code Mode**:
    - Code Mode スクリプトが `EnterWorktree` で入ったワークツリーを無視する・`~` パスをプロジェクトへ書く・サインイン切れ後も `/mcp` が接続中表示のままになる問題を修正。
    - 権限ダイアログ／プラン承認で Yes と共に打った語が Claude に届かない問題、Code Mode スクリプト中に終了したセッションを再開すると Claude が勝手に作業を始める問題（次のプロンプトを待つよう）を修正。

  - **コンテキスト・セッション・コンパクト**:
    - 多数のサードパーティゲートウェイや Foundry で毎ターン context length エラーになりコンパクトしない問題、クリーン終了しなかった後の再開で直近ターンが欠落する問題を修正。
    - `CLAUDE_CODE_MAX_CONTEXT_TOKENS` が `claude-` で始まる未知モデル ID のコンテキストウィンドウも設定するよう変更。出力トークン上限で打ち切られたサブエージェントは末尾だけでなく全回答を簡潔に再要求。

  - **その他（UI・CLI・テレメトリ）**:
    - 出力トークン上限・`/stats` の Active days が1日多い問題・`/insights` の誤レポート/未エスケープ・`/voice` の表示・`claude purge`/`claude plugin eval`/`claude -p` の各種問題を修正。
    - OpenTelemetry の `user_prompt` イベント（ツール実行中送信で `delivery.mode: "mid_turn"`、キュー結合時の欠落、画像時の欠落）を修正。
    - `claude remote-control` が自己終了時に status 4、登録不可時に 69 を返すよう改善（単一セッションは 0）。dataviz スキルの part-to-whole 助言を改善。
    - ポリシーがリクエストをブロックした際に「`/rewind` で変更、または `/clear`」の継続方法を表示。Jupyter ノートブック読み書き後にセルの再実行ヒントを表示。

  - **クライアント別**:
    - `[VSCode]`: ターミナルと同じプロンプト候補（Tab で採用、`promptSuggestionEnabled: false` で無効）を追加。API キーを作らない Console サインインを追加。SSH/WSL/コンテナ窓で MCP サインインのリダイレクト URL 貼り付け欄を追加。モデルピッカーのチェック残留、`maxEffortLevel`/組織上限を超える effort 提示、`allowedProviders` 非許可のサインイン提示、MCP ツール権限プロンプトの理由非表示などを修正。
    - `[Claude Code on the web]`: ツール検索経由で読み込む MCP ツール説明の上限を 4,096 → 16,384 文字に（他セッションと同じに）。
    - `[Claude Tag]`: サインイン切れ時に Slack 貼り付けのアーティファクトリンクにカードが出ない問題を修正（プレーンカードを表示）。
