## 今回の注目ポイント

前回（2026-09-18 収録、v2.1.277 まで）以降、changelog に **v2.1.278**（2026-09-19 更新）が 1 バージョン追加された。今回の目玉は **auto モードの分類器（classifier）の課金・実行場所の変更**。Claude API / Enterprise ユーザー、および Bedrock・Vertex・Foundry・各種ゲートウェイ利用時に、auto モードが既定でサーバーサイドの分類器を使うようになり、分類器オーバーヘッド分の課金が発生しなくなった。さらに `/status` に「Auto mode server」行が追加され、現在のセッションの auto モード分類器がサーバー側で動いているかを確認できる。

---

## 新機能・変更（changelog）

> 対象バージョン: v2.1.278

### v2.1.278（2026-09-19）
- **バージョン**: v2.1.278（2026-09-19）
- **内容**:
  - **auto モードの分類器をサーバーサイド既定に変更**。Claude API・Enterprise ユーザー、および Bedrock・Vertex・Foundry・ゲートウェイ利用時に、既定でサーバーサイドの分類器を使うようになり、分類器のオーバーヘッド分は課金されなくなった。Bedrock・Vertex・Foundry・ゲートウェイでは `CLAUDE_CODE_AUTO_MODE_SERVER=0` でオプトアウト可能。課金対象のフォールバックが発生した場合は警告が出る。詳細は docs（`https://code.claude.com/docs/en/auto-mode-classifier-billing`）を参照。
  - **`/status` に「Auto mode server」行を追加**。現在のセッションの auto モード分類器がサーバー側で実行されているかを表示する。

---

## 使い方メモ（任意）

- **auto モード利用者**: v2.1.278 以降、対応環境では分類器がサーバー側で動き、その分の課金がなくなる。挙動を従来どおり（クライアント側）に戻したい場合は、Bedrock・Vertex・Foundry・ゲートウェイ環境で `CLAUDE_CODE_AUTO_MODE_SERVER=0` を設定する。
- **確認方法**: `/status` の「Auto mode server」行で、このセッションの分類器がサーバー側で走っているかどうかを確認できる。課金対象のフォールバックが起きると警告が表示されるため、コストを気にする場合はこの警告を確認するとよい。
