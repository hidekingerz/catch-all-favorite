## 今回の注目ポイント

v2.1.308 / v2.1.309（いずれも 2026-10-22。前回収録は v2.1.307 / 2026-10-21）を収録。v2.1.308 はリリースノート上「バグ修正・信頼性改善」のみ。v2.1.309 は**サンドボックス/権限まわりのセキュリティ修正を多数含む大型リリース**で、`--mcp-config` で渡した MCP 設定ファイルがサンドボックス化 Bash や自動承認編集から書き換えられる問題、シンボリックリンク経由での `denyWrite`/プロファイル書き込み保護のすり抜け、Bash 権限チェックの複数の抜け（`cd` を前置/ラップした git コマンド、リダイレクト先パスなど）を修正。挙動変更として **`claude ultrareview` がワークスペースの信頼（workspace trust）を要求**するようになり、ターミナルでは確認プロンプト、スクリプトでは `--trust-workspace` か `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1` が必要。GitHub 連携では、PR/issue/コメント内のロール名やプレースホルダを誤ってメンション化して無関係なユーザーに通知していた問題を修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.308 〜 v2.1.309

### v2.1.308（2026-10-22）
- **バージョン**: v2.1.308（2026-10-22）
- **内容**: リリースノートは「Bug fixes and reliability improvements」の1点のみ。個別の修正項目の記載なし。

### セキュリティ / サンドボックス / 権限（v2.1.309）
- **バージョン**: v2.1.309（2026-10-22）
- **内容**:
  - `--mcp-config` で渡した MCP 設定ファイルが、サンドボックス化コマンドや自動承認された編集で書き換えられる問題を修正。
  - macOS のサンドボックスで、シンボリックリンク経由で到達したフォルダに `denyWrite` の glob パターンが実パスへ適用されない問題を修正。プロファイルストアの書き込み保護も、設定ディレクトリにシンボリックリンク経由で到達した場合に効かない問題を修正。
  - macOS/Linux のサンドボックス化 Bash が、各コマンド実行前にシェルの起動ファイルをサンドボックス外で実行していた問題を修正。
  - Bash 権限チェックの抜けを複数修正: リダイレクトのオープンに失敗しうるコマンドで設定された変数を信頼してしまう／`cd` をラップ・前置した複合コマンドで git を実行する際にプロンプトが出ない／`Edit(path)` の deny ルールがサブシェルを含む一部コマンドの当該パスへの Bash リダイレクトをブロックしない、など。
  - ワークツリー分離セッションで、ロケール接頭辞付きコマンドや zsh の一部算術コマンドなど、分離ガードが拒否すべきものを受け入れていた問題を修正。
  - 無効化した MCP サーバが、print / SDK セッションで後続の権限プロンプトにより再接続される問題を修正。
  - **挙動変更**: `claude ultrareview` がワークスペースの信頼を要求（ターミナルでは確認、スクリプトは `--trust-workspace`〔値を取らず、PR番号やベースブランチはその前に置く〕か `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1`）。
  - **挙動変更**: Desktop/VS Code の bypass permissions モードで危険な `rm`/`rmdir` を即時 deny（書き換えヒント付き）にし、無人セッションを止めない。`sed -i` は編集プレビューではなく通常の Bash プロンプトで記述どおり実行（`/rewind` の復元対象外に）。
  - **挙動変更**: ワークツリーの作成/再利用時に git がオンデマンドでオブジェクトを取得しないように（partial clone では事前取得）。

### GitHub / コードレビュー（v2.1.309）
- **バージョン**: v2.1.309（2026-10-22）
- **内容**:
  - PR・issue・コメント内でロール名やプレースホルダをメンションとして書き、無関係な GitHub ユーザーに通知してしまう問題を修正。
  - [Code Review] 作成に失敗したレビューが PR にチェックを残さない問題、`@claude review stop` 後も実行待ちの push がレビューを開始してしまう問題を修正。

### エディタ / セッション / その他（v2.1.309）
- **バージョン**: v2.1.309（2026-10-22）
- **内容**:
  - 巨大なネスト `CLAUDE.md` 読み込み後に繰り返しコンパクトされる問題を修正（サイズ超過のネスト `CLAUDE.md` は冒頭のみ読み込み）。
  - mod の `turn.step` フックがモデルをエイリアス（例 `haiku`）で指定すると毎回モデルエラーになる問題を修正（エイリアスがモデルに解決）。
  - claude.ai から同期したプラグイン/スキルがディスク読み取りエラー後にセッション途中で削除される問題を修正。
  - 一部の通常ページ（特定の minified スクリプトを含む等）で artifact の公開・更新が拒否される問題、ターン内でのコンパクト後に artifact 更新で毎回権限を求める問題を修正。
  - 同梱 dataviz スキルがテストのコントラスト指標として **APCA** を受け入れるよう更新（AA 準拠が必要な箇所は WCAG 2 比率を維持）。palette validator に `apca(text, background)` を追加。
  - Amazon Bedrock で `ANTHROPIC_BEDROCK_BASE_URL` を既定エンドポイントに設定時、fine-grained tool streaming が無効のままになる問題を修正。
  - Edit/Write などの速度改善、ディスクフル時のメッセージ改善、Windows での git コマンド高速化ほか多数の修正。
  - [VSCode] 空の "Untitled" セッションが溜まる問題、長いスラッシュコマンドの折りたたみ、Ctrl+J の改行挙動（keybindings で null 設定時は VS Code/OS に委譲）ほかを修正・改善。
  - [Cloud sessions] routine フォームの connector 一覧が読み込み中に「利用不可」と表示される問題、環境変数エディタがクォートを含む値を壊す問題、Changes ペインの表示改善ほか。
  - [Claude Tag] 承認済みドラフトを誤って DM に投稿する問題、停止後の承認カードの Allow/Deny が無反応になる問題ほかを修正。

## 使い方メモ

- `claude ultrareview` を CI などスクリプトから使っている場合は、workspace trust 要件に対応する必要がある。インタラクティブでない実行では `--trust-workspace`（値なしフラグ。PR番号やベースブランチはその前に置く）を付けるか、`CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1` を設定する。
