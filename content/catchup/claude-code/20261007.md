## 今回の注目ポイント

- **v2.1.290 〜 v2.1.293 の4リリースをまとめて収録**（前回収録は v2.1.289 / 2026-10-03）。v2.1.290 が大型のバグ修正リリース、v2.1.291 がその回帰修正、v2.1.292・v2.1.293 が機能追加＋多数の修正。
- **Claude Haiku 5.5（`claude-haiku-5-5`）を追加**（v2.1.293）。Anthropic API の既定 Haiku モデルに。1M コンテキスト、$0.10/$0.50 per Mtok（10万トークン超のプロンプトは $0.50/$2.50）。
- **Agent ツールに `effort` パラメータを追加**（v2.1.292）。サブエージェントを指定した effort レベルで実行できる。
- **セキュリティ修正（複数）**: PreToolUse フック承認・auto モードが **ネットワーク（UNC）パスのファイル読み取りで権限プロンプトをバイパス**する問題を修正（v2.1.292）。画像・ノートブック・PDF 読み取りで、読み取り中に差し替えられた **symlink 経由で承認範囲外のファイルを返せる**問題を修正（v2.1.290/292）。`rm -rf` が home フォルダの 8.3 短縮名など別表記で削除扱いにならない問題を修正（v2.1.292）。
- **WebFetch が 10 万文字超のページ本文を黙って捨てる問題を修正**（v2.1.290）。未読量を伝え、`offset` で続きを読めるように（本キャッチアップでも実際に機能）。
- **スケジュールタスク（`/loop` や予約タスク）の信頼性を大幅に改善**（v2.1.290/292）。compaction 後・resume 後・バックグラウンド移行後に発火しない／余計に再実行される問題などを多数修正。
- **プラグイン / Claude Mods の安定化が引き続き大量**（v2.1.290/292）。フックの `.catch` スキップ、権限フックのすり抜け、ホットリロード周りなどを修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.293 / v2.1.292 / v2.1.291 / v2.1.290

### v2.1.293（2026-10-07）

- **モデル**: Claude Haiku 5.5（`claude-haiku-5-5`）を追加。Anthropic API の既定 Haiku モデルに（1M コンテキスト、$0.10/$0.50 per Mtok、10万トークン超は $0.50/$2.50）。
- **モッド / プラグイン**:
  - `subagentStatusLine` のペイロードに `agentType` を追加（カスタムサブエージェント種別を判別可能に）。
  - `$.tool.register` に `isDeferred` を追加。`false` でツールのスキーマをツール検索の裏ではなく最初からプロンプトに載せる。
- **主な修正**:
  - context compaction の前後で、直前の自分の行動を「完了済み」と誤認して完了済み作業を取り消す／やり直す問題を修正。
  - HTTP MCP 接続が送信した全リクエストを接続終了まで保持するメモリリークを修正。
  - Claude が作業中に送ったメッセージが `←`（バックグラウンド移行）で失われる問題を修正。
  - `/model` の effort の ←/→ が最高・最低を超えて循環し、誤って Low を既定 effort に保存してしまう問題を修正。
  - `--chrome` 開始セッションで `/tui` が Chrome 接続を切る／`--no-chrome` を無視する問題を修正。
  - vim モードの各種修正、キーバインド検証（単独スペースをエラー扱いしない 等）。
- **変更**:
  - claude.ai のスキル同期を、セッション未使用時に約10分ごと→約40分ごとに変更。
  - **v2.1.281 の auto モード拒否メッセージ変更をリバート**／**v2.1.290 のクラウドセッション `/loop` wakeup 復帰修正をリバート**（コンテナ再起動後も起きないまま）。
  - artifacts: 2週間以上前の正確なバージョンにライブラリを固定。
- **[Claude Tag] / [Code Review]**: Slack 周りの修正複数、Code Review の「リポジトリ追加」ダイアログで追加失敗の理由を列挙するよう改善。

### v2.1.292（2026-10-06）

- **新機能**:
  - `claude plugin install` に `--marketplace <source>` を追加（必要ならマーケットプレイスを追加してからインストール）。
  - **Agent ツールに `effort` パラメータを追加**（サブエージェントを指定 effort で実行）。
  - `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS`（529 過負荷リトライの基準遅延）を追加。
  - モッド向けに `prompt.autocomplete` フック、`$.model.complete` のプロンプトキャッシュ（`cache: true`）、`agent.spawn` フックへのワークフローエージェント情報を追加。
- **セキュリティ / 権限**:
  - **PreToolUse フック承認・auto モードが UNC（ネットワーク）パスのファイル読み取りで権限プロンプトをバイパスする問題を修正。**
  - サンドボックスコマンドが `/ultrareview` アップロードのステージ済みコピーを読めた問題、管理サンドボックスの read-deny パスがセッション途中で現れた際に権限が残る問題を修正。
  - ノートブック / PDF 読み取りで、読み取り中に差し替えた symlink 経由で承認範囲外のファイルを返せる問題（macOS/Windows）を修正。
  - 改ざんされたオンディスク設定キャッシュが組み込みポリシープラグインを無効化できる問題、`rm -rf` の 8.3 短縮名など別表記の home/ドライブ削除が検知されない問題を修正。
- **主な修正**:
  - 128 文字超の MCP ツール名で全リクエストが失敗する問題、`NO_PROXY` が自身の API リクエストで無視される問題を修正。
  - Read の `pages` にリスト（例 "6,9,15"）を渡すとエラーなく最初の1件だけ返す問題、256KB 超の @メンションファイルが黙って除外される問題を修正。
  - 長い箇条書き返信のレンダリング速度改善、`claude -p`/SDK の起動改善（MCP の `resources/list` 応答を待たない）。
- **変更**:
  - **予約タスク・Run now の routine 実行が、承認を求めず「本人のみ閲覧可」の新規アーティファクトを公開**するように（コネクタ等を要求するものは引き続き承認が必要）。
  - ローカル(stdio) MCP 接続の既定プロトコルを 2026-07-28 に（`MCP_PROTOCOL_NEGOTIATION=legacy` でオプトアウト）。
- **[Cloud sessions] / [Remote Control] / [Claude Tag] / [Code Review]**: routine が終了後も「実行中」のまま残る問題など多数修正。

## 使い方メモ（任意）

- **Agent ツールの `effort`**: サブエージェントを呼ぶ際に effort レベルを指定できるようになった。重い調査タスクは高 effort、軽い確認は低 effort といった使い分けが可能。
- **WebSearch 予算**: 従来は 1 セッション 200 回で打ち止めだったが、v2.1.290 以降は毎時 100 回ずつ回復する方式に。長時間の調査セッションでも枯渇しにくくなった。
- **権限まわりのセキュリティ修正が重要**: UNC パス・symlink 差し替え経由での読み取り権限バイパスが修正されたため、権限ルール（Read deny・サンドボックス）に依存した運用をしている場合はアップデートが推奨される。
- **routine（クラウド定期実行）の artifact**: 予約タスク・Run now の実行が、承認なしで「本人のみ閲覧可」のアーティファクトを公開するようになった（このキャッチアップ運用のようなレポート系 routine に関係）。
