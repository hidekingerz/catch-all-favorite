## 今回の注目ポイント

- **v2.1.299・v2.1.300 の2リリースを収録**（前回収録は v2.1.296 / 2026-10-09。v2.1.297・v2.1.298 は releases.atom に公開リリースエントリが無いため対象外）。どちらも大量の修正と少量の機能追加を含む。
- **アイドルコンパクション（idle compaction）を追加**（v2.1.299）。20万トークン超の会話を約54分放置すると、1時間のプロンプトキャッシュ失効前に自動で圧縮し、次のメッセージで全体を再処理させない。`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` で閾値変更、`"idleCompaction": false` で無効化。
- **`@` ファイルメンションの扱いを切り替える `CLAUDE_CODE_DISABLE_FILE_MENTIONS` を追加**（v2.1.299）。中身を展開せず「パスだけ」を渡し、Claude 自身にファイルツールで読ませる。
- **MCP 許可ルールの厳密化（破壊的変更）**（v2.1.300）。`mcp__a` が `a__b` や `a_` といった別サーバに一致しなくなった。`__` を含むサーバは `mcp__<正規化名全体>__*` と書く必要があり、agent の `tools:` リストも同様。
- **権限フック `updatedInput` の検証強化（破壊的変更）**（v2.1.300）。PreToolUse / PermissionRequest フックが返す `updatedInput` が Claude 自身の入力と同様に検証され、未知キーは破棄、ツールが拒否する入力は呼び出しも拒否される。
- **AWS 上の Claude Platform に `/advisor` を追加**（v2.1.300）。`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` で無効化。
- **セキュリティ／サンドボックス修正が多数**。サンドボックスからの `--plugin-dir` 書き込み（サンドボックス外で実行されるコード）、macOS のシンボリックリンク経由での拒否パス読み書き、UTF-16LE BOM ファイルの文字化け・非 UTF-8 の暗黙変換（拒否化）などを修正（v2.1.299）。
- **mod（モッド）API を大きく拡充**。`virtualText`・`$.ui.view({ agentId })`・`prompt.change` フック・`$.prompt.media`・`$.session.identity()` などを追加。
- **OpenTelemetry を拡充**。`api_request` にキャッシュ書き込みを寿命別に分ける `cache_creation_5m_tokens`／`cache_creation_1h_tokens` を追加、トレーススパンに GenAI セマンティック規約の属性（`gen_ai.provider.name` 等）を追加。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.299 〜 v2.1.300

### v2.1.300（2026-10-14）

- **新機能 / 追加**:
  - AWS 上の Claude Platform に `/advisor` を追加（`/advisor`・`advisorModel`・`--advisor` で選ぶまでアドバイザは動かない。`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` で無効化）。
  - OpenTelemetry `api_request` イベントにキャッシュ書き込みを寿命別に分ける `cache_creation_5m_tokens`／`cache_creation_1h_tokens` を追加。
  - トレーススパンに OpenTelemetry GenAI セマンティック規約属性（`gen_ai.provider.name`・`gen_ai.conversation.id`・`gen_ai.tool.name`・`error.type` 等）を追加。
- **mod（モッド）**:
  - プロンプト装飾に `virtualText` を追加（プロンプト枠内に描画されるがドラフト／送信プロンプトには入らないテキスト）。
  - `$.ui.view({ agentId })` を追加（メインビューに特定エージェントのトランスクリプトを表示、`$.ui.view({})` で戻る）。
  - `Text` に右書き用の `dir` prop を追加（Windows / VSCode ターミナルで行が右詰め・右向きに）。
  - `agent.spawn` フックで workflow エージェントの `prompt`／`model` を書き換え可能に（従来は拒否のみ）。
  - プロンプト枠のテキストがタイプ以外（履歴呼び出し・クリア・undo・プラグインによる自動入力）で変化したときに発火する `prompt.change` フックを追加。
- **権限 / セキュリティ / フック**:
  - PreToolUse / PermissionRequest フックの `updatedInput` を Claude 自身の入力と同様に検証（未知キー破棄、ツールが拒否する入力は呼び出し拒否）。
  - Cowork クラウドセッションの `PermissionRequest` フックで、allow 内の `setMode` 更新を無視（残りの承認は適用）。
  - `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` セッションが settings 内の CA バンドル・ツールプロキシ・git TLS・`SSL_CERT_FILE` 等の git 設定変数を無視するよう変更（Claude Desktop 下ではプロジェクト設定のみ）。
- **主な修正（抜粋）**:
  - MCP ツールの入力スキーマを API が拒否すると会話が毎ターン 400 で失敗する問題を修正（以降そのツールをパラメータ無しで送る）。
  - 終了時、停止要求から 1.5 秒後も残るバックグラウンドコマンドを強制終了するよう変更（fullscreen で残留していた）。
  - headless / Agent SDK セッションの resume で、出力トークン上限で切れた返信後のコンパクションが保持メッセージ／要約を失う問題を複数修正。
  - エージェントフックが `model` を無視する問題を修正（`haiku` 等のエイリアス解決、未提供モデルは呼び出し元にフォールバック）。
  - reftable ref ストレージ利用リポジトリでの `--worktree` 不具合（`.invalid` ブランチ表示・再オープン失敗・cherry-pick/revert 競合の差分未検出）を複数修正。
  - Claude がセッションスクラッチパッドのファイルをフルパスでなくベース名／相対パスで示す問題を修正。
  - Cowork クラウドセッションの Write/Edit/NotebookEdit が、自分のマシン上のパスに対しファイルが届いていないのに成功と報告する問題を修正。
  - TLS 検査プロキシ（OS 証明書ストア経由でのみ信頼）下で feature flag・段階的ロールアウトが古いままになる問題を修正。
  - 大きな api.anthropic.com リクエストをテレメトリ無効時も gzip 圧縮（`CLAUDE_CODE_GZIP_REQUEST_BODIES=0` で無効化）。
  - ローカルトランスクリプトに各 API リクエストの system prompt・tools・パラメータも記録（共有時にリクエストを正確に再現可能に）。
- **削除**: `claude remote-control` の無効だった `--sandbox`／`--no-sandbox` フラグを削除（指定するとエラー終了。`sandbox.enabled` を使う）。
- **[VSCode]**: エディタ選択テキストを自動でメッセージに入れない `claudeCode.attachSelection` を追加。常時思考モデルでの Thinking トグル表示抑止、Windows の Shift+ドラッグで `/c:/…` が入る問題、WSL/SSH/Dev Container でのファイルドラッグ無反応、Ctrl+Alt+F の誤動作、チャットフォントサイズ追従などを修正。
- **[Claude Tag]**: Slack Connect チャンネル対応（Owner / Claude Tag 管理者が別組織共有チャンネルでの応答を許可、既定オフ）、コネクタ操作の承認用プライベート Allow once / Deny カード、Slack ボイスクリップのトランスクリプト読み取りを追加。
- **[Code Review]**: GitHub 組織メンバーシップが非公開の write 権限者からの `@claude review` を無視する問題を修正、「paused for this repository」コメントの案内先を修正。

### v2.1.299（2026-10-14）

- **新機能 / 追加**:

  - **アイドルコンパクションを追加**（ターミナル）。20万トークン超の会話を約54分放置すると1時間プロンプトキャッシュ失効前に圧縮。`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` で閾値変更、`"idleCompaction": false` で無効化（ともに v2.1.290 以降が必要）。

## 使い方メモ（任意）

- **アイドルコンパクション（idle compaction）**: 20万トークン超の長い会話を放置していると、1時間のプロンプトキャッシュが切れる前に自動圧縮され、再開時の全体再処理（＝高コストな再トークン化）を避けられる。長時間作業を中断しがちな運用ではデフォルト有効が有利。閾値は `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`、無効化は `"idleCompaction": false`。
- **`CLAUDE_CODE_DISABLE_FILE_MENTIONS`**: `@` メンションでファイル中身を一括展開せず、パスだけ渡して Claude に必要箇所だけ読ませる。巨大ファイルを `@` する運用のコンテキスト節約に有効。
- **MCP 許可ルールの厳密化（要注意・破壊的変更）**: `mcp__a` で複数サーバをまとめて許可していた設定は効かなくなる。`__` を含むサーバ名は `mcp__<正規化名全体>__*` と書き直す必要があり、agent の `tools:` リストも同様に見直すこと。
- **権限フック `updatedInput` の検証（破壊的変更）**: PreToolUse / PermissionRequest フックで入力を書き換える運用では、未知キーが破棄され、ツールが拒否する入力は呼び出し自体が拒否される。ガードフックで入力整形している場合は挙動確認を。
