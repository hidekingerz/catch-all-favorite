## 今回の注目ポイント

前回キャッチアップ（2026-08-12、v2.1.229 まで）以降の新着は **v2.1.231**（2026-08-13）の 1 バージョンのみ。内容はピンポイントのバグ修正が 1 件で、**MCP の OAuth サインイン修正**が中心。Slack のように事前登録済み（pre-registered）の OAuth クライアントを使う MCP サーバーで、リダイレクト URI の不一致（redirect URI mismatch）によりサインインに失敗していた問題が修正された。Slack などの MCP サーバーに OAuth で接続していて認証が通らなかった場合は、このバージョンで解消する見込み。なお、changelog のリリース番号は v2.1.229 の次が v2.1.231 で、v2.1.230 は公開リリースとして存在しない。ブログ/ニュースは今回 egress でアクセス不可のため取得なし。docs（code.claude.com）もネットワーク制限で未取得。
