## 今回の注目ポイント

- **v2.1.302 の1リリースを収録**（前回収録は v2.1.301 / 2026-10-15）。新機能は少なめで、大量の修正と挙動変更が中心。
- **クライアント側 auto モードの分類器モデルを選べる `CLAUDE_CODE_AUTO_MODE_MODEL` を追加**（サーバー側 auto モードのモデルは変えない）。`/config` に **Idle compaction（アイドル時コンパクション）** のオン/オフ行を追加。
- **fork サブエージェント（`subagent_type: "fork"`）が既定で有効に**（`claude -p`・Agent SDK・デスクトップ/VS Code。ターミナルは既に有効）。`CLAUDE_CODE_FORK_SUBAGENT=0` で無効化。
- **デスクトップ/VS Code もメイン会話のサブエージェントを常にバックグラウンド実行**に（ターミナルと同様）。サードパーティプロバイダで permission mode 未指定の `claude -p`・Agent SDK セッションは `default` モードで開始するよう変更。
- **Read ツールが画像を無制限にメモリへ読み込む問題を修正**（128MB 超の画像ソースは拒否）。
- **プラグイン多数有効時の起動を高速化**（コマンド/エージェントのファイル読み込みのファイルシステム呼び出しを大幅削減。特に Windows）。
- **[Cloud sessions] 定期ルーティンの信頼性修正が多数**。途中失敗した実行が1時間以上後に最初からやり直され同じ作業（例: 同じレポートの二重投稿）を繰り返す問題、停止時の実行が Completed/Cancelled と誤表示される問題などを修正。ルーティンのページに**未起動の理由（同時実行上限到達など）を示すバナー**を追加。
- **[Claude Tag]（Slack）で多数の修正・改善**。HEIC/SVG/TIFF/BMP 添付が Claude に届かない問題の修正、管理設定のタブ再編（Bundles / Connectors / Skills and plugins / Channels）など。
- **プロンプト候補・提案が、クレジット課金のモデルで使用量クレジットを浪費する問題を修正**（クレジット課金の応答後はスキップ）。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.302

### v2.1.302（2026-10-16）

  - クライアント側 auto モードの分類器が使うモデルを選べる `CLAUDE_CODE_AUTO_MODE_MODEL` を追加（サーバー側 auto モードのモデルは変更しない）。
  - `/config` に `Idle compaction` 行を追加（アイドル時コンパクションのオン/オフ切替）。アイドル時コンパクション後の通知に、無効化方法を表示するようにした。
  - `/design-sync`・`/design-login` に、スタンドアロンの Claude Design（claude.ai/design）が 2026-12-14 に終了する旨の通知を追加。
  - [Cloud sessions] ルーティンのページに、直近の実行が起動しなかった理由（組織の同時実行クラウドセッション上限到達など）を示すバナーを追加。

- **主な修正（抜粋）**:
  - 会話のコンパクション中にターンを止めると「Prompt is too long」エラーになる問題を修正。
  - セッション途中で Vertex / Bedrock に切り替えると「diagnostics: Extra inputs are not permitted」でリクエストが失敗する問題を修正。
  - Read ツールが任意サイズの画像（または画像名のパイプ/デバイス）を丸ごとメモリに読み込む問題を修正（128MB 超の画像ソースは拒否）。
  - ゲートウェイが Opus 4 / 4.1 を `anthropic/claude-opus-4-1` のように接頭辞付きで示すと、`/autocompact`・`/effort` が誤ったモデルに保存される問題を修正。
  - セッション途中で追加したツールが ToolSearch 経由やコンパクション後に再ロードされると、プロンプトキャッシュがミスする問題を修正。
  - `claude plugin` 等のサブコマンドが、キュー中の設定/config 書き込み完了前に終了し変更が失われる/`.tmp` ファイルが残る問題を修正。
  - git が reftable 参照フォーマット既定のとき、プラグインマーケットプレイスが更新のたびに再クローンされ、新規 git プラグインのバージョンが "unknown" になる問題を修正。
  - PowerShell ツールがプラグインの `bin/` 内コマンドを見つけられない問題、何も見つからない検索（rg/grep/findstr/git grep）を `Select-Object` 等に渡すとエラーを報告する問題を修正。
  - デスクトップアプリで、該当オプションの無い場所の MCP サーバ認可/再接続を claude.ai 設定や `/mcp` に案内する問題を修正。
  - artifact の publish が空の edits リストで失敗する問題、新しいバージョンに拒否された後の artifact 更新の再試行方法を誤る問題を修正。

  - 長いリスト内を下移動/セクション折りたたみ後に agents ビューの行が空のままになる問題を修正。
  - 未サインイン時に `claude remote-control --help` が使い方を表示せず終了する問題を修正。
  - クラウドセッションで `/design consent`・`/design revoke` が失敗時に（利用できない）`/design-login` を提案する問題を修正（claude.ai/design/settings を案内）。

## 使い方メモ（任意）

- **`CLAUDE_CODE_AUTO_MODE_MODEL`**: クライアント側 auto モードの分類器に使うモデルを指定できる。auto モード運用で分類器の挙動やコストを調整したい場合に有効（サーバー側 auto モードのモデルは変わらない点に注意）。
- **fork サブエージェントが既定有効に**: `claude -p`・Agent SDK・デスクトップ/VS Code でも `subagent_type: "fork"` が既定で使えるようになった。無効にしたい場合は `CLAUDE_CODE_FORK_SUBAGENT=0`。
- **Idle compaction の制御**: `/config` の `Idle compaction` 行でアイドル時コンパクションのオン/オフを切り替えられる。コンパクション後の通知に無効化方法が表示される。
- **定期ルーティンの二重実行対策**: 途中失敗した実行が後からやり直されて同じ作業（レポートの二重投稿など）を繰り返す問題が修正された。クラウドセッションでルーティンを運用している場合の信頼性が上がる。
- **Claude Design 終了予告**: スタンドアロンの Claude Design（claude.ai/design）は 2026-12-14 に終了予定。`/design-sync`・`/design-login` で通知される。
