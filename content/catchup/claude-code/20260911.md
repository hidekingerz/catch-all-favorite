## 今回の注目ポイント

前回（2026-09-10 収録の v2.1.268）以降の新着は **v2.1.269**（2026-09-11）の1バージョン。目玉はプラグイン品質検証の **`claude plugin eval`**（スコア付き・再現可能な結果を JSON + HTML レポートで出力）と、ヘッドライン/リモート/クラウドセッションでも使える **`/output-style [name]`** による出力スタイル切り替え。Bash ツールがファイル編集を扱った際に変更差分を結果へ表示する `bashEditDiffEnabled`、Workflow ツールの同時エージェント上限を引き上げる `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`（1〜256）なども追加された。加えてプロンプトキャッシュの無効化・再利用まわりや、権限ルール（`!` 否定の適用範囲、`Bash(tee:*)` の書き込み先チェック）に関する重要な修正が多数含まれる。VSCode 拡張ではサブエージェントを可視化する「エージェントマップ」、Hooks／権限ルールの編集ダイアログが追加された。changelog は raw.githubusercontent.com が今回のネットワークポリシーで拒否されたため、GitHub Releases（Atom フィード＋リリースページ）から取得した。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.269

### v2.1.269（2026-09-11）— 主な新機能
- **`claude plugin eval`**: プラグインの eval スイートを Claude Code に対して実行し、スコア付き・再現可能な結果（JSON + HTML レポート）を得られる（`claude plugin eval --help`）。
- **`/output-style [name]`**: 出力スタイルの一覧表示と切り替え。Remote Control 経由・クラウド・その他ヘッドラインセッションでも利用可能。
- **Bash ツールの編集差分**: Bash ツールがファイル編集を扱う際、変更したファイルの差分をツール結果に表示（設定 `bashEditDiffEnabled`）。
- **OpenTelemetry 拡張**: `OTEL_METRICS_INCLUDE_REPOSITORY` でメトリクス/イベントに `vcs.*` リポジトリ属性を付与。`OTEL_LOG_TOOL_DETAILS` でコミットイベントに `vcs.ref.head.*` が付く。
- **`CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`（1〜256）**: Workflow ツールの1実行あたり同時エージェント数上限を引き上げ、推論律速のファンアウト向け。
- **`CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS`**: LLM ゲートウェイの `/v1/models` 検出タイムアウト（既定3秒）を延長可能に。
- スピナーに `/focus`（プロンプト・1行の作業要約・応答だけの表示）を勧めるヒントを追加。

### v2.1.269（2026-09-11）— 権限・キャッシュまわりの重要修正
- 出力トークン上限で応答が途切れ自動再開した次ターンでプロンプトキャッシュが部分無効化される問題を修正。中断後のセッション再開でキャッシュ再利用が悪化する問題も修正。
- `!` で始まる deny/ask 権限ルールが、それを書いた設定ソース外にも適用されていた問題を修正（自ソース内のみに適用、単独の `!` 否定は無視）。
- `Edit()` deny ルールと書き込みパスチェックが Bash の `tee` 書き込み先に適用されない問題を修正（`Bash(tee:*)` 許可が作業ディレクトリ外を対象にしなくなった）。
- 属性表示リマインダーが CLAUDE.md/メモリの「コミット・PR への属性を付けない」ルールを上書きしていた問題を修正（マネージド設定の行は引き続き適用）。
- `--output-format stream-json` の `permission_denials` にパススコープ deny でブロックされた Read/Edit/Write が漏れていた問題を修正。

### v2.1.269（2026-09-11）— クラウド / Web・VSCode・Claude Tag
- **Claude Code on the web**: クラウドセッションでキュー済みメッセージを Claude が読む前に取り消し可能に。一度きりの予定ルーティンが二重実行される問題、サブエージェント利用のルーティン実行が早期終了扱いになり再試行スキップ/重複実行になる問題などを修正。
- **VSCode**: サブエージェントを俯瞰する「エージェントマップ」（"N agents" フッターピルから開き、停止・読み取り専用トランスクリプト）、Hooks 編集ダイアログ、権限ルール編集ダイアログを追加。Focus ビューに実行中サブエージェントのライブ進捗行を追加。
- **Claude Tag（Slack）**: GitHub インストールの Connect all / Disconnect 前に確認ダイアログを追加。予定ルーティンが新規トップレベル投稿ではなく既存スレッドに返信できるように改善。組織が未有効化のモデルへの切替を黙ってフォールバックせず拒否するよう修正。
- 端末対応の改善・修正多数（kitty プロトコル端末の F1/F2/F4、WezTerm の Shift+記号、起動時の制御コード混入など）。日本語・中国語・タイ語など単語区切りのない言語でプロンプト候補が落ちる問題も修正。
