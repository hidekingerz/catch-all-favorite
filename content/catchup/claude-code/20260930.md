## 今回の注目ポイント

- **`--bare` フラグの挙動を刷新**。コマンドラインで指定した MCP サーバーだけを接続し、システムリマインダーを送らず、バックグラウンドタスクも起動しない。`--bare` 下ではタイムアウトしたシェルコマンドはバックグラウンドに移らず停止する。
- **`verify` スキルによるコミット前検証**。プロジェクト／ユーザースキルに `verify` という名前のスキルがある場合、Claude はコミット直前（docs のみ・テストのみのコミットを除く）にそれを実行するよう案内されるようになった。
- **API リトライの見直し**。1つのモデル呼び出し全体を1つのリトライ上限でカバーするよう変更。デフォルト設定では失敗する呼び出しで最大14リクエストまで。
- **モデルフォールバックの改善**。既定モデルやエイリアスが解決するモデルを API が拒否した場合、同ティアの前世代モデルで1回リトライするように。
- **権限プロンプトの UI 刷新**。複数の権限要求が重なった際に「2 of 5」のような件数表示を追加。fetch / skill / file read / sandbox network / Claude in Chrome / workflow / notebook edit などのプロンプトを file edit プロンプトの見た目に統一。
- **VSCode 拡張にブックマーク機能**を追加。Claude の回答を保存して専用サイドパネルに常時表示できる。質問カードへの回答履歴や選択肢プレビューも追加。
- **多数のシークレット漏えい対策**。リダクト済みログ／トランスクリプトで URL パスワードの記号（`)`・引用符・`]`・`&`・2つ目の `@`）や、キー名にゼロ幅スペースを含むシークレットが漏れる問題を修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.286

### v2.1.286（2026-09-30）

- **CLI / コマンド**:
  - 権限プロンプトに「2 of 5」のような件数表示を追加（複数の権限要求が重なった場合）。
  - `--bare` を、コマンドラインで指定した MCP サーバーだけ接続・システムリマインダー無送信・バックグラウンドタスク無起動に変更。`--bare` 下ではタイムアウトしたシェルコマンドが停止する（バックグラウンド移行しない）。
  - フルスクリーンモードの「N more」行にマウス対応を追加（クリックでリスト端へジャンプ、ホバー／押下状態あり）。
  - リスト画面（`/artifacts`・`/mcp`・`/skills`・`/hooks` ほか）で各行の詳細を名前の後ろに一列に揃えるよう変更。オーバーフロー行を「↑ N more」「↓ N more」表記に変更。
  - `/hooks` をイベント別にグループ化した設定済みフック一覧で開くよう変更（フック閲覧が Enter 1回に）。
  - テーマピッカー・出力スタイルピッカーをスクロールリストに変更（数字キーでの選択を廃止）。
- **コミット / 検証**:
  - プロジェクト／ユーザースキルに `verify` という名前のスキルがある場合、コミット直前（docs のみ・テストのみを除く）に実行するよう Claude へ案内。
  - モデルフォールバックが1ターンだけ続いた際にコミット帰属リマインダーがツール出力内で再送される問題を修正。
- **API / モデル / リトライ**:
  - 失敗した API リクエストのリトライを見直し、1つのモデル呼び出し全体を1つの上限でカバーするよう変更（デフォルト設定で最大14リクエスト）。
  - 既定／エイリアスが解決するモデルを API が拒否した場合、同ティアの前世代モデルで1回リトライするよう修正。
  - `--fallback-model` のリトライがフォールバックモデルを高速実行できず失敗する問題を修正（標準速度で実行、対話セッションでは1度だけ通知）。
  - フォールバックで 1M → 200K にコンテキストが縮小した場合、フォールバック通知と autocompact スラッシングエラーにその旨を表示。
- **サブエージェント / タスク**:
  - フォアグラウンドのサブエージェントがタスク管理ツール（TaskCreate/Get/Update/List・TodoWrite）を取りこぼす問題を修正。
  - worktree 分離で起動したサブエージェントが初回ファイル読み取り時にプロジェクト CLAUDE.md を worktree コピーから二重ロードする問題を修正。
  - サブエージェント実行中に入力したメッセージがトランスクリプトに二重表示される問題、hand-back メッセージがエージェント名でなく生のタスク ID を表示する問題を修正。
  - send now（ctrl+enter）でサブエージェントの実行中コマンドをバックグラウンドに移し、メッセージを即座に読むよう改善。
- **セキュリティ（シークレット / 認証情報のリダクト）**:
  - URL パスワードに `)`・引用符・`]`・`&`・2つ目の `@` などの記号を含む場合や、ssh URL で `/` を超えて `[::1]` のようなブラケットホストに達する場合に一部が漏れる問題を修正。
  - キー名に不可視文字（ゼロ幅スペース等）を含むシークレット、`Bearer`／`Basic` が鍵名の前にある場合の資格情報値、パーセントエンコードされた Bearer トークンがログ／エラーに漏れる問題を修正。
  - `/feedback` の zip に含まれるトランスクリプトがリダクト後に不正な JSON 行を含む問題を修正。
- **Remote Control**:
  - 組織ポリシーで Remote Control が無効化されても接続が残る問題を修正（通知とともに切断）。
  - 終了処理中に届いたメッセージが配信済み扱いされ返信されない問題を修正（次回実行までキューに保持）。
  - 添付ファイルが届かなかった際に Claude へ通知されない問題、最後のダウンロード試行が10秒しかもらえない問題を修正。
- **権限プロンプト UI**:
  - fetch / skill / file read / sandbox network / Claude in Chrome / workflow / notebook edit の各プロンプトを file edit プロンプトの見た目に統一。
  - Bash / PowerShell / Monitor のプロンプトでコマンドを破線で囲んで表示。
- **その他の主な修正**:
  - `claude --resume` / `--continue` が、以前のセッションがクラッシュ／強制終了していた場合に並列ツール呼び出しのバッチ後の全ターンを失う問題を修正。
  - ツールやフックがテキストでなくオブジェクト／数値／真偽値を返した後の API 400 エラーを修正。
  - 履歴が非常に大きいクラウドセッションが起動しない問題、macOS セッションが `/login` 成功後も「Not logged in」を表示する問題を修正。
  - スラッシュコマンド候補の応答性改善（単語プレフィックス一致）、外部エディタ（Ctrl+G）がカーソル行で開くよう改善。
- **`--bare` / システム**:
  - `/compact`・`/clear`・`/rewind` をバックグラウンドエージェント／チームメイトのトランスクリプト表示中に入力すると、対象を確認するダイアログを出すよう修正。
  - バックグラウンドジョブが承認待ち中に「完了」と表示される問題を修正。
- **VSCode 拡張**:
  - ブックマーク機能を追加（Claude の回答を保存し Bookmarks サイドパネルに常時表示）。
  - Claude の質問と回答を会話に残す Questions 行、質問カードの選択肢プレビュー、送信されたターミナル出力／ブラウザタブ／選択コードを開く行を追加。
  - サイドバーで既に開いている会話が別タブに二重で開く問題、1MB超出力時に保存失敗を誤報告する問題、「Teleporting session…」の無限スピナーを修正。
  - Stop / Escape を現在のターンのみ停止に変更（バックグラウンドエージェントは継続、エージェントマップから個別停止）。
- **クラウドセッション / ルーティン**:
  - アイドル後の質問カード回答・ツール承認に返信が来ない問題、環境のセットアップスクリプトをクリアしても新セッションが旧スクリプトを実行する問題を修正。
  - クラウドセッションが起動しなかったルーティン実行が「成功」と表示される問題を修正（「失敗」表示に）。
  - 遅延したスケジュール実行を「Due」と予定時刻で表示するよう変更。
- **Claude Tag（Slack）/ Code Review**:
  - スペンドリミットページに任意チャンネル（非公開含む）を追加する Add channel ボタンを追加。
  - デフォルト Sonnet を使えない組織でメモリ想起が何も見つけない問題、Slack スレッドでの作業やり直し（未 push 分の消失）などを修正。
- **プラットフォーム固有**:
  - Windows: `claude --bg` とエージェントビューが、大文字小文字違いで信頼記録が保存されたフォルダを拒否する問題を修正。

## 使い方メモ（任意）

- **`verify` スキル**を用意しておくと、コミット直前（docs のみ・テストのみのコミットを除く）に自動で検証実行を促されるようになる。テスト／リンタを回してからコミットしたいプロジェクトで活用できる。
- **`--bare`** は、最小構成（指定 MCP のみ・リマインダー無し・バックグラウンドタスク無し）で Claude Code を起動したい場合に使う。タイムアウトしたシェルコマンドはバックグラウンド移行せず停止する点に注意。
- API リトライは1モデル呼び出しあたり合算上限（デフォルト最大14リクエスト）に変わったため、以前のリクエスト単位での挙動を前提にした設定は見直すとよい。
