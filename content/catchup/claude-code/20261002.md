## 今回の注目ポイント

- **Claude Mods 登場**。プラグインがより深い挙動を変更できる仕組み。第一弾の組み込みモッド **「You should know」**（サイドエージェントが見落としを警告）も追加された。有効化は `/plugin enable cc-plugin-you-should-know@builtin`（テレメトリ有効の first-party セッション向け）。
- **1M コンテキストがデフォルトに**。Opus 4.7 以降と Fable で、Bedrock / Vertex / Foundry / Claude apps ゲートウェイでは `[1m]` サフィックスなしで 1M コンテキストが既定に。`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で 200K に戻せる。
- **mod 向け `$.ui.selection()` API** を追加。フルスクリーンモードで最後に選択したテキスト（1トランスクリプト行内なら当該行も）を取得できる。
- **MCP の URL プロンプト（2025-11-25 プロトコル）対応**。サインイン等で MCP サーバーが URL を要求できるように。更新後に接続できないサーバーには MCP 設定へ `"bareElicitationCapability": true` を追加する。
- **応答の途中タイムアウトからの継続**。非対話セッション／サブエージェントが部分応答から継続、思考のみの応答はリトライするように修正。長い会話が「Prompt is too long」で失敗せず自動コンパクトされるよう修正。
- **破壊的 `rm` のガード強化（セキュリティ）**。`bash -c`/`sh -c` スクリプト内の危険な `rm`（`/` やホームディレクトリ対象）が bypassPermissions やシェル許可ルール下で無確認実行される問題を修正（#96300）。`~` やワイルドカードへのリダイレクト併用で always-ask が外れる問題も修正。
- **`claude project purge` を `claude purge` に改名**（旧名も通知付きで動作）。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.287 〜 v2.1.288

### v2.1.288（2026-10-02）

- **Mods / UI**:
  - mod 向け `$.ui.selection()` を追加（フルスクリーンで最後に選択したテキストと、1行内選択なら当該行を返す）。
  - エージェントビューに `Ctrl+F`（名前でセッション検索）と `Alt+↑/↓`（グループ間ジャンプ）を追加。検索・リネームともに keybindings.json で再割り当て可能。`n:` フィルター（および Ctrl+F 検索）は Enter で最も名前が一致するセッションを開くよう変更。
  - mod のボタンが、再起動前に描画されたビューで押されたとき別ボタンの動作を実行する問題、`Code` 要素の diff がパースできないとプラグインのペインが空表示になる問題を修正。
- **セッション復元 / コンパクト**:
  - 応答途中の API タイムアウトでターンが失敗する問題を修正（非対話セッション／サブエージェントは部分応答から継続、思考のみ応答はリトライ）。
  - 直近返信のトークン使用量が0と報告された際に長い会話が自動コンパクトされず「Prompt is too long」で失敗する問題、`--resume` がコンパクト直後に復元したファイル等を取りこぼす問題を修正。
  - 復元が、同一セッションがロード中にファイルを書き換えた際に途中で切れたトランスクリプトを読み込む問題、2.1.286 以前で開始した会話の復元がモデルの過去の思考を落とす問題を修正。
- **auto モード / 権限**:
  - 会話が長くなりクライアント側セーフティ分類器がレビューできない場合、ツール呼び出しごとにプロンプト／失敗するのではなくコンパクトするよう改善。
  - auto モードの拒否が、ブロックされたツールが Bash でないのに Bash 権限ルールを指す問題、Bedrock/Mantle で古いモデルへのリクエスト後に残りセッションでローカル分類器に切り替わる問題を修正。
  - サンドボックス内でクォートなしデリミタの heredoc（`python3 <<EOF`）が本文が単純な場合でも毎回承認を求める問題を修正。`BASHPID` 代入が算術評価される場合に無確認許可されていた問題を修正。
- **プラグイン**:
  - プラグイン定義のエージェントを名前指定で起動した際、既定値でなく自身の prompt/tools/disallowedTools/effort で動くよう修正（エージェントチーム）。
  - LSP サーバーの `initializationOptions`/`settings` に `${user_config.*}` や `${CLAUDE_PLUGIN_ROOT}` が未置換で渡る問題、`tool.call` フックが worktree 実行サブエージェントで Bash を失敗させる問題、古い git での `git-subdir` インストール失敗、`--plugin-dir` でロードしたプラグインに「Configure options」が出ない問題を修正。
  - パススコープの `.claude/rules` とネストした CLAUDE.md が Write/Edit でのファイル作成・変更時にロードされない問題（従来は Read のみ）を修正。
- **モデル / 認証 / その他**:
  - 構造化出力を拒否するゲートウェイ（Mantle 等）でセッションタイトル・メモリ想起・プロンプトフックが失敗する問題を修正。`CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` で無効化可能に。
  - `/login` が資格情報を保存できないのに「Login successful」と表示する問題を修正（#73861）。16MB 超／パース不能な MCP 結果でツール呼び出しが二重実行される問題を修正。
  - 無人セッション（`CLAUDE_CODE_RETRY_WATCHDOG`）が長大応答ストリーム失敗後に何時間もリトライし続ける問題を修正（再ストリーム、3回タイムアウトで打ち切り）。
  - 危険な `rm`（`/` やホーム対象）が `bash -c`/`sh -c` スクリプト内で bypassPermissions やシェル許可ルール下で無確認実行される問題を修正（#96300）。
  - LSP ツール呼び出しが無限ハングする問題を修正（60秒でタイムアウト、サーバー毎 `requestTimeout`）。`idle_prompt` 通知フックがバックグラウンドエージェント実行中に発火する問題（#93672）を修正。
- **フック / OpenTelemetry**:
  - PreToolUse / PermissionRequest フックのマッチ失敗やツール入力の JSON 化失敗時にフックがスキップされる問題を修正（呼び出しをブロックするよう変更）。
  - `claude_code.tool.blocked_on_user` スパンが `-p`/SDK で source/decision を `unknown` と報告する問題、未応答の権限要求が `tool_decision` イベントを出さない問題を修正。
- **コマンド / 設定変更**:
  - `/code-review` に `--max-findings <n>|all` を追加（通常上限より多く／少なく報告、`--max-findings default` まで選択を再利用）。
  - バックグラウンドコマンドの時間制限を無人セッション（`-p`・Agent SDK・CI・cloud）のみに適用するよう変更（ターミナル・デスクトップ・VS Code は無制限）。
  - `claude project purge` を `claude purge` に改名（旧名も通知付きで動作）。`/autocompact` の自動コンパクト窓をモデル毎に保存するよう変更。
  - Ctrl+C でクリアしたプロンプトを空プロンプトで Up キー押下すると下書き（貼付テキスト・画像含む）を復元できるように。
- **VSCode / Cloud / Claude Tag**:
  - [VSCode] claude.ai コネクタが認可後も「Needs authentication」のままになる問題（MCP サーバーダイアログに Check connection 追加）、Cmd/Ctrl+N が全ビューで会話開始する問題などを修正。
  - [Cloud sessions] 管理設定の Cloud sessions スイッチが無関係なセキュリティ設定ロード中にロックされる問題を修正。
  - [Claude Tag] 自動作成されたチャンネル設定に常に失敗する「Remove this scope」が出る問題を修正。他チャンネルで読んだだけの関連 Slack スレッドも追跡するよう改善。

### v2.1.287（2026-10-01）

- **Claude Mods（新機能）**:
  - **Claude Mods を追加**。プラグインがより深い挙動を変更できるように。
  - 組み込みモッド **「You should know」** を追加（サイドエージェントが利用者や Claude の見落としを警告）。有効化は `/plugin enable cc-plugin-you-should-know@builtin`（テレメトリ有効の first-party セッション向け）。
- **MCP / プロトコル**:
  - 2025-11-25 プロトコルの MCP サーバーからの URL プロンプト（サインイン等）に対応。更新後に接続できないサーバーには `"bareElicitationCapability": true` を MCP 設定に追加する。
  - MCP サーバーの `alwaysLoad: false` を、そのサーバーの全ツールをツール検索の後ろに遅延させるよう変更。
- **モデル / コンテキスト**:
  - Opus 4.7 以降と Fable で、Bedrock / Vertex / Foundry / Claude apps ゲートウェイにおいて 1M コンテキストを既定化（`[1m]` サフィックス不要、`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で 200K 維持）。
  - Opus 5.5 ⇄ Sonnet 5.5 の切替（`/model`・`opusplan`）が過去の MCP ツール告知を書き換え拡張思考を落とす問題、フラグ後の自動モデル切替が新モデルの既定でなく現在の effort を保つよう変更。
  - `/advisor` のペアリングチェック修正（Sonnet 5.5 が Opus 4.7/4.8 をアドバイス可能に）。
- **エージェントビュー / UI**:
  - エージェントビューに `n:<text>` フィルターを追加（セッション名・タスクに一致、折りたたみセクション内の一致も表示、Enter で先頭一致を開く）。
  - `/config`・`/memory`・`/skill` 等の操作性改善。待機中の権限プロンプトを古い順に表示するよう変更（カウントダウン付きは上に開く）。
- **セキュリティ / 権限**:
  - 危険な `rm`（`/` やホーム対象）が同一コマンドで `~`／ワイルドカードへリダイレクトすると always-ask セーフガードを失う問題を修正。
  - リポジトリにコミットされた symlink 経由でセンシティブファイルや作業ツリー外に書き込むシェル操作を、着地点を示して確認待ちにするよう変更。組織のツール毎権限上限が MCP ツール名 `__proto__` で握りつぶされる問題を修正。
- **スクリーンリーダーモード**: 検索ボックスやサインインコード欄のカーソル位置、diff の変更行欠落、不要な「Tab to amend」ヒントなど多数を修正。
- **リモート / Cloud / ファイル送信**:
  - Remote Control が再接続要求に応答がないと数分メッセージを受信しない問題を修正（30秒で諦めてリトライ）。
  - cloud / Remote Control セッションからのファイル送信のリトライ・ストリーミング改善、17〜20ファイル添付時に先頭16件しか届かない問題を修正。
  - macOS: `claude remote-control` セッションがアイドルスリープでターン中に停止する問題を修正。
  - Windows: 入力がパイプ／リダイレクトされた対話 `claude` が「Raw mode is not supported」でハング／クラッシュする問題を修正（理由を表示して終了、パイプ入力は `-p`）。Bash ツール速度改善。
- **VSCode / Cloud / Claude Tag / Code Review**:
  - [VSCode] 実行中コマンド／サブエージェントの「Run in background」追加、バックグラウンドシェル・Monitor の出力をエージェントマップのカードに表示。
  - [Code Review] 指摘コメントと「Why this was flagged」が途中で切れる問題、新規 push 後に PR をスキップする問題を修正（最新コミットをレビュー）。

## 使い方メモ（任意）

- **「You should know」モッド**は `/plugin enable cc-plugin-you-should-know@builtin` で有効化できる（テレメトリ有効の first-party セッション向け）。サイドエージェントが見落としを警告してくれるため、重要な作業で有効化すると安心。
- **1M コンテキスト**は Opus 4.7 以降と Fable で Bedrock/Vertex/Foundry/Claude apps ゲートウェイの既定になった。従来の 200K を前提にした運用（コスト・トークン管理）は `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` で戻せる。
- **`/code-review --max-findings <n>|all`** で指摘件数の上限を調整できる。選択は `--max-findings default` を渡すまで維持される。
- 構造化出力を拒否するゲートウェイ（Mantle 等）でタイトル生成やメモリ想起が失敗する場合は `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` で無効化できる。
