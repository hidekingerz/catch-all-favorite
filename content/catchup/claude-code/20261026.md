## 今回の注目ポイント

v2.1.311（2026-10-26。前回収録は v2.1.310 / 2026-10-23）を収録。バグ修正・信頼性改善が中心の大型リリース。目玉は、**標準コンテキストのセッションが 200K トークン超で「Usage credits required for 1M context」と止まらず、自動コンパクションして継続する**ようになった点。さらに、**非常に長い CLAUDE.md のリスト項目が起動時やファイル読み書き後に長いフリーズを引き起こす問題**や、**後から接続した MCP サーバのツールをサブエージェントが使えない問題**、**`SubagentStop` フックがサブエージェントごとに毎分2回ほど発火していた問題**を修正。挙動変更では、`ultrathink` が Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 でそのターンを xhigh effort で実行するようになり、設定・mod の `DISABLE_COMPACT` はコンパクションを無効化する方向にのみ作用するよう変更。self-hosted-runner に `--hold-idle-file` / `--max-hold-min` を追加。VS Code・クラウドセッション・Claude Tag 周りも多数修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.311

### ツール / 実行環境（v2.1.311）
- **バージョン**: v2.1.311（2026-10-26）
- **内容**:
  - `self-hosted-runner` に `--hold-idle-file` と `--max-hold-min` を追加（ホストが残存プロセスを報告している間、アイドルセッションを保持できる）。
  - 標準コンテキストのセッションがリクエスト 200K トークン超で「Usage credits required for 1M context」と止まる問題を修正。会話をコンパクションして継続するようになった。
  - 非常に長いリスト項目を含む CLAUDE.md がある際の、起動時・ファイル読み書き後の長いフリーズを修正。
  - 数千行を変更する際に Write / Edit が実行後に最大5秒停止し「0 lines changed」と報告する問題を修正。
  - Bash ツールの説明が「作業ディレクトリは呼び出し間で常に保持される」と誤って主張していた点、環境ブロックがコマンドの実行されないシェル（Bash が zsh を使う際の fish など）を名乗る点を修正。
  - タイムアウトに達したシェルコマンドが、それまでの出力を表示しバックグラウンドで実行継続中と示すよう改善。

### MCP / サブエージェント / エージェントチーム（v2.1.311）
- **バージョン**: v2.1.311（2026-10-26）
- **内容**:
  - サブエージェント起動後に接続完了する MCP サーバのツールを、サブエージェントが使えない問題を修正。
  - `SubagentStop` フックが、サブエージェント終了時に1回ではなく実行中サブエージェントごとに毎分2回ほど発火する問題を修正。
  - バックグラウンドのサブエージェントがまだ作業中の分離ワークツリーが削除される問題、自前シェルを待つ auto モードのバックグラウンドエージェントが wake のたびに新しいメイン会話ターンを開始する問題を修正。
  - 終了した `/code-review` など sub-agent 実行スキルが、クラウド/バックグラウンドセッション再起動時に2回目を実行する問題を修正。
  - エージェントチームのセッションが `--resume` / `--continue` / `/resume` / `--session-id`（`/clear` やクラッシュ後含む）でタスク一覧を空表示する問題、`/branch` が元セッションの一覧へ書き込む問題を修正。
  - `DISABLE_COMPACT` 設定時にエージェントチームメイトが履歴をコンパクションする問題を修正。
  - `claude mcp add/remove` と `/mcp` がリポジトリルート以下で local-scope サーバを保持する `~/.claude.json` のプロジェクトエントリでなくカレントフォルダを名乗る問題、`claude mcp list/get` が接続失敗行でエラーコードを二重表示（例 `ENOENT: ENOENT: …`）する問題を修正。

### コンパクション / メモリ（v2.1.311）
- **バージョン**: v2.1.311（2026-10-26）
- **内容**:

  - モデルの返信に要約が含まれない場合、会話を置き換える前に通常もう一度要約を要求するよう改善。
  - `DISABLE_COMPACT` 設定時に rewind メニューが「Summarize from here / up to here」を提示する問題を修正。

### モデル / effort（v2.1.311）
- **バージョン**: v2.1.311（2026-10-26）
- **内容**:

  - `ultrathink` のレインボー表示を、effort を上げられる箇所でのみ表示し、引用符付きやファイルパスの一部では表示しないよう変更。
  - 効果のないモデルでモデル名/ID から `[1m]` サフィックスとそのラベルを削除（サフィックス自体は引き続き受け付ける）。
  - Vertex AI / Microsoft Foundry / AWS 上 Claude Platform で、長い hidden thinking が idle として切られる問題を修正。
  - API が再試行しないと示したリクエストを Claude Code がリトライし、ターンを数分間（無人リトライ `CLAUDE_CODE_RETRY_WATCHDOG` では無期限に）保持しうる問題を修正。

## 使い方メモ

- 1M コンテキスト未加入の標準セッションでも、200K トークンを超えた時点でエラー停止せず自動コンパクションして継続できるようになった。長いセッションが途中で止まっていた場合は解消が期待できる。
- 大規模な CLAUDE.md（特に非常に長いリスト項目を含むもの）で起動やファイル編集後にフリーズしていた場合、今回の修正で解消する。
- `ultrathink` は Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1（Anthropic API 経由）でそのターンを xhigh effort で実行するようになった。作業中に入力すると残りのターンの effort を引き上げられる。
- `DISABLE_COMPACT` はコンパクションを無効化する方向にのみ効くようになった（設定・mod 双方）。再有効化はできない点に注意。
