## 今回の注目ポイント

- **前回収録の v2.1.329 以降、v2.1.330 が公開。** 大半は修正と改善だが、新しい組み込み mod・Enterprise 向けサインイン・定期タスクの実行期間延長など注目の変更がいくつか入った。
- **Enterprise Admin Console の組織サインインに対応。** `claude auth login` 後、Anthropic の Enterprise Admin Console で管理される組織の設定を適用し、その組織のクラウドプロバイダ／ゲートウェイを使うようになった。
- **チャートを描く組み込み mod「easel」を追加。** 依頼時や MCP メトリクスの結果で自動的にチャートを描画する（Pro / Max、および提供される場合は Team / Enterprise。macOS / Linux）。自動チャートは `/config` でオフにできる。
- **定期タスク・`/loop` の実行期間を 7 日 → 30 日に延長。** セッションが起動し続けている間、定期スケジュールタスクと `/loop` のウェイクアップが最大 30 日まで動くようになり、終了時に通知する（本リリース以前に作成したタスクは引き続き 7 日で終了）。
- **v2.1.329 で撤去された `max_tokens` 自動再試行を復活（revert）。** モデル／ゲートウェイの出力トークン上限を超えた際の自動再試行が元に戻された。
- **`rm` の確認対象を拡大。** ルート・ホーム・トップレベルフォルダ・作業フォルダを対象とする `rm` のうち、さらに多くを承認待ちに変更（誰も応答できない場合は拒否）。
- **`/mcp` の表示を整理。** プラグイン提供のサーバを「Plugin MCPs」、`--mcp-config` と組み込みサーバを「Other MCPs」の下にまとめ、各サーバのページに提供元プラグイン名を表示。
- **長い会話のコンパクト直後の数分間のフリーズ、WebFetch による数分のフリーズ・空結果を修正。** 安定性まわりの大きな修正が多数。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.330（v2.1.329 までは収録済み）。「What's changed」は節見出しのない一続きのリストで 150 項目超。主なものを機能カテゴリ別に整理する（全項目は changelog / GitHub Releases を参照）。

### v2.1.330（2026-11-20。easel mod 追加・Enterprise サインイン・定期タスク 30 日化・大量の安定性修正）
- **バージョン**: v2.1.330（2026-11-20）
- **内容**:

  - **追加（Added）**:
    - **Enterprise Admin Console** で管理される組織へのサインイン。`claude auth login` 後、組織の設定を適用しその組織のクラウドプロバイダ／ゲートウェイを使用。
    - **easel**（組み込み mod）。依頼時と MCP メトリクスの結果でチャートを描画（Pro / Max、提供時は Team / Enterprise。macOS / Linux）。自動チャートは `/config` でオフ。
    - `CLAUDE_CODE_FULL_SIGN_IN_LINK=1` で完全なサインインリンクを表示（短縮リンクがエラーになる／スクリプトが値を読む場合向け）。
    - セルフホストランナー: `--start-dir` / `SELF_HOSTED_RUNNER_START_DIR`（設定・フックは通常どおり読み込みつつ、作業開始フォルダを指定）。プラグインマーケットプレイスをフェッチできない／Anthropic 管理 git がプラグイン自身のリポジトリを拒否した際の通知。`/metrics` に `..._order_to_registered_seconds`・`..._order_to_first_session_seconds` を追加。
    - `claude plugin install --json` の結果に `commandPrinted`（インストールコマンドが stderr に出力）・`commandFailed`（異常終了／kill／タイムアウト）を追加。

  - **変更（Changed。挙動・方針）**:
    - **定期スケジュールタスク・`/loop`** をセッション起動中は最大 **30 日**（従来 7 日）まで実行し、終了時に通知（本リリース以前作成分は 7 日で終了）。
    - ルート・ホーム・トップレベル／作業フォルダ対象の **`rm` の確認対象を拡大**（応答者なしでは拒否）。
    - `deniedMcpServers` の name 指定は同一 URL の他コネクタを隠さず、名指しの claude.ai コネクタのみ非表示に（全ブロックは厳密な URL を deny）。
    - `claude --teleport` は一部構成でブランチ切り替えコマンドを実行せず表示のみ（`-p` では切り替えまで exit 1）。
    - "sonnet"／"haiku" を含む未知のモデル名も短いシステムプロンプトを使用（`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` で全モデルにフルプロンプト）。
    - `model` 設定で実行するスキル（`context: fork` を除く）はサブエージェント・フォーク・コンパクト・`/recap` をセッションのモデルのままに。サブエージェントのモデルフォールバックを引き継ぐよう変更。
    - Claude apps gateway サインイン時のサブエージェント進捗サマリを、会話全体でなく短いメモから生成し大幅にトークン削減。

  - **撤去・revert（Removed / Reverted）**:
    - v2.1.329 の `max_tokens` 超過時の自動再試行の撤去を **revert（復活）**。

  - **安定性・フリーズ・パフォーマンス（影響大）**:
    - 非常に長い会話のコンパクト直後に Claude Code が数分フリーズする問題、WebFetch が一部ページで数分フリーズ／一部で空結果を返す問題、ファイル diff の速度を修正・改善。
    - 複数プロセス同時保存でユーザ設定が失われる、`--continue`／`--resume` が最後の保存メッセージのタイムスタンプ不正で空セッション／失敗、2 分以上スリープ後の最初のプロンプトが死んだ接続で 3 分待つ（Linux / WSL）などを修正。
    - 多数の MCP ツールが API の拒否する入力スキーマを持つときの "JSON schema is invalid" 失敗とセッションファイル肥大化を修正。Linux で `node_modules` 等の大きな無視フォルダがあるリポジトリの Bash 遅延・diff 非表示、Windows の Git Bash 起動遅延による以降の Bash 低速化を修正。

  - **ワークツリー・rewind・権限・サブエージェント**:
    - `ExitWorktree` と終了ダイアログが別の実行中セッションが作業中のワークツリーを削除する問題、`/rewind` がキュー済みプロンプト／スタックしたスキル同時実行時に古い版を復元する問題、権限プロンプト承認時に追加したテキスト／画像がコマンド失敗で失われる問題を修正。
    - 停止したバックグラウンドサブエージェントが停止し続けない、完了直後に停止したエージェントを待ち続ける（アプリ／SDK 実行時）、プラン承認後に以前の権限モードで復帰する問題を修正。

  - **MCP・ツール・Code Mode**:
    - `@` メンション時に claude.ai コネクタ／プラグインサーバの MCP リソースが添付されない、サブエージェントが宣言した MCP サーバが 1 つの完了で他が使用中でもシャットダウンされる問題を修正。`/mcp` がプラグインサーバを組み込みと誤表示 → 「Plugin MCPs」「Other MCPs」に整理しプラグイン名を表示。組み込みチャートツールを除外した allowlist／denylist で毎回 "easel blocked" 警告が出る問題を修正。
    - Code Mode: パススコープ／Read deny ルールで数百ファイル読み込み後の長い停止、組み込みチャートツールの失敗、auto／bypass モードでスクリプトの turn 終了要求無視、Esc と `/compact` 後にスクリプトが読んだファイルを復元しない、`/context` のシステムツール過少計上などを修正。画像／PDF の扱いの指示を追加、Esc 後に赤エラーでなく "Interrupted" 表示、サブエージェントが数千ツール呼び出し後のフリーズ時間短縮。

  - **認証・モデル・CLI**:
    - Amazon Bedrock（Mantle）でモデル未選択起動時に pin した Opus を無視し、フォールバック告知後も使用不可の既定モデルを呼ぶ問題を修正。モデル変更後にシステムプロンプトが旧モデルの指示を残す、`/context` 後・初回メッセージ前のモデル変更などの問題を修正。
    - `claude -p` が満杯ディスクへの出力で無言 exit 0 → エラー表示し exit 1。`forceLoginOrgUUID` 起動が一時サーバエラー／接続切断 1 回で拒否される問題、`claude mcp remove` が claude.ai コネクタで進めない問題などを修正。claude.ai サインインリンクを大幅に短縮。

  - **Remote Control・セルフホストランナー**:
    - 電話／Web からの Stop で終了したバックグラウンドエージェントの通知がユーザ入力のように端末表示される、途中オンにした後にモバイルが Diff／PR ボタンを隠す／停止セッションを実行中と表示する問題を修正。
    - セルフホストランナー: 失敗報告喪失後のセッション無視、`--push-outcome-on-release` 時に push 済み作業なしで復帰、`pkill -f` が自身のシェルを exit 144 で終了、満杯ディスク起動、403（IP allowlist 等）を不正トークンと誤記録、など多数修正。`spawn-runner` フックの並行実行（`--hook-concurrency`、既定 4）、Bash の diff スキップ（`bashEditDiffEnabled`）など変更。

  - **端末表示・UI・その他**:
    - プラン到着時のフルスクリーンで入力中テキストが消える、Mermaid 図の改行／クラスステレオタイプ欠落（HTML アーティファクト）、CLAUDE.md／メモリの HTML コメントでリンク参照定義が落ちる、`/stats` が UTC 日で集計、`/config` の検索改善などを修正・改善。

  - **[VSCode]**:
    - **追加**: `/fork`（最後の返信後に会話をフォーク、#69272）、`/workflows`（実行中ワークフローのエージェントマップ）、`claudeCode.escapeStopsClaude`（#91536）・`claudeCode.pinPrompt`・`claudeCode.contextUsageThreshold`（#93036）設定、「Open in Side Bar」の `prompt` 引数、セッショングループの Move up / down（#98654）。
    - **修正**: 接続端末セッションで毎プロンプトごとに端末を開いてフォーカスする、コードブロックコピー時の末尾改行で貼り付け実行（#96976）、`/rewind` の Enter 長押しや Remove／Delete のダブルクリックで無確認実行、macOS の Cmd+A/C/V/X/Z・Ctrl+F/P がボックスで効かない、Accept／Reject ボタン無反応、フォークした会話の旧プロンプト再実行・`/loop` 二重実行、advisor 呼び出しの "Unsupported content type"（#73499 ほか）などを修正。
