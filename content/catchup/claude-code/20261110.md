## 今回の注目ポイント

- 新モデル **Claude Fable 5.2（`claude-fable-5-2`）** が追加され、Fable のデフォルトモデルになった。1M コンテキスト、$8/$40 per Mtok（キャッシュ読み取り $0.20/Mtok）。保存済みの Fable 5.1 選択は `fable` に移行され、`/model claude-fable-5-1` で戻せる。
- **セキュリティ修正が複数**。MCP OAuth がリダイレクト時にリフレッシュトークン等の秘密情報を別ホストへ送らなくなった、読み取り専用の Bash コマンドが許可プロンプトなしでサンドボックス外実行されなくなった、`cp`/`mv` でディレクトリに書き込むファイルにも deny ルール／保護ファイルのプロンプトが適用されるようになった。
- **fast mode の挙動が改善**。レート制限・過負荷時に、返答を失ったりモデルを切り替えたりせず、まず同一モデルの標準速度にフォールバックするようになった。さらに Vertex（global / us / eu リージョン）でも fast mode に対応した。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.321 〜 v2.1.322（v2.1.320 は欠番）

### v2.1.322
- **バージョン**: v2.1.322（2026-11-10）
- **内容**: Vertex（global / us / eu リージョン）で fast mode に対応。Vertex が fast mode を拒否した場合は標準速度にフォールバックする。

### v2.1.321（新モデル・セキュリティ・多数の修正）
- **バージョン**: v2.1.321（2026-11-09）
- **内容**:
  - **新機能・モデル**: Claude Fable 5.2（`claude-fable-5-2`）を追加し、Fable のデフォルトに。1M コンテキスト、$8/$40 per Mtok、キャッシュ読み取り $0.20/Mtok。`claude remote-control` に `--settings <file>` を追加（起動する全セッションに設定が適用され、変更は `claude remote-control` の再起動後に反映）。
  - **セキュリティ修正**: MCP OAuth がサーバーのリダイレクト時にリフレッシュトークン等の秘密情報を別ホストへ送らないよう修正。読み取り専用 Bash コマンドが許可プロンプトなしでサンドボックス外実行されない。`cp`/`mv` でディレクトリへ書き込むファイルにも deny ルール／保護ファイルのプロンプトが適用される。
  - **主な修正**: fast serving がレート制限／過負荷のとき、まず同一モデルの標準速度にフォールバック（返答喪失・モデル切り替えを回避）。WebFetch は読み取りモデルがテキストを返さない場合に「No response from model」を本文として渡さず、明確なエラーで失敗する。`claude -p` がバックグラウンドコマンドの停止を「30分」と誤って伝える（実際は10分で停止）バグを修正。
  - **変更**: 保存済みの Fable 5.1 モデル選択は `fable` に移行（`/model claude-fable-5-1` で戻せる）。`/model` の「More models」が番号なしの行になり、旧モデルはその下に表示。`claude agents` と VS Code 拡張の auto mode の扱いを変更（詳細はフィード参照）。このリリースは約80項目に及ぶ大型アップデート。
