## 今回の注目ポイント

- **v2.1.283**（2026-09-25）の1バージョンが新着。モデルガバナンス系の管理設定が拡充され、`availableModelsMatch: "exact"`（列挙したモデルのみ許可＝新リリースは登録するまでブロック）と `deniedModels`（特定モデルを明示ブロック）が追加された。
- 前バージョン **v2.1.282 で予約された `claude-ai` 名前空間の予約が取り消し（Revert）** され、`claude-ai` 名のスキル/コマンド/ワークフロー/MCP が再び読み込めるようになった。`Skill(claude-ai:*)` も通常の prefix ルールに戻る。
- 設定/CLAUDE.md 保守向けに **`/doctor prompt-audit`（`/checkup prompt-audit`）** を追加。古いモデル向けのプロンプト記法を CLAUDE.md・スキル・エージェント・コマンドから検出できる。
- `claude plugin validate` / `install` / `uninstall` 周りの不具合修正が多数。加えて vim モード、起動/初回応答レイテンシ、各種リスト UI（ページキー/マウス対応）の改善、Windows の PowerShell 削除コマンドのセキュリティ修正など。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.283（v2.1.282 まで収録済み）

### モデル管理・ゲートウェイ
- **バージョン**: v2.1.283（2026-09-25）
- **内容**:
  - `availableModelsMatch` 管理設定を追加。`"exact"` にすると `availableModels` の各エントリはそのバージョンのモデルだけを許可し、新リリースは列挙されるまでブロックされる。
  - `deniedModels` 管理設定を追加。`availableModels` で許可されていても特定モデルをブロックできる。
  - LLM ゲートウェイが1つのユーザープロンプトに紐づくリクエストをグルーピングできるよう、ゲートウェイヒントヘッダに `x-claude-code-prompt-id` を追加（`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` でオプトイン）。
  - Claude apps ゲートウェイに、リクエストを構築・署名するが上流に送らずクライアントへ定型応答を返す `load_test_mode` ブロック（負荷試験用・オプトイン）と、Amazon Bedrock の Mantle エンドポイント向け `mantle` 上流プロバイダを追加。

### 名前空間（`claude-ai` 予約の取り消し）
- **バージョン**: v2.1.283（2026-09-25）
- **内容**: v2.1.282 で行った `claude-ai` 名の予約を Revert。`claude-ai` 名のスキル/コマンド/ワークフロー、および MCP サーバのスキル/プロンプトが再び読み込めるようになり、`Skill(claude-ai:*)` ルールは通常の prefix ルールとして扱われる。あわせて `Skill(anthropic-skills:<name>)` の deny ルールは Claude Desktop がプラグインとして配信した同スキルにも効くようになり、`Skill(skill:<name>)` の deny はスキルのエイリアス/表示名にもマッチするよう変更。

### 診断・可観測性
- **バージョン**: v2.1.283（2026-09-25）
- **内容**:
  - `/doctor prompt-audit`（`/checkup prompt-audit`）を追加。CLAUDE.md・スキル・エージェント・コマンドを、古いモデル向けに書かれたプロンプト記法がないか監査する。`prompt-audit` は設定監査で stale なパス/コマンドや矛盾する指示ファイルを先頭に出し、Claude Code が公式に文書化している thinking キーワードは保持するよう改善。
  - `OTEL_LOG_TOOL_CONTENT=1` のとき、MCP ツール・WebFetch・WebSearch の出力を OpenTelemetry の `tool.output` span イベントに含めるよう追加。
  - `/context` が MCP サーバの instructions を独立行として計上し、合計にカウントするよう修正。

### プラグイン
- **バージョン**: v2.1.283（2026-09-25）
- **内容**: `claude plugin validate` の検証強化（インストール不能な marketplace/plugin 名の弾き、`outputStyles`/`themes`/`monitors`/`lspServers` のパス欠落・ディレクトリ外参照を fail に）、`claude plugin details` が `plugin.json` 宣言の MCP サーバ数を 0 と表示する不具合、`marketplace remove` / `uninstall`（大文字小文字違いの id 誤削除）・バージョン未宣言プラグインの復元・`installed_plugins.json` の破損時リカバリなど多数の修正。`--plugin-dir` の読み込み失敗エントリに該当ディレクトリを示す `path` を追加。

### 入力・エディタ（vim / キーバインド）
- **バージョン**: v2.1.283（2026-09-25）
- **内容**: vim モードの `.`（Shift+Enter 改行の欠落、アクセント文字内でのカーソル、`3J`/Visual `J` 後の誤リピート）、超長プロンプトの normal モード復元時のカーソル位置、`V`→`p` の着地、`J` の行結合スペーシングを Vim 準拠に修正。`keybindings.json` はミススペル修飾子（例 `ctl+k`）を debug ログで警告し修正案を提示。組み込みキーバインドガイドのチョードのタイムアウト表記（1秒→3秒）や `cmd`/`meta` の説明も修正。高速連打（type-ahead・キーリピート・ssh/tmux 越しのバースト）が古い状態に対して処理される不具合も修正。

## 使い方メモ（任意）

- モデルの版数を厳密に固定して運用したい組織は `availableModels` + `availableModelsMatch: "exact"`（＋必要なら `deniedModels`）で「登録した版だけ許可」を実現できる。新モデルは明示登録するまで自動では使われない。
- 手元の CLAUDE.md やスキルが古いモデル前提の書き方になっていないかは `/doctor prompt-audit` で点検できる。
