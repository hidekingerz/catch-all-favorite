## 今回の注目ポイント

- **前回収録の v2.1.326 以降、v2.1.327・v2.1.328・v2.1.329 の 3 リリースが立て続けに公開。** いずれも大半が修正と改善で、サンドボックス／権限チェックの引き締めとパス検査の厳格化、Code Mode の安定化、Remote Control／クラウド／セルフホストランナーまわりの信頼性向上が中心。
- **auto モードの対象モデル拡大（v2.1.328）。** Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude apps gateway 上の **Claude Opus 4.6 / Sonnet 4.6** で auto モードに対応し、権限モード未設定の対話セッションは auto モードで開始するようになった。
- **`/code-review` の方針変更（v2.1.328）。** 多くのモデルで `/code-review` はバグと CLAUDE.md 違反のみを報告し、再利用・簡素化・効率化のクリーンアップは `/simplify` に分離。各指摘を Important / Pre-existing / Nit で分類し、要約末尾に修正案を添える。
- **`/tasks` が一元化（v2.1.329）。** セッションの定期タスク・`/loop` のウェイクアップ・ゴール・この会話のフォークを `/tasks` に表示し、x で確認のうえ停止できるようになった。
- **サンドボックス／パス検査とシークレット保護の継続的な強化（v2.1.327〜）。** 一部のシンボリックリンク拒否、ワーキングディレクトリ内外判定の見直し、`permissions.blockReadsOutsideWorkingDirectories` の拡張、WebFetch が 2,000 文字超の URL を権限確認前に拒否、など。
- **computer use（macOS）が新しい安全ルールに更新（v2.1.329）。** 一部操作が拒否され、一部アプリのアクセスが縮小。あわせて v2.1.326 で入った `max_tokens` エラー時の自動再試行は撤去された。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.327 / v2.1.328 / v2.1.329（v2.1.326 までは収録済み）。各リリースとも「What's changed」の一続きのリストで 100 項目超。主なものを機能カテゴリ別に整理する（全項目は changelog / GitHub Releases を参照）。

### v2.1.327（2026-11-17。サンドボックス／パス検査の厳格化・セッション復帰とバックグラウンドエージェントの大量修正）
- **バージョン**: v2.1.327（2026-11-17）
- **内容**:

  - **追加（Added）**:
    - `/install-github-app` がリポジトリを変更する前に確認を表示。
    - `claude mcp add-json <name> -` で標準入力からサーバ JSON を読み込み、トークンをコマンドラインに残さずに済む（Claude Code セッション内では不可）。
    - 復帰時に過去メッセージを読み込めない場合の説明行、`/status` に壊れたエージェント／スキル／コマンド／出力スタイルファイル・キーバインドエラー・利用不可サンドボックス・無視された権限設定・一致しないフックマッチャの一覧、`/config` に他設定が行を上書きしている旨の注記を追加。
    - `attributionProject` 設定でセッションの課金グループ名を指定（`admin.billing_group_tag` を設定する Claude apps gateway 向け）。`/tui classic`（非フルスクリーンレンダラの名称。`/tui default` も有効）。

  - **サンドボックス・権限・パス検査（引き締め。影響大）**:
    - 一部のシンボリックリンクを拒否するようパス検査を変更。ワーキングディレクトリの内外判定を見直し、一部パスは権限確認を求めるよう変更。
    - `permissions.blockReadsOutsideWorkingDirectories` を、bypass／auto モードでより多くの Bash コマンドに確認を求め、auto モードでは一部を拒否するよう拡張。Read／Edit の deny ルール配下のパスを名指すコマンドも確認から拒否へ。
    - auto モードが「任意のパッケージを実行する許可ルール（`Bash(pnpm dlx *)` 等）」やパス／バージョン形（`/usr/bin/npm run:*`）をさらに無視し、安全チェックに委ねるよう変更。課金分類器へのフォールバック撤去を予告する通知に変更（撤去後は各操作が確認／拒否になる）。
    - 変数が非常に長いテキストに展開される Bash コマンドを拒否。PowerShell ツールはルールがあっても 1 コマンド追加で確認（誰も応答しなければ拒否）。Claude in Chrome が一部の資格情報ファイルのアップロードを拒否。
    - `ExitWorktree` は未保存作業を含み得るワークツリー削除前に確認（don't-ask／応答者なしでは拒否、ただし allow ルール・auto・bypass で許可）。`--worktree` と相対 `--add-dir` の組み合わせでサンドボックスに渡すフォルダを整理。

  - **セッション復帰・バックグラウンドエージェント・サブエージェント**:
    - クラッシュ・バックグラウンド移行・空返信／killed コマンド後の復帰で、回答の喪失・巻き戻したプロンプトの復活・`/clear` 後タスクの喪失／復活などを多数修正。出力トークン上限で切れた返信直後のコンパクトがツール呼び出しと結果を失う問題も修正。
    - lead と別モデルのインプロセスエージェントが lead のコンテキスト上限・モデルでコンパクトする問題、兄弟サブエージェントのモデル／effort で再開する問題、サブエージェント完了がメイン会話／auto モードに通知されない問題、デスクトップ／Web／SDK で 30 秒以上権限待ちのバックグラウンドエージェントを「実行中」と誤報告する問題を修正。

  - **MCP・ツール**:
    - リモート MCP サーバが VPN 切断等の長い障害後に切断したままになる問題（ホスト名＋https のサーバを約 1 日バックグラウンド再試行）、`/mcp` が設定なしと誤表示する問題を修正。
    - Edit がコンパクト後に未変更ファイルで「File has not been read yet」を出す問題、Grep の `head_limit`＋`offset` ページングでの重複／欠落（ファイルパス順ソートに）、Read の Jupyter 未知出力での失敗、NotebookEdit が末尾改行を削る問題、Read のサイズ誤表示、WebFetch が 2,000 文字超 URL を権限確認前に拒否するよう変更。

  - **アーティファクト**:
    - 同期／リモートフォルダでタイムスタンプだけ変わった際の公開失敗、各アーティファクト承認が必要な組織でのクラウド定期タスク／SDK アプリ経由の新規アーティポンプ拒否、`/artifacts` のリスト一部表示／「No artifacts yet」誤表示を修正。

  - **端末表示・UI・入力**:
    - Ghostty のリサイズでのスクロールバック崩れ、Windows Terminal／VTE 0.50.0 でのリンクアドレス非表示、16 色での選択ハイライト欠落、tmux `allow-passthrough` での行崩れなど端末表示を多数修正。
    - 権限プロンプト直後の Esc 無視、遅延ロードリストでの Enter／矢印キー無視、shell モードの Tab 補完、`/resume` の表示件数、transcript 検索（n/N・キャンセル位置）などを修正。
    - 最初の Bash コマンドの速度（起動ファイルを承認前に走らせる。`CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1` で無効化）、Windows の起動時間、PowerShell ツール速度（最大 ~0.5 秒／コマンド）、大きい PNG 読み込みなどを改善。

  - **[VSCode]**:
    - エクスプローラ右クリックに「Claude Code: Add to Chat」を追加。PreToolUse フックの確認理由非表示（#85950）、権限プロンプトのツール／ファイル名切れ、Escape がダイアログを閉じると同時に応答も止める問題などを修正。複数編集時の速度・`@` メンション検索速度・起動時のモデルピッカー表示を改善。

### v2.1.328（2026-11-19。auto モードのモデル拡大・`/code-review` 方針変更・Code Mode 改善）
- **バージョン**: v2.1.328（2026-11-19）
- **内容**:

  - **追加（Added）**:
    - Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude apps gateway 上の **Claude Opus 4.6 / Sonnet 4.6** で auto モードに対応。権限モード未設定の対話セッションは auto モードで開始。
    - `mcp_tool` フックに `"onFailure": "block"`（呼び出し失敗で操作をブロック）を追加。権限プロンプトをスキップするセッションからのメッセージがクラウドセッションで保留・破棄され得る旨の警告、OpenTelemetry エクスポータのエンドポイント未設定時の `/status`・`claude doctor` 通知、`CLAUDE_CODE_DISABLE_DEFERRED_TOOL_RESUME`、埋め込みアプリ向けの policy プラグイン `allowManagedModsOnly` 対応などを追加。
    - セルフホストランナーに `--repository-folder`・`--hook-label`・`--metadata key=value`・新メトリクスなどを追加。

  - **変更（Changed。挙動・方針）**:
    - **`/code-review`**: 多くのモデルでバグと CLAUDE.md 違反のみ報告（再利用・簡素化・効率化は `/simplify` へ）。各指摘を Important / Pre-existing / Nit で分類し、要約末尾に修正案を提示。問題なしのレビューは「Code review found no issues.」と表示。
    - 第三者プロバイダ上の Opus 4.6 / Sonnet 4.6 のプランモード・Bash プロンプトで auto モードを使用／提示（`disableAutoMode` で両方オフ）。Code Mode は UserPromptSubmit フックをスクリプト出力に対して実行しないよう変更（出力の秘匿は PostToolUse フックの `updatedToolOutput` を使用）。
    - `deniedMcpServers` の `claude.ai <name>` 形がクラウド／セルフホストランナーにも適用。管理 PostToolUse フックが実行前に拒否された呼び出しでは発火しないよう変更。`/bug` は送信前に Yes/No を確認。`/list-agents` の一覧は本人のみに表示。

  - **Code Mode**:
    - auto／bypass モードでの前スクリプト実行中に接続した MCP サーバを呼べない問題、`claude --resume` 選択セッションでバックグラウンド実行されない問題、複数スクリプトを 1 返信で走らせたセッション復帰時のスキル／フックコンテキスト／メモ喪失、`{` ブロック始まりや top-level `await`＋`return` の誤拒否などを修正。速度（0.75 秒の待機撤去）・トークン使用量・プロンプトキャッシュ・実行中のコマンド表示を改善。

  - **Remote Control・クラウド・セッション**:
    - 再接続メッセージの重複、リモート再起動中の権限プロンプト喪失、巻き戻し→`/clear` 後の会話復活、ランナー／ワーカー喪失時のツール呼び出し／結果喪失、クロスセッションメッセージングの到達性、クラウドセッションの返信可否の説明などを修正。
    - 自動コンパクトがシステムプロンプトを再構築しない問題、遅延保存による復帰時のコンパクト要約／直近メッセージ喪失、スピナー／サブエージェントのトークン計数などを修正。

  - **安定性・端末・プラットフォーム**:
    - zsh での `=` 始まりワードの「not found」、markdown レンダリングのフリーズ、まれな画面フリーズ、`FORCE_COLOR` 負値／低メモリ時のクラッシュ、Linux のクリップボード（`xclip`／`wl-copy`、画像貼り付け）、GNU screen の色、kitty キーボードプロトコルでの Shift+Enter／Alt ショートカットなどを修正。
    - 大きいセッション／画像の多いセッションの復帰速度・メモリ使用、長い SDK／デスクトップセッションのメモリ・応答性、computer use 承認ダイアログ（アプリごとのアクセスレベル表示）、クロスセッションメッセージングの説明などを改善。
    - 第三者プロバイダ／テレメトリ・機能フラグ無効時の挙動（MCP ツールのスキーマ対応・貼り付けテキストのマーク・クローズ時のターン終了など）を整理。`[VSCode]` は保留メッセージの通知・権限プロンプトのレイアウト・失敗ツール呼び出しの理由表示を修正。

### v2.1.329（2026-11-19。`/tasks` 一元化・フック信頼ダイアログ・computer use 安全ルール更新）
- **バージョン**: v2.1.329（2026-11-19）
- **内容**:

  - **追加（Added）**:
    - フックがどこで宣言されているかを示す信頼ダイアログの警告、管理設定のフック読み込み失敗を会話／Claude Desktop 等の非対話ホストで知らせる警告を追加。
    - **`/tasks`** にこのセッションの定期タスク・`/loop` のウェイクアップ・ゴール・この会話のフォークを表示（x で確認のうえ停止）。`/mcp` のサーバページに「Server message」行（接続拒否するリモート HTTP MCP サーバの JSON-RPC エラー）、`/status` に「Marketplace auto-update」行を追加。
    - OpenTelemetry のイベント／メトリクス有効時に Code Mode をオンにできるよう対応（各ツール呼び出しがイベントを送信。トレーシングは引き続きオフにする）。

  - **変更（Changed）・撤去（Removed）**:
    - **computer use（macOS）** を新しい安全ルールに更新（一部操作を拒否、一部アプリのアクセス縮小。アプリ起動は 30 秒で諦める）。
    - v2.1.326 で入った `max_tokens` エラー時の自動再試行を撤去（出力トークンの少ないゲートウェイでは `CLAUDE_CODE_MAX_OUTPUT_TOKENS` を設定）。
    - 保存済み定期タスクは、新規サインインセッションでは旧バージョン保存分の多くを再スケジュールが必要（同一セッションの `--resume` では引き続き実行）。`/code-review` をターゲットなしで既定ブランチ全体のレビューに変更（複数コミットブランチの diff 喪失も修正）。「Exit and stop tasks」がセッションの定期タスクを終了。auto モードは大きいリポジトリで `git status` の実行頻度を下げる。Code Mode の PreToolUse フックがエラーでもスクリプトのツール呼び出しを拒否しないよう変更（拒否させたいなら `"onFailure": "block"`）。

  - **認証・設定・MCP**:
    - `~/.claude.json` がネットワーク遅延／ファイルロックで読めずデフォルトに戻る問題、macOS Keychain に書けない際の繰り返しサインアウト、認証クリア中のトークン更新での再サインイン、クリア済み MCP 認証の再サインインを修正。遅い再接続で停止したバックグラウンド MCP タスクを自前で再接続。`application/octet-stream` で届く PDF／画像／Office ファイルが `.bin` 保存される問題を修正。

  - **Code Mode**:
    - 大きいテキストファイルを読むたびにメモリを保持する問題、10 分制限で MCP フォーム／リンクプロンプト待ち中にスクリプトを止める問題、2 分超の MCP 呼び出しで「バックグラウンド移行」メッセージをデータとして受け取る問題、一部ツールのみ列挙する mod が無言で Code Mode をオフにする問題、`let x;` が前スクリプトの値を保持する問題、4,096 超ツール時の `tools` 経由アクセス喪失などを修正。

  - **端末表示・UI・入力**:
    - フルスクリーン／`/help`／履歴検索でのパネル・質問の切れ、短いウィンドウでのバックグラウンドタスク一覧の行／タイトル欠落、ダイアログ内テーブルの折り返し、復帰時の「Rejected／Declined」誤表示、`/passes`・`claude --help` のパイプ切れ、`/terminal-setup`（VS Code 設定／キーバインド破損、Terminal.app の Option as Meta）などを修正。
    - 権限プロンプト／質問／`/model`／`/rewind` のキーヒントが `keybindings.json` を無視する問題、`/config` スイッチが実行中セッションに反映されない問題、Read／`@` メンションの行数過多、長いコードブロックの空行崩れなどを修正。

  - **セルフホストランナー・[VSCode]**:
    - `--push-outcome-on-release` がブランチを誤削除、Git LFS／SSH ホストエイリアス／GitHub SSH 証明書での起動失敗、タイムアウト後のリモート MCP ツール喪失などを修正。`[VSCode]` は信頼プロンプト拒否後の Review trust 行追加、サインインサーバ遅延時の全ウィンドウサインアウト、IME 合成中のフォーカス移動（#106358）、octet-stream 由来の表示崩れなどを修正。
