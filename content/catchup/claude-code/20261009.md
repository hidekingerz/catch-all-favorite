## 今回の注目ポイント

- **v2.1.296 の1リリースを収録**（前回収録は v2.1.295 / 2026-10-08）。機能追加を少量含みつつ、プラグイン/モッド・権限・Windows まわりを中心とした大量の修正リリース。
- **Read ツールに `allow_large` を追加**。通常のサイズ上限を超えるテキストファイルを、必要時に1回で全読みできる（本キャッチアップ運用のような大きめファイルの一括読みに関係）。
- **サブエージェントに `autoCompactWindow` を追加**。サブエージェントをメイン会話より早めに auto-compact させられる。
- **Sonnet 5.5 のキャッシュ読み取り価格を $0.20→$0.10 per Mtok に改定**（`/cost`・status line・`--max-budget-usd`・SDK のコスト表示に反映）。
- **MCP ツール説明・MCP サーバ指示の既定上限を 2,048→4,096 文字に変更**（v2.1.295 のツール説明 16,384 文字化とは別の既定値）。
- **権限・セキュリティ修正が多数**。`BASH_ARGV0` を使うコマンドの自動承認、Git Bash での `rm -rf /c/Users/<name>`（bypass モード）の無確認、非 UTF-8 ファイル（Shift-JIS / GBK 等）の破壊的 Edit、共有トランスクリプト/デバッグログのシークレット秘匿漏れなどを修正。
- **ワークフロー / プラグイン / モッドまわりの不具合を多数修正**。約2万階層超の深いネスト結果の切り詰め、プラグインの `$` メソッドが呼び出し元エージェントの作業ディレクトリで動かない問題、`constructor`/`prototype` 名のマーケットプレイス/シークレット事故などを修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.296

### v2.1.296（2026-10-09）

- **新機能 / 追加**:
  - Read ツールに `allow_large` を追加（全読みが必要でコンテキストに余裕がある場合、通常のサイズ上限を超えてテキストファイルを1回で読む）。
  - サブエージェントの frontmatter・`--agents` 定義に `autoCompactWindow` を追加（メイン会話より早く auto-compact 可能）。
  - `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` を追加（全ワークフローエージェントを単一モデルで実行。他のサブエージェントは各自のモデルを維持）。
  - `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` を追加（過負荷 529 リトライのバックオフ最大遅延を延長指定）。
  - Claude apps gateway の `managed.policies[]` に `code` キーを追加（`cli` と同じ設定を Claude Desktop の Code タブにも適用。`desktop` と並べると Desktop のゲートウェイモードを有効化）。
  - `/plugin` に、別の有効プラグインと同名のためフックが除外されたプラグインを示す注記を追加。
- **モデル / 価格**:
  - **Sonnet 5.5 のキャッシュ読み取りを $0.20→$0.10 per Mtok に改定**（`/cost`・status line・`--max-budget-usd`・SDK）。
  - Haiku 5.5 など adaptive thinking のみのモデルで、一部ゲートウェイ経由のトークンカウント失敗／別環境での budget thinking 誤計上を修正。
- **MCP / ツール**:
  - MCP ツール説明・MCP サーバ指示の既定上限を 2,048→4,096 文字に変更。
  - headless セッションが、フォルダで無効化した `.mcp.json`／プラグイン MCP サーバを cd・プラグイン再読込後に起動する問題を修正。
  - `$.http.fetch`（モッド）が `Content-Length` が 4 MiB 超を宣言する `HEAD` リクエストを拒否する問題を修正。
- **フック / 設定（managed）**:
  - managed settings の `PreToolUse` フックが `"continue": false` で拒否、managed `prompt` フックがブロックした際、呼び出しは拒否するがターンを終わらせないよう修正。
  - managed settings の PostToolUse フックが一部セッションで `updatedMCPToolOutput` を適用しない問題を修正。
  - late-loading プラグインの SessionStart フック出力が headless セッションの `/clear` 後に新会話へ届く／同名プラグインが先に動くと skip される問題を修正。
  - PowerShell が `CLAUDE_ENV_FILE` にフックが書いた変数（単純代入のみ）を参照できない問題を修正。
- **セキュリティ / 権限**:
  - **Bash 権限チェックが `BASH_ARGV0` を代入して使うコマンドを自動承認する問題を修正**（承認を求めるように）。
  - **Git Bash で `rm -rf /c/Users/<name>` が bypass permissions モードで無確認だった問題を修正**（Windows）。
  - Edit / NotebookEdit が非 UTF-8 ファイル（Windows-1252・Shift-JIS・GBK）の全非 ASCII 文字を置換してしまう問題を修正（該当編集を拒否）。
  - 共有トランスクリプト・デバッグログのシークレット秘匿が、値の無いキーの後に続く値（シェル文字列内 JSON 含む）を取りこぼす問題を修正。
  - クラウドセッションが、保存済み権限で許可された Claude in Chrome アクションの auto モード判定を、feature flag 未読込時にスキップする問題を修正。
- **ワークフロー / プラグイン / モッド**:
  - ワークフロースクリプトが約2万階層超の深くネストした結果・エージェントオプション等を無言で切り詰める／巨大タスク出力ファイルを書く問題を修正。
  - プラグインの `$` メソッドがメインセッションの作業ディレクトリで動く／呼び出し元フックのターンを無視する問題を修正（呼び出し元エージェント基準に）。
  - `$.agent.register` が、再読込・削除後も走り続けるモッドのフックから成功する問題を修正（拒否するように）。
  - `constructor` 名のマーケットプレイスで `marketplace add/update`・`plugin install` が内部エラーになる問題、`constructor`/`prototype` 名のプラグインシークレットが次の保存で消える問題を修正。
  - claude.ai 同期スキルが install を完了せず毎同期で再ダウンロードされる問題、同期プラグインが同期マーケットプレイス依存で無効化される問題を修正。
  - macOS で Linux からコピーしたプラグインパス（/home 配下）による起動ハング、CRLF 改行のワークフロースクリプト拒否を修正。
- **その他の主な修正**:
  - `CLAUDE_CODE_RESUME_INTERRUPTED_TURN` が、MCP ツール結果でターンが終わった後の再起動で完了ターンを再実行する問題を修正。
  - `←`（バックグラウンド移行）直後に送ったプラン／`!` コマンド、SessionStart フック実行中に送ったプロンプトの二重実行・消失（`↑` で復帰可能に）を修正。
  - `/code-review` がクラウドセッション・Agent SDK・IDE で生の JSON 配列で終わる問題を修正（番号付きリスト表示に）。
  - `--teleport` が履歴読込失敗時に空会話を開く問題、resume したサブエージェントに「ユーザーがツール呼び出しを拒否」と誤って伝える問題を修正。
  - `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC`・`claude purge` が Unicode 行/段落区切り（U+2028/U+2029）を含むメッセージを落とす問題、`claude self-hosted-runner` の誤解を招くエラー表示を修正。
- **変更 / 改善**:
  - `←`: バックグラウンド移行中に開始されたターン／`!` コマンドを、見えない所で完走させず停止するように変更。
  - 全画面モードでマウス下のリンクに下線を表示、ctrl+o（トランスクリプト切替）の応答性改善（ハイライト済みコードブロックのキャッシュ）。
  - 同梱 dataviz スキルを更新（7系列目の violet をライト時に明るく、ダーク時の本文色を柔らかく、y 軸ラベルを `1K` 等にコンパクト化）。
  - `--debug` 出力の改善（カスタムエージェントの未知 frontmatter フィールド・タイポ指摘、フックの command/plugin/結果/所要時間ログ）。
- **[Windows]**: 約1KB 超の PowerShell コマンドが常に承認を求める問題を 32KB まで許可ルール/読み取り専用判定が効くよう修正、stdio MCP サーバの強制終了を stdin クローズ優先（300ms 後にツリー kill）に、SSH 鍵無し環境での `owner/repo` プラグイン install を HTTPS clone に再試行。
- **[VSCode]**: `claudeCode.spinnerVerbs` の settings.json 補完/検証、Claude in Chrome を全セッションで操作前確認（`@browser` 接続含む）、フル Windows パス（`C:\...`・`file:///C:/...`）のチャットリンクが開かない問題、reduced motion 時のインジケータ、キャッシュ時計の誤表示を修正。
- **[Cloud sessions]**: self-hosted 環境の Activity タブに Sessions/Runners のステータスフィルタ（複数選択可）を追加、runner 待ちキュー位置を各セッションごとに表示、返信中に送ったメッセージが返信の上に飛ぶ問題を修正。
- **[Claude Tag]**: Slack のフッター（セッションリンク・モデル・コスト）を最新返信のみに表示、括弧を含む URL のリンク崩れ・PR 番号等を色コードと誤認する問題を修正、Memory タブでのワークスペース/チャンネルメモリ編集を追加、プラグイン確認カードの ID→名称表示修正。
- **[Code Review]**: レビュー完了後も PR チェックが "in progress" のまま残る問題を修正（結果を表示）、管理設定の保存失敗理由を明示。

## 使い方メモ（任意）

- **Read の `allow_large`**: 通常のサイズ上限を超えるファイルも、全文が必要でコンテキストに余裕があれば1回で読める。従来は `offset`/`limit` で分割していた大きめファイルの一括読みに有効。
- **サブエージェントの `autoCompactWindow`**: サブエージェントだけメイン会話より早く auto-compact させられる。長い調査系サブエージェントのコンテキスト管理に。
- **managed フックの挙動変更（運用者向け）**: managed settings の `PreToolUse`/`prompt` フックで拒否・ブロックした際、呼び出しは止めるがターンは終了しなくなった。ガードフックでツール呼び出しだけ弾いて会話を継続させたい運用に影響。
- **Sonnet 5.5 のキャッシュ読み取り値下げ**: $0.20→$0.10 per Mtok。キャッシュを多用するワークフローのコスト見積もりに反映される。
