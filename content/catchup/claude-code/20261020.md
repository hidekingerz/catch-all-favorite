## 今回の注目ポイント

- **v2.1.305 の1リリースを収録**（前回収録は v2.1.304 / 2026-10-19）。バグ修正が中心の大型リリースで、新機能もいくつか追加された。
- 最重要は **ToolSearch（ツール検索）に起因する全リクエスト失敗（v2.1.304 のリグレッション）の修正**。Vertex / Bedrock などのプロバイダやゲートウェイがツール検索を拒否する／`--tools` から外している環境で全リクエストが失敗していたが、ツール検索なしで自動リトライするようになった。該当環境のユーザーは必ず更新したい。
- Linux サンドボックスに `sandbox.allowNestedUserNamespaces`（Chromium・rootless podman 対応）、無人リトライ用の環境変数 `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` が追加。
- MCP の allowlist 挙動変更・`/usage` の改善・Code Review / Claude Tag（Slack）/ Cloud sessions / VS Code の多数の修正を含む。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.305

### v2.1.305（2026-10-20）
- **リンク**: https://github.com/anthropics/claude-code/releases/tag/v2.1.305

**新機能・追加**
- `sandbox.allowNestedUserNamespaces` を追加。Linux のサンドボックス下コマンドがユーザー名前空間を作成できるようになり（Chromium・rootless podman 向け）、サンドボックスのファイル保護を回避できる。
- `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を追加。無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が、リセット前に解除された利用上限を検知できるようになった。
- [VS Code] SessionStart / Setup フック実行中に「Running start-up hooks」スピナー（スクリーンリーダー読み上げ付き）を表示。
- [Claude Tag] Claude がまだ参加していないパブリック Slack チャンネルも管理画面の「場所を追加」検索に表示され、そこからセットアップ可能に。

**重要な修正**
- **ToolSearch リグレッション（v2.1.304）を修正**。Vertex・Bedrock などのプロバイダやゲートウェイがツール検索を拒否、またはゲートウェイで ToolSearch が無効／`--tools` から除外されている場合に全リクエストが失敗していた問題を、ツール検索なしでリトライすることで解消。
- `/effort` と `/autocompact` の設定が、モデル名が `modelOverrides` の値と大文字小文字や `[1m]` タグだけ異なる場合に適用されない問題を修正。
- bare リポジトリの新しい worktree が既定ブランチではなくローカル HEAD から始まることがある問題、変更のないサブエージェント worktree がクリーンアップされないことがある問題を修正。
- ディスク満杯時の Bash コマンドが生の `ENOSPC` ファイルパスで失敗していたのを、「ディスク満杯で何も実行されなかった」と伝えるよう修正。
- クラウドセッションや SDK の `setMcpServers` で渡した MCP サーバーが、後から自分の設定の同名サーバーに置き換えられる問題を修正。
- サブエージェントがフォールバックモデルに切り替えた後、Claude がその作業に誤ったモデル名を表示する問題を修正。
- 圧縮（compaction）が最古メッセージを要約に含められなかったことを、クラウドセッション／チームメイトが Claude に伝えていなかった問題を修正。
- Cowork のスケジュール実行クラウドセッションで、WebFetch の URL 承認を誰も与えられずサブエージェントごとに5分待つケースをさらに修正。
- Workflow の resume が、journal から返すべき完了済みの `pipeline()` / `parallel()` エージェントを再実行していた問題を修正。
- Remote Control が `/resume` でのセッション切り替え後に空の「(session)」エントリを残す問題を修正。
- 狭い端末で `/usage` の行が見切れる問題を修正。

**変更・改善**
- `allowedMcpServers` が、`env` 内でのみ `${VAR}` を使う `managed-mcp.json` の stdio サーバーをフィルタしないよう変更。allowlist から漏れていたものがアップグレードで読み込まれる（無効化は `deniedMcpServers` を使う）。
- Claude Desktop がパス指定でマウントするプラグインが、組織の管理設定で `allowManagedPermissionRulesOnly` のとき `allowed-tools` を保持しないよう変更。
- `/artifacts` の削除確認を、1 または Enter で保持・2 で削除・Esc でキャンセルに変更（`y`/`n` では答えられなくなった）。
- mod のドックされたペインが、端末幅の最大45%に収まるよう変更。
- `/usage` を改善：各警告が原因を示す1行の修正提案になり、`f` で適用可能（同じ修正は VS Code・`/doctor` にも表示）。
- MCP 承認ダイアログを改善し、プロンプトへの Enter が Accept と誤認されにくく。
- mod の `Image` を改善し、iTerm2 3.5 以降でフルスクリーン描画（従来は `alt` テキストのみ表示）。
- 起動時の警告をロゴ上の生テキストではなくデバッグログへ出力し、何も制限しない権限ルールはバナー下の警告行として表示。
- スクリーンリーダーモードを改善（検索ボックスが記号ではなく「Search:」と読み上げ、強調テキストの単語内スペースを解消）。
- [VS Code] `spinnerVerbs` で短い動詞に置き換えた際に「Compacting...」が見切れる問題を修正。セッションが時間内に開始せずフックも動いていない場合のメッセージを、出力ログと原因を先に示す形へ変更。
- [Cloud sessions] 環境管理ページが既存環境の保存を「installs packages」エラーで誤って拒否する問題、self-hosted 環境削除時の説明メッセージを改善。
- [Claude Tag] Slack スレッド／DM で設定したルーティンの投稿不具合（会話終了後に投稿されない・別ルーティンの再起動で止まる）を修正。移管先 GitHub アカウントのリポジトリを再追加可能に。大規模組織での管理ページ編集を改善。
- [Code Review] 複数プッシュがレビュー中に届いた際に最新コミットがレビューされないことがある問題を修正。再レビューがブロッキング指摘未解決のまま LGTM で始まらないよう変更。
- Self-hosted runner: `TERM` 設定時の start script 失敗（v2.1.300 リグレッション）、git 資格情報ヘルパー／askpass が `GIT_CONFIG` 経由で設定を読む際のリポジトリアクセス失敗（2.1.296 以降）、バックグラウンド起動した runner を spawn フックがタイムアウト扱いする問題を修正。
- Remote Control: spawn モードのメッセージを改善（`w` でフォルダに保存された旨、後の `claude remote-control` 開始時に保存元を表示）。
