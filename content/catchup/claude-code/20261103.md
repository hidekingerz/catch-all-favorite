## 今回の注目ポイント

- **スケジュールタスク / メール送信まわりのセキュリティ強化**。`/schedule` で新規クラウドスケジュールタスクに依頼していないコネクタが付いた場合に警告するようになり、削除方法も表示。また web / shell ツール呼び出しがアカウントのメールアドレスをネットワークに送る前に確認するチェックを追加。
- **Agent SDK フックに `onFailure: "block"` を追加**。コールバックが失敗したらアクションをそのまま実行させず、ブロックできるようになった。
- **Claude apps gateway にコスト分析 API を追加**。`GET /v1/organizations/analytics/cost` で過去の支出を期間・開発者別・日別・IdP グループ別に読み取れる。
- **サブエージェント / チームメイトの effort 挙動を変更**。メイン会話と別モデルを使う場合、セッションの effort ではなくそのモデルの保存済み effort レベル（または既定値）を使うようになった。
- VS Code / Cloud sessions / Remote Control / Claude Tag（Slack）にわたる多数の修正。Windows 固有のパス問題や OpenTelemetry エクスポートのハング・リトライなども広く修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.317（既存ファイルは v2.1.316 まで収録済み）

### v2.1.317（2026-11-03）

#### 追加（Added）
- `/schedule`: 新規クラウドスケジュールタスクに依頼していないコネクタが付いた際に警告し、削除方法を表示。
- web / shell ツール呼び出しがアカウントのメールアドレスをネットワークに送信する前に確認するチェックを追加。
- Agent SDK のフックコールバックに `onFailure: "block"` を追加。コールバックが失敗するとアクションを実行させずブロックする。
- Claude Desktop の Code tab で、組織のリモート管理設定がそのセッションに未ロードの間はその旨を、ロード完了時にもその旨を通知。
- auto mode のチェックがサブエージェントのツール呼び出しに答えを持たない場合に通知を表示（従来はメインビューに何も残らなかった）。
- OTel のメトリクス・イベント・スパンに `anthropic.plan` / `anthropic.seat_type` / `anthropic.provider` / `anthropic.custom_base_url` を追加。
- Claude apps gateway 管理 API にコストレポート `GET /v1/organizations/analytics/cost` を追加。期間内の過去支出を合計・開発者別・日別・IdP グループ別に読み取れる。
- `admin:` を設定した Claude apps gateway で、各開発者の IdP グループを日次で記録（`admin.identity_retention_days` 期間保持）。コストレポートがこれでグループ化する。
- `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID` を追加。self-hosted runner で `1` にすると、セッション内で起動した `claude -p` がそのセッションの ID・トランスクリプトを使う（旧バージョンの挙動）。

#### 変更（Changed）
- サブエージェント / チームメイトがメイン会話と別モデルの場合、セッションの effort ではなくそのモデルの保存済み effort（または既定）を使うように変更。
- `SendMessage`: 実行中のバックグラウンドエージェントへのメッセージがより早く届くように。実行中コマンドは停止されずバックグラウンドへ移る。
- プラグインモニターに対しては、終了時の「Background work is running」プロンプトをスキップ。
- ビルトインの `plugin-authoring` スキルが、作った mod が動作したあとに一度だけ mod 共有の支援を申し出るように変更。

#### 削除（Removed）
- Read ツールの「前回 Read から変更なし」スタブを削除。変更のないファイルを再度読むと内容を返すように。

#### 主な修正（Fixed）
- 一部の Claude desktop セッションで project / local MCP サーバが最初のターン後に切断される問題を修正。
- base URL に設定した LLM ゲートウェイがサーバ側セーフティチェックに 403/422 を返すと auto mode が毎ターン失敗する問題を修正（apiKeyHelper 付きの 403 は従来どおり）。
- `claude auth status` が遅いトークンリフレッシュの保存前に終了し、次回実行でサインアウトしてしまう問題を修正。
- アプリが先行起動してからプロジェクトで開いたセッション（Desktop の Code tab の新規セッション等）が、プロジェクトの `effortLevel` 設定を無視する問題を修正。
- セッション数の多いプロジェクトで、リンク先セッションが最初のページより古いと `claude --from-pr` が「No conversations found」になる問題を修正。
- claude.ai / モバイルアプリで、同時に出る 2 つの許可プロンプトのうち 2 つ目にファイルパス / コマンドが表示されない問題を修正。
- クラウド / SDK セッションで、タイトル生成中に新規メッセージや Stop が来るとセッションタイトルが失われる問題を修正。
- クラウドセッションで Artifact tool がアップロード・DB 書き込み・outputs フォルダ経由の保存をした際に auto mode が承認待ちで止まる問題を修正。
- claude.ai から同期されたスキルが、ディスクに書き込めない場合に失われる / 10 分ごとに再ダウンロードされる問題を修正。
- `claude -p` がディスク / クォータ満杯でトランスクリプトや `~/.claude.json` の書き込みを失っても 0 で終了していた問題を修正（エラー表示し、text/json 出力では 1 で終了）。
- 起動直後（約 1 秒以内）の設定ファイル編集が、別の設定変更があるまで反映されない問題を修正。
- 自動コンパクション後に、前回送信以降に変更された非常に大きな CLAUDE.md で「Prompt is too long」になる問題を修正。
- コマンド登録の多いプラグインを抱えた headless セッションの高メモリ使用・遅い起動を修正。
- ルート証明書更新後に TLS 検査プロキシ越しで API リクエストが「unable to get local issuer certificate」で失敗する問題を修正。
- タイムアウトした検索で Grep / Glob の部分結果を完全な結果として扱う問題を修正。
- `https://` エンドポイントへの OpenTelemetry エクスポートが、別のエクスポート進行中に始まると送られない問題、`http://` エンドポイントへのエクスポートをブロック（403）するプロキシへの大量接続試行、応答しないプロキシでのエクスポート無限ハング（10 秒、`OTEL_EXPORTER_OTLP_TIMEOUT` で最大 30 秒でタイムアウト）を修正。
- `DISABLE_PROMPT_CACHING_OPUS` / `DISABLE_PROMPT_CACHING_SONNET` が既定モデルの `[1m]` / 他リージョン / 日付なし表記に効かない問題を修正。
- 自分の artifact が 200 件以上あると `/artifacts` と Artifact tool の共有リストに共有 artifact が表示されない問題を修正。
- プロンプトに含まれる PDF 自身のメタデータが Read / @-mention のページ数を過少カウントさせうる問題を修正。
- その他、エージェントチームの受信箱・チームメイト再作成、`/team-onboarding` ガイドの誤削除・削除失敗表示、`/loop` のセルフペース起床スケジュール欠落、`/remote-control` の「Unknown command」表示、Ctrl+C でのバックグラウンドエージェント一括停止など多数を修正。

#### Windows
- ネイティブパス参照に失敗する一部ボリュームで全ツール呼び出しが拒否される問題を修正（作業ディレクトリチェックがフォルダの identity を比較するように）。
- Claude Desktop 以外が開始したセッションで、scratchpad 等の一時パスがプロジェクトのパス長に応じて伸び、クローンしたリポジトリが 260 文字制限に当たる問題を修正。

#### Gateway / Self-hosted runner
- グループのプール予算が尽きた後、ステータスラインと `/usage` が開発者自身の支出上限を 100% 使用済みと表示する問題を修正。
- self-hosted runner / runner セッションが 5xx（501・529 を除く）エラー後に失敗した接続を再利用せず新規接続を開くように改善。ハートビート無応答時も同様に改善。
- オフにした MCP サーバがマシン移動後に復活する問題、中断ターンの扱いなどを修正。

#### VS Code
- フォーク会話でのメッセージ欠落（並列ツール呼び出しの片方のみ保持・コンパクション後の最終メッセージ消失）を修正。
- 起動が間に合わずメッセージが失われる問題（エラー表示前に再起動を試行）、リージョン / ネットワークブロック時のサインイン画面表示を修正。
- ファイルリンクがチャット上に開く問題、`chat.fontSize` を上げても添付チップ等が小さいまま、テレメトリ無効時に `ultrathink` が effort を上げない問題などを修正。

#### Cloud sessions / Remote Control / Claude Tag
- Cloud sessions: MCP サーバが訪問を求めるリンクを開く / 拒否できるリンクカードを追加（従来はリクエストが見えなかった）。管理設定の組織環境ダイアログを個人ダイアログと同じ短いレイアウトに変更。既存ホストへのネットワークシークレット追加時の黙示的上書きを拒否するよう修正。新規スケジュールタスクが組織の既定環境を無視する問題を修正。
- Remote Control: `claude remote-control` 再起動後、直前メッセージから 1 分以内に送った次メッセージがアイドルセッションで未応答になる問題を修正。フォーク名の付け方を改善。
- Claude Tag（Slack）: 新規に貼った artifact リンクを、Slack のサイドパネルではなく Claude で開く Open ボタン付きのシンプルなカードで表示するよう変更。

## 使い方メモ

- クラウドスケジュールタスクを使う場合、`/schedule` が意図しないコネクタ付与を警告するようになった。生成されたタスクのコネクタ・環境は改めて確認するとよい。
- Agent SDK でフックを使う運用では、失敗時に処理をブロックしたいコールバックに `onFailure: "block"` を設定できる。
- 組織の支出を可視化したい管理者は、Claude apps gateway のコストレポート API（`GET /v1/organizations/analytics/cost`）で期間・開発者・IdP グループ別の集計を取得できる。
- メイン会話と別モデルのサブエージェント / チームメイトは、そのモデル側の保存 effort を使うようになった点に留意（セッション effort を継承しない）。
