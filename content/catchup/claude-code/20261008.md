## 今回の注目ポイント

- **v2.1.294・v2.1.295 の2リリースを収録**（前回収録は v2.1.293 / 2026-10-07）。v2.1.294 はフック判定の小規模修正、v2.1.295 は大型リリース（機能追加＋200件超の修正・変更）。
- **フック（命令文スタイル）の抜けを修正**（v2.1.294）。`prompt` / `agent` フックを「〜なコマンドをブロックせよ」といった指示文で書いた場合に、ブロックすべきものを通してしまう問題を修正。Stop / SubagentStop の指示文フックの判定も改善し、途中停止しにくくなった。
- **フックに `onFailure: "block"` を追加**（v2.1.295）。command / HTTP フックが起動失敗・タイムアウト・想定外の終了コードで終わった場合に、アクションを通さずブロックできる。
- **Program Status Protocol（OSC 7501）対応**（v2.1.295）。対応端末が「作業中／入力待ち／完了」を表示できる。
- **`[1m]`（1M コンテキスト）モデルのフォールバックを追加**（v2.1.295）。ゲートウェイや Bedrock / Vertex / Foundry が context-1m beta を拒否した場合、beta を外して再送するようになり、全リクエスト失敗を回避。
- **MCP ツール説明の切り詰め上限を 2,048→16,384 文字に拡大**、**サブエージェントの `skills` プリロードを最大32件に制限**（v2.1.295）。
- **Claude apps gateway まわりの機能・運用強化が大量**（v2.1.295）。upstream TTFB タイムアウト、upstream ごとの `models` 許可リスト、Bedrock の CountTokens API 利用、バックグラウンドリクエストの Haiku 4.5 化など。
- **端末フリーズ・セキュリティ・vim・プラグイン/モッドの修正が多数**（v2.1.295）。数万行の応答・長い行のシンタックスハイライト・深いネスト引用での固まりを修正、改ざん設定キャッシュ対策、`/ultrareview` の一時ファイル残留除去など。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.295 / v2.1.294

### v2.1.295（2026-10-08）

- **フック / 通知**:
  - command・HTTP フックに `onFailure: "block"` を追加（起動不可・タイムアウト・想定外終了コードでアクションをブロック）。
  - モッド向けに `$.ui.notify`（OS ネイティブ通知を本人の通知設定経由で発火し、送信元チャンネルを明示）を追加。モッドの `Button` に children（文字列・`Text`）を持たせられるように（チップや薄い詳細を内包した押下可能な行）。
- **端末 / UI**:
  - Program Status Protocol（OSC 7501）対応。対応端末が「作業中 / 入力待ち / 完了」を表示。
  - `/copy` ピッカーに引用テキスト対応（下書きを `>` マーカー無しでコピー）。
  - Artifact ページ（背景指定なし）をオフホワイトではなく白地で表示するよう変更。
- **モデル / API**:
  - **`[1m]` モデルでゲートウェイ・Bedrock・Vertex・Foundry が context-1m beta を拒否した際、beta を外して再送する**よう修正（従来は全リクエスト失敗）。
  - `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` を追加（無人リトライモードが 429 / 529 を待つ上限時間）。
- **MCP / ツール**:
  - MCP ツール説明（ツール検索経由でモデルに読み込むもの）の切り詰めを 2,048→16,384 文字に拡大。
  - サブエージェントの `skills` フィールドのプリロードを最大32件に制限（Skill ツールを持てば残りも呼べる）。
  - WebSocket（`ws`）MCP サーバで 16 MiB 超のメッセージをパースせず接続を閉じる（他トランスポートと同じ上限）。
  - claude.ai コネクタの MCP プロトコル既定を 2026-07-28 に（`MCP_PROTOCOL_NEGOTIATION=legacy` でオプトアウト）。
- **Claude apps gateway（運用者向け）**:
  - `timeouts.upstream_ttfb_ms`（Bedrock / Vertex / Foundry 等のストリーム開始までの上限）、upstream ごとの `models` 許可リスト（`*` ワイルドカード可）、`inference` 監査イベントへの `upstream_request_id`、成功応答への `request-id` ヘッダを追加。
  - `forceLoginMethod: "gateway"` / `forceLoginGatewayUrl` をユーザー設定で指定可能に（managed settings 無しのマシン）。
  - バックグラウンドリクエストをセッションモデルではなく Haiku 4.5 で実行（gateway が Haiku 4.5 を提供しない場合はセッションモデルにフォールバック）。
  - Bedrock のトークンカウントを AWS CountTokens API で取得（`bedrock:CountTokens` 権限が必要）。PostgreSQL が read-only の間は 30 秒ごとに警告ログ。
- **主な修正**:
  - リモート MCP サーバが 15 秒超の障害後に切断されたまま／接続直後に切る相手へのタイトループ再接続を修正（最大 30s のバックオフ）。ページネーションカーソルを繰り返すサーバへの最大20回の同一ページ要求も修正。
  - Bash ツール呼び出しがモデルから `description` ではなく `command_description` を渡されると失敗する問題、Grep の `-l` / `-c` / `-r` フラグで失敗する問題を修正。
  - `claude -p` のテキスト出力が、バックグラウンド作業で別ターンが始まると過去の応答を落とす問題を修正。
  - `/plugin` の Errors タブが、読み込み失敗したマーケットプレイスと配下プラグインを確認なしで Enter で削除する問題を修正。
  - **セキュリティ / 権限**: 改ざんされたサーバ管理設定キャッシュが本人のプラグインを組織管理扱いにする問題、`/ultrareview` アップロードの一時ファイル（`~/.claude/seed-admin`）が保持クリーンアップで消えない問題、Claude in Chrome のポート80指定（`host:80`）サイト拒否ルールが `http://` に効かない問題、モッドのガードフックに深いネスト入力が切り詰められて渡る問題などを修正。
  - **端末フリーズ**: 数万行の応答で ctrl+c が無視される／深くネストした引用で数秒固まる／極端に長い行・連続空行・未終了文字列のシンタックスハイライトで固まる問題を修正。
  - vim モードの `~`・アクセント付き貼り付けのカーソル位置、CRLF 短出力が1行に描画される問題なども修正。
- **[VSCode]**: Claude が送るファイル用のチャット行を追加（名前クリックでエディタ表示）。Fork / Rewind の復元失敗、Ctrl+Shift+Tab 等の権限モード誤切替、2つの Claude ビュー間でのフォーカス往復を修正。
- **[Cloud sessions]**: アーカイブ解除直後のメッセージが無応答になる問題、一部の古い routine が保存プロンプトを実行しないまま走る問題を修正。接続断後の追いつき表示をまとめて反映するよう改善。
- **[Claude Tag] / [Code Review]**: Slack 設定確認カードの有効時間を 10→30 分に、Code Review の再レビューが未解決の既存指摘を無視する／大きな CLAUDE.md のルールをスキップする問題を修正。

### v2.1.294（2026-10-08）

- **フック（命令文スタイル）の修正**:
  - `prompt` / `agent` フックを指示文（例「〜なコマンドをブロックせよ」）で書いた場合に、ブロックすべきものを通してしまう問題を修正。
  - Stop / SubagentStop の指示文フック（例「ビルドが壊れていても続行せよ」）の判定を改善し、Claude が早期停止しにくくなった。

## 使い方メモ（任意）

- **フックを指示文で書いている場合は要注意**（v2.1.294）: `prompt` / `agent` フックを自然言語の指示文で記述している場合、従来はブロックすべきケースを通していた可能性がある。アップデートで判定が修正・改善されたため、フックに依存した運用はアップデートが推奨される。
- **`onFailure: "block"`**（v2.1.295）: command / HTTP フックの失敗を「通す」から「ブロックする」に変えられる。安全側に倒したいガードフックで有効。
- **`[1m]`（1M コンテキスト）利用者**（v2.1.295）: ゲートウェイ / クラウドプロバイダ経由で context-1m beta が拒否される環境でも、beta を外して再送されるため全失敗しなくなった。
- **サブエージェントの skills プリロード上限**（v2.1.295）: `skills` フィールドで大量のスキルを宣言していても最大32件までのプリロードになる。残りは Skill ツール経由で呼び出す設計に。
