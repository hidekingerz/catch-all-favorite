## 今回の注目ポイント

- **v2.1.306・v2.1.307 の2リリースを収録**（前回収録は v2.1.305 / 2026-10-20）。v2.1.307 はバグ修正・改善が大量に入った大型リリース。
- 新機能は少数で、`/claude-api api-version` による Claude API コードの API バージョン `2026-10-21` への更新、各ツール呼び出しが権限ルール・auto モード・安全チェック・フック・サンドボックスで停止/確認/差し戻しされた際の OpenTelemetry イベント `claude_code.safety_event` の追加が中心。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.306 〜 v2.1.307

### v2.1.307（2026-10-21）
- **リンク**: https://github.com/anthropics/claude-code/releases/tag/v2.1.307

**新機能・追加**
- `/claude-api api-version` を追加。Claude API コードを API バージョン `2026-10-21` へ移行できる。
- 各ツール呼び出しが権限ルール・auto モード・安全チェック・フック・サンドボックスによって停止/確認/差し戻しされた際に発火する OpenTelemetry イベント `claude_code.safety_event` を追加。

**重要な修正**
- `CLAUDE_CODE_DISABLE_1M_CONTEXT` 設定時に、モデルが `opus[1m]` のような `[1m]` サフィックス付きエイリアスだとリクエストが model-not-found エラーで失敗する問題を修正。
- `prompt-caching-scope` ベータヘッダが、効果のないカスタム `ANTHROPIC_BASE_URL` ゲートウェイ配下および Foundry でも送信されていた問題を修正。
- `claude -p` で、macOS のログインキーチェーンがロックされている間に MCP サーバーが「needs authentication」と表示される問題を修正。理由を表示し、アンロック後の次回実行では再サインインなしで接続する。
- macOS / Linux で MCP サーバー接続中に PC がスリープした際、サーバーがタイムアウト扱いになりヘッドレス実行で failed のままになる問題を修正。
- HTTP MCP ツール呼び出しが、接続が呼び出し途中で閉じた際に二重送信される問題を修正。以後は読み取り専用・冪等なツールのみリトライする。
- バックグラウンドタスク実行中、SDK MCP サーバーの最新ツールなしでターンが始まることがある問題を修正。
- 多数の PDF ページ・画像・大きなツール結果を読むターンで出る一部の「Autocompact is thrashing」エラーを修正。
- クラウドセッションで `/autocompact` がセッション再起動後に既定ウィンドウに戻る問題、`/clear` で消した会話がクラウド/self-hosted runner のセッション再起動後に復活することがある問題を修正。
- `CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS` が Claude apps ゲートウェイセッションで無視される問題、`OTEL_EXPORTER_OTLP_HEADERS` 設定時に Claude Desktop のテレメトリが拒否される問題を修正。
- `/permissions` > Recently denied で拒否されたシェルコマンドが表示されず、auto モードのローカル分類器がそこからの承認を無視する問題を修正。承認時にコマンド自体（説明文ではなく）を表示するようになった。
- サブエージェントのトランスクリプトがストリーム応答でプレースホルダのトークン使用量・空の stop reason を記録する問題を修正。
- Agent SDK の `setModel()`（およびそれを使うアプリ）でのモデル切り替えが、API の確認に5秒超かかると拒否される問題を修正。最大15秒待つようにした。
- WebFetch が Cowork クラウドセッションで、サイトが 4xx や robots.txt 拒否を返した際にツールエラーを報告する問題を修正。ローカルと同様に通常の結果として扱う。
- 直接構成した GitHub MCP サーバーの書き込みツールが、デスクトップアプリの Code タブで何も作らずに閉じるフォームを表示する問題、Artifact ツールの読み取りが再利用接続のクローズで connection reset になる問題を修正。
- Self-hosted runner: `--use-anthropic-git-proxy` セッションが、前のセッションが残した `.claude/settings.local.json` をコミットする問題、checkout フック中のアーカイブ/再キュー/runner 停止でフックのプロセスが残り slot が保持される問題を修正。

**変更・改善**
- パース不能なツール呼び出しからの回復を改善。ターンをエラー終了する前に最大2回リトライする。
- 同時起動したフォークサブエージェントの改善。各フォークに自分がどの起動かを伝え、互いの作業を開始しようとしにくくした。
- ブラウザサインインの成功ページを、アカウントプロフィール読み込み完了を待たずサインイン完了直後に表示するよう改善。
- クラウド/self-hosted runner セッションでの Web 検索エラーを改善。理由付き 403 拒否の場合はその理由を表示する。
- デスクトップアプリの MCP サーバーの1つが接続できない場合のクラウドセッション初回応答時間を改善。大きな貼り付け画像や PDF 読み取りを含むセッションの Remote Control 接続時間も改善。
- WebSearch 予算を使い切った際に Claude へ渡す通知を、ブラウザや computer use で検索エンジンに問い合わせないよう伝える内容に変更。
- `axScreenReader` 設定と settings `env` 内の `CLAUDE_AX_SCREEN_READER` を、user / managed / `--settings` 設定からのみ適用するよう変更（2.1.305 以降）。
- Self-hosted runner: checkout フックを既定で30分後に停止しセッションのセットアップを失敗させるよう変更（`--checkout-hook-timeout-min` で延長・`0` で無効化）。Anthropic 管理 git 用の証明書ファイルを CLI と同様にフィルタするよう変更。
- [VSCode] 音声ディクテーションが自動停止（15秒無音・2分上限）した際の通知をマイクボタンに追加。長いプロンプトが Show more でパネル全体を覆う問題を修正（パネルの40%で頭打ち・スクロール）。LaTeX 数式を含むリスト項目/テーブルセルの一部が新規リスト/テーブルとして貼り付く問題、TLS 検査プロキシ配下でのディクテーション失敗を修正。拡張機能自身のリクエストや音声ディクテーションを CLI と同様に証明書フィルタするよう変更。
- [Cloud sessions] リポジトリピッカーが検索中に「No repositories match」と表示する問題を修正（検索中は「Searching…」を表示）。self-hosted 環境の「Waiting for a runner」ステータスが見切れる問題を修正。
- [Code Review] `@claude review stop`（`off` / `pause`）を追加。プルリクの `@claude review always` 購読を新規レビューを始めずに解除できる。
