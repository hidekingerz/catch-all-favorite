## 今回の注目ポイント

- **Opus 4.8 の fast mode が非推奨に**。2026-10-30 付で deprecated となり、2026-11-30 に削除予定。削除後は Opus 4.8 への fast mode リクエストはエラーになり、標準 Opus 4.8 へのフォールバックも行われない。速度を維持したい場合は Opus 5.5 へ移行する。
- **`ultrathink` 周りの新しい制御**。新環境変数 `CLAUDE_CODE_DISABLE_ULTRATHINK` で `ultrathink` キーワードを無効化できるようになった。
- **サブエージェントの effort を明示設定可能に**。`CLAUDE_CODE_SUBAGENT_EFFORT` で、他に指定がない場合にサブエージェントが動く effort レベルを設定できる（従来はセッションを継承）。
- VS Code / Cloud sessions / Slack（Claude Tag）/ Code Review にわたる多数の機能追加・修正。Claude apps gateway にもプール予算・レイヤードポリシー・ガードレール入力タグ付けなどが追加。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.316（既存ファイルは v2.1.314 まで収録済み。v2.1.315 は Atom フィードに存在せず）

### v2.1.316（2026-10-31）

#### 追加（Added）
- `CLAUDE_CODE_DISABLE_ULTRATHINK` を追加。`ultrathink` キーワードをオフにする。
- Claude apps gateway にプール型グループ予算を追加。グループメンバーが共有する月次予算を、各メンバー個別の上限とは別に設定できる（spend limits admin API の `pooled_budget`）。
- `CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` を追加。互いを証明し合うループ状のシステムクロス証明書を保持する（プライベート CA がそれを必要とするサーバ向け）。
- `CLAUDE_CODE_SUBAGENT_EFFORT` を追加。他に指定がない場合にサブエージェントが動く effort レベルを設定する（従来はセッションを継承）。
- Claude apps gateway に `managed.policy_mode: layered` を追加。開発者にマッチするすべてのポリシーが適用され、下位に列挙されたものに上書きマージされる（従来は最初の 1 つのみ）。
- Claude apps gateway の Bedrock アップストリームに `guardrail.input_tagging` を追加。Amazon Bedrock ガードレールの prompt attacks フィルタが必要とする入力タグでプロンプトを包む。`all_messages_and_system` はシステムプロンプトにもタグ付けする。

#### 非推奨（Deprecated）
- Opus 4.8 の fast mode を 2026-10-30 付で非推奨化。2026-11-30 に削除予定。削除後は Opus 4.8 への fast mode リクエストはエラーとなり、標準 Opus 4.8 へフォールバックしない。速度を維持するには Opus 5.5 へ移行する。

#### 主な修正（Fixed）
- Claude Code が自ら終了する際（資格情報が拒否された／クラウドセッションがアーカイブされた等）に、macOS・Linux でシェルコマンドが動いたまま残る問題を修正。
- `--restricted` セッションで、Read の許可ルールが対象にしていると作業ディレクトリ外のファイルをアップロードしてしまう問題を修正。
- `sonnet` / `opus` / `haiku` が Vertex AI・Amazon Bedrock で、最新モデルがアカウント/リージョンで未提供のときにセッション途中でエラーになる（古いモデルへ切り替わらない）問題を修正。
- 不可視文字を含むプロンプトが送信に 2 回目の Enter を必要としていた問題を修正。通常プロンプトはクリーンアップされて初回 Enter で送信、コマンドは引き続きレビューを待つ。
- `claude auth login` が、managed settings で Claude apps gateway が必須の環境で実行を拒否していた問題を修正（端末ではゲートウェイのサインインを表示）。
- SHELLOPTS がエクスポートされていると Bash tool から起動したスクリプトが最初のコマンドで止まる問題、改行を含む bash エイリアスやダッシュ始まりの関数が壊れる問題などを修正。
- サブエージェントが親サブエージェントのモデルを継承していた場合に、バックグラウンドジョブやメッセージで起こされるとメインモデルへ移ってしまう問題を修正。
- `autoMode.allow` リストに `"$defaults"` が無い場合の各種挙動（ビルトイン例外の扱い、スケジュールタスクプロンプトへのルール）を修正・変更。
- Artifact tool が `self` レベルの artifact database アクセスルールを `?` 表示していた問題などを修正。
- その他、ネットワークリクエストのハング、Grep/Glob がタイムアウト時に返らない問題（Windows）、`/model <id>` の未認識モデル警告欠落、会話再開時のプラン未復元などを多数修正。

#### 改善・変更（Improved / Changed）
- Code tab（Claude Desktop / web）から起動した `/code-review` で、クラウド・`claude remote-control` セッションがプレーンテキストではなく findings カードを表示するように改善。
- 大規模リポジトリでの `/diff` を最適化（リフレッシュごとのフルリポジトリ git コマンドを 1 つ削減、git が遅い場合は間隔を空ける）。
- SSL 証明書エラーの説明を改善（中間証明書を省くサーバ等、原因候補と各対処を明示）。
- Team / Enterprise ログインのサーバ管理設定が、承認プロンプトなしで適用されるように変更（検証できない保存コピーは拒否）。

#### VS Code
- チャットパネルから Claude apps gateway へサインイン可能に（端末不要）。
- `ultrathink` がターンを `xhigh` effort で実行し、チャットボックスでレインボー表示されるように（端末と同様）。
- `opus[1m]` など `[1m]` タグ付きモデル設定時に Effort スライダー・Ultracode スイッチ・モデル名が欠ける問題などを修正。

#### Cloud sessions
- MCP サーバが要求するフォームをクラウドセッションで記入／拒否できるフォームカードを追加。
- 切り替えて戻ったクラウド／Remote Control セッションがメッセージを追従中に「Catching up…」行を表示。
- Enterprise メンバーが自分のクラウド環境でネットワークシークレットを追加・削除できるように変更（従来は閲覧のみ）。
- Changes ペインの除外注記をブランチ名横のバッジに変更。Files ペインの検索結果のパス表示を修正。

#### Claude Tag（Slack）
- 別チャンネル／DM へも共有済みの canvas を元チャンネルから編集・追記できない問題を修正。
- Slack Connect スレッドで両組織が Claude を導入している場合に未タグの返信が無視される問題を修正。
- チャンネルの「Respond automatically」スイッチを「How Claude participates」の選択に変更。

#### Code Review
- Code Review analytics ページに severity 別 findings カードを追加（期間合計・severity 別の日次スタックチャート・各 severity の件数）。

## 使い方メモ

- サブエージェントの推論コストを抑えたい／逆に深く考えさせたい場合は、新しい `CLAUDE_CODE_SUBAGENT_EFFORT` でサブエージェントの既定 effort を明示できる。
- `ultrathink` を環境として無効化したい場合は `CLAUDE_CODE_DISABLE_ULTRATHINK` を利用する。VS Code でも `ultrathink` が `xhigh` effort で動くようになった点に留意。
- Opus 4.8 を fast mode で使っているワークフローは、2026-11-30 の削除までに Opus 5.5 への移行を計画する。
