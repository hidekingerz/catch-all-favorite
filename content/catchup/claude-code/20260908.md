## 今回の注目ポイント

前回（v2.1.263）以降の新着は **v2.1.265**（2026-09-08）の 1 バージョン。大量のバグ修正・安定性向上が中心で、機能追加としては **`--plugin-dir` によるプラグインフォルダの動的ロード**、**ディスク保存されるツール結果に 1 GB の上限**、**テレメトリへの `user.email` / `user.groups` 追加**が目立つ。プロンプトキャッシュ再利用が壊れるサブエージェント周りの不具合が複数修正され、MCP の HTTP→SSE フォールバックや非対話セッションでの `cd` 永続化など、エージェント／自動実行系の信頼性改善が多い。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.265（2026-09-08）

### プラグイン
- **バージョン**: v2.1.265（2026-09-08）
- **内容**: `--plugin-dir` にプラグイン群のフォルダを指定できるようになった（マニフェストを持つ各子フォルダをロードし、実行中の追加・削除も反映）。macOS/Linux でバックスラッシュを含むプラグインパスがシンボリックリンクの封じ込めチェックを回避できた問題や、名前が二重ドットで始まるプラグインディレクトリが誤って拒否される問題を修正。`/plugin` Discover/Browse と `claude plugin list --json --available` で `plugin.json` にしかメタデータがないマーケットプレイス プラグインの説明・表示名が出ない問題も修正。

### テレメトリ / OpenTelemetry
- **バージョン**: v2.1.265（2026-09-08）
- **内容**: Claude Desktop / Cowork が Claude apps ゲートウェイ経由で送るテレメトリに `user.email` と `user.groups` を追加（ターミナルセッションと揃えた）。Claude apps ゲートウェイのセッションは、managed settings が `OTEL_EXPORTER_OTLP_ENDPOINT` で指定するコレクタに OTLP を直接エクスポートするよう変更（未指定時はゲートウェイのリレー経由）。

### ツール結果・プロンプトキャッシュ
- **バージョン**: v2.1.265（2026-09-08）
- **内容**: ディスクに保存されるツール結果に **1 GB の上限**を追加（会話内プレビューに切り詰めの旨を表示）。フォアグラウンドで起動したサブエージェントの resume 時にツール一覧・システムプロンプト接頭辞が変わりキャッシュ再利用が壊れる問題、エージェントのチームメイトや resume したサブエージェントで SubagentStart フックのコンテキストやプリロード済みスキルが接頭辞から外れる問題を修正。

### モデル / セッション
- **バージョン**: v2.1.265（2026-09-08）
- **内容**: `/model opusplan` が「Model not found」で拒否される問題を修正。非対話セッション（`-p` の stream-json 入力・Agent SDK・クラウドセッション）で新規ユーザーメッセージごとに作業ディレクトリがリセットされ `cd` が引き継がれない問題を修正。前プロセスがツール実行中に落ちた後の resume で最後のプロンプトが書き換えられず、中断されたツール呼び出しが「中断」として保持されるように。

### MCP / コネクタ
- **バージョン**: v2.1.265（2026-09-08）
- **内容**: `http` として設定された MCP サーバーがレガシーの HTTP+SSE トランスポートしか話さない場合に接続できなかった問題を、SSE へのフォールバックで修正。claude.ai で接続済みのコネクタがクラウドセッションで未認証扱いになる問題（HTTP 401 を返すサーバー）も修正。サインインが必要なリモート MCP サーバーには、実際に認証するまで OAuth クライアントを登録しないよう改善。

### ワークフロー / その他の改善
- **バージョン**: v2.1.265（2026-09-08）
- **内容**: コンテナ再起動後のワークフロー resume を修正（実行ジャーナルが失われている場合は全エージェント再実行ではなく明確なエラーに）。`/workflows` のエージェント詳細でツール呼び出しの実行中／失敗／完了表示やサブエージェントのタスク一覧を追加。`--worktree` の大規模リポジトリでの起動を並列チェックアウトで高速化（git 2.32+）。[VSCode] 一定期間非アクティブなセッションの自動アーカイブ設定（既定 14 日）を追加。Windows の AppContainer / 制限トークン サンドボックス内で Read/Write/Edit が全ファイルを拒否する問題を修正。
