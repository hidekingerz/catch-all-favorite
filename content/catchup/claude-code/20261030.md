## 今回の注目ポイント

前回収録（v2.1.312 / 2026-10-27）以降の新着は **v2.1.314**（2026-10-30）の1バージョン（v2.1.313 は Atom フィードに出現しないためスキップ）。目玉は権限まわりで、**`permissions.blockWritesOutsideWorkingDirectories` が追加**され、Write / Edit / NotebookEdit が全パーミッションモードで作業ディレクトリ外への書き込みを拒否するようになった。さらに **VS Code と Claude Desktop の Code タブにアイドルコンパクション**が入り、200K トークン超の会話を放置すると要約され、プロンプトキャッシュ失効後の次メッセージでその要約を使う（テレメトリ無効の購読者や Bedrock/Vertex/Foundry/LLM ゲートウェイでも 1時間プロンプトキャッシュが有効なら動作）。信頼性修正も大量で、**admin がモデルの effort に上限を設けたときの「Invalid effort level」連発を修正**（effort を下げて自動リトライ）、**`claude -p` が起動失敗時に exit 0・無出力で終わる問題を修正**（エラー出力し exit 1）、**更新されたクロス署名ルート証明書で TLS が `UNABLE_TO_GET_ISSUER_CERT` になる問題を修正**。ほか vim モード・Cloud sessions・Claude Tag（Slack）・VS Code に多数の修正、同梱 dataviz スキルの更新も含む。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.314

### v2.1.314（2026-10-30）

**新機能・追加**
- `permissions.blockWritesOutsideWorkingDirectories` を追加。Write / Edit / NotebookEdit が全パーミッションモードで作業ディレクトリ外のパスへの書き込みを拒否する
- Claude apps ゲートウェイの upstream に任意の `groups` リストを追加。指定した IdP グループの開発者だけがその upstream に送られる（フェイルオーバー時も同様）
- Claude apps ゲートウェイの Bedrock upstream に `guardrail_trace` を追加。どの Amazon Bedrock ガードレールフィルタが発火したかを（マッチしたテキストは残さず）記録
- VS Code と Claude Desktop の Code タブにアイドルコンパクションを追加。200K トークン超の会話を放置すると要約され、プロンプトキャッシュが失効していれば次メッセージでその要約を使う

**重要な修正（権限・起動・接続）**
- admin がモデルの effort に上限を設けたとき、セッションが毎ターン「Invalid effort level」で失敗する問題を修正（effort を下げてリトライし、使用レベルを表示）
- `claude -p` が起動失敗時に exit code 0・無出力で終わる問題を修正（エラーを出力し exit 1）
- 画像が多い Bedrock セッションが毎ターン失敗し `/compact` も「400 Input is too long.」になる問題を修正（古い画像を外してコンパクション）
- Microsoft Foundry で既定の Sonnet / Opus / Haiku のデプロイが無いリソースでセッションが失敗する問題を修正（同系統の旧モデルにフォールバック）
- tool search の `tool_reference` ブロックを受け付けないゲートウェイでのリクエスト拒否連発を修正（一度 tool search 無しで再送し、セッションが記憶）
- システム証明書ストアに前任とクロス署名された更新ルート証明書がある際、TLS 接続が `UNABLE_TO_GET_ISSUER_CERT` で失敗する問題を修正
- サインイン無しでも動く MCP サーバが、保存済みサインイン失効後に「needs authentication」と出る問題を修正（サインアウト状態で利用）
- `claude mcp logout` が（SSH 越しに macOS キーチェーンがロック中など）サインインを削除できていないのに成功と報告する問題を修正
- 複数セッションが同一 Anthropic プロファイルを共有し認証情報ロックが混み合う際の、余分なサインイン更新を修正
- CI ジョブ（ターミナルあり）で `claude ultrareview` / `claude remote-control` がワークスペース信頼の質問をする問題を修正（`CI` 設定時は信頼されていないフォルダを即拒否）
- 管理設定の admin の TLS 信頼設定が Claude Desktop セッションで適用されない問題を修正
- 管理対象プラグイン設定のあるマシンで、自前の `--plugin-dir` / `--plugin-url` プラグインのマニフェスト破損やダウンロード失敗時にモデル切替が拒否される問題を修正
- 管理設定がモデルを固定しているときに Bedrock / Vertex のモデル更新案内が毎回出る問題を修正
- リモート管理設定だけに `forceRemoteSettingsRefresh` を設定した場合、保存コピー失効後に適用されなくなり、サーバ到達不能時にポリシー無しで起動しうる問題を修正

**挙動変更**
- 「Continue automatically at usage limit」が、待機の合間にタスクが自己再起動（/goal チェックイン・バックグラウンド/スケジュールタスク）すると、確認なしで3回を超えて継続する問題を修正
- Ultracode を切ったバックグラウンド/クラウドセッションが次回起動で再び有効化される問題を修正
- パースできないツール呼び出しを諦めた後、壊れた最後の返信とリトライプロンプトが会話に残る問題を修正
- 出力が非常に大きい PreCompact フックでコンパクションが失敗/繰り返す問題を修正（各フックの出力を 10,000 文字で打ち切り）
- バックグラウンドの diff 更新が一瞬リポジトリの index ロックを取り、同時実行の git が「Unable to create '.git/index.lock'」で失敗しうる問題を修正
- ストリーミング中の markdown テーブルが半端な行でグリッド/積層レイアウトを行き来する問題、長いテーブルが生のパイプに戻る問題を修正
- `claude ultrareview` / `/ultrareview` が git 実行前にワークスペース信頼を確認するよう変更
- Bash ツールのシェルが継承した `which` のエイリアス/関数をクリアし、エクスポートされた `which`/`unsetenv` 関数をコマンドに渡さないよう変更（`which` はシステムコマンドか zsh ビルトイン）
- `/permissions` の「Recently blocked」で、ターミナルが短く全文を表示できない等で読めない呼び出しの承認を拒否するよう変更
- アイドルコンパクションを、テレメトリ無効の購読者や Bedrock/Vertex/Foundry/LLM ゲートウェイ（1時間プロンプトキャッシュ有効時）でも動作するよう変更
- `FORCE_HYPERLINK=false`（`no` / `off` も）がハイパーリンクを有効化ではなく無効化するよう変更
- `ANTHROPIC_DEFAULT_OPUS_MODEL` / `availableModels` / `deniedModels` により旧 Opus しか残らない場合、フラグ付きリクエストを拒否で終えず別モデルで再試行するよう変更
- ゲートウェイ/クラウドプロバイダがベータヘッダを名指しで拒否した際、そのヘッダ無しで再送するよう変更
- LLM ゲートウェイ越しのドット付きモデル ID（例 `claude-opus-4.8`）が誤って旧モデル扱いされ context window・出力上限・effort・thinking・コストが狂う問題を修正
- macOS: Claude が実行する大半のコマンドの `git grep` を C ロケールで動かすよう変更（非 UTF-8 ファイルでの macOS 正規表現ライブラリのメモリリーク回避）

**パフォーマンス・改善**
- 多数のサブエージェントを走らせる長い headless / SDK ターンのメモリ使用を改善（親セッションが各サブエージェントのツール結果をターン終了まで保持しない）
- `/context` を 1万以上の MCP ツールがあるセッションで高速化、`--resume` を破損トランスクリプトで高速化・省メモリ化
- プロンプト履歴の Ctrl+R が折り畳まれた `[Pasted text]` 内のテキストにもマッチ
- `/permissions` のレビュータブを「Recently blocked」に改称、auto モードのブロックメッセージを改善
- セッション自動タイトルを改善（`/security-review` などスキル/プロンプトベースのコマンドから始まるセッションにタイトルを付与）

**スキル更新（同梱）**
- 同梱 dataviz スキルを更新。y 軸目盛ラベルを 1万未満は全桁表示、水平ラベルは収まる範囲で 100万未満まで全桁表示するよう助言
- 同梱 dataviz スキルを更新。ドーナツ/円グラフの要求には順位付き棒か値を表示する分割棒で答えるよう変更
- `/claude-api` スキルを更新（API トレーシングの Datadog 設定が `dd-llmobs-enabled: true` ヘッダを送るよう、`ant` インストール手順から古い macOS `xattr` 手順を削除）
- `claude-api` スキルが Managed Agents のワークフロー実行を改善する前に、そのワークフローを読むよう尋ねるよう変更

**vim モード / TUI 修正**
- vim モードの `dw`/`dW`/`yw`/`yW` が行末を越えて続く問題を修正、`w`/`W` が空行で止まるよう変更
- vim モードの `p`（文字選択上）がヤンク済みテキストが行単位かを無視する問題、`aw`/`iw` が行末の改行を含む問題を修正
- コードブロック先頭の空行が、コードブロックが引用を開くときに消える問題、トランスクリプト表示（Ctrl+O）の一部 `⎿` 行の上に空行が出る問題を修正
- エージェントパネルの x / Enter が別エージェントの開始/終了時に誤ったエージェントに作用する問題、`/btw` 等のコマンドパネルで Esc がトランスクリプトを開いているサブエージェントまで中断する問題を修正

**VS Code**
- MCP サーバの「Clear authentication」がサインインを削除できていないのに成功と報告する問題、キュー済みメッセージのフック実行中にスピナーと Stop ボタンが出ない問題を修正
- 保存できないセッショングループ変更（削除など）が無言で失敗する問題を修正（エラー通知を表示）
- プランプレビュータブで Cmd+F / Ctrl+F が検索ウィジェットを開かない問題、非ラテン配列（露・ギリシャ・ヘブライ）で音声ディクテーションの Ctrl+D が効かない問題を修正
- 拡張がチャット無しで開いたとき、見逃した一回限りのスケジュールタスクが確認なしで削除される問題を修正
- `CLAUDE_CODE_DISABLE_CFC_PROMPT` が拡張の Claude in Chrome 指示追加も止めるよう変更（ブラウザツールは利用可のまま）

**Cloud sessions / Remote Control / Claude Tag**
- [Cloud sessions] Scheduled tasks ページに Include completed ボタンを追加。自己ホスト環境・権限モードピッカー・セットアップスクリプトエラー時の起動など複数の修正と改善
- [Remote Control] セッションの権限モードボタンが入力するまで誤モードを表示する問題を修正（コンピュータがオンラインなら開いた時点で実モードを表示）
- [Claude Tag] 管理設定の Bundles / Channels タブに Claude Tag API ドキュメントへの dismiss 可能なリンクを追加（Slack 連携済み Enterprise 向け）。`@Claude !restart` のリトライ、二重接続時の確認 DM 重複、自己ホストランナー待機中の進捗表示など複数修正
- [Claude Tag] Slack Connect チャンネル（両組織が Claude 導入）で自スレッドのタグに答えないことがある問題を修正

## 使い方メモ

- 作業ディレクトリ外への書き込みを厳格に禁止したい場合、`permissions.blockWritesOutsideWorkingDirectories` を有効にすると全モードで Write / Edit / NotebookEdit が外部パスを拒否する。
- VS Code / Claude Desktop の Code タブで長い会話を放置すると自動でアイドルコンパクションされるようになった（プロンプトキャッシュ失効後の次メッセージで要約を使用）。
- `FORCE_HYPERLINK=false`（`no` / `off`）の意味が反転していた不具合が直り、意図通りハイパーリンクを無効化できるようになった。
