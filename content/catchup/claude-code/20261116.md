## 今回の注目ポイント

- **v2.1.326 は 270 項目規模の巨大リリースで、大半が修正と改善。** 前回収録の v2.1.325（サンドボックス／権限の既定変更）に続き、今回も Bash サンドボックス・権限チェックの引き締めが数十項目に及ぶ。あわせて端末表示（ストリーミング・フルスクリーン・ナロー幅・テーマ）とサインイン／認証まわりの不具合修正が大量に入っている。
- **エージェントチーム有効時に Code Mode を併用できるようになった。** すでに Code Mode を有効にしている場合、チームを有効にしたセッションは Code Mode で開始する。
- **サンドボックスの既定書き込み先がさらに縮小。** macOS / Linux / WSL でサンドボックス化コマンドが書き込める機密なホームフォルダを既定で減らし、必要なものは `sandbox.filesystem.allowWrite`（ユーザ設定／管理設定）で個別許可する。サインインファイル（`.credentials.json` など）への書き込みはファイルツールが拒否するようになった。
- **既定モードの変更。** 組織ポリシー未ロード時／モード未設定のセッションは Manual ではなく auto モードで開始するよう変更。HIPAA 構成の組織では端末・VS Code セッションが既定で auto モードで開始する（`disableAutoMode` で無効化）。初回セットアップのテーマ既定は Dark から「Auto（端末に合わせる）」に変更。
- **`/update-config` のコンテキスト消費を約 93,000 → 約 13,000 トークンに削減。** `/model` の「Default (recommended)」表示がプランの既定モデル名を出すようになるなど、UI 文言・整合性の改善も多数。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.326（v2.1.325 は収録済み）

### v2.1.326（270 項目規模。サンドボックス／権限の継続的な引き締め・端末表示と認証の大量修正）
- **バージョン**: v2.1.326（2026-11-16）
- **内容**: 「What's changed」の一続きのリストで約 270 項目。主なものを機能カテゴリ別に整理する（全項目は changelog / GitHub Releases を参照）。

  - **追加（Added）**:
    - エージェントチーム有効時の Code Mode 併用に対応（有効化済みならチーム有効セッションは Code Mode で開始）。
    - `--allowedTools` / `--disallowedTools` / `--tools` の値に完全なルールに見えない項目があると起動時に警告。
    - セッション中に管理者が `managed-mcp.json` を追加して MCP サーバの読み込みが止まった理由を表示。
    - `/status` に、プロバイダや `DISABLE_TELEMETRY` 等の環境変数で機能が無効化されているかを示す行を追加。
    - `/plugin`・`claude plugin list` で、`plugin.json` の `author`・`homepage` 等の不正フィールドが無視された旨を表示。
    - Ctrl+O で起動時の隠れた通知を表示。失敗後の操作を示す空プロンプトのヒント、サブエージェント表示での `esc to stop` フッタヒントを追加。
    - OpenTelemetry のリソース属性に `host.name`・`host.id` を含める `OTEL_RESOURCE_INCLUDE_HOST`（既定オフ）。
    - mod の `Box` に `overflowX="scroll"`、`Text` に `maxLines`・`wrap="clip"` を追加。

  - **サンドボックス・権限（引き締め。影響大）**:
    - Bash の権限チェックを改善し、一部コマンドは先に確認するか、誰も応答できない場面では拒否するよう変更。Code Mode の権限チェックも同様に厳格化。
    - サンドボックス化コマンドが macOS / Linux / WSL で書き込める機密ホームフォルダを既定で縮小（`sandbox.filesystem.allowWrite` で個別許可）。
    - ファイルツールがサインインファイル（`.credentials.json` など）への書き込みを拒否。Bash 権限チェックもサインインファイルに触れる前に確認。一部のデバイス／プロセスファイルも拒否。
    - 一部の `cp`・`mv`、環境変数を設定する行、非常に長い値で検査しきれないコマンド、bypass permissions モードの一部ツール呼び出しについて、確認を求める／拒否するよう変更。
    - ワークツリーに隔離したサブエージェントが、チェックアウトと共有するブランチを書き換え得る一部の git コマンドを拒否（セッション本体は影響なし）。`ExitWorktree` はバックグラウンドのサブエージェント／シェルが動作中のワークツリー削除を拒否（`discard_changes` 指定時を除く）。
    - PowerShell ツールの確認・拒否対象を拡大（bypass permissions モードでも一部は確認／拒否、組み込みコマンド名の関数定義は改名を促して拒否、不正なコマンドは拒否）。
    - auto モードがプログラムを名指さない／`$HOME` 始まりの一部ワイルドカード許可ルールを無視して安全チェックに委ねるよう変更（`.\` 始まりのルールは将来復活予定）。
    - サンドボックスは `.git` 内の想定外エントリをコマンド後に退避。Linux / WSL では不足する一部の `--add-dir` フォルダを各コマンド前に作成。macOS Bash サンドボックスの保護も強化。

  - **認証・サインイン**:
    - `/login` が承認済み `ANTHROPIC_API_KEY` を使ったまま「Login successful」で終わっていた問題を修正（API キー利用を明示）。Console アカウントサインインが Claude サブスクリプションのログインを置換する問題も修正。
    - `claude auth logout` が資格情報を残す／トークン更新が失敗する問題、エージェントビューから再開した過去会話がバックグラウンドサービスのサインインで送信される問題、Claude Desktop の Code タブで単発の 401 認証エラーが出た際にもう一度送るよう変更。
    - サインインコードの貼り付け表示（`claude auth login`・`/login`・`claude setup-token`）、ネットワークブロックページ（HTTP 403）を再サインイン要求と誤表示する問題などを多数修正。

  - **MCP**:
    - 同一ミリ秒で届いた 2 つの長い結果で並列 MCP ツール呼び出しが別の呼び出しの保存結果を読む問題（#105138）、名前が酷似したサーバで MCP プロンプトが消える問題、ルートに `anyOf`/`oneOf` を持つツールで Claude に最初のブランチの引数形式しか見せない問題を修正。
    - `headersHelper` 失敗時に他セッションがそのサーバ無しで起動する問題、`/mcp` がローカル（stdio）サーバの起動失敗理由を表示しない問題、スロー起動サーバの Enable で進捗が出ない問題などを修正。`claude mcp add-json` のエラー文言を改善。

  - **Code Mode**:
    - auto モード下で承認が必要なインライン `!` コマンドを含むスキル／スラッシュコマンドが Code Mode で読み込めない問題、Code Mode で起動したバックグラウンドサブエージェントがそうしたスキルをプリロードすると失敗する問題を修正。
    - mod が `$.tool.call`・`$.tool.check` 経由で Bash・Read 等を使えない問題を修正。Code Mode の `$` シェルヘルパは一部の値をエラーで拒否（何も実行しない）。

  - **Remote Control・クラウド・セルフホストランナー**:
    - サーバ一時停止でセッションが応答途中に切断する問題、短い端末ウィンドウ（80×24 等）で QR コードが切れる問題、端末セッションが電話側でアイドル表示になる問題を修正。`claude remote-control`・Claude Desktop・VS Code の応答が電話／ブラウザへ逐次ストリーミングされるよう改善。
    - プロキシが独自に返す HTTP 502/504/520〜524 でクラウド／Remote Control のファイル送信が即失敗する問題（再試行するよう修正）、`claude self-hosted-runner` が時計のずれでトークンを無限に要求する問題を修正。Remote Control のプロキシ接続は CONNECT トンネルを使うよう変更。

  - **コンテキスト・セッション・コンパクト**:
    - クラッシュ後の再開で直近ターン／過去の会話履歴が失われる問題、Bedrock・Vertex・Foundry やテレメトリ無効時にコンパクトが要約せず返信してしまう問題、画像の多い Vertex AI セッションが 30MB 超の 400 エラーで固まる問題を修正。
    - `max_tokens` がモデル上限を超えた際に Anthropic API 報告の最大値で再試行。

  - **端末表示・レンダラ・UI（修正が最多）**:
    - ストリーミング中にスクロールバックから行が欠落する／プロンプトが飛ぶ問題、フルスクリーンの再描画・リサイズでの位置ずれ、ナロー幅での各種表示（`/context` グリッド・リトライ通知・テーブル・`?` ショートカット一覧）の切れ・崩れを多数修正。
    - `/model` が保存モデルを「Default (recommended)」と表示する問題を修正（Default はプラン既定モデル名を表示）。`/rewind`・`/resume`・`/skills`・`/privacy-settings` 等の多くの不具合、タイマ表示・診断の表示も修正。
    - 絵文字・インド系の母音記号・結合絵文字で後続テキストがずれる問題、diff で「No newline at end of file」が行番号をずらす問題を修正。スクリーンリーダモードの残留ヒントも修正。
    - タイピング・ストリーミング・リサイズの応答性、ファイル読み書き後の応答時間（特に Windows）、アイドル時 CPU、サブエージェント 20 超時の CPU を改善。

  - **変更（Changed。既定・挙動）**:
    - モード未設定／ポリシー未ロード時は auto モードで開始。HIPAA 構成組織は端末・VS Code が既定 auto（`disableAutoMode` で無効化）。
    - フック `"decision": "block"` がより多くの場面で有効化（常に block を出すフックは呼び出しをブロックし始める可能性）。auto モードが一部の以前通っていたシェルコマンドを止めるよう変更。
    - プラン承認のカードを 2 択（「はい、このセッションは default (ask each time) に切り替え」「いいえ」）に変更。`/update-config` のコンテキスト消費を約 13,000 トークンに削減。
    - 初回セットアップのテーマ既定を Dark から「Auto（端末に合わせる）」に変更。`/usage` のフルスクリーン表示をサブスク向けにプラン上限バー優先に変更。

  - **クライアント別（[VSCode]）**:
    - プロンプト候補を無効化する `claudeCode.promptSuggestions` 設定を追加。
    - フォーク会話での「Rewind code to here」が 1 ターン余計に戻してファイルを削除する問題、サンドボックス無効時に Sandbox ダイアログがホーム／`.git` に空ファイルを作る問題、一部ネットワークで保存済みサインインが失われる問題を修正。
    - 2 つ目のセッションで `/ide` がエディタ接続を無言で奪う問題（最新接続が勝ち、置換された側に切替方法を表示）、メモリダイアログの表示やシンボリックリンクループでの RAM 肥大、アーティファクト公開後の「Open artifact」リンク欠落などを修正。Edit / Write 速度も改善。
