## 今回の注目ポイント

- **Claude Sonnet 5.5（`claude-sonnet-5-5`）を追加**。Anthropic API 上での Sonnet 系のデフォルトモデルになり、1M コンテキスト、料金は $2/$10 per Mtok（キャッシュ読み取り $0.20/Mtok）。
- auto モードで作業ディレクトリ外の読み取り確認プロンプトに「Yes, but ask again next time（次回もまた確認する）」の選択肢が追加。
- `/usage` とステータスラインに Claude apps gateway の利用上限が金額（ドル）表示されるようになった。
- effort スライダー操作用のキーバインド、`/rate-limit-options` コマンド、対話ターミナルでの `/mcp reconnect all` を追加。
- ストリーム破損・thinking ブロック後のサーバーエラー・「Prompt is too long」の恒常化・Agent SDK のクラッシュなど、多数の重要な不具合を修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.284

### v2.1.284（2026-09-28）
- **モデル**: Claude Sonnet 5.5（`claude-sonnet-5-5`）を追加。Anthropic API 上での Sonnet 系デフォルトモデルとなり、1M コンテキスト、料金は $2/$10 per Mtok（キャッシュ読み取り $0.20/Mtok）。
- **権限 / auto モード**: 作業ディレクトリ外の読み取り前に表示される auto モードの確認プロンプトに「Yes, but ask again next time」の回答を追加。
- **利用状況表示**: `/usage` とステータスラインの Claude apps gateway 利用上限に金額（ドル）を表示。
- **キーバインド**: effort スライダー制御用のアクションを追加（`effortSlider:decreaseEffort` / `increaseEffort` / `toggleUltracode`）。
- **コマンド**: `/rate-limit-options` コマンドを追加。対話ターミナルで `/mcp reconnect all` を追加。
- **Gateway（管理者向け）**: Claude apps gateway に管理ポリシー設定の問題を知らせる起動時警告を追加。gateway の ID プロバイダー向けに証明書クライアント認証（`private_key_jwt`）を追加。
- **主な修正**:
  - 破損したレスポンスストリーム、thinking ブロック後の overloaded/server エラー、恒常化する「Prompt is too long」エラー、model-unavailable 通知を修正。
  - 不正な画像による Agent SDK のセッションクラッシュ、再開セッションでの MCP ツール呼び出し、plan-usage エンドポイントの繰り返し呼び出しを修正。
  - `claude mcp add` が誤って成功と報告する問題、プラグイン設定画面の問題、`ANTHROPIC_FOUNDRY_RESOURCE` の検証、Claude Desktop の 1M コンテキストオプションを修正。
  - shell モード選択の問題、Windows での Bash ツール失敗、`sparsePaths` を使ったプラグインマーケットプレイスの clone、フルスクリーン描画、スクロール位置のジャンプ、タブバーの折り返し、モデルピッカーの件数表示、キーバインドの書き込み、vim モードなどを修正。
  - VSCode・クラウドセッション・Claude Tag 全般でも多数の修正。

## 使い方メモ（任意）

- 新しい Sonnet を使う場合、モデル選択（`/model` やモデルピッカー）で `claude-sonnet-5-5` を確認できる。API 上の Sonnet デフォルトが 5.5 に切り替わっている点に注意。
- 特定モデルへの固定・新モデルのブロックが必要な管理環境では、前バージョン（v2.1.283）で追加された `availableModelsMatch`（"exact"）や `deniedModels` の管理設定と合わせて挙動を確認するとよい。
