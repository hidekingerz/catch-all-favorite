## 今回の注目ポイント

- **v2.1.301 の1リリースを収録**（前回収録は v2.1.300 / 2026-10-14）。新機能は少なめで、修正と改善が中心。
- **vim モードに `%` モーション（対応するカッコへジャンプ）を追加**。単独でも d/c/y と組み合わせても使える。
- **VS Code 拡張に LaTeX 数式レンダリングを追加**（`$$`・複数行 `\[ … \]`・インライン `$…$`／`\(…\)`）。
- **Read ツールがバイナリを誤ってテキスト読みする問題を修正**（.xlsm・.parquet・.epub・.heic など）。**Grep / Glob は検索プログラムが結果を返す前に異常終了したとき「一致なし」でなくエラーを返す**ように修正。
- **コンテキストウィンドウの小さいモデルへ切り替える際の挙動を改善**。長すぎる会話は切り替え前のモデルで先に要約。さらに、要約に利用クレジットを無断で消費してしまう問題も修正。
- **unattended retry モードに `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` を追加**。使用量リミットのリセットが遠すぎる場合、待たずにリクエストを終了できる。
- **mod（モッド）の `Input` に複数行入力 `rows` を追加**（Enter で送信、Shift+Enter またはバックスラッシュ＋Enter で改行）。質問ダイアログ上のツリーが Markdown＋最大48行に対応（ターミナルは12行プレーンのまま）。
- **OpenTelemetry を拡充**。`tool_decision` イベントに `classifier_verdict`・`permission_mode`（auto モードの分類器判定と権限ルール由来を区別）、`OTEL_LOG_TOOL_DETAILS=1` 時に `classifier_category` を追加。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.301

### v2.1.301（2026-10-15）

- **新機能 / 追加**:
  - unattended retry モード（`CLAUDE_CODE_RETRY_WATCHDOG`）向けに `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` を追加（リセットが遠すぎる使用量リミットでは待たずにリクエストを終了）。
  - `claude-api` スキルに OpenTelemetry トレーシングのガイダンスを追加（`ant` CLI でのトレース送信先設定を含む）。
  - vim モードに `%` モーション（対応するカッコへジャンプ。単独でも d/c/y と併用も可）を追加。
  - mod の `Input` に `rows` を追加（ターミナルで複数行のテキストフィールド。Enter で送信、Shift+Enter またはバックスラッシュ＋Enter で改行）。
  - OpenTelemetry `tool_decision` イベントに `classifier_verdict`・`permission_mode` を追加（auto モードの分類器判定と権限ルール由来を区別）。
  - OpenTelemetry `tool_decision` イベントに `classifier_category` を追加（`OTEL_LOG_TOOL_DETAILS=1` 時。分類器ブロックが一致した組み込みルール名を表示）。
- **主な修正（抜粋）**:
  - 終了時、`WorktreeCreate` フックが作った worktree に未 push コミットが残り得る場合でも無確認で削除していた問題を修正。
  - `fable`（および `best`）モデルエイリアスが、最新 Fable モデルを組織が利用不可のとき Anthropic API でエラーになる問題を修正（1回だけ前の Fable モデルで再試行）。
  - ディスク満杯でログイン更新に失敗した際の誤解を招く「Please run /login」エラーを修正（該当ディスク名とファイル削除の案内を表示）。
  - Grep / Glob が検索プログラムの異常終了時に「一致なし」と報告していた問題を修正（検索失敗のエラーを返す）。
  - workflow エージェントが「タスク文にユーザー権限は無い」という harness 注記を読んだ後、ステップをスキップしつつ成功報告する問題を修正。
  - PreToolUse フックが Edit / Write を対象にしている環境で artifact の更新が拒否される問題を修正（publish 呼び出しで変更せず、ファイルを編集してから再 publish）。
  - 引数名が非常に多い/長いスキル・コマンドの起動が数秒止まる問題を修正（先頭64件・各64文字までに制限）。引数が多くのプレースホルダを埋めるスキル/コマンド/フックの大量メモリ消費も修正。
  - VTE 0.53 未満ベースのターミナル（RHEL 8 の MATE Terminal 等）で trust プロンプトを覆う `>0q`、終了時シェルプロンプト前の `>4m` を修正。一部 iTerm2 起動時の `GOK` 迷子テキストも修正。
  - 名前に `application-inference-profile` を含むモデルへ切り替えると、Bedrock でないのに `awsAuthRefresh` が走りモデル切替フックが遅れる問題を修正。
  - `claude auth status`・`claude plugin list` 等の短命コマンドがトークン更新の途中で終了するとサインイン更新タイムアウトや予期せぬサインアウトになる問題を修正。
  - ターン途中に送られたメッセージで権限チェック中のツール呼び出しが中断されると、モデルに「ユーザーが拒否」と報告される問題を修正。
  - コンテキストウィンドウの小さいモデルへ切り替える際、前モデルの要約に無確認で利用クレジットを消費する問題を修正。
  - LLM ゲートウェイがリクエストと異なるモデル名を返す場合に、選んでいないモデルで会話が繰り返しコンパクションされる問題を修正。
  - 低速/高負荷マシンで Escape 後も vim モードが INSERT のまま残る問題、vim モードで AskUserQuestion の入力中 Esc が回答を破棄する問題（自由入力欄が NORMAL モード対応になり、Esc は NORMAL からのみキャンセル）を修正。
  - Read ツールが .xlsm・.parquet・.epub・.heic 等のバイナリをテキストとして読む問題を修正。
  - ヘッダ行のみの Markdown テーブルがターミナル幅を超えると何も描画しない問題（plan 承認カードの plan 内含む）を修正。

## 使い方メモ（任意）

- **vim モードの `%`**: 対応するカッコへジャンプ。`d%`・`c%`・`y%` でカッコ対応範囲の削除/変更/ヤンクができ、コード編集時の移動が速くなる。
- **`CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`**: 無人の自動リトライ運用で、使用量リミットのリセットが遠すぎるときに延々と待たせず打ち切れる。CI やルーティン等の自動実行で待機時間が読めない場合に有効。
- **Read / Grep / Glob の挙動変化**: バイナリ（.xlsm・.parquet・.epub・.heic 等）がテキスト誤読されなくなり、Grep/Glob は検索自体が失敗したとき「一致なし」でなくエラーを返す。スクリプトで結果を判定している場合、無言の空結果が減り失敗を検知しやすくなる。
- **小さいコンテキストウィンドウのモデルへの切替**: 長い会話は前モデルで先に要約されるため切替が通りやすくなった。一方で以前は無断でクレジットを消費していた要約も確認が入るよう修正された。
