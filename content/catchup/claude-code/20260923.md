## 今回の注目ポイント

## 新機能・変更（changelog）

> 対象バージョン: v2.1.281

### v2.1.281（2026-09-23）
- **バージョン**: v2.1.281（2026-09-23）
- **内容**:
  - **設定 / 属性表示**:
    - **`settings.json` に `"attribution": false` を追加**。コミットと PR の属性（attribution）表示をすべて非表示にできる。古い CLI はこれを保持する設定ファイルを読み飛ばすため、バージョン横断で共有するファイルではオブジェクト形式を維持すること。
  - **MCP**:
    - **URL モードの elicitation に対応**（2026-07-28 プロトコル接続）。サーバーが Claude Code にブラウザベースのフローを開くよう要求できる。サーバー側に完了を確認する手段がない場合、待機ダイアログを画面に残さない。
    - **`claude plugin validate` に MCP サーバー検査を追加**。ロード時に黙って破棄される `.mcp.json` エントリ、未宣言の `${user_config.*}` 参照、安全でない URL を報告する。
  - **auto モード / insights**:
    - **`/insights` に auto モードの推奨を追加**。直近のセッションで auto モードが処理できたはずの権限プロンプト数を見積もって表示する。
  - **Claude apps gateway（エンタープライズ / ゲートウェイ）**:
    - `desktop` ポリシーブロックで、新しい Claude Desktop キー（`blockReadsOutsideWorkingDirectories`・`disableBypassPermissionsMode`）に対応する Claude apps gateway サポートを追加。
    - **Bedrock upstream に `assume_role` を追加**。ゲートウェイが STS 経由で引き受けた IAM ロールとして Bedrock を呼び出す（必要なら別 AWS アカウント、任意で開発者ごとに 1 セッション）。
    - **Bedrock upstream に `guardrail: {id, version}` を追加**。そのゲートウェイ経由の全リクエストに Amazon Bedrock ガードレールを適用する（Bedrock upstream 全体に設定するか、一切設定しないかのどちらか）。
    - `telemetry.resource_attributes` を Claude apps gateway 設定に追加。Claude Desktop と `/login` セッションのテレメトリに固定ラベルを付与できる。
  - **UI/UX（ターミナル）**:
    - フルスクリーンモードの `/skills`・`/mcp`・`/plugin` の Installed 一覧に、`/workflows` と同様のスクロールバーを追加（マウスオーバー中に表示され、クリック/ドラッグ可能）。
  - **その他**:
    - 上記に加え、クラッシュ修正、セッション管理、ツール呼び出し処理、MCP/プラグインの改善、UI 改善、プラットフォーム別修正（Windows・macOS）、VSCode・Claude Code on the web・Claude Tag・Code Review 向けの修正など、130 件超のバグ修正・改善を含む。

## 使い方メモ（任意）

- **属性表示を消したい利用者**: `settings.json` に `"attribution": false` を設定するとコミット/PR の属性表示を一括で消せる。ただし古い CLI と共有するファイルではオブジェクト形式を保つこと（古い CLI は当該設定ファイルを読み飛ばす）。
- **MCP プラグイン作者**: `claude plugin validate` が `.mcp.json` の破棄されるエントリ・未宣言の `${user_config.*}`・安全でない URL を報告するようになったため、配布前の検証に活用できる。
- **auto モードの導入検討者**: `/insights` で「auto モードが処理できたはずの権限プロンプト数」を確認でき、導入効果の見積もりに使える。
