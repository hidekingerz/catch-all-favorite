## 今回の注目ポイント

- **claude.ai サインインの有効期限が可視化された**。`claude auth status` に失効日時（`loginExpiresAt`）、`claude -p` の JSON 結果に `credential_expires_at` が追加され、失効の10日前から `claude -p` の text 出力に1行の警告を stderr に出すようになった。無人運用での突然のサインアウトを事前に察知しやすくなる。
- **共有ネットワークホームディレクトリまわりの堅牢化が大規模に実施**。`~/.claude.json`・設定ファイル・保存済みログインが保存時に消える / 一時的に空になる / 古いコピーに置き換わる事象を広く修正。壊れた・空の `~/.claude.json` の扱いや復元コマンドの案内も改善。
- **IDE ターミナルから起動したときに IDE 拡張を自動インストール / 更新しなくなった**。インストールは外部ターミナルからの `/ide` かエディタの拡張ビューで行う。
- **Mod（拡張）関連の機能追加**。Claude Code がセッション内で書いた mod を有効化するか尋ねたときに回答を記録。`$.model.fork` に `effort` オプションが追加され、セッションの effort に関わらずサブジョブを `low` などで実行できる（結果に送った effort を報告）。
- **サブエージェントの挙動変更**。「メッセージがフラグされたらモデル切り替え」が「毎回確認」のときはサブエージェントがモデル切り替えではなく停止するように。バックグラウンドサブエージェントは全プロバイダで3分後にシェルコマンドをバックグラウンド移行し、プロンプトキャッシュ失効を防ぐ。
- **Claude apps gateway の `mantle` upstream に `assume_role` を追加**。別 AWS アカウントのロール引き受けと開発者別の AWS コスト按分に対応。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.318（既存ファイルは v2.1.317 まで収録済み）

### v2.1.318（2026-11-04）

**認証・サインイン有効期限**
- `claude auth status` に保存済み claude.ai サインインの終了日時（`loginExpiresAt`）を追加。`claude -p` の JSON 結果にも `credential_expires_at` を追加。
- 保存済み claude.ai サインインの失効10日前から、`claude -p` の text 出力に1行の警告を stderr に出すようになった。
- `claude.ai` サインインが時間制限に達したときのサインイン失敗を、`claude -p` では `claude auth login` と `claude setup-token` を案内するよう修正。
- `setup-token` のトークンが、許可された組織に属する場合に `forceLoginOrgUUID` のマシンで起動時に拒否される問題を修正。
- 別ターミナル / ホストが同一アカウント・組織・ホームに再サインインするとジョブが `Not logged in` で終了する問題を修正。

**Mod（拡張）**
- Claude Code がセッション内で書いた mod を有効化するか尋ねたとき、その回答を記録するようになった。
- mod の `$.model.fork` に `effort` オプションを追加（短いサブジョブをセッションの effort に関わらず `low` 等で実行可能。結果に送った effort を報告）。
- `plugin.submit`（`prompt.submit`）で mod が添付するものがユーザーのターン内に留まり、システムメッセージとして送られないよう変更。
- mod の `turn.step` フックが絡む `claude -p` / Agent SDK セッションで、API エラーで返信が途切れても成功報告していた問題、および停止した返信が成功扱いになる問題を修正。

**サブエージェント / チームメイト**
- 「メッセージがフラグされたらモデル切り替え」が「毎回確認」のとき、サブエージェントが切り替えではなく停止するよう変更。
- バックグラウンドサブエージェントが全プロバイダで3分後にシェルコマンドをバックグラウンド移行（プロンプトキャッシュ失効防止）。
- Bedrock / Vertex / Foundry / テレメトリ無効環境でコールドキャッシュ時、サブエージェント進捗サマリーが最大5分まで保留応答を待てるよう変更。

**Claude apps gateway**
- `mantle` upstream に `assume_role` を追加（別 AWS アカウントのロール、開発者別 AWS コスト按分）。
- federation（`external_account`）資格情報の Google アクセストークン失効間近にログ警告を追加。
- `listen.trusted_proxies` のログヒントを改善。AWS CountTokens 失敗時の警告を改善（501後はゲートウェイではなく Claude Code が集計する旨、アクセス拒否時のみ IAM を示唆）。

**IDE / VS Code**
- IDE ターミナルから起動したときに IDE 拡張をインストール / 更新しないよう変更（`/ide` を外部ターミナルで使うかエディタの拡張ビューで）。
- [VSCode] 組織設定がサインインを拒否するウィンドウが毎分バックグラウンドで新プロセスを起動する問題、チャットパネルのエラーバナーの長い語で閉じるボタンが見切れる問題、サインインステータスチェック失敗時の出力表示を修正・改善。

**MCP / 権限 / 設定**
- `deniedMcpServers` の URL エントリが、upstream URL が一致する Anthropic 提供サーバや、クラウドセッション / セルフホストランナーのコネクタもブロックするよう変更（それ以外は名前で拒否）。
- `claude mcp add` / `remove` がロックなしで設定を書き込む問題を修正（ロック待ちか exit 1）。
- stdio MCP サーバがバージョン探査で終了すると毎回再探査される問題を修正（3秒未満で死ぬサーバは7日間レガシーハンドシェイクに固定）。
- `/mcp` がクラウドセッションでモデルが使えないツールまで数える問題を修正（利用可能ツール数を表示）。
- MCP ツールのロード前呼び出しで input schema を返すよう改善。
- `/permissions` のルール詳細・組み込みルール・削除確認を標準ダイアログに変更（Ctrl+C 2回で終了ではなく戻る / キャンセル）。
- `/claude-api managed-agents-onboard` で新エージェントの組み込みツールとクイックスタートテンプレートの MCP ツールに既定で `auto`（リスクある操作を判定）権限ポリシーを付与。

**設定ファイル / `~/.claude.json` の堅牢化**
- 共有ネットワークホームで設定ファイル更新に失敗したとき、`/logout`・`claude auth logout`・`claude mcp remove` が成功報告し trust / consent / MCP 設定変更が黙って捨てられる問題を修正。
- 非対話起動で不正 JSON の `~/.claude.json` を既定値で上書きする問題を修正（起動を失敗させ復元方法を案内、ファイルはそのまま）([#87551](https://github.com/anthropics/claude-code/issues/87551))。
- バックアップのない空 `~/.claude.json` が破損扱いされる問題、破損 / 欠落時の復元コマンドが空 / 切れたバックアップを示す問題を修正。
- 共有ネットワークホームでの `~/.claude.json`・設定ファイル・保存済みログインの保存を改善（削除 / 一時的な空化 / 古いコピーへの置換が減少）。設定ファイルが誤って欠落報告された場合に再確認するよう改善。
- `NODE_EXTRA_CA_CERTS` ファイルが空 / PEM でない / 先頭証明書が壊れている場合に全接続が失敗する問題を修正（読める証明書を使い stderr に警告）。
- 無人起動（`claude -p`、SDK）で内容無変更時に毎回 `~/.claude.json` を書き換えないよう改善。

**プラグイン**
- `claude plugin` 系コマンドが遅いトークンリフレッシュ保存前に終了してサインアウトする問題、`claude plugin validate` がカスタム名のマーケットプレイスファイルを通す問題を修正。
- 多数のコマンドを登録するプラグインを持つヘッドレスセッションの高メモリ / 遅い起動を修正（v2.1.317 相当の改善も継続）。

**ヘッドレス / `claude -p` / SDK / 会話復元**
- `--continue` が不正なツール呼び出しのリトライ切れ後に以前の会話を失うことがある問題（2.1.314 のリグレッション）を修正。
- `claude -p` と Agent SDK で、カスタムスラッシュコマンドが失敗 / Claude のみ呼び出し可能なときに何も出力しない問題を修正。
- アイドル圧縮が会話をサマリーでない返信で置き換える問題、超長会話で圧縮が自前リクエストを短縮する際に以前のサマリーを失う問題を修正。
- 再起動セッションが API エラーで失敗したメッセージを新しい待機メッセージより先に再送する問題、中断ターンを落とす問題を修正。

**クラウドセッション / セルフホストランナー / Remote Control**
- [Cloud sessions] リポジトリを選ばず起動できる「No repository」オプションを追加（Anthropic ホスト環境）。
- [Cloud sessions] Playwright 以外のツールが組み込み Chromium を google-chrome / CHROME_PATH 経由で見つけられるよう通常の Chrome 名を追加。環境削除時のカードに New session ボタンを追加。
- [Cloud sessions] GitHub Actions ログ読み取りを修正（`gh run view --log`・`gh api` が到達不能なリダイレクトでなくログを取得）。Create PR 失敗メッセージを改善（理由や GitHub リンクを表示）。
- クラウドセッションがアップロードを数分拒否されたときターン途中で停止する問題、`Setup` フックが `CLAUDE_ENV_FILE` に書いた変数が Bash ツールに届かない問題を修正。
- `claude remote-control` ホスト / バックグラウンドデーモン / セルフホストランナーがアップデートやバージョン整理で実行中バイナリを削除され新セッション起動に失敗（`spawn ENOENT`）する問題を修正。別ユーザー所有プロセス（`sudo claude` 由来等）が死亡扱いされバイナリ削除される問題も修正。
- Self-hosted runner: spawn-runner フック環境に `CLAUDE_RUNNER_SPAWN_REASON`（`runner_lost`・`resumed` 等）を追加。オーケストレータのログ形式を変更（`ok session=…` / `nack session=…` の出力レベル・フィールド順。`retryable=true:` などをマッチする更新スクリプトは要修正）。

## 使い方メモ（任意）

- claude.ai サインインの有効期限が見えるようになったため、CI / 無人運用では `claude auth status` の `loginExpiresAt` や `claude -p` JSON の `credential_expires_at` を監視し、失効10日前の stderr 警告を拾って事前に `claude auth login` / `claude setup-token` を回すと突然のサインアウトを避けられる。
- 共有 NFS / ネットワークホーム上での設定消失が広く修正されたため、該当環境で `~/.claude.json` や MCP 設定が消える問題に遭遇していた場合は v2.1.318 への更新が有効。
