## 新機能・変更（changelog）

> 対象バージョン: v2.1.274 〜 v2.1.275

### v2.1.275（2026-09-17）
- **バージョン**: v2.1.275（2026-09-17）
- **内容**: 新機能として、(1) claude.ai アカウントのスキル/プラグインをターミナルのセッションへ同期、(2) Send-now キー（Ctrl+Enter、または Ctrl+X Ctrl+S）で現在のターンを中断してキュー済みメッセージをまとめて送信、(3) `/plugin install <plugin> --marketplace <source>` でマーケットプレイスを指定してプラグインを導入、(4) Claude apps ゲートウェイへのサインイン済みアカウント確認、(5) システムプロンプトのプロンプトキャッシュ改善（`__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__`）を追加。主な修正: メモリファイルの経年注記によるプロンプトキャッシュミス、`--forward-subagent-text` がサブエージェントのメッセージを取りこぼす問題、**プラグイン/マーケットプレイスのメッセージがパスワードやトークンを露出していた問題**、プラグイン マーケットプレイス更新が取得失敗時にローカルコピーを削除していた問題、Linux のサンドボックス Bash が zsh で失敗コマンドを終了コード 0 と報告する問題、Grep/Glob が 20MB 超の出力でハングする問題、`/rewind` がゼロ埋め/切り詰めファイルを復元する問題、フルスクリーンセッションが「unrecoverable interface error」で終了する問題など。VS Code 拡張ではメモリダイアログでの保存済みメモリの閲覧/編集/削除、テキストなしでの添付画像送信、変更差分タブでの変更ごとの承認/却下ボタンなどを追加。

### v2.1.274（2026-09-17）
- **バージョン**: v2.1.274（2026-09-17）
- **内容**: 新機能として、(1) メモリ使用量が危険水準のときに表示される警告、(2) MCP 起動待ち時間を制御する環境変数 `CLAUDE_CODE_MCP_STARTUP_WAIT_MS`、(3) OpenTelemetry の `claude_code.llm_request` スパンへの `effort` 属性、(4) Postgres 接続タイムアウト用のゲートウェイ設定 `store.connect_timeout_seconds` を追加。主な修正: セッションが「unexpected tool_use_id」400 エラーのリトライで停止する問題、レガシー HTTP+SSE の MCP サーバーが 422 で接続失敗する問題、Streamable HTTP の MCP ツール呼び出しが 5 分でタイムアウトする問題、MCP の prompts/resources が list-changed 通知で更新されない問題、圧縮済みセッション再開時に有効な `/goal` が失われる問題、`claude agents` が自動更新後にモデル/effort/権限モードを失う問題、言語サーバーのプロジェクト全体診断によるターンごとの速度低下、セルフホストランナーがトークン更新後に 401 で失敗する問題、VS Code でクリック可能なローカルファイルパスが機能しない問題など。VS Code/クラウドではウィンドウ再読み込み後の中断ステップの継続、Customize メニューへの Memory/Instructions 追加、`claudeCode.lockEditorGroups` 設定、クラウドセッション差分ビューの「Compare against」ブランチ選択などを追加。
