## 今回の注目ポイント

- **前回収録（v2.1.331）以降、v2.1.332 が公開。** 大半は安定性・UI の修正だが、MCP サーバ由来のスキル対応や新しいフックイベント、各クラウドプロバイダのデフォルトモデル更新など注目の追加がある。
- **MCP サーバのスキルに対応（ベータ）。** `/` メニューに `server:skill` 形式で表示され、エージェントスキルを MCP サーバ経由で配布・利用できるようになった。
- **`PreSkillShellCommand` フックイベントを追加。** スキルやコマンドがロード時に実行するインラインシェルコマンドを、ロード時点で拒否できる。v2.1.331 以前でこのイベントを設定ファイルに書くと起動時にダイアログが出る点に注意。
- **各クラウドプロバイダのデフォルトモデルが Sonnet 5 / 5.5 系へ更新。** Bedrock Mantle・Agent Platform・Foundry のターミナル／VS Code セッションが Sonnet 5 または 5.5 で起動し（モード未設定なら auto モード）、Foundry の既定は Sonnet 5.5、`opus` エイリアスは Opus 5.5 に。Bedrock の `sonnet` は Sonnet 4.5 のまま。
- **`--model default` のフォールバック挙動を改善。** デフォルト指定したモデルが使えないとき、エラーで止まらず古いモデルへ段階的に下がるようになった（auto モードでは auto が許容するモデルのみ）。
- **音声ディクテーションの無音タイムアウトを延長。** タップモード／VS Code とも、無音 15 秒・上限 2 分から「無音 60 秒・上限 10 分」に緩和。
- **フック暴走・大容量ログ・MCP 出力氾濫によるフリーズ／メモリ肥大を多数修正。** 長時間会話・大きなトランスクリプト・プロキシ経由（413）などでの安定性と復帰性が大きく改善。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.332（2026-11-25。v2.1.331 までは収録済み）。「What's changed」は節見出しのない一続きのリストだが、各項目が Added / Changed / Fixed / Improved で始まるため、それに沿って主要項目を整理する（全項目は changelog / GitHub Releases を参照）。

### v2.1.332（2026-11-25）

- **バージョン**: v2.1.332（2026-11-25）
- **内容**:

  - **追加（Added）**:
    - **MCP サーバのスキルに対応（ベータ）**: `/` メニューに `server:skill` 形式で表示される（他のスキルは従来どおりの名前）。
    - **`PreSkillShellCommand` フックイベント**: スキル／コマンドがロード時に実行するインラインシェルコマンドを、ロード時に拒否できる（v2.1.331 以前でこのイベントを設定すると起動時にダイアログが出る）。
    - 他セッションからの保留メッセージに「Always deliver（常に配信）」を追加。
    - フラグ付きメッセージが別モデルのセッションを指しているとき、`/model` でモデルを選ぶまでフッター行を表示。
    - レスポンスロギング有効時、SendUserMessage や Cowork のメッセージツールで送るテキストに OpenTelemetry の `assistant_response` イベントを追加。
    - VS Code / Desktop の Code タブで、セッションの一部が保存できなかったとき・再開時に以前のメッセージがロードされなかったときに警告を表示（`/compact` での保存方法も案内）。
    - 対象モデルで Cyber Verification Program のアクセス層を起動ヘッダのモデル名横に表示（claude.ai アカウントでサインイン時）。
    - [VSCode] 差分の扱いや Manage plugins のバージョン表示など、UI の通知を追加。

  - **変更（Changed）**:
    - **クラウドプロバイダのモデル既定を更新**: Bedrock Mantle・Agent Platform・Foundry のターミナル／VS Code セッションを Sonnet 5 または 5.5 に移行し、モード未設定なら auto モードで起動（`disableAutoMode` を `"disable"` で抑止）。Agent Platform / Foundry の `sonnet` は Sonnet 5.5、Foundry の `opus` は Opus 5.5、Foundry の既定は Sonnet 5.5（`claude-sonnet-5-5` をデプロイするか `ANTHROPIC_DEFAULT_SONNET_MODEL` を指定）。Bedrock の `sonnet` は Sonnet 4.5 のまま。
    - **`--model default` / Default 選択のフォールバック**: 使用不可のときエラーで止まらず古いモデルへ移る（auto モードでは auto が許容するモデルのみ）。
    - Microsoft Foundry: Claude Sonnet 4・Opus 4・Opus 4.1 を retired 扱いにし、それ以下への step-down を止め、ピン留め時は retired と警告。
    - Claude apps gateway の組み込みモデル一覧で Sonnet 5.5 が Sonnet 4.5 に代わり 2 番目のモデルに。
    - 音声ディクテーション（タップモード／VS Code）の無音タイムアウトを「無音 60 秒・上限 10 分」に延長。
    - OpenTelemetry: Desktop Code タブの既定 `service.name` を `claude-code-desktop` に変更（`claude-code` 前提のフィルタは更新、または `OTEL_SERVICE_NAME` で従来名を維持）。`tool_input` はレスポンスロギング無効時にテキスト長のみを記録。
    - Self-hosted runner: `CLAUDE_CODE_OAUTH_TOKEN` の接頭辞に `oat02-` を許可（`oat01-` にマッチするプロキシ規則・ログスクラバは要更新）。
    - `/schedule`・権限プロンプト・`/loop` のクラウド案内で「routine」「cloud schedule」ではなく「cloud scheduled task」と表示（`/routines` は引き続き利用可）。
    - 破壊的な質問（エージェント画面からの `/clear` など）で PgUp / Home が No に移動。
    - `computer-use` を予約スキル名化（computer use 有効な Mac では同名スキル／コマンドのロードを停止し、リネームを案内）。

  - **修正（Fixed・主なもの）**:
    - **認証／モデル／プロバイダ**: `claude auth login` が保存失敗時に成功と誤報告していた問題（exit 1 と原因表示に修正）、`--fallback-model` のファミリ名脱落、ゲートウェイがモデルを拒否した際の step-down 不備、`sonnet` エイリアスの誤解決（Bedrock Mantle で Haiku 4.5 に解決 → Sonnet 5 に）など多数。使用制限が解除後も到達扱いになる／返信が誤って赤い使用制限エラーになる問題も修正。
    - **セッション／コンパクション／コンテキスト**: 自動コンパクション失敗の連鎖後に「Prompt is too long」で止まる問題、巨大ログでフック失敗時のフリーズとコンテキスト溢れ（約 5 万文字超を短縮）、ワークツリー移行後に CLAUDE.md / ルールが二重送信される問題などを修正。
    - **Code Mode**: 10 分超のスクリプトでサブエージェントが「Agent stalled」になる問題、停止済みコマンドを数分待つ問題、再開時に最後の返信を失う問題などを修正。
    - **ツール／ファイル／編集**: 書き込みのない名前付きパイプで Read / @メンション / コンパクションがハングする問題（20 秒でタイムアウト）、大きな git リポジトリで Esc が Bash を止められない問題、128 文字超の MCP タスク ID で「malformed task handle」になる問題（1,024 文字まで対応）、Grep の `-o` / `-A` / `-B` の不具合などを修正。
    - **フック／プラグイン／MCP／性能**: フックの出力が止まらないときのフリーズとメモリ肥大、ローカル MCP サーバの標準出力氾濫で端末がフリーズする問題、SSE MCP サーバがストリーム切断後に全ツール呼び出しを拒否する問題、`~/.claude/plugins/cache` に `temp_*` が溜まる問題などを修正。
    - **VS Code / Desktop**: Rewind が「Checking code changes…」のまま固まる問題、モデルピッカーの矢印キー／スクリーンリーダー対応、NTFS ドライブでのフォーク／メモリ保存失敗、コンパクションサマリが自分のプロンプトとして表示される問題など多数。
    - **Windows / Linux / computer use**: 一部企業 PC で起動直後に無出力終了する問題、クリップボード画像読み取り不可時に導入パッケージ名（`wl-clipboard` / `xclip`）を案内するなど。

  - **改善（Improved・主なもの）**: `claude plugin marketplace add`（Windows でファイルロック時に再試行）、computer use のコンテキスト削減、`/context` / `/usage` / `/permissions` の出力・性能改善、プロキシ／ゲートウェイのサイズ制限（413）での長い会話の復帰、Windows での Glob 並列化、起動・再開時のメモリ使用量改善など。
