## 今回の注目ポイント

- **WebFetch ツールの無効化用環境変数 `CLAUDE_CODE_DISABLE_WEB_FETCH` を追加**。管理環境やネットワーク制限下で WebFetch を止められるようになった。
- **`claude --desktop`** で現在のディレクトリを Claude デスクトップアプリで開けるように。**`claude plugin configure <plugin>`** でプラグイン設定を表示・変更可能に。
- **`allowedProviders` 管理設定**を追加し、マシンが利用できる API プロバイダーを制限できるように。カスタム `ANTHROPIC_BASE_URL` のセッションは 1M コンテキストを使うよう変更。
- バックグラウンドの Bash / PowerShell コマンドは時間制限（デフォルト 30 分・最大 2 時間）で停止するよう変更。
- サブエージェント（fork / background）・クラウドセッション・プラグイン／マーケットプレイス周りを中心に多数の不具合を修正。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.285

### v2.1.285（2026-09-29）
- **設定 / 環境変数**:
  - `CLAUDE_CODE_DISABLE_WEB_FETCH` 環境変数を追加し、WebFetch ツールを無効化できるように。
  - `allowedProviders` 管理設定を追加し、マシンが利用できる API プロバイダーを制限。
  - カスタム `ANTHROPIC_BASE_URL` を使うセッションを 1M コンテキストウィンドウで動作させるよう変更。
  - クラウドセッションで MCP サーバー名 `widgets` を予約語に。
- **CLI / コマンド**:
  - `claude --desktop` を追加。現在のディレクトリを Claude デスクトップアプリで開く。
  - `claude plugin configure <plugin>` を追加。プラグインのオプションを表示・設定。
- **サブエージェント / auto モード**:
  - `claude -p` を `CLAUDE_CODE_FORK_SUBAGENT=1` で使ったとき、サブエージェント自身の Agent 呼び出しがフォアグラウンドで動くよう修正。
  - fork サブエージェントがセッションの plan モード / `dontAsk` モードを引き継がない問題を修正。
  - auto モードのバックグラウンドサブエージェントが各レポート後に冗長な返信を求める問題を修正。
- **ワークフロー / レビュー**:
  - Code Review と `/ultrareview` を `disableWorkflows` が有効でも実行するよう変更（管理者設定で明示的に無効化されている場合を除く）。
  - `/ultrareview` のアップロードに未コミットの認証情報ファイルが含まれる問題を修正。
- **バックグラウンド実行**:
  - バックグラウンドの Bash / PowerShell コマンドを時間制限（デフォルト 30 分・最大 2 時間）で停止するよう変更。
- **プロバイダー**:
  - Bedrock / Vertex で失敗する代わりに旧モデルティアへ切り替えるよう改善。
- **主な修正**:
  - SSH 経由のプラグイン／マーケットプレイスのインストール・更新が `GIT_SSH` や `core.sshCommand` を無視する問題を修正。ワークツリーや `/teleport` の取得での SSH パスフレーズ入力がターミナルを占有する問題を修正。
  - 会話のコンパクション後にクラウドセッションが Artifact 更新を拒否する問題、コンパクション後に読み取りタイミングが早すぎる Remote Control の問題を修正。
  - セッション中にモデルを切り替えると新モデルが組み込みの出力トークン上限のままになる問題、フォールバック時に `/cost` や SDK の `modelUsage` が誤ったモデルに計上される問題を修正。
  - リダクトされたログに `@` を含む URL のパスワードが表示される問題を修正。
  - セッション中に追加した MCP サーバーが切り替え後も残る問題、`.` / `-` / `@` や大文字違いだけの ID でのプラグインインストール競合を修正。
  - サンドボックスの自動許可がインラインスクリプト実行ごとに承認を求める問題、クラウドセッション作成が最新 20 環境しか読まない問題を修正。
  - WebFetch がレート制限されたドメインをポリシーブロックとして報告する問題、`/artifacts` の dismiss がファイルのリンクを解除する問題を修正。
  - Artifact ツールの結果に publish の提案を表示するよう改善。

## 使い方メモ（任意）

- WebFetch を止めたい管理環境では `CLAUDE_CODE_DISABLE_WEB_FETCH` を、利用可能な API プロバイダーを絞りたい場合は `allowedProviders` 管理設定を利用する。
- 長時間走るバックグラウンドコマンドはデフォルト 30 分（最大 2 時間）で自動停止する点に注意。長時間ジョブは分割するか上限を意識して設計するとよい。
