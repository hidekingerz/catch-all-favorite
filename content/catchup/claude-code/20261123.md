## 今回の注目ポイント

- **前回収録の v2.1.330 以降、v2.1.331 が公開。** 新機能は少数で、大半は安定性・UI の修正（特に VSCode 拡張の大量修正）だが、エンタープライズ／ゲートウェイ・プラグイン運用に影響する注目の変更がいくつか入った。
- **Code Mode がターミナルセッションでも各クラウドプロバイダに対応。** Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude Platform on AWS でターミナルセッションの Code Mode が使えるようになった。
- **管理対象プラグインマーケットプレイスの自動更新が既定化（2026-11-30 以降のリリースで）。** 管理設定の `extraKnownMarketplaces` にあるマーケットプレイスは既定で自動更新されるようになる。無効化するには各エントリに `"autoUpdate": false` を設定する。
- **`claude doctor` に API 接続チェックを追加。** API に到達できるか（HTTP ステータスまたはエラー、未テストならその理由）を表示するセクションが加わった。
- **MCP ツール呼び出しが最大 30 分ハングする問題を修正。** ローカル／WebSocket サーバからの不正な応答でツール呼び出しが最大 30 分ハングする問題を解消。
- **Windows: レジストリの管理設定が日本語など非 ASCII を含むと起動拒否する問題を修正（#93280）。** あわせてレジストリの `HKLM` ポリシーが `managed-settings.json` より優先される旨の注意が追加された。
- **`--resume` / `--continue` で権限モードを切り替えると thinking とプロンプトキャッシュが失われる問題を修正（Code Mode）。** 起動・再開まわりの修正と高速化が多数。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.331（v2.1.330 までは収録済み）。「What's changed」は節見出しのない一続きのリストで、VSCode を含め 150 項目超。主なものを機能カテゴリ別に整理する（全項目は changelog / GitHub Releases を参照）。

### v2.1.331（2026-11-23。Code Mode のクラウドプロバイダ対応・マーケットプレイス自動更新の既定化・大量の安定性/UI 修正）
- **バージョン**: v2.1.331（2026-11-23）
- **内容**:

  - **追加（Added）**:
    - **Code Mode をターミナルセッションで各プロバイダに対応**: Amazon Bedrock・Google Cloud の Agent Platform・Microsoft Foundry・Claude Platform on AWS。
    - Claude apps gateway に `oidc.groups_jsonpath` を追加（JSONPath のサブセット（RFC 9535）でオブジェクトのリストの該当エントリからグループを読む）。
    - **`claude doctor` に API 接続セクション**を追加（到達可否を HTTP ステータス／エラー付きで表示、未テストならその理由）。
    - タップモードの音声ディクテーションが自動停止したとき（15 秒無音または 2 分の上限）に通知を表示。
    - `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION`（圧縮応答を切るプロキシ向けに非圧縮応答を要求。セルフホストランナー／Remote Control ではまだ非推奨）。
    - `CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1`（Claude apps gateway で `oidc.use_proxy: true` 時、`NO_PROXY` 設定下でもサインインリクエストが `https` の IdP のホスト名をプロキシに渡す）。
    - `claude_code.llm_request` トレーススパンに `gen_ai.usage.*`・`gen_ai.response.model`・`gen_ai.operation.name` を追加（`gen_ai.usage.input_tokens` はプロンプトキャッシュトークンを含む）。
    - プラグインマニフェストに `optionalDependencies`（それを列挙するプラグインと一緒にインストールされ、単独で無効化／アンインストールできる）。

  - **変更（Changed。挙動・方針）**:
    - **管理対象の `extraKnownMarketplaces` のプラグインマーケットプレイスを、2026-11-30 以降のリリースで既定で自動更新**。無効化は各エントリに `"autoUpdate": false`。
    - **Windows**: レジストリの管理設定での起動方針を変更。`HKLM` ポリシーが `managed-settings.json` より優先されるため、アップグレード前に確認すること（壊れた値は起動を止めうる）。
    - `PermissionDenied` フックの `retry: true` が Claude に伝える内容を変更（そのコールを依頼した場合のみ拒否されたコールを再実行）。
    - `/ide` の自動接続停止の確認、サブエージェントビューでの `/clear`・`/compact`・`/rewind` の確認で Yes を先頭に並べるよう変更（開始位置は引き続き No。Down → Enter で No を選ぶ動作に）。

  - **安定性・ハング・パフォーマンス（影響大）**:
    - **MCP ツール呼び出しがローカル／WebSocket サーバの不正応答で最大 30 分ハングする問題**を修正。
    - 返信が沈黙しても Claude が thinking 中なら 1 回リクエストを再試行するよう修正（クラウドセッションでの turn／サブエージェント失敗や、他環境での長い返信のタイムアウトを解消）。
    - クラウド／ネットワークファイル読み込みが停滞したとき Esc・Stop が約 1 分以上待つ問題、CLI が一部応答でフリーズし引用テキストが消える／二重表示される問題を修正。
    - 起動高速化: 直前に別セッションを起動した直後のセッションがモデル一覧を待たない、git リポジトリ外で `.claude/settings.local.json` が無い場合に git を待たない。スクリーンリーダモードの入力速度を長いセッションで改善。
    - **Windows**: レジストリの管理設定が日本語など非 ASCII を含むと起動拒否する問題（#93280）、ほぼメモリ切れ時のクラッシュ、カスタムシェル起動ファイルが無いマシンでの初回 Bash の速度などを修正・改善。

  - **Code Mode・権限・フック**:
    - `--resume` / `--continue` で別の権限モードで再開した Code Mode セッションが thinking とプロンプトキャッシュを失う問題（確認モードで開始した場合はスクリプトにその上限を維持）、スクリプト実行中に `!` やスラッシュコマンドを入力すると毎秒リクエストを送る問題、長いスクリプト出力の中間が失われる問題（Claude に未切り詰めテキストへのパスを渡す。#111373）、`--bare` でスクリプトが呼べるものを Claude に伝えない問題を修正。
    - サブエージェントのモデルへの権限ルール（例 `Agent(model:*)`）がモデル未指定で開始したサブエージェントへのフォローアップを妨げる、`PermissionRequest` フックが `Skill(name:*)` の allow ルールをローカル設定外に保存しない、カスタム API エンドポイントがツール名無しのツール呼び出しを返すとクラッシュ（エラーで失敗させセッション継続）などを修正。
    - rewind が復元失敗後にファイルを削除する問題、auto モードが Claude の `/loop` 停止コールを拒否して次のウェイクアップが発火する問題、Workflow エージェントのバックグラウンドシェル／MCP サーバがレポート返却後も残る問題を修正。

  - **その他の修正・改善（抜粋）**:
    - `@file#10-12` のような行指定メンションがその行だけでなくファイル全体を添付する問題、貼り付けたアーティファクト招待リンクの誤解釈（招待を受けてアーティファクト自身のリンクを貼るよう案内）、`/install-github-app`・`/diff`（24〜26 行の窓でキーヒントを隠す／ファイル選択不可、コミットの無いリポジトリで `git add -N` のファイルを除外）、`/compact`・auto-compact が特定の XML タグを含む要約の一部を失う問題などを修正。
    - プラグイン更新の中断／失敗で部分的なフォルダが残り後でスキル等が欠けて読み込まれる問題（#102186）、管理設定が承認を要するのに尋ねられず `claude plugin install`・`marketplace add` が無出力でハングする問題などを修正。Console サインインリンクをさらに短縮。

  - **[VSCode]（追加・大量の修正・高速化）**:
    - **追加**: ノートブックセルメニューの「Add Cell to Chat」（出力／エラー付きでセルを添付）、エラー／警告・失敗テストへのクイックフィックス「Fix with Claude Code」、Source Control の変更ファイル右クリックの「Add to Chat」、マージ競合のあるファイルへの「Resolve Merge Conflicts」、ログアウト時の失効ページへのリンク警告、巨大な選択／添付ファイル送信前の通知。
    - **修正**: フォークした会話が元会話のプランファイルを上書きする、Alt+K の行指定（例 `@app.ts#5-10`）がファイル全体を送る、UTF-8 以外の `files.encoding` で差分が文字化けして保存される、長い会話のフォーク／rewind ごとにメモリが増える、`ELECTRON_RUN_AS_NODE=1` 未設定で Electron アプリ／拡張テストが起動失敗する問題など多数。
    - **高速化**: パネル・新規チャットタブの起動、長い会話（特にファイル編集が多い／git が遅い場合）の開閉・切り替え、リモート環境（SSH・WSL・コンテナ）の応答、アクセシビリティ有効時の送信時フリーズ削減など。
    - **変更**: 提案された差分は提案側（右）をクリック／入力してから受理、ターミナルセッションからの差分はフォーカスを移さず開く、`allowManagedPermissionRulesOnly` 設定時に allow ルールを出すカードは Yes／No のみ表示（キー 2 は No）。
