## 今回の注目ポイント

v2.1.310（2026-10-23。前回収録は v2.1.309 / 2026-10-22）を収録。目玉は **Monitor ツールとプラグインモニタの対応範囲拡大**で、Bedrock・Vertex・Foundry 上、およびテレメトリや非必須トラフィックを無効化した環境でも利用可能になった（同環境では長時間のフォアグラウンド sleep もブロックされる）。信頼性面では、`effort-2025-11-24` ベータ値や会話途中のシステムメッセージを拒否する一部ゲートウェイ/互換サーバ向けに**それらを外して自動リトライ**するようになり、「Prompt is too long」後のコンパクションが base64/SVG など高密度テキストを残しすぎて次リクエストが再び失敗する問題も修正。auto モードは作業ディレクトリ外の初回読み取りをブロックするとシェルコマンドが権限確認を求める旨を説明するよう改善。クラウドセッション関連では、Enterprise カスタムロールに Cloud sessions / Remote Control 権限が追加された。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.310

### ツール / 実行環境（v2.1.310）
- **バージョン**: v2.1.310（2026-10-23）
- **内容**:
  - **Monitor ツールとプラグインモニタ**を Bedrock・Vertex・Foundry 上、およびテレメトリ/非必須トラフィックを無効化した環境でも利用可能に。これらの環境では長時間のフォアグラウンド sleep もブロックされるようになった。
  - `effort-2025-11-24` ベータ値や会話途中のシステムメッセージを拒否する一部ゲートウェイ/互換サーバで、リクエストが失敗する問題を修正（それらを外して自動リトライ）。
  - 非インタラクティブセッション（`-p`、Agent SDK）でトランスクリプトファイルが非常に大きい場合の、コンパクション時のメモリ使用を改善。
  - 非インタラクティブセッションで、サーバの elicitation（ユーザー問い合わせ）が未応答のまま MCP ツール呼び出しがタイムアウトした際のエラーを変更。応答が来なかったこと、呼び出しを繰り返さないことを Claude に伝えるように。

### 権限 / サンドボックス（v2.1.310）
- **バージョン**: v2.1.310（2026-10-23）
- **内容**:
  - ファイル読み取りの権限プロンプトがシンボリックリンクの参照先を表示しない問題を修正。
  - auto モードの、作業ディレクトリ外の初回読み取り前プロンプトを改善。これらの読み取りをブロックするとシェルコマンドが権限確認を求めるようになる旨を表示。
  - Windows: Git Bash がなく、フックのコマンドが引用符付き文字列のみ（例: 引用符付きパス）の場合に、PreToolUse / PermissionRequest フックがツール呼び出しを通してしまう問題を修正。
  - 設定でサンドボックスから除外したコマンドが、サンドボックス有効だが起動できない状況で write-list パスへ書き込む前に確認を求めるよう変更（非サンドボックスのフォールバックは拒否）。

### コンパクション / ファイル管理（v2.1.310）
- **バージョン**: v2.1.310（2026-10-23）
- **内容**:
  - 「Prompt is too long」後のコンパクションが、base64 や SVG など高密度テキストの会話を残しすぎて次リクエストが再び失敗しうる問題を修正。
  - `cleanupPeriodDays` を非常に大きな値に設定した際、バックグラウンドクリーンアップが貼り付け画像など最近のファイルを削除してしまう問題を修正。
  - 質問の auto-continue タイムアウトが、長い編集後に外部エディタを閉じた瞬間に発火する問題を修正。

### モッド / 表示 / Linux（v2.1.310）
- **バージョン**: v2.1.310（2026-10-23）
- **内容**:
  - mod の `Image` を、`allow-passthrough` と `focus-events` を有効化した tmux 内、および kitty・Ghostty・iTerm2 3.5+ のフルスクリーンレンダリングで描画するよう改善（従来は `alt` テキストのみ表示）。
  - Linux: bubblewrap がサンドボックスを起動できない際、`/sandbox` とサンドボックス起動時の警告が Ubuntu のユーザー名前空間に対する AppArmor 制限とその解除方法を示すよう改善。

### クラウドセッション / VSCode / その他（v2.1.310）
- **バージョン**: v2.1.310（2026-10-23）
- **内容**:
  - [Cloud sessions] Enterprise カスタムロールに Claude Code クラウドセッションと Remote Control の権限を追加（Owner がロール単位でアクセスを制御可能に）。クラウド環境のセットアップスクリプトをファイルから読み込む Choose file ボタンを追加。編集ダイアログの保存/アーカイブ失敗やルーティンの API トークン操作失敗のエラー表示、セッション開始チェックリストのセットアップスクリプト出力表示などを改善・修正。
  - [VSCode] プラン審査カードの「Send feedback and keep planning」で Enter がプランを承認してしまう問題、Session history の Web タブから開いたクラウドセッションで「Switch branch & continue」後にパネルが「Something went wrong」と表示する問題を修正。
  - [Claude Tag] 太字/斜体/取り消し線で送った `!restart`・`!help` などの `!` コマンドが通常メッセージ扱いされる問題、管理チャンネル/ワークスペースページがバンドル一覧のバックグラウンド更新失敗でロードエラーに置き換わる問題などを修正。
  - [Code Review] リポジトリ一覧の更新失敗後に Code Review 管理セクションがリポジトリとスイッチを隠す問題を修正、初回ロードのリトライと Try again バナー表示を改善。

## 使い方メモ

- Bedrock / Vertex / Foundry 利用者や、テレメトリ・非必須トラフィックを無効化している環境でも Monitor ツール（およびプラグインモニタ）が使えるようになった。これらの環境では長時間のフォアグラウンド sleep がブロックされる点に注意。
- 一部ゲートウェイ/互換サーバ経由で `effort-2025-11-24` ベータ値や会話途中のシステムメッセージが拒否されてリクエストが失敗していた場合、今回の自動リトライで解消する可能性がある。
