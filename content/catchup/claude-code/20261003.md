## 今回の注目ポイント

- **v2.1.289 がリリース**。前回（v2.1.288）に続くパッチで、大半は **Claude Mods / プラグイン周りの安定化** と **セキュリティ（Bash の deny/ask ルールのすり抜け）修正**。
- **エージェントチーム向けに `agent.spawn` を追加**。プラグインフックイベント間で 1 つのエージェント ID を共有し、`$.agent.list()` に idle / waiting 状態が加わった。
- **サンドボックス自動許可（auto-allow）下での Bash 権限ルールのすり抜けを複数修正**。環境変数プレフィックス（例: `TZ="$HOME" rm -rf build`）付きコマンドや、コマンド前の素の変数代入で deny/ask ルールが外れる問題を修正。
- **シンボリックリンク経由の `Read` deny ルール回避を修正**。IDE で @メンション・変更・選択されたファイルを symlink 経由で読む場合に deny ルールが効かない問題を修正。
- **モッドの描画エラーでセッションが落ちる問題を多数修正**。モッドの描画失敗が周囲の描画やセッション全体を巻き込まず、単体で失敗して `ui.fault` を上げるように。
- **[VSCode] 2.1.288 の `claude auth status` 変更をリバート**（サインアウトが頻発する可能性があったため）。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.289

### v2.1.289（2026-10-03）

- **エージェントチーム / エージェント API**:
  - teammate 向けに `agent.spawn` を追加。プラグインフックイベント間で 1 つのエージェント ID を共有し、`$.agent.list()` に idle / waiting 状態を追加。
- **セキュリティ / Bash 権限ルール**:
  - サンドボックス自動許可時に、展開値を持つ環境変数プレフィックス（例: `TZ="$HOME" rm -rf build`）の後ろのコマンドに Bash の deny/ask ルールが効かない問題を修正。
  - サンドボックス自動許可時に、コマンドの前に素の変数代入があると Bash の deny/ask ルールがスキップされる問題を修正。
  - IDE で @メンション・変更・選択されたファイルを symlink 経由で読む際に `Read` の deny ルールが適用されない問題を修正。
  - 管理対象マシンで、複合シェルコマンドのネストした部分の deny/ask ルールが、ユーザーインストールのモッドの承認をまたいで保持されない問題を修正。
  - ユーザーインストールのプラグインが、組織管理 MCP サーバーのサインインツールの説明を書き換えられてしまう問題を修正。
- **Claude Mods / プラグイン（安定化）**:
  - アップグレード後の最初のセッションでインストール済みモッドがロードされない問題を修正。
  - モッドの `ui.render` フックが書いた値で行が描画中に例外を投げると「unrecoverable interface error」でセッションが終了する問題を修正（エンジンが自前の行を描画するように）。
  - モッドの `Client` が描画中に失敗すると周囲の描画を巻き込む問題を修正（単体で失敗し `ui.fault` を上げる）。また、ターミナルが描画中に例外を投げると、その後セッション全体でモッドの Client 領域が失敗したままになる問題も修正。
  - プラグインのペインが、リンクに localhost アドレス・パス中の `@`・大文字ホスト・`file:` パスを使うと何も描画しない問題、ボーダースタイル未知の Box 描画で起動時にフリーズ／強制終了する問題、高さ 0 のリージョンが伸び続けるとインターフェースエラーで終了する問題などを修正。
  - プラグインのオンスクリーンハンドラが非同期で例外を投げると supervised / background セッションが終了する問題、プラグインのタイマー／読み取り実行中にリロード・無効化すると落ちる問題を修正。
  - バックグラウンドタスクダイアログをフルスクリーンで開いている間、プロンプト上部のプラグイン行に古い行が表示される問題を修正。
  - プラグインコードペインで大きなファイルを開く速度を改善（ハイライト済みビューを最終幅で一度だけレイアウト）。
  - `plugin list` / `plugin eval` / `plugin update` がローカルフォルダマーケットプレイスからインストールしたプラグインの古いコピーを表示する問題、symlink された `--plugin-dir` のホットリロードを修正。
  - `claude plugin validate` が、フォルダにマーケットプレイスマニフェストも含まれるとプラグインをスキップする問題、Anthropic マーケットプレイス自身のプラグインを失敗扱いにする問題を修正（`--json` でクリーンな `plugin.json` を表示）。
  - `claude plugin test` が、古い保存設定だけを読んでモッドをリモートで無効と誤報告する問題を修正。
  - プラグインコンポーネントの描画失敗時のメッセージ改善（モッド名を示し、何も描画されなかったと伝える／失敗理由が空のとき `Error` や空表示になる問題を修正／右寄せコンテンツが閉じマークや `[-]` の下に描画される問題や端から 1 列内側を保つように修正／バンドの一時的な描画失敗でカードが退避する問題を修正）。
- **ターミナル描画 / その他**:
  - 閉じられていない `<script>` タグが多い短いコードブロックや深くネストした `${` 置換でターミナルがフリーズする問題を修正。
  - 公開アーティファクトページが、閉じられていない `<script>` タグの多い短いコードブロックで読者のブラウザタブをフリーズ／クラッシュさせる問題を修正。
  - タブ・迷子のエスケープ・C1 制御文字を含むテキスト（または CRLF 改行とタブを含む短いテキスト）が下の行に重ねて描画される問題を修正。

## 使い方メモ（任意）

- **`agent.spawn`**（エージェントチーム）により、プラグインのフックイベントをまたいでエージェント ID を一貫して扱えるようになった。`$.agent.list()` では idle / waiting の状態も取得できる。
- サンドボックスの auto-allow を使っている場合、環境変数プレフィックスや変数代入を前置した `rm` などで権限ルールがすり抜けていた可能性がある。v2.1.289 で deny/ask ルールが正しく効くようになったため、権限設定に依存した運用をしている場合はアップデートが推奨される。
