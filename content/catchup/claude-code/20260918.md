## 今回の注目ポイント

前回（2026-09-17 収録、v2.1.275 まで）以降、changelog に **v2.1.276・v2.1.277**（いずれも 2026-09-18 更新）の 2 バージョンが追加された。v2.1.276 は **v2.1.275 で入ったリグレッションの緊急修正**で、`ANTHROPIC_BASE_URL` がプロキシ/ゲートウェイを指している環境で全リクエストが `400 … Input tag 'advisor_20260301'` で失敗していた問題を修正する。ゲートウェイ経由で Claude Code を使っている場合は速やかに更新したい。v2.1.277 は 60 件超の修正を含む大型更新で、**CLAUDE.md が無い場合に `AGENTS.md` を読み込む**対応、フォワードプロキシのエグレス境界を指定する `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1`、`/tasks` などのパネルにバックグラウンドタスクの待機状態を表示する UI、「text content blocks must be non-empty」で会話が失敗する問題や、古い Claude Code ビルドが同一マシンで動くと意図せずログアウトする問題などの重要修正が入っている。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.276 〜 v2.1.277

### v2.1.277（2026-09-18）
- **バージョン**: v2.1.277（2026-09-18）
- **内容**: 60 件超の修正・改善を含む大型更新。主な新機能: (1) CLAUDE.md が利用できない場合に **`AGENTS.md` を読み込む**対応、(2) フォワードプロキシのエグレス境界を指定する環境変数 `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1`、(3) `/tasks` 等のパネルにバックグラウンドタスクの待機ステータスを表示する UI。主な修正: 会話が「text content blocks must be non-empty」で失敗する問題、同一マシンで古い Claude Code ビルドが動くと意図せずログアウトする問題、更新チェックが 30 分ごとに無効なバージョンでエラーになる問題、プラグイン再インストール時に導入済みコピーが壊れる問題、Edit ツールがエスケープ済みバックスラッシュを誤って扱う問題、Windows で長いパス名の PDF ページ読み込みが失敗する問題、再開したサブエージェントがプロンプトキャッシュを壊す問題など。VS Code ではセッションのコスト/トークン使用量表示、エージェントマップへのバックグラウンドタスク表示、レスポンスのコピーボタンを追加。Web ではパーソナル/組織の環境セクション、クラウド環境の共有機能を追加。

### v2.1.276（2026-09-18）
- **バージョン**: v2.1.276（2026-09-18）
- **内容**: **v2.1.275 のリグレッション緊急修正**。`ANTHROPIC_BASE_URL` がプロキシ/ゲートウェイを指している場合に、全リクエストが `400 … Input tag 'advisor_20260301'` で失敗していた問題を修正。ゲートウェイ/プロキシ経由で利用している環境では必須の更新。

## 使い方メモ（任意）

- **AGENTS.md**: v2.1.277 で CLAUDE.md が無いプロジェクトでも `AGENTS.md` がプロジェクト指示として読まれるようになった。他ツールと共通の `AGENTS.md` を使っているリポジトリでは、Claude Code 側でもそのまま指示が効く。
- **ゲートウェイ利用者**: v2.1.276 の緊急修正が該当するため、`ANTHROPIC_BASE_URL` を設定している場合は v2.1.276 以降へ更新すること。エグレス境界を明示したい場合は v2.1.277 の `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` も参照。
