## 今回の注目ポイント

前回キャッチアップ（2026-08-07、v2.1.224 まで）以降の新着は **v2.1.225** と **v2.1.226**（ともに 2026-08-08）の 2 バージョン。v2.1.226 は「バグ修正と信頼性改善」のみで詳細項目なし。実質的な内容は v2.1.225 に集約される。目玉は、前回追加されたクロスセッション `SendMessage` の**リモート機能への拡張**で、別マシン上の Remote Control セッションを**名前で指定して会話を開始**できるようになった（従来は相手から先にメッセージが来た後にしか返信できなかった。`ListAgents` が `name [ref]` 形式で一覧表示）。あわせて **gateway のスペンドリミット対応**が使用量警告に加わり、上限到達メッセージが上限額・リセット時刻・オペレーターのメッセージを明示するようになった（gateway 側 2.1.225 が必要）。`claude agents` に**信頼していないディレクトリ向けのワークスペース信頼プロンプト**が追加され、`claude` 本体と挙動が揃った。修正面では、短命トークンによる `CLAUDE_CODE_OAUTH_TOKEN` 置き換えでヘッドレスセッションが壊れる問題、macOS の MCP OAuth サーバの断続的 401、auto モードが自身の権限チェックへのセーフティフィルタ拒否を連続ブロック数にカウントしてしまう問題、大規模会話のコンパクション後に Remote Control セッション再開で会話履歴が壊れる問題、`claude self-hosted-runner` が `--base-dir` を作成/書き込みできない場合に登録後に毎セッション失敗する問題などが修正された。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.225 〜 v2.1.226（2026-08-08）

### クロスセッション通信（SendMessage / ListAgents）

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - `SendMessage` が、別マシン上の **Remote Control セッションと名前で会話を開始**できるようになった（`ListAgents` が `name [ref]` 形式で一覧表示）。従来は相手が先にメッセージを送ってきた後でしか返信できなかった。
  - 既に確認済みの Remote Control 宛先が、相手側の一覧を確認できなかった場合でも、このマシン上の同名セッションに差し替えられないように修正。
  - ヘッドレスセッションや起動時に、クロスセッションメッセージが通知も期限もないまま滞留する問題を修正。

### 使用量・課金（gateway スペンドリミット）

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - Claude Code の使用量警告に **gateway のスペンドリミット対応**を追加。上限到達メッセージが、上限額・そのリセット時刻・オペレーターのメッセージを明示するようになった（gateway 側 2.1.225 が必要）。

### 権限・信頼・auto モード

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - `claude agents` に、信頼していないディレクトリ向けの**ワークスペース信頼プロンプト**を追加。`claude` 本体と同じ挙動に揃えた。
  - auto モードが、自身の権限チェックに対するセーフティフィルタの拒否を連続ブロック上限にカウントしてしまう問題を修正。当該アクションは引き続き拒否されるが、モデルにはリトライではなく次に進むよう指示されるようになった。

### 認証・トークン・MCP

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - 一時的な 401 が、長命の `CLAUDE_CODE_OAUTH_TOKEN` を保存済みログインの短命トークンで置き換えてしまい、再起動までヘッドレスセッションが壊れる問題を修正。
  - macOS で MCP OAuth サーバが、keychain 読み取りのタイムアウト後に、認証済みでないかのように 401 のバーストで断続的に失敗する問題を修正。

### セルフホスト実行環境

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - `claude self-hosted-runner` が、`--base-dir` を作成/書き込みできないときに登録後に毎セッション失敗していた問題を修正。起動時に明確なエラーで終了するようになった。

### Remote Control・Web / モバイル

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - 非常に大きな会話がコンパクションされた後、Remote Control セッション再開で会話履歴が壊れる問題を修正。
  - Claude Code on the web のセッションが「スタック」と誤報告され、再接続のたびに増え続けるイベントのバックログを再送していた問題を修正。
  - 改善: Claude アプリから添付された写真を、別のツール呼び出しでディスクから読むのではなく、直接 Claude に見せるように。

### エージェント一覧・表示

- **バージョン**: v2.1.225（2026-08-08）
- **内容**:
  - エージェント一覧で別プロジェクトのセッションにホバーすると、次のエージェントの開始ディレクトリが変わってしまう問題を修正。
  - [VSCode] Focus ビューが最新の to-do リスト・保留中の質問のコンテキスト・確定済みの回答を畳んでしまう問題を修正。thinking のみの折りたたみは「Thought for Ns」と表示し、そのターン完了時に再度折りたたむように。

### その他

- **バージョン**: v2.1.226（2026-08-08）
- **内容**:
  - バグ修正と信頼性改善（changelog に個別項目の記載なし）。

## 使い方メモ（任意）

- **クロスセッション `SendMessage` のリモート拡張**: v2.1.224 で追加された同一マシン内のセッション間メッセージングが、v2.1.225 で別マシン上の Remote Control セッションにも広がった。`ListAgents` が相手を `name [ref]` 形式で表示するので、相手からのメッセージを待たずに名前指定で会話を開始できる。複数マシン・複数環境にまたがるマルチエージェント運用の土台がさらに実用的になった。
- **gateway スペンドリミット**: gateway 経由で Claude Code を利用している組織では、v2.1.225 で上限到達時のメッセージに上限額・リセット時刻・オペレーターのメッセージが表示されるようになった。利用が上限に達した際の原因把握がしやすくなる（gateway 側も 2.1.225 が必要）。
- ヘッドレス / CI 運用者向けには、`CLAUDE_CODE_OAUTH_TOKEN` が短命トークンで置き換わってセッションが壊れる問題の修正が重要。長命トークンでヘッドレス実行している場合は v2.1.225 への更新が推奨される。
