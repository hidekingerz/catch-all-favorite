## 今回の注目ポイント

- **Claude Fable 5.1（`claude-fable-5-1`）が追加され、デフォルトの Fable モデルに**。1M コンテキスト、$10/$50 per Mtok（キャッシュリード $0.25/Mtok）。ただし Claude apps gateway 経由では当面 `fable`/`best` は Fable 5 に解決され、Fable 5.1 を使うには `/model` で明示選択が必要。
- **セキュリティ強化が複数**。auto モードに「Containment Escape」ルールが追加され、クラウドのメタデータ認証情報取得・egress 回避・クロステナントアクセスは（環境が想定と明示しない限り）自動承認されなくなった。作業ディレクトリ外の初回ファイル読み取り前に一度確認プロンプトが出るようになり（`permissions.blockReadsOutsideWorkingDirectories` でブロック可）、プラグインがシンボリックリンク経由で自ディレクトリ外を読む挙動も拒否されるようになった。`defaultMode: "bypassPermissions"` はプロジェクト設定では無視される。
- **サブエージェント運用の改善**。ストリーム中断（スリープ・接続断・サーバエラー）でサブエージェントが停止せず自動継続するように。`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` で全サブエージェントにモデルを強制適用できる。
- 時刻表示の設定（`timeFormat` / `timeZone`）、`/effort` のセッション限定変更（`s`）、VSCode 拡張の UI 追加（モデルピル・アカウント/使用量セクション・セッションのアーカイブ化）など、細かな使い勝手の改善も多数。

## 新機能・変更（changelog）

> 対象バージョン: v2.1.257 〜 v2.1.258（v2.1.252 までは記録済み）

### モデル
- **バージョン**: v2.1.257（2026-09-01）
- **内容**: Claude Fable 5.1（`claude-fable-5-1`）を追加し、デフォルトの Fable モデルに。1M コンテキスト、$10/$50 per Mtok、キャッシュリード $0.25/Mtok。Claude apps gateway セッションでは `fable`/`best` は当面 Fable 5 に解決される（gateway が 5.1 未対応で拒否するため）。5.1 を使うには `/model` で選択する。gateway 供給の `description` を `/model` ピッカーのエントリに表示できるようになった（`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY`）。

### 権限・セキュリティ（auto モード）
- **バージョン**: v2.1.257（2026-09-01）
- **内容**:
  - auto モードに「Containment Escape」ルールを追加。クラウドのメタデータ認証情報取得・egress 回避・クロステナント到達は、環境が想定と明示しない限り自動承認されない。
  - 作業ディレクトリ外の初回ファイル読み取り前に一度だけ確認プロンプトを表示（`permissions.blockReadsOutsideWorkingDirectories` で読み取り自体をブロック可能）。
  - `defaultMode: "bypassPermissions"` を `.claude/settings.json` / `settings.local.json` で指定しても無視されるように（`"auto"` と同様）。ユーザー/管理設定か `--permission-mode` で指定する。
  - プラグインがコマンド/エージェント/スキル/フック等のパスにシンボリックリンクを使って自ディレクトリ外のファイルを読む挙動を拒否。
  - Cowork / claude.ai クラウドセッションで、自分のものでないアーティファクトの読み取りは auto モードでも常に確認するように。
  - `permissions.ask` ルールが複合コマンド/サブシェル内でスキップされる問題や、Bash の `Read()`/`Edit()` deny ルールが `< file` リダイレクトや `tac`/`egrep` に効かない問題を修正。

### サブエージェント・バックグラウンド/エージェント運用
- **バージョン**: v2.1.257（2026-09-01）
- **内容**:
  - `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` を追加。`CLAUDE_CODE_SUBAGENT_MODEL`（または主モデル）を全サブエージェントに適用し、spawn 単位・エージェント定義のモデル上書きを無視する。
  - ストリームがコンピュータのスリープ・接続断・サーバエラーで中断してもサブエージェントが停止せず自動継続。
  - `claude agents` のバックグラウンドセッション周りの多数の修正（別セッションからの承認待ち表示、再プロンプト後の Completed の並び順、`Ctrl+S`/`Ctrl+T` のリバインド対応など）。
  - `/fork` が新バックグラウンドセッションで元会話のプロンプトキャッシュを維持するように改善。

### 設定・使い勝手
- **バージョン**: v2.1.257（2026-09-01）
- **内容**:
  - 「Time format」（`timeFormat`）と `timeZone` 設定を追加（12/24時間・24時間UTC・strftime パターン）。
  - `/effort` に `s` を追加し、現在のセッションのみ effort を変更可能に（`/model` と同様）。
  - `/doctor` に、強制終了されたセッションが残した古い sandbox マスクファイルの警告を追加。
  - `/add-dir` が作業ディレクトリ内のディレクトリを受け付けるように修正（スキル/コマンド/エージェントを読み込む）。`--add-dir` などがネットワークパス（UNC 共有・`/net/<host>`）を拒否するように。
  - `/btw` の履歴移動を `Shift+←`/`Shift+→`（または `[`/`]`）に変更。
  - レンダリング/入力応答性能の改善（長い会話での再描画削減、ストリーミング速度低下の解消）。

### VSCode 拡張
- **バージョン**: v2.1.257（2026-09-01）
- **内容**: 入力フッターにモデルピル（モデル表示＋ピッカー、Effort 行、More models）を追加。セッション一覧に折りたたみ可能な ACCOUNT & USAGE / SESSION MANAGER ヘッダ、出力スタイル選択を追加。「Delete session」を「Archive session」に変更。サードパーティプロバイダ（Bedrock/Vertex 等）で claude.ai 限定機能が表示される問題などを修正。

### 不具合修正
- **バージョン**: v2.1.258（2026-09-01）
- **内容**: macOS 12（Monterey）で Claude Code が起動しない問題（2.1.255 で混入したリグレッション）を修正。リモート/スケジュールセッションが、再送された権限承認を適用できず "user messages must have non-empty content" で失敗する問題を修正。

## 使い方メモ

- auto モードを使う環境（特にクラウド/CI）では、今回の Containment Escape ルールと作業ディレクトリ外読み取りプロンプトにより、これまで自動で通っていた一部の操作が確認待ちになる可能性がある。想定される操作は環境側で許可設定を見直すとよい。
- サブエージェントを多用するワークフローでは、`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` でモデルを統一できるようになった点と、中断時の自動継続で長時間タスクが途中終了しにくくなった点が有用。
