## 今週の注目ポイント

- **React 19.3 が正式リリース**: View Transitions と Fragment Refs が stable に昇格し、SSR をオプトアウトできる `use(browser())` API、Trusted Types によるセキュリティ機能、RSC で `<Context>` を直接レンダリングできる機能などが追加された。View Transitions / Fragment Refs を試したかった人はこのバージョンで本番投入を検討できる。
- **React Compiler の Rust 実装が Vite で 17 倍高速に**: 「React Now Rusted All The Way Out」が Rust 版 React Compiler の Vite 対応をまとめ、Babel 版比 17 倍の高速化を報告。React Router のフレームワークモード利用者向けの代替手段も示されており、ビルド時間に悩むプロジェクトに直接効く。
- **shadcn 発の `cn` エンジン**: Tailwind のクラスマージ/衝突解決を担う新エンジンで、`tailwind-merge` + `clsx` の 30 倍速を謳い、同一 API を提供。すでに shadcn 4.21 に統合済みで、多用するユーティリティだけに影響が大きい。
- **メジャーバージョン更新ラッシュ**: Jotai 3.0（ESM-only 化）、Vitest 5.0、htmx 4.0（XHR→fetch への破壊的変更）、NestJS 12.0（ESM ファースト・Rspack 採用）が同週に到着。ESM 移行や破壊的変更を含むものが多く、依存関係のアップグレード計画に影響する。

## React

### React 19.3
- **URL**: https://react.dev/blog/2026/09/09/react-19-3
- **要約**: React の新しいマイナーバージョンが正式リリース。View Transitions と Fragment Refs が stable になり、サーバーサイドレンダリングをオプトアウトする `use(browser())` API、Trusted Types セキュリティ機能、RSC が `<Context>` を直接レンダリングできる機能などを含む。

### React DevTools 8.0
- **URL**: https://github.com/react/react/blob/main/packages/react-devtools/CHANGELOG.md#800
- **要約**: Suspense タブの有効化、React Element パネルの追加、Timeline プロファイラを Performance トラックへ置き換え、Activity のサブツリーを暗く表示、などを含む。まだ npm や拡張機能ストアには公開されていない。

### React DevTools CDT MCP
- **URL**: https://github.com/react/react/tree/main/packages/react-devtools-cdt-mcp
- **要約**: React チームが実験中の新パッケージで、最近 npm に公開された。MCP サーバーそのものではなく、Chrome DevTools がエージェントに有用な React ツールを発見・登録・公開できるようにするもの。

### Document missing SSR and hydration options（react.dev PR）
- **URL**: https://github.com/reactjs/react.dev/pull/8632
- **要約**: `formState`、`importMap`、`maxHeadersLength` といった SSR オプションについて、これまで抜けていた API ドキュメントを追加する PR。

### Upgrade web-vitals to v6 and report soft navigations（Next.js PR）
- **URL**: https://github.com/vercel/next.js/pull/97232
- **要約**: `useReportWebVitals()` が、Core Web Vitals に最近追加された SPA のソフトナビゲーションを近く報告できるようになる。

### React Now Rusted All The Way Out
- **URL**: https://blog.master.dev/react-now-rusted-all-the-way-out/
- **要約**: Rust 版 React Compiler の Vite 対応を概観する記事。Babel 版比 17 倍の高速化を報告し、React Router フレームワークモード利用者向けの代替手段も示す。

### Replacing Next.js with a vibe-coded "framework"
- **URL**: https://maxleiter.com/blog/thank-u-next
- **要約**: 個人サイトの Next.js を、Claude が設計した 5000 行のフレームワークに置き換えた事例。サーバー側は依然として React/MDX、クライアント側は Preact のアイランドで、送出する JS を 99% 削減した。

### How Turbopack chunks your JavaScript
- **URL**: https://nextjs.org/blog/turbopack-chunking
- **要約**: コード分割戦略のトレードオフと、ダウンロードサイズとリクエスト数の両方を最小化するために使われるヒューリスティックを解説する。

### How we closed 1,500 GitHub issues in one month（Next.js）
- **URL**: https://nextjs.org/blog/how-we-closed-1500-github-issues
- **要約**: バックログの issue を分析するエージェントを構築し、メンテナが自信を持って数千件の issue をクローズできるよう支援した取り組み。

### React Google Maps 1.10
- **URL**: https://github.com/visgl/react-google-maps/releases/tag/v1.10.0
- **要約**: 既存の Google Maps 3D 対応を完成させ、GLB モデル・HTML マーカー・ポリライン・ポリゴン・地形フラット化・円形パスの宣言的コンポーネントを追加した。

### cn - A new engine for Tailwind class merging and conflict resolution
- **URL**: https://github.com/shadcn-ui/cn
- **要約**: Tailwind のクラスマージと衝突解決のための新エンジン。`tailwind-merge` + `clsx` と同じ API で 30 倍高速を謳う。すでに shadcn 4.21 に統合済み。

### Effective RSC
- **URL**: https://www.nikhilsnayak.dev/blog/introducing-effective-rsc
- **要約**: Bun 向けの実験的な Effect ネイティブの React Server Components フレームワーク。RSC ページは `Effect.fn()` 関数で、ルートパラメータは Schema でデコードされる。

### Vidact
- **URL**: https://www.vidact.dev/
- **要約**: React コードを直接的な DOM 操作へコンパイルする。ベータ版で React 19 の一部をサポート。コンポーネントはマウント時に一度だけ実行される。

### uf - Unified Toolchain for Flow and React
- **URL**: https://docs.uniflowed.dev/
- **要約**: Vite+ に匹敵する Rust 製ツールチェーンで、React と Flow の DX を改善する。Flow は React 向けに TypeScript より精密な型システムと説明されている。

### DevJar 1.0
- **URL**: https://github.com/huozhi/devjar
- **要約**: 自サイトにインタラクティブな React ベースの体験を埋め込むための、CodeSandbox に代わる興味深い選択肢。

### Bamboo CSS
- **URL**: https://bamboocss.com/docs/overview/getting-started
- **要約**: ゼロランタイムの CSS-in-JS。Vite コンパイラがランタイムを消去し、未使用トークンを刈り取り、無効なトークンではビルドを失敗させる。

### Base UI 1.8
- **URL**: https://base-ui.com/react/overview/releases/v1-8-0
- **要約**: Menu/Popover のマウント性能を改善し、`Combobox.createItems()` API、Avatar の遅延読み込みなどを追加した。

### Rsbuild Plugin React Router 0.6
- **URL**: https://github.com/rstackjs/rsbuild-plugin-react-router/releases/tag/rsbuild-plugin-react-router%400.6.0
- **要約**: React Router 8 とその RSC モードをサポートする。

### Storybook 10.6
- **URL**: https://github.com/storybookjs/storybook/releases/tag/v10.6.0
- **要約**: TanStack / NextJS-Vite フレームワークの修正、エージェントのツール/スキル向け CLI バインディング、性能改善を含む。

### React Window 2.3
- **URL**: https://github.com/bvaughn/react-window/releases/tag/2.3.0
- **要約**: 新しいオプションの `rowKey` / `columnKey` props を追加した。

### Jotai 3.0
- **URL**: https://github.com/pmndrs/jotai/releases/tag/v3.0.0
- **要約**: 非推奨 API を削除し、ESM-only の近代化されたパッケージになった。
