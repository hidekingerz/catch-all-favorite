## 今週の注目ポイント

- **TanStack Redact**: Tanner Linsley の AI 駆動の React プロジェクション実験が、本番採用される実際の TanStack プロジェクトになった。ブラウザ向けの軽量な React 互換ランタイムで、Start / Next.js / Vinext / Vite で動作。サーバー側は React が SSR と Server Components を担当し変わらない。トレードオフは同期レンダリング（time slicing なし）で、重いレンダーは入力を遅延させうる。
- **Node.js のセキュリティリリース（Node2Shell）**: Brotli デコーダーにリモートコード実行（RCE）脆弱性。第三者の制御下の Brotli データをデコードするアプリは Node.js（または Bun）を即アップグレードすべき。Bun 1.4.4 でも修正済み。
- **Next.js の 11 月セキュリティリリース予告**: 11 月 3 日に 7 件の medium 深刻度の脆弱性修正を予定。事前に把握しておくべき。
- **TanStack AI 1.0**: フレームワーク非依存の AI インターフェースが安定版に。非推奨 API を削除して API 安定性にコミット。23 のプロバイダアダプタ、サブエージェント、MCP サーバ、実験的なエージェントハーネスを備え、`useChat()` などの React バインディング/フックを同梱。
- **Reylo と TS 7.1 content mappers**: Zod 作者が TS 7.1（beta）の content mappers を活用し、`.sql` ファイルから完全な型推論を実現。TOML / YAML / CSV / Markdown front matter / .env などに型安全性を提供する Motherload も公開。

## React

### TanStack Redact
- **URL**: https://tanstack.com/blog/introducing-tanstack-redact
- **要約**: Tanner Linsley の AI 駆動の React プロジェクション実験が本番採用の TanStack プロジェクトに。ブラウザ向けの軽量な React 互換ランタイムで、Start / Next.js / Vinext / Vite で動作。サーバー側は React が SSR と Server Components を担当し変わらない。軽量な代わりに同期レンダリング（React の time slicing なし）で、「重いレンダーは入力を遅延させうる」とブログも認めている。
