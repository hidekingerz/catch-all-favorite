## 今週の注目ポイント

- **Octane が公開**。Inferno 作者・元 React/Svelte の Dominic Gannaway による「Reactの後継」。React のメンタルモデルを保ちつつ Hooks/Suspense/Actions を事前コンパイルし、Virtual DOM を排除。Hook のルールや依存配列の管理も不要にする野心的なプロジェクト。
- **TanStack が RSC を一部撤退して SSR に回帰**。tanstack.com で重い依存には RSC を使っていたが、ライブラリが軽量化したため SSR に切り替え性能改善。TanStack Start では SSR / RSC を文脈ごとに選べる方針。あわせて新ブランディング・デザインシステムへの刷新も発表。
- **npm の公開時マルウェアスキャンが GitHub から提供開始**。新規公開パッケージは公開前に自動スキャンされ、公開〜一般公開の間に5〜15分の遅延が入るようになる。サプライチェーン対策の強化。
- **Chrome 151 が SPA のソフトナビゲーション（`history.pushState` 遷移）を Core Web Vitals として既定計測**。DevTools・web-vitals・Lighthouse・PSI・RUM に統合される。

## React

### Octane – React's programming model, compiled
- **URL**: https://octanejs.dev/
- **要約**: 元 React/Svelte・Inferno 作者の Dominic Gannaway による新しい「Reactの後継」。React のメンタルモデルを維持しつつ Hooks・Suspense・Actions を事前コンパイル。Virtual DOM を排除しネイティブのブラウザイベントを利用、Hook のルールや依存配列の管理を不要にする。JSX/TSX と TSRX に対応し、TanStack・React Three Fiber・Lynx・StyleX・NativeScript との統合を持つ。

### Next.js docs preview - Offline support
- **URL**: https://preview.nextjs.org/docs/app/guides/offline-support
- **要約**: `experimental.useOffline` を有効化すると、ネットワーク断時に Next.js がエラーを投げず、リクエストを保留にして自動リトライできるようになる。

### React Advanced London Conference
- **URL**: https://reactadvanced.com/?utm_source=thisweekinreact
- **要約**: 10月23日・26日にロンドンで開催。TanStack・Vercel・Apollo から初期スピーカーが発表。コード「TWIR」で10%割引。

### TanStack - We Stopped Using RSC on TanStack.com
- **URL**: https://tanstack.com/blog/we-stopped-using-rsc-on-tanstack-com
- **要約**: 重い依存のために RSC を採用していたが、ライブラリが軽量化したため SSR に切り替え、より良い性能を達成。TanStack Markdown と TanStack Highlight（alpha）を導入。TanStack Start では SSR / RSC を文脈ごとに選択できる。

### Making Referential Stability a Type
- **URL**: https://www.jovidecroock.com/blog/referential-stability-types/
- **要約**: `stableref/react` を使い、メモ化済みの値を `Stable<T>` 型でタグ付けする提案。メモ化されていない props や依存にはコンパイルエラーを出し、API がメモ化済みの値のみを受け取ることを強制する。

### Experimenting with RSCs for Performance and UX in Next.js
- **URL**: https://aurorascharff.no/posts/experimenting-with-rsc-for-performance-and-ux-in-nextjs/
- **要約**: Next.js 16.3 でサーバー側処理を維持する3つの実験。クエリパラメータによるページネーション、ストリーミング結果でフォーカスを保つ検索フィールド、アクションからの JSX 生成。

### How to find a Next.js memory leak in production
- **URL**: https://xabierlameiro.com/blog/nextjs/nextjs-memory-leak-in-production
- **要約**: Next.js の3つのメモリリークをヒープスナップショットで検出する方法を解説。v16.3 での Dan Abramov による最近の修正も含む。

### The state of zero-runtime CSS-in-JS, mid-2026

### How to Think in Remix UI Instead of React
- **URL**: https://sergiodxa.com/tutorials/think-in-remix-ui-instead-of-react
- **要約**: React の視点から Remix v3 を実践的に紹介。コンポーネントは一度だけ実行され render クロージャを返し、`this.update()` で再レンダリングする。Hooks より制御しやすいがボイラープレートは増える。
