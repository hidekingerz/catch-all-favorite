## 今週の注目ポイント

- **300号の節目**: This Week in React の第300号。Next.js と TanStack チームからの大型リリース、React Foundation の動きが特集されている。
- **Next.js 16.4**: Cache Components が成熟し、`create-next-app` で既定有効化。静的保証・プリフェッチ制御に加え、View Transitions や Fragment Refs を含む React 19.3 統合を取り込む。
- **TanStack Charts 1.0**: 小さなバンドル・高速な更新・合成可能で型安全な設計を備えたチャートライブラリが正式に安定版化。React アダプタを提供。
- **React Foundation の動き**: Callstack から Barbara Markiewicz が Director of Community に就任。招待制の Contributors Summit（11/10–12・ロンドン）、初の財団主催カンファレンス React Conf Ghana（11/4–5・アクラ）を告知。
- **Effect 4.0**: 依存ゼロでコアを全面再構築し、バンドルを 5 分の 1 に縮小、長期サポートを表明。React 向け公式バインディング Effect Atom React も登場。

## React

### Next.js 16.4
- **URL**: https://nextjs.org/blog/next-16-4
- **要約**: Cache Components が成熟し、`create-next-app` で既定有効化。静的保証とプリフェッチ制御を備え、View Transitions・Fragment Refs を含む React 19.3 統合を取り込んだ。

### TanStack Charts 1.0
- **URL**: https://tanstack.com/blog/tanstack-charts-1-0
- **要約**: 小さなバンドル・高速更新・合成可能で型安全な設計を特徴とするチャートライブラリの安定版。React アダプタを同梱する。

### TanStack Markdown + Highlight 1.0
- **URL**: https://x.com/tan_stack/status/2105549976025915676
- **要約**: 小さく高速な Markdown レンダラとシンタックスハイライタ。フレームワーク非依存で、React コンポーネントも提供する。

### React Foundation - New Director of Community
- **URL**: https://x.com/sethwebster/status/2105422444529963495
- **要約**: Callstack 出身の Barbara Markiewicz が React Foundation の Director of Community に就任した。

### React Foundation Contributors Summit
- **URL**: https://www.react.foundation/summit
- **要約**: 招待制の貢献者サミットを 2026年11月10〜12日に、ロンドンの Meta King's Cross オフィスで開催する。

### React Conf Ghana
- **URL**: https://reactghana.react.foundation/
- **要約**: React Foundation が主催する初のカンファレンス。2026年11月4〜5日にアクラ（ガーナ）で開催する。

### Making React Context Cheap
- **URL**: https://jjenzz.com/making-react-context-cheap/
- **要約**: 5,000 個の connected な radio input を題材に、React Compiler が context の selector 相当の利点を実現できることを示す。

### React's browser() API
- **URL**: https://certificates.dev/blog/reacts-new-browser-api-rendering-components-only-in-the-browser
- **要約**: ブラウザ環境でのみコンポーネントをレンダリングするための新しい `browser()` API を解説する。

### Ink 8.0
- **URL**: https://github.com/vadimdemedes/ink/releases/tag/v8.0.0
- **要約**: React 製 CLI レンダラのメジャー更新。React 19.3+ 対応、スクロール可能な Box ビュー、レンダリング修正を含む。

### Streamdown 2.7
- **URL**: https://github.com/vercel/streamdown/releases/tag/streamdown%402.7.0
- **要約**: AI 向けの Markdown ストリーミングレンダラ。インクリメンタルなコードハイライトの高速化とノンブロッキングな Mermaid 対応。

### stableref 0.2
- **URL**: https://github.com/JoviDeCroock/stableref/releases/tag/v0.2.0
- **要約**: React / Preact 向けに、型レベルで参照の安定性を保証する。branded な `useSyncExternalStore` を提供する。

### Medula
- **URL**: https://github.com/posva/medula
- **要約**: Devframes をベースにしたエージェント向けのヘッドレス devtools。React と Next.js をサポートする。

### Shaders
- **URL**: https://shaders.com/updates/shaders-is-open-source
- **要約**: WebGPU によるエフェクトをコンポーネントとして扱えるライブラリがオープンソース化。React・Vue・Svelte・Solid・素の JavaScript に対応。

### Klipp
- **URL**: https://github.com/pmndrs/klipp
- **要約**: React Three Fiber バインディングを備えたカメラツールキット。
