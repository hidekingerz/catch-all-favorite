## 今週の注目ポイント

- **Next.js 16.3.6 セキュリティアップデート**: `ImageResponse` を Node ランタイムで使い、ユーザー制御の動的 SVG 入力を扱っている場合の重大なリモートコード実行（RCE）脆弱性を修正。該当構成のアプリは早急なアップデートが必要。
- **React の新しい `<img>` API リファレンス**: `<img>` は単に画像を表示するだけでなく、SSR 時にプリロードヒントを自動生成し、`<ViewTransition>` アニメーションとも統合される。地味だが実用的な機能が正式ドキュメント化された。
- **React Redux 9.4 alpha でシグナルベース最適化**: `useSignalSelector()` と `<SignalProvider>` を追加。数千のコネクテッドコンポーネントを持つ大規模アプリ向けのドロップイン最適化で、dispatch 時に影響を受けるセレクタのみ再実行する。
- **Redact 0.1 登場**: TanStack による軽量・同期レンダリングの React 再実装が GitHub に公開され、初のマイナーリリース。React 19.3 API 対応と同期レンダリング契約の維持が特徴。
- **TC39 第116回ミーティング**: 多くの Iterator 系プロポーザルが Stage 4 へ、Composites が Stage 2 へ進む可能性がある回。ES の進化を追ううえで注目。
