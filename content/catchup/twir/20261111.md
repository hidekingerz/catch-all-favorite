## 今週の注目ポイント

- **X（旧Twitter）をゼロから再構築**: Vite・React・Relay・Fastify によるフルリライトを展開中。ストリーミング SSR と Suspense を活用し、低速回線でのプロフィール初回投稿の表示が 23.9 秒から 2.7 秒へと大幅に短縮された。大規模アプリでのモダンな React スタックの実例として注目。
- **e18e Framework Performance プロジェクト発足**: 9 つのメタフレームワークを独立した立場でベンチマークする取り組み。すでに React RSC のパース高速化という成果につながっており、フレームワーク選定の客観的な材料になる。
- **Next.js のメモリリークと TanStack Start への移行**: React Query の GC タイマーが SSR のリクエストコンテキストを保持し続けるメモリリーク（約5GB→約1GB）の調査記事と、繰り返すメモリリークを理由に Next.js から TanStack Start へ移行した事例が同時に取り上げられた。SSR 運用時のメモリ挙動に注意。
- **MobX React Plugin 1.0**: MobX と React Compiler の非互換を解消する公式の Vite/Babel プラグイン。React Compiler を導入したい MobX ユーザーにとって重要。
- **Node.js セキュリティリリース**: 22・24・26 系向けに high 深刻度の修正を含むセキュリティリリース。該当ラインを使っている場合は速やかにアップデートすべき。
