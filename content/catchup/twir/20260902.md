## 今週の注目ポイント

- **React Compiler の Rust 実装が Vite / Bun で使えるようになった**: `@vitejs/plugin-react` 6.1 が `oxc-transform-react` による `{compiler: true}` オプションを追加し、Babel 版より 10 倍以上高速と謳う。Bun 1.4 も Rust 版 React Compiler を内蔵。ビルド時間に悩むプロジェクトは移行を検討する価値がある。
- **React 19.3 の新 API `use(browser())` と型定義の追加**: サーバーレンダリング中にコンポーネントを「ブラウザ専用」として扱う新 API。DefinitelyTyped の PR で 19.3 の型追加（`browser()`、安定版 `<ViewTransition>`、`<Fragment ref>`）が確認できる。SSR/RSC 構成で選択肢が広がる。
- **Zod 4.5 で事前コンパイルによる大幅高速化**: スキーマの事前（AOT）コンパイルとメソッドのメモ化により、プリコンパイル済みスキーマのパースが 3〜9 倍高速化。メモリ使用量も改善。バリデーションが重い箇所で効く。
- **Remix 3.0 RC / pnpm 12.0 など基盤ツールの節目**: Remix 3.0 は Web プリミティブベースの単一依存フレームワークとして機能を凍結し SemVer にコミット。pnpm 12.0 は Rust 書き換えでインストールが大幅高速化。周辺エコシステムの大きな更新が続く。

## React

### StyleX をめぐる最近の話題（Linear の移行 / 解説記事 / Tailwind-StyleX / Syntax.fm）
- **URL**: https://linear.app/blog/styling-linear-for-the-future-with-stylex
- **要約**: Meta のアトミック CSS-in-JS ライブラリ StyleX に関する議論が活発。Linear は styled-components から移行し、「型安全な強い制約・決定的で高速なスタイルのマージ・styling-at-a-distance をあえて難しくする」点を評価。深掘り記事は「Tailwind の方が人間向けの構文は良いが、StyleX の方がエージェント向けの制約が強い」と結論。Tailwind トークンのアダプタ（tailwind-stylex）や Syntax.fm のポッドキャスト回もある。

### React 19.3 の型追加 PR（browser() ほか）
- **URL**: https://github.com/DefinitelyTyped/DefinitelyTyped/pull/75429
- **要約**: React 19.3 で追加予定の型を確認できるドラフト PR。サーバーレンダリング向けの新 `browser()` API、React DOM 向けの安定版 `<ViewTransition>` と `<Fragment ref>` が含まれる。

### React DOM `use(browser())` API
- **URL**: https://react.dev/reference/react-dom/browser
- **要約**: v19.3 の新 API。サーバーレンダリング中にコンポーネントをブラウザ専用としてマークする。Client Component のコンテキストと Suspense 境界が必要で、レポート用のサーバー API `onBrowserBailout()` も備える。

### TanStack Start を Vercel にデプロイするガイド
- **URL**: https://vercel.com/kb/guide/deploy-a-tanstack-start-app-to-vercel
- **要約**: Nitro の Vite プラグインを活用し、Vercel を TanStack Start のファーストクラスなホストとして位置づける公式デプロイドキュメント。

### Next.js セキュリティリリース

- **要約**: 16.3.3 と 15.5.24 で critical（緊急）severity の脆弱性に対応。該当バージョンを使っている場合は更新を検討。
