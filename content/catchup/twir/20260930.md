## 今週の注目ポイント

- **Panda CSS 2.0**: Oxc 上の Rust コンパイラへ書き直したメジャーバージョン。スタイリング API は維持しつつエンジンを刷新し、ゼロランタイム CSS、タイポグラフィプリセット、デザインシステムの publish、ESLint プラグイン対応を追加。既存ユーザーは移行の影響を要確認。
- **Vinext 1.0**: Cloudflare による Vite ベースの Next.js 再実装が安定版に。「99%+ の互換性」を謳い、App Router / Pages Router の両方をサポート。Next.js を Vite で動かす選択肢として注目。
- **Preact 11.0**: 6 年以上ぶりのメジャーバージョン。ESM-only、TS 5.1+、ストリーミング SSR 対応の Hydration 2.0、props としての refs、`Object.is` ベースの hook 依存比較、React 互換の改善などを含む破壊的変更。
- **Next.js セキュリティリリース（16.3.8 / 15.5.27）**: 「critical 1 件・high 2 件・medium 5 件」の脆弱性に対応。該当バージョンを使うアプリは早急なアップデートが必要。
- **TC39 ミーティング（Composites ほか）**: Records & Tuples の後継となる Composites（値で比較されるオブジェクト、interning を利用）や Iterator メソッド、`export defer` などが進捗。ES の進化を追ううえで重要な回。
