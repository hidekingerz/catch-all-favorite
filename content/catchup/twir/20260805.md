## 今週の注目ポイント

- **Next.js 16.3 が公開**。開発時の RAM 使用量を最大90%削減する大規模なエンジン改良が入り、Turbopack が Vite 風の `import.meta.glob()` に対応。SSR のリクエスト処理が22%向上し TypeScript 7 もサポート。`catchError` や `next/root-params`（i18n 向け）など新 API も追加され、日常の開発体験に直結する更新。
- **TanStack Table V9 が正式リリース**。2年超の開発を経て、tree-shaking 可能なプラグインアーキテクチャ・TanStack Store ベースの状態管理・大幅な性能改善を実現。React 18+ / React Compiler 対応、atom/selector による粒度の細かい読み取りに対応。
- **React コアに `browser()` API の PR**。ブラウザ固有のコンポーネントに対して SSR を安全にサスペンドできるクライアント専用の react-dom API。サーバーエラー抑制のハック的な回避策を不要にする。
- **npm と GitHub Actions のサプライチェーン攻撃対策が進行**。ここ数か月で npm / GitHub Actions に投入された対策のまとめ。あわせて GitHub の Stacked PR がパブリックプレビューに入り、pnpm 11.20 ではマルチレジストリのパッケージ差し替え脆弱性が修正された。

## React

### Next.js 16.3 - Instant Navigations and 90% less RAM in dev
- **URL**: https://nextjs.org/blog/next-16-3
- **要約**: 開発時の RAM 使用量を最大90%削減する大規模なエンジン改良を投入。Turbopack が Vite 風の `import.meta.glob()` に対応し、SSR は22%多くのリクエストを処理、TypeScript 7 をサポート。新 API としてカスタムエラーバウンダリ向けの `catchError`、i18n 向けの `next/root-params` を追加。

### TanStack Table V9
- **URL**: https://tanstack.com/blog/announcing-tanstack-table-v9
- **要約**: 2年以上の開発を経た V9 が登場。tree-shaking 可能なプラグインアーキテクチャ、TanStack Store による状態管理、大幅な性能改善を導入。React 固有の更新として React 18+ 対応、React Compiler 互換、atom/selector による粒度の細かい読み取りをサポート。

### React Core PR - `browser()` API
- **URL**: https://github.com/react/react/pull/37143
- **要約**: ブラウザ固有のコンポーネントに対して SSR を安全にサスペンドできるクライアント専用の react-dom API を公開する PR。サーバーエラー抑制のハック的な回避策を不要にする。

### React 19's useActionState: Preventing Sequenced Double Submits
- **URL**: https://shubhra.dev/tutorials/react-19-useactionstate
- **要約**: React 19 の `useActionState` のキュー挙動を解説し、`isPending` 状態を扱って二重送信を防ぐ方法を示す。

### Next.js 16 useOptimistic: Fixing Rapid-Click Race Conditions & Auto-Rollbacks
- **URL**: https://shubhra.dev/tutorials/nextjs-16-useoptimistic-rollback-pattern
- **要約**: React 19 の楽観的 UI のエッジケースを扱い、手動のロールバックロジックが不要になる理由や、アイテムごとにリクエストの重複を防ぐ方法をキャッシュ再検証とともに解説。

### Visual Regression Testing: The Most Important Test You're Not Running
- **URL**: https://howtotestfrontend.com/resources/visual-regression-testing-introduction-guide
- **要約**: 機能テストでは見逃されるレイアウトや CSS のバグを、ビジュアルリグレッションテストがどう捕捉するかを解説。E2E ランナーやコンポーネント環境向けのセットアップ例付き。

### React Arven: Optimizing React Context Performance for Complex Local State
- **URL**: https://granat.blog/posts/2026-07-24-react-arven/
- **要約**: `useSyncExternalStore` と安定したアクション参照を使い、複雑なローカル状態を扱う際の React Context の再レンダリングを排除する 1.4 kB の依存なしライブラリを紹介。

### Architectural Patterns for Generative UI in React
- **URL**: https://boda.sh/blog/generative-ui/
- **要約**: LLM に動的に UI を構築させる3つのアプローチ（スキーマで制約した出力、宣言的な JSON 仕様 A2UI/AG-UI、サンドボックス化した自由なコード生成）を分解して解説。

### TanStack Charts pre-alpha
- **URL**: https://github.com/TanStack/charts
- **要約**: D3 上に構築された、約8 KiB の最小コア・フレームワーク非依存のチャート用プリミティブ群。React 向けの一級バインディングを持つ。

### React Aria 1.20
- **URL**: https://react-aria.adobe.com/releases/v1-20-0
- **要約**: PreviewTrigger ポップオーバー、インラインタグ用の TokenField、ネイティブコンテキストメニュー、操作可能なテーブル行、Next.js 16 の RSC コレクションサポートを追加。

### React Three Fiber 9.7
- **URL**: https://github.com/pmndrs/react-three-fiber/releases/tag/v9.7.0
- **要約**: reconciler を強化して react-dom に整合させ、子要素の同期ずれ・prop のリセット・イベント優先度の問題を修正。

### use-webmcp-tool
- **URL**: https://github.com/GoogleChromeLabs/use-webmcp-tool
- **要約**: Chrome チームによる実験的プロジェクト。WebMCP を介してクライアント側のツールをブラウザ AI エージェントに公開するための React 抽象化。

### MobX 7.0
- **URL**: https://github.com/mobxjs/mobx/releases/tag/mobx%407.0.0
- **要約**: レガシー互換を削除し、mobx-react-lite と mobx-react のアーキテクチャを維持しつつ ESM バンドルサイズを削減。

### SWR 2.5
- **URL**: https://github.com/vercel/swr/releases/tag/v2.5.0
- **要約**: 重複リクエストなしにクライアントキャッシュをハイドレートする実験的な RSC データプリロードを追加。キャッシュを破棄して実行中のクエリを中断する新しい `unload()` API も導入。

### React Hook Form 7.84
- **URL**: https://github.com/react-hook-form/react-hook-form/releases/tag/v7.84.0
- **要約**: `<Form />` の送信挙動を強化し、性能を改善、バンドルサイズを削減。

### BaseUI 1.7
- **URL**: https://base-ui.com/react/overview/releases/v1-7-0
- **要約**: バンドルサイズを約3%削減し、モバイル UX と `<ScrollArea.Thumb>` のオーバースクロールフィードバックを改善。アクセシビリティとバグ修正も同梱。

### Astryx 0.2
- **URL**: https://github.com/facebook/astryx/releases/tag/v0.2.0
- **要約**: 専用 ESLint ルール付きの RTL 自動ミラーリング、入力向けの tooltip ステータスバリアント、スクリプト可能な CLI エンジン API を追加。TabList の orientation と CLI JSON 型を削除。

### React Bits upgrade
- **URL**: https://reactbits.dev/
- **要約**: クリエイティブ開発者向けの新しい React コンポーネントを27個追加。

### Styled Components 6.5
- **URL**: https://github.com/styled-components/styled-components/releases/tag/styled-components%406.5.0
- **要約**: 型チェックを大幅に高速化し、React Native のスタイルをより厳密に、新しい CustomStyle 型ヘルパーを追加。
