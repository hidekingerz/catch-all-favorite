## 今週の注目ポイント

- **Vercel UI SDK ベータ**: `createPopup` / `createTypeahead` / `createRovingFocus` など 50 以上のアクセシブルで合成可能な「振る舞い（headless behaviors）」をエージェントが組み合わせて独自コンポーネントを作る SDK。React Aria の headless フックや Chakra の Zag ステートマシンの流れを汲むが、エージェント時代に向けた作りが特徴。
- **HTML-first React（静的 RSC マークアップの二重送信をやめる実験）**: 初回ロードで RSC ページが静的コンテンツを HTML と Flight ペイロードの両方で二重に送る問題に対し、Flight から静的コンテンツを除くフラグを追加する実験的 React フォーク。大きなテーブルのページで秒間リクエスト数が約 3 倍になったとされる。
- **Solid 2.0 リリース**: 非同期のリアクティブグラフ、Server Functions のコア取り込み、エージェント向け診断、API の縮小、SolidStart の廃止、フレームワーク非依存の Vite プラグインを導入。計算が Promise や async iterator を返せるようになり、ローディング状態や競合、楽観的ロールバックを Solid が扱う。
- **Webpack が CSS / HTML をネイティブ対応**: Webpack 5.109 でネイティブ CSS・CSS Modules・HTML エントリが使えるようになり、各種ローダ/プラグインが非推奨に。
- **Node.js の green threads 実験**: ワーカスレッドと vm の中間を狙う実験的な `node:green_threads` PR。ワーカより低コストで、CPU / メモリ上限を組み込みで持つが、Node.js API にアクセスできないなどの制約がある。

## React

### Vercel UI SDK beta - Headless UI behaviors for agents to build components
- **URL**: https://ui-sdk.dev/docs/core/changelog/introducing-ui-sdk
- **要約**: `createPopup` / `createTypeahead` / `createRovingFocus` など 50 以上のアクセシブルで合成可能な振る舞いを提供し、エージェントがそれらを組み合わせて独自コンポーネントを構築する SDK。React / Vue / Svelte / Solid / Web Components 向けの 50 以上の未スタイルコンポーネントも同梱。`createAgent()` や WebMCP でエージェント自身がページを読んで操作できる。

### Nexity - open source system to start and grow Next.js + Sanity sites
- **URL**: https://github.com/Pagepro/nexity
- **要約**: Next.js + Sanity サイトの立ち上げと成長のためのオープンソースシステム。9 つのエージェント、16 のスキル、エージェントを逸脱させないためのルールを含む。MIT ライセンス。

### HTML-first React - An unofficial experiment to stop sending static Server Component markup twice
- **URL**: https://html-first-react.pages.dev/summary/
- **要約**: 初回ロード時に RSC ページが静的コンテンツを HTML と Flight ペイロードの両方で二重に送る点を解消する非公式実験。静的コンテンツを Flight ペイロードから除くフラグを追加した実験的フォークで、パッチ適用済みの Next.js / Waku で検証され、大きなテーブルのページで秒間リクエストが約 3 倍になったとされる。

### How we're using AI to make Next.js more secure
- **URL**: https://nextjs.org/blog/how-were-using-ai-to-make-nextjs-more-secure
- **要約**: AI によって脆弱性の発見コストが下がり、今年は 51 件のアドバイザリにつながった。Next.js の全 PR に敵対的なセキュリティエージェントのレビューが入るようになり、`npx next@canary upgrade --agent` でコーディングエージェントに最新の安全なリリースへ移行させられる。

### Remix v3: Fast Pages, Thin Ecosystem
- **URL**: https://marmelab.com/blog/2026/11/12/remix-v3-fast-pages-thin-ecosystem.html
- **要約**: 同じ不動産アプリを両方で作って Remix v3 と TanStack Start を比較した記事。性能は同等だが、著者は多くのプロジェクトでは依然 TanStack Start を推奨。Remix で最も不足を感じたのは Vite プラグイン（Tailwind）や Vitest など一般的なツールとの統合。

### The Invisible Shape
- **URL**: https://sorenblank.com/craft/the-invisible-shape
- **要約**: カーソルが斜めに動いてもサブメニューが開いたままになる仕組みをインタラクティブに掘り下げた解説。1980 年代の Mac のアルゴリズムや Amazon の特許から、Base UI や React Aria の safe triangle まで各手法を比較。OpenUI の議論では将来ブラウザがネイティブに扱う可能性も示唆。

### When an import becomes a zip bomb: bundle regressions in Next.js
- **URL**: https://bra31k.dev/en/blog/bundle-size-regressions/
- **要約**: Next.js ビルドでルートごとのバンドルサイズ予算を定義する CI / CLI ツールを紹介。

### Fate 2.0 - Modern data client
- **URL**: https://fate.technology/posts/whats-new-in-fate-2.0
- **要約**: Christoph Nakazawa による Relay インスパイアのデータクライアント。クライアント状態の管理、リアクティブな memo フィールド、GraphQL、永続化とオフラインミューテーションに対応し、既存の GraphQL API でも動作する。Meta の Astryx デザインシステムと組み合わせ、Async React に全面的に賭けて滑らかで中断可能な UX を提供する。

### Dragology - Declarative drag-and-drop for React SVG interfaces
- **URL**: https://github.com/declarative-dragging/dragology
- **要約**: 宣言的なドラッグ概念でドラッグ＆ドロップの表現を押し進めるライブラリ。命令的なドラッグハンドラを書く代わりに、要素がドラッグできる状態を列挙すると、滑らかな移動・スナップ・アニメーションをライブラリが担う。

### React Virtualized 10.0 - TypeScript rewrite, function components with hooks
- **URL**: https://github.com/bvaughn/react-virtualized/releases/tag/10.0.0
- **要約**: React 18 以降向けの書き直し。`scrollElement` が `WindowScroller` を置き換え、StrictMode や React 19 でのクラッシュなど長年のバグを修正。10 ステップの移行ガイドと新しいドキュメントサイトを用意。

### React Resizable Panels 4.22 → 4.24
- **URL**: https://github.com/bvaughn/react-resizable-panels/releases
- **要約**: ワークスペースのポップアウトウィンドウ、外部からのドロップ、ブロック可能な変更、遅延タブコンテンツを追加。`element.moveBefore()` をサポートするブラウザでは、タブを移動しても iframe が再読み込みされず、メディアも止まらない。

### React Helmet Async 3.1
- **URL**: https://github.com/staylor/react-helmet-async/releases/tag/v3.1.0
- **要約**: React 19 でネストした `<Helmet>` のマージが復活し、`<meta charset>` の優先度対応、依存 2 つを削除。React 19 では組み込みの挙動と違ってタイトルや meta タグの重複を再び排除する。

### React Flow 13
- **URL**: https://xyflow.com/blog/react-flow-13-major-release
- **要約**: ストアを分割し `useNode` / `useEdge` フックで再レンダリングを削減、ESM のみ、React 18 以降対応、ダークモード自動対応。ノードベースのワークフロー UI を作るこのライブラリは React コア npm ダウンロードの約 8% を占め、AI で作られるアプリの増加が背景にあるという。

### React Anatomy - Browser DevTools panel showing a React page's components as 3D layers
- **URL**: https://react-anatomy.com/
- **要約**: React ページのコンポーネントを 3D レイヤーとして表示するブラウザ DevTools パネル。Xcode の view debugger に似ており、コンポーネントツリーに沿ってページをレイヤーに分解する。

### A2UI 1.0 - Google protocol for generative UI
- **URL**: https://developers.googleblog.com/a2ui-10-build-delightful-fast-reliable-agentic-experiences/
- **要約**: 生成 UI 向けの Google のプロトコル。React / Angular / Lit / Flutter / SwiftUI のレンダラを持つ。

### React Router 8.5.1
- **URL**: https://reactrouter.com/changelog#v851
- **要約**: React の `use()` 上に構築された `<Await unstable_promise>` を追加し、fetcher の再検証に関する修正を含む。

### Remotion - Make videos programmatically, interactively and agentically
- **URL**: https://www.remotion.dev/blog/make-videos-programmatically-interactively-and-agentically
- **要約**: プログラム的に動画を作るツール。Remotion Studio が完全にインタラクティブになり、要素の選択・ドラッグ・トリム・クロップができ、コードやエージェントに戻って作業できる。
