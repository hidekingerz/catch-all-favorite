## 今週の注目ポイント

- **React Server Components の未認証リモートコード実行（RCE）脆弱性**: React 19.3.1 で修正され、19.0.9 / 19.1.10 / 19.2.9 にもバックポート。Next.js では `"use cache"` 関数が複数の typed array を返すケースで影響。Next.js 16.4.1 または 15.5.28 へのアップグレードが必要。最優先で対応すべき。
- **PHP の重大な RCE 脆弱性（php2shell）**: ログイン不要で悪用可能、PHP 5.4 以降すべてに影響し WordPress や Laravel サイトも対象。即時アップグレードが推奨されている。
- **TypeScript 7.1 beta**: TypeScript-ESLint などのエコシステムツールが TS 7 と連携するための新 API が目玉。Import Attributes の Ambient Modules 対応、`es2026` lib/target の安定化、パフォーマンス改善を含む。
- **React DevTools for agents**: 実験的な `react-devtools-cdt-mcp` パッケージが Chrome DevTools MCP に React 固有の 12 ツールを追加。エージェントによるデバッグを支援。
- **tsrs（TypeScript 7 型チェッカーの Rust 移植）**: Cloudflare/VoidZero が Oxc の傘下で開発。すでに tsgo より高速で、Oxlint の型対応リンティングも高速化が期待される。

## React

### React vulnerability - Unauthenticated Remote Code Execution in React Server Components
- **URL**: https://github.com/react/react/security/advisories/GHSA-xqc2-xf4c-x3h3
- **要約**: React 19.3.1 で修正され、19.0.9 / 19.1.10 / 19.2.9 にもバックポート（Server Functions の DoS 修正も同梱）。Next.js では `"use cache"` 関数が複数の typed array を返すケースで RCE の影響を受ける。Next.js 16.4.1 または 15.5.28 へアップグレードすること。

### React Foundation Meetup - Nov 11, London
- **URL**: https://luma.com/g9q690i2
- **要約**: 初の一般公開 React Foundation ミートアップ。招待制のコントリビューターサミットと同じ週に開催される。

### Next.js PR - `<Link prefetch="navigation">`
- **URL**: https://github.com/vercel/next.js/pull/99871
- **要約**: ユーザーがクリックしそうなリンクについて、新しい `await navigation()` 境界を越えてプリフェッチできるようにする。

### React docs - React DevTools for agents
- **URL**: https://react.dev/reference/dev-tools/react-devtools-cdt-mcp
- **要約**: 実験的な `react-devtools-cdt-mcp` パッケージのドキュメント。ライブサンドボックス付きで、Chrome DevTools MCP に React 固有の 12 ツールを追加する。

### Improving navigation experience in v0 with Next.js 16.4
- **URL**: https://nextjs.org/blog/improving-navigation-experience-in-v0-with-nextjs-16-4
- **要約**: クリック前に UI が準備完了か `instant()` テストで確認できるまでエージェントがリファクタリングを続けるスキルを紹介。

### Building a filterable menu that works for everyone
- **URL**: https://base-ui.com/blog/building-a-filterable-menu
- **要約**: Base UI がフィルタ可能なメニューで採用したアクセシビリティ上の選択（combobox ではなく dialog を使う、キーボードとサブメニューの挙動）を解説。

### Pure UI in the Agentic Era
- **URL**: https://mattrothenberg.com/notes/pure-ui-agentic-era/
- **要約**: エージェントが書いた UI をレビューするための指針。コンポーネントを純粋に保ち、状態を明示的な入力として渡し、全組み合わせをグリッドでレンダリングする。

### React Router 8.5 - Deprecated view transition APIs, unstable API-only mode
- **URL**: https://reactrouter.com/changelog#v850
- **要約**: React 19.3 の `<ViewTransition>` を `<Outlet>` でラップする方法を推奨。新しい API-only モードはプリレンダリング済み HTML を CDN から配信し、loader と action は別サーバーで動かす。

### React Three Fiber 10.0 alpha 6 - WebGPU renderer by default, better React 19 support
- **URL**: https://github.com/pmndrs/react-three-fiber/releases/tag/v10.0.0-alpha.6
- **要約**: `<Activity>` と `<ViewTransition>` に対応。StrictMode と Fast Refresh で Canvas が再構築されなくなった。

### Hydrogen 2026-10
- **URL**: https://hydrogen.shopify.dev/update/hydrogen-2026-10-now-available
- **要約**: Hydrogen がフレームワークからライブラリへ。既存の Next.js や React Router アプリに追加できるようになった。エージェントスキルと組み込みの WebMCP サポートを含む。

### shadcn/ui - AI Elements, Trace and Code Block
- **URL**: https://ui.shadcn.com/docs/changelog/2026-10-ai-elements
- **要約**: エージェント UI 向けのコピー&ペースト可能な 21 パターン。Vercel の AI SDK Elements を置き換えるもので、AI SDK Elements は非推奨になる予定。

### Vinext 1.2 → 1.3 - 69% fewer JS requests per page, 5x faster cold starts, cache key collision fixes
- **URL**: https://vinext.dev/blog
- **要約**: ページあたりの JS リクエストを 69% 削減、コールドスタートが 5 倍高速化、キャッシュキー衝突の修正。

### Mutative 2.0 - Faster updates, safer patches
- **URL**: https://mutative.js.org/blog/releases/2.0
- **要約**: API は同じまま、ベンチマークで Immer の約 3.6 倍高速。ただしバンドルサイズは大きい（7.9 vs 3.6 kB）。

### Immer 11.2 - `isModified()` helper
- **URL**: https://github.com/immerjs/immer/releases/tag/v11.2.0
- **要約**: `isModified()` ヘルパーを追加。

### React Window 2.4 - Server rendering improvements
- **URL**: https://github.com/bvaughn/react-window/releases/tag/2.4.0
- **要約**: サーバーレンダリングの改善。

### Astryx RichText - Lexical-based rich text field with lossless Markdown
- **URL**: https://astryx.atmeta.com/blog/introducing-astryx-richtext
- **要約**: Lexical ベースのリッチテキストフィールド。Markdown をロスレスで相互変換できる。

### React Bits 2.0 - 215 animated React components, rebuilt design tools
- **URL**: https://x.com/davidhaz/status/2110662315959803905
- **要約**: アニメーション付きコンポーネント集のバージョン 2.0。デザインツールを刷新。リンク先は X の投稿。

### c15t v3 - One consent engine for 8 frameworks, banner in the server HTML
- **URL**: https://c15t.com/changelog/3.0.0
- **要約**: 8 つのフレームワークに対応する単一の同意（consent）エンジン。バナーをサーバー HTML でレンダリングする。

### React Trees Playground - Paste React code, see its parent and owner trees
- **URL**: https://julesblom.com/react-trees

### The Future of CSS

### JPEG XL vs AVIF for web use-cases
- **URL**: https://jakearchibald.com/2026/jpeg-xl-vs-avif/
- **要約**: 非可逆圧縮では依然 AVIF が優勢。可逆圧縮と既存 JPEG の再圧縮では JPEG XL が有利。

### TypeScript 7.1 beta - New TypeScript API, Import Attributes in Ambient Modules, stable `es2026` lib/target, performance improvements

### tsrs - Rust port of the TypeScript 7 type checker and LSP

### Node.js 24.22 LTS - `util.throttle()` and `util.debounce()`, crypto improvements

### Rsdoctor 2.0 - Now Rspack-only, Agent CLI, 57% faster analysis, 56% smaller install, multi-compiler reports
