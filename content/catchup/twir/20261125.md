## 今週の注目ポイント

- **React / Next.js のセキュリティ週**: React Router に high 4 件・moderate 3 件のアドバイザリが出て 7.18.6 / 8.5.2 へのアップグレードが必須。さらに乗っ取った GitHub アカウントから未パッチの React / Next.js サーバを突く自動攻撃「React2STEAL」が 1,281 台以上を侵害し、漏れたシークレットを公開リポジトリに投稿していた。アップグレードとシークレットのローテーションが急務。
- **Ricky Hanlon が 8 年在籍した Meta を離脱**: React コアチームの多くがすでに Meta を離れており、彼も新しい会社で React の開発を続けるという。React の開発体制の変化を示すニュース。
- **TanStack Query v6 ロードマップ**: ESM-only・React 19 最小・非推奨 API の削除といった小さめのメジャー。`enabled` を廃止し `skipToken` に寄せる可能性も議論されている。
- **npm audit の盲点**: 新規 Next.js アプリは `npm audit` で脆弱性 0 件と出るが、バンドルされた依存には `npm audit` から見えない critical / high の問題が潜む、という指摘（zachleat）。依存監査の過信への警鐘。
- **Webpack 5.113 / Express の組み込みトレーシング / Parcel 3.0 alpha 3**: ツールチェーン側も活発。Webpack は HTML 内 CSS Modules・SVG 最適化を追加、Express はモンキーパッチ不要の `TracingChannel` を内蔵、Parcel は別ジェネレータなしで静的サイトを構築できるようになった。
