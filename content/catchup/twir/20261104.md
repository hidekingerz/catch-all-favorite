## 今週の注目ポイント

- **Next.js 11月セキュリティリリース（16.4.5 / 15.5.29）**: 予告されていた7件の medium 深刻度の脆弱性を修正。Next.js を使っているプロジェクトは速やかにアップデートすべき。
- **Node.js 27.0 alpha**: 新リリースモデル初のアルファ。偶数/奇数での安定判定を廃止し、V8 15.6・npm 12.1・`--allow-env` パーミッション・ネイティブ `fs.glob`・`net/promises` API などを搭載。2027年4月に Current、10月に LTS となる予定。
- **Chrome 157 で HTML-in-Canvas が安定化**: 2D / WebGL / WebGPU の Canvas 内にインタラクティブな DOM を描画できる機能がフラグなしで出荷され、多彩な表現が可能に。
- **React.lazy と Suspense の隠れた300ms遅延**: `React.lazy` は初回レンダリングで必ず suspend し、React は Suspense の表示を300msスロットルするため、ケースによっては問題を引き起こす。挙動を理解しておくべき。
- **Parcel 3.0 alpha / Rspack 2.3**: Parcel は Rust で書き直し最大100倍高速化・単体バイナリ化。Rspack 2.3 は SWC Next パーサーを採用しビルドが5〜20%高速化、メモリも最大27%削減。バンドラー勢の高速化競争が続く。
