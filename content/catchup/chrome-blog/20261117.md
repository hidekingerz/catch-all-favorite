### New in DevTools - December 2026
- **URL**: https://developer.chrome.com/blog/new-in-devtools-december-2026?hl=ja
- **公開日**: 2026-11-13
- **要約**: 11 月に Chrome 157 / 158 で Stable にロールアウトされた DevTools 機能のまとめ。Chrome DevTools MCP サーバー（v1.11.0〜v1.13.0）にログポイント デバッグ・仮想 WebAuthn 認証システム・ライブ構成リロード・オフライン ヒープ スナップショット分析・並列ツール実行が追加され、AI アシスタンスではマルチカテゴリ（all）および agentic-browsing の Lighthouse 監査が実行可能になった。Elements パネルの `:buffering` / `:stalled` 強制と `position-try-fallbacks` スウォッチ、Sources の ECMA-426 ソースマップ scopes による元の変数名・関数名表示、Application パネルでのサブアプリ検査なども含む。
