### Modern Web Guidance 1.0: The web platform expertise your coding agent is missing
- **URL**: https://developer.chrome.com/blog/modern-web-guidance-v1?hl=ja
- **公開日**: 2026-11-10
- **要約**: コーディングエージェントに Web プラットフォームの専門知識・ベストプラクティス・ブラウザ互換性データを与えるスキル群「Modern Web Guidance」が 1.0（安定版）に到達した。既存コードベース（HTML / CSS / JavaScript / package.json）を静的解析し安全なモダン化候補を洗い出すワークフロー、専門家レビュー済みのクロスブラウザ対応ガイドを拡充したデータベース、ガイダンス有無でのエージェント比較の公開評価結果を含む。Chrome が開始したプロジェクトに Firefox・Edge も参画し、クロスブラウザ互換性の改善を進める。アクセシビリティ・UX・パフォーマンス・セキュリティの観点で見落としがちな点をエージェントに補わせ、ネイティブの HTML / CSS 機能を優先させる狙い。Chrome DevTools for agents との併用が推奨されている。
