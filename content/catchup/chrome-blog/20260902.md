## 記事一覧

### Chrome 154 beta
- **URL**: https://developer.chrome.com/blog/chrome-154-beta?hl=ja
- **公開日**: 2026-09-02
- **要約**: Chrome 154 のベータ。CSS に `scroll-marker-group` の links/tabs モード、下線などの位置を制御する `text-decoration-inset`、空白部分の装飾を抑える `text-decoration-skip-spaces`、`FontFace` の width 別名、ポップオーバー/ダイアログの light dismiss 改善（クリック外しは `click` イベントベースに、スクロール/右クリックでは閉じない）、子ドキュメントに合わせてサイズ変更できる `<iframe>` などが追加。JavaScript では Iterator に `includes()` が入り、Web API では WebCrypto のポスト量子暗号（ML-KEM 768/1024、ML-DSA 44/65/87、ChaCha20-Poly1305、X-Wing）、WebSocket コンストラクタのオプション辞書（`{ protocols: "..." }`）対応、DOM への HTML 挿入メソッド（`before()`/`after()`/`append()` 等の HTML 対応、`streamAppendHTML()`）、WebGPU の `@builtin(frag_depth)` に early-Z 最適化用の less/greater 指定などが加わる。Private Verification Tokens（PVT）などの新しいオリジントライアルも開始。**Background Fetch へ通常の fetch と同じセキュリティポリシー（CORS）が適用され、ローカル/ループバック宛リクエストには Local Network Access 権限が必要になる**ため、該当機能を使うサービスワーカーは影響を確認すること。
