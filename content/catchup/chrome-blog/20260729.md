### What's new in DevTools (Chrome 151)
- **URL**: https://developer.chrome.com/blog/new-in-devtools-151?hl=ja
- **公開日**: 2026-07-28
- **要約**: コーディングエージェント（Claude・Antigravity・Codex）向けの DevTools が強化され、重複文字列検出を含むメモリデバッグ改善と複数エージェントの同時ページルーティングに対応。AI Assistance パネルにネットワーク性能可視化のウィジェットや GitHub Flavored Markdown テーブル描画を追加。Styles タブでセレクタにホバーすると、クラス・ID・要素・擬似クラスが詳細度計算にどう寄与するかを示す詳細ツールチップを表示。ネイティブ V8 コンテキスト属性と新しい「Held by Context」フィルタで、クロージャコンテキスト経由でのみ保持されるオブジェクトを特定しやすくなった。
