## 記事一覧

### Use the Vercel AI SDK UI and AI Elements with the Prompt API
- **URL**: https://developer.chrome.com/blog/prompt-ui-ai-elements-with-vercel-ai?hl=ja
- **公開日**: 2026-07-16
- **要約**: Vercel AI SDK と Chrome の組み込み Prompt API を組み合わせて、ストリーミング対応のチャット UI を構築する方法を解説。バックエンドサーバーなしにブラウザ内でAIチャットボットを動かせ、Prompt API が使えない環境では Gemini 2.5 Flash などのクラウドモデルへ自動フォールバックできる。AI Elements の UI コンポーネントを使った実装手順が示されている。

### Selective format read: A better default for the Async Clipboard API
- **URL**: https://developer.chrome.com/blog/selective-format-read?hl=ja
- **公開日**: 2026-07-03
- **要約**: Chrome / Edge の Async Clipboard API に「選択的フォーマット読み取り」が導入された。クリップボードの全フォーマットを一括で読み込むのではなく、利用可能なフォーマットを列挙して必要なものだけを取得できるようになり、貼り付け処理の高速化とメモリ消費の削減につながる。ドキュメント編集や表計算など貼り付けの多いWebアプリで効果が大きい。
