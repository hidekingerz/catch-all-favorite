## 今回の注目ポイント

DevTools の月次アップデート「New in DevTools - November 2026」が公開された（Chrome 155・156 対応）。エージェント向け DevTools に CSS スタイル検査用の `get_css_styles` ツールや設定ファイル対応が追加されたほか、Elements パネルに CSS アンカーポジショニングの `position-area` ビジュアルエディタ、Network パネルのローカルオーバーライド永続化、ヒープスナップショットからの未使用クロージャ変数検出など、デバッグ体験を広く強化する内容。

## 記事一覧

### New in DevTools - November 2026
- **URL**: https://developer.chrome.com/blog/new-in-devtools-november-2026?hl=ja
- **公開日**: 2026-10-20
- **要約**: Chrome 155・156 向けの DevTools 月次アップデート。エージェント向け DevTools に computed/matched CSS をページネーション付きで調べる `get_css_styles` ツール、サーバーフラグやファイルシステムルートの設定ファイル対応、大容量トレースのチャンク解析（既定 1.2 GB バッファ）などを追加。Elements では CSS アンカーポジショニングの `position-area` ビジュアルエディタ、Flexbox エディタの `wrap-reverse` トグル、`@starting-style` の不正ルール検査などを追加。Network はローカルオーバーライドやカスタムヘッダー列のリロード後保持、Memory は共有 V8 コンテキストで残存する未使用クロージャ変数の強調表示、Performance はタイムラインのミニマップ操作の滑らかさ向上など、幅広い改善が含まれる。
