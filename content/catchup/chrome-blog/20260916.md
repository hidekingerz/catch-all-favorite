## 記事一覧

### Chrome 155 beta
- **URL**: https://developer.chrome.com/blog/chrome-155-beta?hl=ja
- **公開日**: 2026-09-16
- **要約**: Chrome 155 のベータ版が公開。CSS では counter style をインライン定義できる `symbols()` 関数、`border-radius` と `corner-shape` をまとめて指定する corner shorthand、空白部分の下線を抑制する `text-decoration-skip-spaces`、先頭/末尾要素前後のマージンを除去する `margin-trim` を追加。JavaScript では失敗したモジュール読み込みのリトライ、`import ... with { type: "text" }` によるテキストモジュールをサポート。Web API では `maximize()`/`minimize()`/`restore()` の追加ウィンドウ制御、ポスト量子暗号（ML-KEM・ML-DSA・X-Wing 等）、Digital Credentials API、JPEG XL 画像対応などが入った。

### New ad metrics in Chrome User Experience Report
- **URL**: https://developer.chrome.com/blog/crux-ad-metrics?hl=ja
- **公開日**: 2026-09-15
- **要約**: Chrome User Experience Report（CrUX）に広告体験を測る 4 つの実験的メトリクス（Ad Count・Ad Density・Ad Weight (Network Usage)・Ad Weight (CPU Usage)）が追加され、サイト上の広告読み込み状況をより詳細に把握できるようになった。WPP・The Guardian・Mediavine・Google Ads など広告エコシステムの主要関係者が支持しており、広告品質の改善やパブリッシャーへのインセンティブ向上が期待される。メトリクスは「実験的」段階で、コミュニティからのフィードバックを募集している。
