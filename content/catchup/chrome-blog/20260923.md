## 今回の注目ポイント

DevTools の最新アップデートをまとめた「New in DevTools - October 2026」が公開された（Chrome 153・154 相当の変更を扱う）。コーディングエージェント向けのセキュリティ制御・パフォーマンスチューニング・メモリ分析機能の強化、Application パネルへの広告関連情報の集約、Performance パネルのソフトナビゲーション完全対応など、デバッグ・最適化まわりの改善が中心。

### New in DevTools - October 2026
- **URL**: https://developer.chrome.com/blog/new-in-devtools-october-2026?hl=ja
- **公開日**: 2026-09-22
- **要約**: Chrome 153・154 相当の DevTools 変更をまとめた記事。コーディングエージェント向けに JavaScript 実行制御・ヒープスナップショット検査・PWA 自動化などのセキュリティ制御／パフォーマンス／メモリ分析機能を追加。Application パネルにはページ全体の広告関連情報を一元的にデバッグ・最適化できる新しい「広告」セクションが加わった。Performance ではソフトナビゲーションの完全サポートと CPU 性能階層のオーバーライド、Elements では非アクティブなスタイル表示・キーボードアクセス可能な装飾・DOM 要素のドラッグ&ドロップ並べ替えが実装された。
