## 記事一覧

### Chrome 152 beta
- **URL**: https://developer.chrome.com/blog/chrome-152-beta?hl=ja
- **公開日**: 2026-07-30
- **要約**: Chrome 152 ベータ版の変更点まとめ。Web アプリがデバイスの CPU 性能ティアを判別して体験を最適化できる CPU Performance API、`::backdrop` / `::scroll-marker` / `::view-transition` に対する `CSSPseudoElement` 対応の拡張、`:playing` / `:paused` / `:seeking` / `:buffering` / `:muted` などメディア要素の状態を表す擬似クラス群、CSS Color 5 の相対 `alpha()` 関数、editable 要素の自動修正を制御する `autocorrect` グローバル属性が追加された。加えて HTTP レスポンスヘッダで外部接続を制御する Connection Allowlists、textarea/input のテキスト操作用 OpaqueRange、`getDisplayMedia()` の `audioPreference` オプション、WebGPU のサブグループ制御などが含まれ、Private Aggregation API の削除が非推奨として告知されている。
