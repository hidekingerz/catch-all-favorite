### Chrome 153 beta
- **URL**: https://developer.chrome.com/blog/chrome-153-beta?hl=ja
- **公開日**: 2026-08-20
- **要約**: 新しい2週間リリースサイクルにおける最初の Chrome リリースのベータ版まとめ。単一軸スクロールコンテナと新しい `scroll-axis-lock` プロパティによるスクロール挙動の改善、JavaScript の Iterator Join / Joint Iteration、メディアキャプチャ向けの `<camera>` / `<microphone>` 機能要素、IAMF 空間オーディオ対応などが追加される。XSLT 以外の XML パースにメモリ安全な Rust 実装を導入する一方、非標準の `_current` ナビゲーションターゲット・`requestStorageAccessFor` API・Related Website Sets が削除されるため、これらに依存するサイトは影響を確認する必要がある。
