### ICYMI: Modern Web Guidance が安定版になりました
- **URL**: https://developer.chrome.com/blog/modern-web-guidance-recap?hl=ja
- **公開日**: 2026-11-13
- **要約**: Modern Web Guidance が安定版 1.0 として利用可能になったことをまとめた ICYMI（見逃した人向け）記事。1.0 では、パフォーマンス・スタイル・ユーザー補助・セキュリティ・プライバシー・フォームなど専門家が監修したガイドの追加、Firefox・Edge・Chrome のチームによるデフォルトでのクロスブラウザ対応（Baseline 互換性データとフォールバック付き）、数千回の評価実行を検査できる公開評価ダッシュボードを提供する。`npx modern-web-guidance@latest install` でセットアップでき、`legacy-scan` で既存コードベースのモダナイズも行える。Policybazaar / MetaMask / WeTV / note inc. などパートナーの導入事例（UI バグ 90% 超削減、CLS 回帰の自動診断・修正でデバッグ時間 87% 短縮、最新ウェブチェック合格率 61%→94% など）も紹介されている。

### Beyond code generation: Using Modern Web Guidance for continuous developer learning
- **URL**: https://developer.chrome.com/blog/beyond-code-generation?hl=ja
- **公開日**: 2026-11-11
- **要約**: Modern Web Guidance 1.0 を、コード生成の速度向上だけでなく開発者自身が最新のウェブ機能を学び続けるために使う視点を論じた記事。AI エージェントは 10 年分のレガシーコードを学習しているため放っておくと古いパターン（JavaScript アニメーションライブラリや div の入れ子など）に頼りがちだが、公開評価ダッシュボードの約 1,000 回の評価では、フロンティアモデル単体で最新ウェブチェックの合格率が約 60%、Modern Web Guidance のガイド適用で約 80〜90% に向上した。エージェントがコードを書く直前に簡潔で専門家が書いたガイドを読み込むことで、Popover API や CSS Anchor Positioning といった既存のネイティブ機能に開発者が気づき、理解を深められると説明している。
