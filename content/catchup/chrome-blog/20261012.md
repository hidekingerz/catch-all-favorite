## 記事一覧

### Email verification updates, October 2026
- **URL**: https://developer.chrome.com/blog/email-verification-october-2026?hl=ja
- **公開日**: 2026-10-05
- **要約**: Chrome 150 でデスクトップ向けに開始したメール検証オリジントライアルが開発者フィードバックを受けて更新され、正式リリースに向けて今後の破壊的変更は想定されない段階に入った。Chrome 154 では Android 対応・サードパーティ向けオリジントライアルトークンが追加され、`Sec-Fetch-Dest` の値が `email-verification` に変更される。検証側は任意の鍵識別子 `kid` への対応、メールプロバイダー側は送信されたメールアドレスを改変せず返す対応が必要（改変するとトークンが拒否される）。

### HTML-in-Canvas updates: Iterating toward a better Web API
- **URL**: https://developer.chrome.com/blog/html-in-canvas-ot-changes?hl=ja
- **公開日**: 2026-09-29
- **要約**: Chrome 150 と 155 で HTML-in-Canvas の API に、開発者および標準化のフィードバックを反映した変更が入る。WebGL / WebGPU メソッドの改名と引数シグネチャの変更、`layoutsubtree` 属性の `content="drawable"` への置き換え、2D canvas コンテキストでの DOM ヒットテスト自動同期などが含まれる。オリジントライアル利用者はコードを更新し、複数の Chrome バージョンをサポートするための feature detection を行い、トライアル期間が Chrome 160 まで延長されたためトークンを更新する必要がある。

### Connection allowlists: Secure your web application's network access
- **URL**: https://developer.chrome.com/blog/connection-allowlist-announcement?hl=ja
- **公開日**: 2026-09-23
- **要約**: Chrome 152 で、ドキュメントやワーカーに厳格なネットワーク境界を設定できるセキュリティ機構「Connection Allowlists」が導入される。サイトは `Connection-Allowlist` レスポンスヘッダーで許可するエンドポイントを定義し、ブラウザはそれ以外への送信接続を発生前にブロックする。サードパーティスクリプトや AI 生成コードがデータを送信できる先を制限する手段となり、まず report-only モードで導入して既存動作を壊さずに問題を検出できる。
