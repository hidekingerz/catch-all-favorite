### Enhance multitasking extensions with the new Tabs Split View API
- **URL**: https://developer.chrome.com/blog/split-view-api-extensions?hl=ja
- **公開日**: 不明（記事ページに Published 表記なし。最終更新: 2026-09-16 UTC）
- **要約**: Chrome 155 で、拡張機能から Chrome ネイティブの分割ビュー（Split View）を制御できる新しい Split View API が追加された。従来は複数ウィンドウのリサイズ・iframe への埋め込み・サイドパネルといった不安定な回避策に頼っていた並べて表示する体験を、既存の Tabs API と統合された API で分割ビューの検出・作成・管理として直接扱えるようになる。Mozilla など他ブラウザベンダーと WebExtensions Community Group で協調して策定されており、マルチタスク系拡張機能の開発者は確認しておきたい。
