### What's New in WebGPU (Chrome 153-154)
- **URL**: https://developer.chrome.com/blog/new-in-webgpu-153-154?hl=ja
- **公開日**: 2026-09-15
- **要約**: Chrome 153・154 の WebGPU 新機能まとめ。WGSL の `buffer_view` 拡張で `bufferView<T>()` / `bufferArrayView<T>()` / `bufferLength()` によりバッファデータを複数の型として再解釈でき、`swizzle_assignment` 拡張では `position.xy = vec2f(10.0, 20.0)` のようにベクトルのスウィズルへ直接書き込める。加えて `texture_formats_tier1` の JavaScript マッピング修正、`subgroup_size_control` 有効時に `subgroups` を自動有効化する更新、Dawn 側では GPU アクセス可能なマップドバッファを扱う `BufferMapWriteExtendedUsages` の追加や macOS 13.0+ 要件などが入った。WebGPU でグラフィックス/GPU 計算を扱う開発者は確認しておきたい。
