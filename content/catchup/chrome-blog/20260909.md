## 記事一覧

### New in Chrome 153
- **URL**: https://developer.chrome.com/blog/new-in-chrome-153?hl=ja
- **公開日**: 2026-09-08
- **要約**: Chrome 153 の新機能まとめ。**Single-axis scroll containers** では `overflow` プロパティがスクロール値（`auto` / `scroll` / `hidden`）と `clip` の組み合わせ（例: `overflow: scroll clip`）をサポートし、軸ごとに独立したスクロール挙動を制御できる。**Capability elements** として `<camera>`（映像キャプチャ）と `<microphone>`（音声キャプチャ）の専用要素が導入され、ブラウザ制御の宣言的な UI でメディアキャプチャを扱える。**Joint Iteration** では `Iterator.zip()` と `Iterator.zipKeyed()` が追加され、複数のイテレータを "shortest" / "longest" / "strict" のモードを指定して同期処理できる。CSS レイアウト・メディアキャプチャ・JavaScript の反復処理に関わるプロジェクトは確認しておきたい。
