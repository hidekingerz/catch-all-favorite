## 今回の注目ポイント

オリジントライアルを経て、HTML-in-Canvas API が Chrome 157 で正式に安定版リリースされた。`<canvas>` 要素の中にライブでインタラクティブ、かつアクセシブルな DOM サブツリーを 2D・WebGL・WebGPU のいずれのコンテキストにもレンダリングできるようになり、従来は標準 HTML 要素と生の canvas のどちらかを選ぶ必要があったトレードオフが解消される。canvas 中心の UI を構築しているプロジェクトに影響する。

### HTML-in-Canvas in Chrome 157: Interactive DOM inside 2D, WebGL, and WebGPU
- **URL**: https://developer.chrome.com/blog/html-in-canvas?hl=ja
- **公開日**: 2026-10-26
- **要約**: オリジントライアル成功を受けて、HTML-in-Canvas API が Chrome 157 で正式に安定版リリースされた。この API は DOM のインタラクティブ性・アクセシビリティと、canvas のピクセル単位・GPU アクセラレーションによる描画性能とのギャップを埋めるもの。`<canvas>` の中に HTML を配置することで、コンテンツはインタラクティブなまま保たれ、ブラウザの各種統合機能（アクセシビリティや DevTools サポートなど）が自動的に機能する。従来は canvas 中心の UI を作る際に標準 HTML 要素と生の canvas コンテキストのどちらかを選ばざるを得なかったが、そのトレードオフを解消する。
