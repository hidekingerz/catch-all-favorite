## 今週の注目ポイント

ランタイムとフレームワークの大型ニュースが並んだ号。**Cloudflare が Deno を買収**し、Deno ランタイムは1年間の修正・セキュリティ更新を継続、Deno Deploy は6か月後にサンセット、JSR は Cloudflare へ移管される。フレームワークでは **TanStack Start 1.0** が安定版に到達（React / Solid 対応のフルスタック）、**Next.js 16.4** が `create-next-app` で Cache Components を既定有効化し React 19.3 に対応。ツールチェーンでは **Bun 1.4.3** が型チェッカー `bun check` を追加、**Panda CSS 2.0** が ESM 専用・Rust/Oxc 製コンパイラへ刷新。さらに **Preact 11**（Hydration 2.0・CJS/UMD 廃止）、**Node.js 26.11.0**、**QUnit 3.0.0**、**Express 5.3.0**、**Partytown 1.0.0** と節目のリリースが集中した。

## ヘッドライン

### Deno is joining Cloudflare
- **URL**: https://deno.com/blog/cloudflare
- **タグ**: deno cloudflare JavaScript news
- **要約**: Cloudflare が Deno を買収。Deno ランタイムは1年間の修正・セキュリティ更新を継続し、Deno Deploy は6か月後にサンセット、JSR は Cloudflare へ移管される。

### TanStack Start 1.0 is Stable
- **URL**: https://tanstack.com/blog/tanstack-start-1-0
- **タグ**: TanStack React Solid ReleaseNote
- **要約**: TanStack Start 1.0 が安定版に。TanStack Router 上に構築された React / Solid 向けフルスタックフレームワークで、SSR・ストリーミング・型付きサーバー関数に対応する。

### Bun v1.4.3
- **URL**: https://bun.com/blog/bun-v1.4.3
- **タグ**: Bun TypeScript ReleaseNote
- **要約**: Bun 1.4.3 リリース。TypeScript 型チェック用の `bun check`、run/test/build 向けの `--check` フラグ、文字列ベースのコード生成を禁止するフラグ、コンパイルビルドのバイトコード順序づけを追加した。

### Panda CSS 2.0 | Panda CSS Blog
- **URL**: https://panda-css.com/blog/panda-css-v2
- **タグ**: css JavaScript ReleaseNote
- **要約**: Panda CSS 2.0 リリース。ESM 専用化・Node.js 22 以上必須となり、コンパイラを Rust と Oxc で書き直し。デザインシステムの配布機能や新しいヘルパー関数を追加した。

### Preact 11 – Preact
- **URL**: https://preactjs.com/blog/preact-11/
- **タグ**: JavaScript library ReleaseNote React
- **要約**: Preact 11 リリース。破壊的変更として CommonJS/UMD ビルドと `render()` の第3引数を削除し、Hydration 2.0 を追加、ref を既定で転送するようにした。

### Next.js 16.4 | Next.js
- **URL**: https://nextjs.org/blog/next-16-4
- **タグ**: Next.js React ReleaseNote
- **要約**: Next.js 16.4 リリース。`create-next-app` で Cache Components を既定有効化、エージェントベースのアップグレード手段、Turbopack ビルドの高速化、本番での短い CSS Module クラス名、React 19.3 対応を追加した。

### Node.js 26.11.0 (Current)
- **URL**: https://nodejs.org/en/blog/release/v26.11.0
- **タグ**: nodejs ReleaseNote
- **要約**: Node.js 26.11.0 リリース。Buffer・HTTP のユーティリティ追加、HTTP/2 とヒストグラムの追加、`--process-timeout` フラグ、`process.ref()`/`unref()` の安定化、npm 11.20.0 を同梱した。

### QUnit 3.0.0
- **URL**: https://github.com/qunitjs/qunit/releases/tag/3.0.0
- **タグ**: JavaScript library ReleaseNote test
- **要約**: QUnit 3.0.0 リリース。レガシー Node.js・PhantomJS・AMD サポートを削除し、ネイティブ ESM を提供。既定のテストタイムアウトを3秒に変更し、HTML レポーターを刷新した（[アップグレードガイド](https://qunitjs.com/upgrade-guide-3.x/)）。

### Express 5.3.0
- **URL**: https://github.com/expressjs/express/releases/tag/v5.3.0
- **タグ**: express nodejs ReleaseNote
- **要約**: Express 5.3.0 リリース。`Content-Disposition` のクォート方法の変更、`res.send()` での既存 Content-Type パラメータの保持、`req.fresh` の QUERY メソッド対応、既定エラーハンドラでの `Error.cause` のログ出力を追加した。

### Partytown v1.0.0
- **URL**: https://github.com/QwikDev/partytown/releases/tag/v1.0.0
- **タグ**: JavaScript library webworker ReleaseNote
- **要約**: Partytown 1.0.0 リリース。サードパーティスクリプトを Web Worker 上で実行するライブラリの初の安定版。
