## 今週の注目ポイント

今週はパッケージ供給網まわりの動きが目立つ。Next.js 16.3 は `cacheComponents` / `partialPrefetching` によるオプトインの Instant Navigations を導入し、App Router の SSR を Web Streams から Node.js Streams へ移行して性能を改善、`import.meta.glob` にも対応した。npm は publish 時のマルウェアスキャンを開始し、新規パッケージは公開前に検査され通常公開・手動レビュー・ブロックのいずれかになる（誤検知対策として `contentPolicy` と `DISCLOSURE` による dual-use 宣言が可能）。vlt 1.0 は Hosted Package Registries や Phased Installations、OIDC Trusted Publishing を GA とし、npm/pnpm/Yarn/Bun/Deno 互換のミラー配信を提供する。自分のCI・公開フローや依存管理への影響を確認しておきたい号。
