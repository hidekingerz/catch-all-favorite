## 今週の注目ポイント

今週はメジャーリリースが集中した号。React 19.3 がリリースされ、`<ViewTransition>` と Fragment Refs が Stable 化、`browser()` と Trusted Types のサポートが加わった。pnpm は 12.4 / 12.6 で `python.enabled` / `cargo.enabled` による Python・Cargo 依存関係の管理に対応（pnpm 自体が Rust で実装されるため）。VoidZero からは Vite+ 1.0 が正式リリースされ、CI 向けのセットアップや `vp` コマンド群、Vitest 5 への移行サポートが揃った。加えて Zod 4.6、webpack 5.111（ESM 出力の Stable 化）、Jotai v3.0.0、Apollo Client 4.3、Safari 27.0 の WebKit 機能など、ツールチェーン・ブラウザ両面で節目となるアップデートが並んでいる。

## ヘッドライン

### React 19.3 – React
- **URL**: https://react.dev/blog/2026/09/09/react-19-3
- **タグ**: React JavaScript ReleaseNote
- **要約**: React 19.3 リリース。`<ViewTransition>` と Fragment Refs が Stable 化し、`browser()` と Trusted Types のサポートを追加。Server Components で `<Context>` を直接レンダリング可能になり、`onFullscreenChange` / `maskType` のサポートも加わった。

### pnpm 12.4 | pnpm
- **URL**: https://pnpm.io/blog/releases/12.4
- **タグ**: pnpm ReleaseNote
- **要約**: pnpm 12.4 リリース。`python.enabled` / `cargo.enabled` による Python・Cargo 依存関係の管理を追加（pnpm 自体が Rust で実装されるため）。`pnpm pipeline`、`trustPolicyExcludePrune`、`pnpm change check` も追加された。

### Zod 4.6
- **URL**: https://zod.dev/blog/zod-4-6
- **タグ**: JavaScript TypeScript library ReleaseNote
- **要約**: Zod 4.6 リリース。`.validate()` / `.validateAsync()` と `z.instanceof().properties()` を追加。JSON Schema キーワード対応、`z.iban()`、`z.withParser()` も追加された。

### Webpack 5.111 | webpack
- **URL**: https://webpack.js.org/blog/2026-09-14-webpack-5-111/
- **タグ**: webpack ReleaseNote
- **要約**: webpack 5.111 リリース。ESM 出力が Stable となり `output.module` が利用可能に。`output.copy`、CSS 最小化設定の `lowerUnsupported` / `colorFallbacks` を追加し、`acorn` / `neo-async` への依存を削除した。

### Release v3.0.0 · pmndrs/jotai
- **URL**: https://github.com/pmndrs/jotai/releases/tag/v3.0.0
- **タグ**: React JavaScript library ReleaseNote
- **要約**: Jotai v3.0.0 リリース。React 18 / TypeScript 5.5 / Node.js 22.12.0 以上が必須に。CJS/UMD/SystemJS ビルドを削除し、`useAtomValueRaw` と `useAtomValueRawSync` を追加した。

### What's New in Apollo Client 4.3 - Apollo GraphQL Blog
- **URL**: https://www.apollographql.com/blog/whats-new-in-apollo-client-4-3
- **タグ**: JavaScript GraphQL TypeScript ReleaseNote
- **要約**: Apollo Client 4.3 リリース。`Scalar` による Custom Scalars のシリアライズ/デシリアライズ、`TypeOverrides` による Cache 型の上書きに対応。`@defer` / `@stream` の Incremental Data 型も改善された。

### pnpm 12.6 | pnpm
- **URL**: https://pnpm.io/blog/releases/12.6
- **タグ**: pnpm ReleaseNote
- **要約**: pnpm 12.6 リリース。`autoDedupe` による依存関係の重複排除、`pnpm add --save-types`、Catalogs での `file:` / `link:` をサポート。`pnpm tasks status`、`pnpm cache prune --dry-run` も追加された。

### WebKit Features for Safari 27.0 | WebKit
- **URL**: https://webkit.org/blog/18325/webkit-features-for-safari-27-0/
- **タグ**: safari browser WebAssembly JavaScript css ReleaseNote
- **要約**: Safari 27.0 の WebKit の変更点。Safari MCP、`<select>` のカスタマイズ、`<modal>` 要素、`<img sizes="auto">` のサポートを追加。WebAssembly JSPI と Service Worker Static Routing API にも対応した。

### Announcing Vite+ 1.0 | VoidZero
- **URL**: https://voidzero.dev/posts/announcing-vite-plus-1-0
- **タグ**: vite Tools CLI ReleaseNote
- **要約**: Vite+ 1.0 リリース。GitLab CI/CD 向け `setup-vp`、Homebrew/Docker イメージ、`vp hooks` / `vp staged` を追加。Vitest 5.0.1 へ移行し、`vp migrate` による Vitest 5 移行サポートも備えた。
