## 今週の注目ポイント

今週はテスト・バリデーション周りのメジャーリリースと、大きな買収ニュースが並んだ。Vitest 5.0 は `clearMocks` をデフォルトで有効化し、ネストしたプロジェクトで設定を継承するようになったほか、Browser Mode の `browser.traceView` や `vi.when`、`vitest doctor` など機能を強化した。Zod 4.5 は `z.compile()` によるスキーマの事前コンパイルを導入し、`z.creditCard()` などの新しいバリデータを追加、文字列長のカウントを Code Point ベースに変更した。そして Tailwind Labs が Shopify にジョインし、Tailwind CSS などの OSS は引き続き MIT ライセンスのまま開発が継続されることが announce された。加えて htmx 4.0.0（`fetch()` ベースへ移行）、Remix 3 RC、Node.js v24.20.0 (LTS) など、フレームワーク・ランタイムの節目となるリリースも多い号。

## ヘッドライン

### Release v4.0.0 · plotly/plotly.js
- **URL**: https://github.com/plotly/plotly.js/releases/tag/v4.0.0
- **タグ**: JavaScript chart library
- **要約**: Node.js 22 未満のサポートを終了し、`scattermapbox`/`choroplethmapbox`/`densitymapbox` を削除。MathJax v2 サポートも削除し、カラーライブラリを culori へ移行した。

### htmx 4.0.0 has been released!
- **URL**: https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released
- **タグ**: JavaScript HTML library
- **要約**: 継承を明示する `:inherited` 属性を導入し、イベント名を `htmx:phase:action` 形式へ変更。実装を XHR ベースから `fetch()` ベースへ刷新し、Morph Swap や `<hx-partial>` などの新機能を追加した。

### Zod 4.5
- **URL**: https://zod.dev/blog/zod-4-5
- **タグ**: JavaScript TypeScript library
- **要約**: `z.compile()` によるスキーマの事前コンパイル、`z.creditCard()`/`z.properties()` を追加。`z.deepPartial()`・`.exactPartial()`・`z.validate()`・`z.toZod<T>()` も追加し、文字列長のカウントを Code Point ベースへ変更、`__proto__` は常に削除するようになった。

### Announcing Rspack 2.2
- **URL**: https://rspack.rs/blog/announcing-2-2
- **タグ**: rspack
- **要約**: HMR の改善と Browserslist の baseline クエリをサポート。Rspack 固有のモジュール変数を `import.meta` 経由で公開。Rsbuild は Node.js ビルドで split chunks をデフォルト有効化し、Solid v2 に対応した。

### Node.js v24.20.0 (LTS)
- **URL**: https://nodejs.org/en/blog/release/v24.20.0
- **タグ**: nodejs
- **要約**: `AsyncLocalStorage` への `using` scope の追加、`Buffer` に `end` パラメータを追加。`permission.drop()`・`--permission-audit`・package maps・`node:stream/iter` も追加された。

### Remix 3 Release Candidate
- **URL**: https://remix.run/blog/remix-3-release-candidate
- **タグ**: Remix JavaScript
- **要約**: Remix 3.0.0-rc.1 がリリースされた。

### Electron 44
- **URL**: https://www.electronjs.org/blog/electron-44-0
- **タグ**: Electron
- **要約**: Chromium 152.0.7977.54、Node.js v24.18.1、V8 15.2 へ更新。macOS 12・Windows 32bit・Linux ARM 32bit のサポートを終了。`clipboard` API を非同期化し、`windowStatePersistence`・`net.WebSocket` を追加した。

### Vitest 5.0 is out!
- **URL**: https://vitest.dev/blog/vitest-5.html
- **タグ**: JavaScript vite testing
- **要約**: `clearMocks` をデフォルトで有効化し、ネストしたプロジェクトで設定をデフォルト継承。Locator は strict マッチングを行うようになった。Benchmarking API を書き直し、Browser Mode の `browser.traceView`・`vi.when`・`vitest doctor`・`--repeats` を追加。

### Release v1.63.0 · microsoft/playwright
- **URL**: https://github.com/microsoft/playwright/releases/tag/v1.63.0
- **タグ**: playwright testing
- **要約**: 共有リソースを使うテストを排他実行する `lock` と `locator.visible()` を追加。フレームをまたいだ locator 検索に対応し、`trace` に `snapshots` オプション、`locator.ariaSnapshotJSON()` を追加した。

### Firefox 155.0
- **URL**: https://www.firefox.com/en-US/firefox/155.0/releasenotes/
- **タグ**: Firefox browser, css, WebAssembly, HTTP3, WebRTC
- **要約**: CSS の `attr()`/`progress()`/`alpha()`、HTTP/3 での QUIC v2 をサポート。WebAssembly の Compact Import Section と Wide Arithmetic に対応。開発ツールで `prefers-reduced-motion` のエミュレーションや JSON Lines 表示が可能になった。

### Tailwind Labs is joining Shopify
- **URL**: https://tailwindcss.com/blog/tailwind-is-joining-shopify
- **タグ**: css OpenSource news
- **要約**: Tailwind CSS などの OSS は MIT ライセンスのまま、Tailwind Labs のチームが Shopify の支援で開発を継続する。Tailwind Plus と ui.sh は既存顧客のアクセスを維持するが、新規登録は締め切る。

## アーティクル

### How Turbopack chunks your JavaScript
- **URL**: https://nextjs.org/blog/turbopack-chunking
- **タグ**: Next.js JavaScript, performance
- **要約**: Turbopack のチャンク分割アルゴリズムと、リクエスト数・帯域のトレードオフを解説。Next.js 16.3 の `generateComponentChunks` はビルド時にマージ済みチャンクと個別チャンクの両方を生成し、ナビゲーション時に結合チャンクと部分チャンクのどちらを取得するかを判断する。

### Fixing Top-Level Await in Safari
- **URL**: https://webkit.org/blog/18227/fixing-top-level-await-in-safari/
- **タグ**: safari JavaScript
- **要約**: Safari の Module Loader を JavaScript 実装から C++ 実装へ書き直し、ECMAScript 仕様に沿って Top-Level Await に対応した。Safari 27 と Safari Technology Preview 251 で正しく動作するようになった。
