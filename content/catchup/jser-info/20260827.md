## 今週の注目ポイント

今週はパッケージマネージャーとランタイムの Rust 化が目立つ。pnpm 12 は pnpm 11 からコマンド・設定・ロックファイル形式を引き継いだまま Rust で書き直された安定版としてリリースされ、GitHub/GitLab/Bitbucket の Git 依存を正規化した HTTPS URL でロックファイルに記録するようになった。`globalShims` によるプロジェクト単位のグローバル bin、`pnpm-workspace.yaml` の未知設定の報告、`pnpm update --patches`、`pnpm stage approve` によるバッチ承認なども追加された。Bun 1.4 も Zig から Rust への書き直しで Node.js 互換性・メモリ/CPU 使用量・起動速度を改善し、`bun audit fix` や HTTP/3 に対応。Solid 2.0 RC は async 値のリアクティブな扱いや OXC ベースの Rust コンパイラを導入し、SolidStart の終了を announce した。ランタイム・ツールチェーンの Rust 化トレンドが一段と鮮明になった号。

## ヘッドライン

### SolidStart v2 is now Stable
- **URL**: https://github.com/solidjs/solid-start/discussions/2281
- **タグ**: Solid JavaScript vite ReleaseNote nodejs
- **要約**: Vite Environment API を使った client/server ビルドへ移行。Nitro v3 と Cloudflare Vite プラグインをサポートし、Node.js 24 以上を要求する。

### Release v1.7.0 · video-dev/hls.js
- **URL**: https://github.com/video-dev/hls.js/releases/tag/v1.7.0
- **タグ**: HLS JavaScript library ReleaseNote
- **要約**: TypeScript 型定義を厳格化。`hls.createIFramePlayer()` による iframe プレイリスト再生、CMCD v2 に対応。`hls.nextAudioTrack`、`abrSwitchInterval`、`appendTimeout` を追加。

### Release 3.50.0 - 2026.08.05 · zloirock/core-js
- **URL**: https://github.com/zloirock/core-js/releases/tag/v3.50.0
- **タグ**: JavaScript library ReleaseNote
- **要約**: `Iterator.zip` と `Iterator.zipKeyed` を Stable ES として追加。`Iterator.prototype.chunks`/`windows` が Stage 3 へ。新たな Stage 3 提案として `Iterator.prototype.includes`/`join` や `Promise.allKeyed`/`Promise.allSettledKeyed` を含む。

### Release v2.0.0 RC - The Big <Reveal> · solidjs/solid
- **URL**: https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0
- **タグ**: Solid JavaScript ReleaseNote vite
- **要約**: async 値をリアクティブに扱うように変更。`createResource`・`batch`・`startTransition`・`useTransition` を削除。OXC ベースの Rust コンパイラを導入し、`start: true` で SPA/SSR/Server Functions の Vite サポートを提供。SolidStart の終了を発表。

### Release Notes for Safari Technology Preview 250 | WebKit
- **URL**: https://webkit.org/blog/18191/release-notes-for-safari-technology-preview-250/
- **タグ**: safari browser css JavaScript ReleaseNote
- **要約**: CSS `ruby-overhang: spaces`、`using`/`await using`、`Iterator.zip()`/`Iterator.zipKeyed()` に対応。`fetch()` での ReadableStream アップロード、WebAssembly relaxed SIMD と複数メモリをサポート。

### Release v5.6.0 - npm staged publishing · lerna-lite/lerna-lite
- **URL**: https://github.com/lerna-lite/lerna-lite/releases/tag/v5.6.0
- **タグ**: npm ReleaseNote monorepo
- **要約**: `lerna publish --stage` による npm staged publishing をサポート。

### Better Auth 1.7
- **URL**: https://better-auth.com/blog/1-7
- **タグ**: TypeScript library ReleaseNote OAuth MCP
- **要約**: Breaking changes として `oidcProvider` プラグインを削除し `@better-auth/oauth-provider` へ移動、MCP auth を `@better-auth/mcp` へ移動。SCIM Groups と Device Authorization のサポートを追加。

### Firefox 154.0, See All New Features, Updates and Fixes
- **URL**: https://www.firefox.com/en-US/firefox/154.0/releasenotes/
- **タグ**: Firefox browser css JavaScript ReleaseNote

### Bun 1.4 | Bun Blog
- **URL**: https://bun.com/blog/bun-v1.4
- **タグ**: Bun JavaScript ReleaseNote
- **要約**: Zig から Rust へ書き直し、Node.js 互換性・メモリ/CPU 使用量・起動速度を改善。`bun dedupe`/`prune`/`audit fix`、タイミングベースの sharding、React Compiler サポートを追加。HTTP/3 と静的ファイル配信に対応。

### pnpm 12.0 | pnpm
- **URL**: https://pnpm.io/blog/releases/12.0
- **タグ**: pnpm ReleaseNote
- **要約**: 後方互換を保ったまま Rust で書き直した安定版。Git 依存の HTTPS URL 正規化、未知設定の報告、`globalShims`、パッケージマネージャーのインストール、Registry revisions、`pnpm update --patches` を追加。
