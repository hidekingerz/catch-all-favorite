## 今週の注目ポイント

TypeScript と Node.js の大きな節目が並んだ号。**TypeScript 7.1 Beta** が ambient モジュールでの Import Attributes や `import source`、`es2026` ターゲット、`typescript/sync` / `typescript/async` の新 API と Content Mappers を追加。Node.js は **26.13.0 が LTS（Lithium、2029年4月まで）** に入り、同時に新リリースモデル初の **27.0 Alpha** が V8 15.6 や `--allow-env`、実験的な `net/promises` を搭載した。さらに10月のセキュリティリリースで Node.js 22/24/26 の10件の脆弱性を修正。ブラウザでは **Safari 27.1** が折りたたみ iPhone 向けに Device Posture / Viewport Segments を実験的に追加。周辺では **Nuxt 4.6**、**Vite+ 1.4.0**、**Playwright 1.65**、そして TypeScript 7.1 を要求する **ts-loader 10 Beta** がリリースされた。

## ヘッドライン

### Announcing TypeScript 7.1 Beta - TypeScript
- **URL**: https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/
- **タグ**: TypeScript ReleaseNote
- **要約**: TypeScript 7.1 Beta リリース。ambient モジュールでの Import Attributes、`import source` 対応、`es2026` ターゲット/lib を追加。埋め込みコード向けの Content Mappers と `typescript/sync` / `typescript/async` の新 API も導入した。

### Nuxt 4.6 · Nuxt Blog
- **URL**: https://nuxt.com/blog/v4-6
- **タグ**: Vue ReleaseNote
- **要約**: Nuxt 4.6 リリース。`nuxt init` を廃止して `npm create nuxt` に移行し、共有のサーバ API とセッション管理、`$fetch` / `useFetch` の型推論改善、Vue Vapor との相互運用を追加した。

### Node.js — 2026年10月21日（水）セキュリティリリース
- **URL**: https://nodejs.org/en/blog/vulnerability/october-2026-security-releases
- **タグ**: nodejs security ReleaseNote
- **要約**: Node.js 22 / 24 / 26 向けのセキュリティリリース。複数の高深刻度を含む10件の脆弱性を修正し、OpenSSL や Undici などの依存も更新した。

### WebKit Features for Safari 27.1 | WebKit
- **URL**: https://webkit.org/blog/18486/webkit-features-for-safari-27-1/
- **タグ**: safari browser css WebAPI ReleaseNote
- **要約**: Safari 27.1 が、折りたたみ iPhone 向けの Device Posture API と Viewport Segments API をフィーチャーフラグの裏で実験的に追加した。

### Release v10.0.0-beta.0 · TypeStrong/ts-loader
- **URL**: https://github.com/TypeStrong/ts-loader/releases/tag/v10.0.0-beta.0
- **タグ**: TypeScript webpack ReleaseNote
- **要約**: ts-loader 10 Beta リリース。TypeScript 7.1 以上・Node.js 22 以上を要求し、コンパイルを `typescript/sync` API へ移行、いくつかのローダオプションを削除した。

### Release vite-plus v1.4.0 · voidzero-dev/vite-plus
- **URL**: https://github.com/voidzero-dev/vite-plus/releases/tag/v1.4.0

- **要約**: Vite+ 1.4.0 リリース。`vpx` による TS/JS ファイルの実行、tsx からの移行コマンド、チェック時の `--deny-warnings` オプションを追加した。

### Node.js — Node.js 26.13.0 (LTS)
- **URL**: https://nodejs.org/en/blog/release/v26.13.0

- **要約**: Node.js 26 が Lithium のコードネームで LTS に移行し、2029年4月までサポートされる。Node.js 25 以降の Linux バイナリは `libatomic` にリンクする。

### Node.js — Node.js 27.0.0-alpha.0.0.0 (Alpha)

- **要約**: 新リリースモデル初の Node.js 27 Alpha。既定のヒープ上限を変更し、V8 を 15.6 に更新、`v8.serialize()` のフォーマットを変更。`--allow-env` フラグと実験的な `net/promises` API も追加した。

### Release v1.0.0 · dy/jz
- **URL**: https://github.com/dy/jz/releases/tag/v1.0.0

### Release v1.65.0 · microsoft/playwright
- **URL**: https://github.com/microsoft/playwright/releases/tag/v1.65.0
- **タグ**: playwright testing ReleaseNote
