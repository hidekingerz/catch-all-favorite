> **取得メモ**: 今回の実行環境では `product-details.mozilla.org`・`www.firefox.com`・`developer.mozilla.org` など Mozilla 系ホストが egress プロキシでブロックされ（環境のネットワークポリシー）、直接取得できなかった。バージョン検出と本文は WebSearch 経由で取得した公式リリースノートの要約に基づく。

## 今回の注目ポイント

- **Firefox 155 安定版がリリース**（155.0: 2026-09-01、155.0.1: 2026-09-04 提供開始）。前回キャッチアップ（2026-08-25 収録、154.0 / 154.0.1）以降の新バージョン。
- **Firefox 155 からリリースサイクルが 4 週間から 2 週間に短縮**。今後は約 2 週間ごとに新バージョンが提供される（Chrome の 2 週間サイクル移行と同時期の動き）。
- **開発者向け**: DevTools のメディア特性エミュレーションが専用パネル（`@` ボタンで開く）に集約され、`prefers-reduced-motion` のエミュレーションが追加。JSON Viewer が JSON Lines（NDJSON）に対応し、各行を行番号付きの折りたたみ可能なエントリとして個別にパースする。
- **ESR も更新**: ESR 153.2.0 / ESR 140.15.0 / ESR 115.40.0 がいずれも 2026-09-01 に提供開始（前回記録は 153.1.0esr / 140.14.0esr）。

## バージョン一覧

### Firefox 155.0（安定版）
- **URL**: https://www.firefox.com/en-US/firefox/155.0/releasenotes/
- **公開日**: 2026-09-01
- **要約**:
  - **リリースサイクル変更**: Firefox 155 を起点に、リリースサイクルが 4 週間から 2 週間に短縮された。
  - **開発者ツール**: Rules ビューのメディア特性エミュレーションボタンが専用のエミュレーションパネル（`@` ボタンで開く）にまとめられ、`prefers-reduced-motion` のエミュレーションが追加された。JSON Viewer が JSON Lines（NDJSON）ドキュメントを開けるようになり、各行が行番号ラベル付きの独立した折りたたみエントリとして解析される。
  - **プロダクト機能**: Smart Window が米国・カナダ・フランスの全ユーザーで試用可能に（作業中トピックへ素早く戻るためのパーソナライズされた会話再開の起点を追加）。Assistant が Exa の Web 検索ソース引用付きでより高速に応答。Organize Tabs が関連タブのグルーピング精度を改善し、各グループにより分かりやすい名前を付けるように。

### Firefox 155.0.1（安定版・修正リリース）
- **URL**: https://www.firefox.com/en-US/firefox/155.0.1/releasenotes/
- **公開日**: 2026-09-04（Release チャネルへの提供開始日）
- **要約**: 155.0 の不具合修正リリース。CSS の blur と backdrop filter を併用するページで Firefox が反応しなくなる問題を修正。「タブとサイドバーを隠す」オプションを有効にした状態で Firefox を再起動するとサイドバーが再表示されない問題を修正。

### Firefox ESR 153.2.0 / ESR 140.15.0（法人向け ESR）
- **URL**: https://www.firefox.com/en-US/firefox/153.2.0/releasenotes/
- **公開日**: 2026-09-01（ESR チャネルへの提供開始日）
- **要約**: ESR 系の定例更新。現行の主要 ESR は 153.2.0（前回記録の 153.1.0esr から更新）。並行して ESR 140.15.0（前回記録の 140.14.0esr から更新）、ESR 115.40.0 も 2026-09-01 に提供開始。主にセキュリティ・安定性の修正を含む定例リリース。
