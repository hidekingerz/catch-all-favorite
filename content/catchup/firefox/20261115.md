## 今回の注目ポイント

- **Firefox 160.0 が 2026-11-10 にリリース**（Release チャネルへ提供開始）。前回収録の 157.0.1 から 158・159 を挟んでの現行安定版。目玉は、タブやページの一部を常に最前面に表示する小型ウィンドウにポップアウトする **Mini Window**（early version。Mozilla Connect でフィードバック募集中）。
- **ピクチャー イン ピクチャー（PiP）の再生速度を 0.25x〜2.0x で変更可能**に。履歴エントリをサイドバーからタブストリップへドラッグして新しいタブで開けるようになった。
- **mailto: リンクの扱いを繰り返し要求するサイトをブロックする「許可しない（Never allow）」ボタン**を追加。メディア面では FLAC / MP3 / PCM 音声を含む **MKV ファイルの再生に対応**。
- セキュリティ面では **MFSA 2026-125**（99 件の CVE に対処）を同梱。
- **ESR は 153.7.0 が 2026-11-10 に公開**（現行 ESR ブランチ 153 の dot update）。

## バージョン一覧

### Firefox 160.0（安定版）
- **バージョン**: 160.0
- **リリース日**: 2026-11-10
- **リリースノート**: https://www.firefox.com/en-US/firefox/160.0/releasenotes/
- **要約**: 現行安定版。新機能として、タブやページの一部を常に最前面の小型ウィンドウにポップアウトする **Mini Window**（早期バージョン）、PiP の再生速度変更（0.25x〜2.0x）、履歴エントリのタブストリップへのドラッグ＆ドロップ、mailto: リンクを繰り返し要求するサイトをブロックする「許可しない」ボタン、FLAC / MP3 / PCM 音声入りの MKV ファイル再生対応、Smart Window の「タブを整理」のフランス語対応、アドレスバーのコンテキストメニューでの「貼り付けて検索」などを含む。セキュリティは MFSA 2026-125（99 件の CVE）。
- **開発者向け (MDN)**: `developer.mozilla.org` が egress ブロックにより取得できず、Web プラットフォーム／開発者向け変更点は本ファイルでは未収録（JSON・MDN にアクセスできる次回実行で補完する）。
- **備考**: リリースノート本文（`www.firefox.com`）が egress ブロックにより直接取得できず、変更点は WebSearch で得られた公式リリースノートの要約と複数の技術ニュースの裏取りに基づく。Phoronix が報じた「Web Speech API による端末内音声認識（40 言語）」は公式リリースノートや他ソースで裏取りできなかったため、確定項目には含めない。

> ESR について: WebSearch では現行 ESR ブランチ 153 の最新が **153.7.0esr（2026-11-10）** と示唆された（既収録のベースライン 153.3.0esr からの継続的な dot update）。ただし権威ある `firefox_versions.json` の `FIREFOX_ESR` 値が egress ブロックで取得できず、ESR のリリースノート本文も確認できなかったため、本ファイルでは確定版として `**バージョン**:` 行には含めない（誤記録を避けるため）。JSON にアクセスできる次回実行で改めて検知・収録する。

> 収録漏れ（158・159）について: 157.0.1（20261008.md）以降、`product-details.mozilla.org` の egress ブロックにより Firefox のバージョン検知が機能せず、158・159 のメジャーリリースを個別に収録できていない。これらの変更点は JSON・リリースノート本文にアクセスできる環境での再実行時に補完する（本ファイルでは現行安定版 160.0 の収録にとどめる）。
