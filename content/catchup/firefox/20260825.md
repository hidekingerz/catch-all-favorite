## 今回の注目ポイント

初回キャッチアップ。安定版は Firefox 154 系（154.0 が 2026-08-18、dot release の 154.0.1 が本日 2026-08-25 リリース）。Firefox 154 では CSS の `sibling-count()` / `sibling-index()` 関数と `text-box-edge` / `text-box-trim` / `text-box` プロパティ、JavaScript の `Iterator.prototype.includes()` / `join()` / `chunks()` / `windows()` が新たにサポートされ、Web 開発者向けの追加が多い。154.0.1 はパスワードストレージ変更起因の不具合（保存パスワードへのアクセス遅延・想定外のプライマリパスワード要求）などのバグ修正が中心。ESR は 140.14.0（セキュリティ修正、MFSA 2026-76）。

## バージョン一覧

### Firefox 154.0.1（安定版）
- **バージョン**: 154.0.1
- **リリース日**: 2026-08-25
- **リリースノート**: https://www.firefox.com/en-US/firefox/154.0.1/releasenotes/
- **開発者向け (MDN)**: https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/154
- **要約**: バグ修正の dot release。パスワードストレージの変更に起因する保存パスワードへのアクセス遅延と想定外のプライマリパスワード要求、一部サイトでの住所オートフィル失敗、Windows で起動のたびにスタートメニューのショートカットが追加される問題、HTTP ページからローカルネットワーク機器への接続が許可プロンプトなしで失敗する問題などを修正。メジャー版 Firefox 154（2026-08-18）の開発者向け変更としては、CSS の `sibling-count()` / `sibling-index()` 関数と `text-box-edge` / `text-box-trim` / `text-box`、JavaScript の `Iterator.prototype.includes()` / `join()` / `chunks()` / `windows()`、WebRTC の `RTCIceTransport.getSelectedCandidatePair()` などが追加され、拡張機能では `sandbox` manifest キーがサポートされた。

### Firefox 140.14.0esr（ESR）
- **バージョン**: 140.14.0esr
- **リリース日**: 2026-08-18
- **リリースノート**: https://www.firefox.com/en-US/firefox/140.14.0/releasenotes/
- **要約**: ESR 140 系のセキュリティアップデート。各種セキュリティ修正を含む（[MFSA 2026-76](https://www.mozilla.org/security/advisories/mfsa2026-76/)）。機能追加はなし。なお次期 ESR として 153 系（153.1.0esr）への移行が進行中。
