## 今回の注目ポイント

- **Firefox 161.0 が 2026-11-24 にリリース**（Release チャネルへ提供開始）。前回収録の 160.0.1 に続くメジャー版で、2026 年 9 月の Firefox 155 以降に移行した「2 週間ごとのメジャーリリース」サイクルに沿った更新。複数ソースが 160 系より機能追加の少ない小規模なリリースと評している。
- 新機能として、**現在のタブの URL をキーボードショートカットでコピーできる**ようになった。テーマ設定に **「Classic themes（クラシックテーマ）」のコレクション**が追加された。
- **macOS で System Settings（システム設定）経由で割り当てたキーボードショートカットが、Firefox の組み込みショートカットを上書きする**ようになった。
- **Android では、拡張機能の更新で追加の権限承認が必要になった場合に通知が届く**ようになった。
- メジャー番号 161 は本ファイルで初記録のため、MDN の開発者向けリリースノート（Web プラットフォーム変更）の URL を参照先として記載するが、`developer.mozilla.org` が egress ブロックにより取得できず、CSS / JS / Web API の具体的な変更点は直接取得できていない（JSON・MDN にアクセスできる次回実行で補完する）。

- **要約**: 2 週間サイクルに沿ったメジャー版で、160 系より機能追加は小規模。現在のタブの URL をキーボードショートカットでコピー可能になり、テーマ設定に「Classic themes」コレクションを追加。macOS では System Settings 経由で割り当てたキーボードショートカットが組み込みショートカットを上書きするようになった。Android では拡張機能の更新で追加権限の承認が必要な場合に通知が届く。セキュリティ修正（MFSA）の有無・件数は egress ブロックによりリリースノート本文・MFSA 一覧を直接確認できず未収録。
- **備考**: リリースノート本文（`www.firefox.com`）・バージョン JSON（`product-details.mozilla.org`）・MDN（`developer.mozilla.org`）がいずれも egress ブロックにより直接取得できず、変更点は WebSearch で得られた複数のソース（portableapps・Neowin・Tux Machines・piunikaweb・LinuxToday 等）および公式リリースノートページのタイトルに基づく。MFSA・Web プラットフォーム変更点は JSON・リリースノート本文・MDN にアクセスできる次回実行で裏取り・補完する。
