## 今回の注目ポイント

- **iOS & iPadOS 27.3 Beta のリリースノートが新規公開**（前回収集時は 27.2 RC が最新）。SDK は Xcode 27.3 に同梱される。
- **App Intents に Siri AI 関連の既知の問題**: unlock を要求する `authenticationPolicy` を `AppEntity` に定義しても、Siri AI が表示前に unlock を要求しないことがある (190573761)。27.3 で解放された Siri AI Developer Preview に関連する項目。
- **NEURLFilter で複数の破壊的変更（Deprecations）**: ユーザー階層（user tiers）が非サポートになり、PIR シャード数は 2 の累乗かつ最大 65,536 に制限、サービス URL / Privacy Pass issuer URL は Info.plist の `NSPIRConfiguration` に静的宣言する方式へ移行。該当する URL フィルタ拡張の開発者は対応必須。
- **StoreKit にマルチシート サブスクリプション**: 自動更新サブスクの複数シート購入に対応し、`Product` / `AdvancedCommerceProduct` の新プロパティ `supportsMultiSeatPurchase` でサポート可否を確認できる (164581840)。

## バージョン一覧

### iOS & iPadOS 27.3 Beta Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_3-release-notes
- **要約**: iPhone / iPad 向け iOS & iPadOS 27.3 beta の開発をサポートする SDK のリリースノート。SDK は Xcode 27.3 に同梱される。掲載項目は以下のとおり。
  - **既知の問題（App Intents）**: unlock を要求する `authenticationPolicy` を `AppEntity` またはそのプロパティに定義しても、Siri AI がエンティティ表示前に unlock を要求しないことがある (190573761)。
  - **新機能（Live Caller ID Lookup）**: システムが未使用の評価鍵（evaluation key）をサービスにアップロードしておき、事前アップロード済みの鍵を使い切った場合はクエリにインラインで新しい評価鍵を送る。クエリに評価鍵が含まれる場合、サービスはユーザー識別子から鍵を探すのではなく、その鍵を直接使用しなければならない (187726157)。
  - **廃止・変更（Live Caller ID Lookup）**: サービスの PIR 構成のシャード数は 2 の累乗（256・512・1024・2048 など）である必要があり、それ以外の構成は拒否される。既存の 2 の累乗構成は変更不要 (191651833)。
  - **新機能（NEURLFilter）**: Live Caller ID Lookup と同様のインラインフォールバックで未使用評価鍵を保持。クエリに評価鍵が含まれる場合は直接使用しなければならない (187726173)。
  - **廃止・変更（NEURLFilter）**: (1) ユーザー階層（user tiers）が非サポートになり、`/token-key-for-user-token` エンドポイントは呼ばれず、Privacy Pass トークン発行者ディレクトリの最初の有効な公開鍵が使われる (191651440)。(2) PIR 構成は最大 65,536 シャードかつ 2 の累乗に制限され、超過・非累乗の構成は拒否される (191651462)。(3) 実行時のみの URL 指定は非推奨。サービス URL と Privacy Pass issuer URL はアプリ本体（URL フィルタ拡張ではない）の Info.plist に `NSPIRConfiguration` 辞書（`PIRServerURL` / `PrivacyPassIssuerURL`）で静的宣言する。実行時にも設定する場合は Info.plist の値と完全一致が必要で、不一致だと無効な構成エラーでフィルタが起動しない (191651632)。
  - **新機能（StoreKit）**: マルチシート サブスクリプションに対応。顧客が自動更新サブスクの複数シートを購入して他者を招待できる。新プロパティ `supportsMultiSeatPurchase`（`Product` / `AdvancedCommerceProduct`）で App Store Connect の設定に基づくサポート可否を確認できる (164581840)。
  - **解決された問題（StoreKit）**: Family Sharing グループの iCloud アカウントでサインイン中に Sandbox で Ask to Buy をテストすると、sandbox の Ask to Buy リクエストの閲覧・承認ができなくなることがある問題を修正 (190639717)。
  - **解決された問題（StoreKit Testing in Xcode）**: サブスクリプション バンドルに含まれるサブスクリプションの購入で、エラーを投げるべきところ誤ってアンバンドルできてしまう問題を修正 (186018916)。
  - **既知の問題（StoreKit Testing in Xcode）**: `SKTestSession` を使うアプリの初回起動時に、一部の StoreKit Test API 呼び出しがハングすることがある (186670057 / FB24651858)。回避策: スキームの実行オプションで StoreKit 構成ファイルを設定し、テストを再実行する。
