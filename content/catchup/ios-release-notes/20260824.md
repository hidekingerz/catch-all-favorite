## 今回の注目ポイント

- **iOS & iPadOS 27 が Beta 7 に更新**（前回キャッチアップ時点＝Beta 6, 2026-08-17 から進行）。今回の新着は 27 Beta 7 のみ。26 系の正式版に新規更新はなし。リリースノートは 27.0 の累積形式のため、以下は Beta 7 時点で記載されている開発者向けの主要な変更点。
- Beta 4〜6 から継続している**破壊的変更・必須対応**は引き続き有効: シーンベースライフサイクル未対応アプリの起動失敗、Launch screen キー必須化、On Demand Resources / `NSBundleResourceRequest` 廃止→Background Assets、旧 MetricKit API（`MXMetricManager` 等）非推奨→`MetricManager`、`FileDocument`/`ReferenceFileDocument` 非推奨→`Document` プロトコル、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、AirPort Utility の新規ダウンロード終了、**27.0 で MDM/DDM/Automated Device Enrollment・構成プロファイル・アプリ配信・ソフトウェア更新に関わるシステムプロセスの TLS 要件厳格化**（サーバが要件を満たさないと接続失敗の可能性）。
- Beta 7 で目立つ開発者向けの追加・変更: **SwiftUI の `AsyncImage` が HTTP キャッシュに自動対応**（`URLRequest` の `cachePolicy` でカスタマイズ可）、**選択可能な `Text`（`.textSelection(.enabled)`）がシステムのテキスト選択 UI によるインタラクティブ選択に対応・`TextRenderer` 対応**、**`TabsPickerStyle` / `TextInputBorderShape`（`.bordered` テキストフィールドスタイル、`.squareBorder`/`.roundedBorder` はソフト非推奨）**、**外部ディスプレイ向け `.sceneAccessory`（`ExternalNonInteractiveAccessory`）**、**Game Controller が PlayStation Access コントローラを macOS/iPadOS/iOS でサポート**、**AudioAccessoryKit でサードパーティ製オーディオアクセサリの固定空間オーディオ対応（当面は開発者テスト用）**、**Media Sharing Extensions フレームワーク**、**App Intents の `notes.createNote`/`notes.updateNote` が `AttributedString` の name パラメータを受け取り可能**。
- 継続中の主要新機能: Core AI（Neural Engine 改善＋バックグラウンド推論エンタイトルメント `com.apple.developer.background-tasks.continued-processing.inference`）、Dictation の「Advanced Dictation Preview」オンデバイスモデル、HealthKit の心拍/サイクリングパワーゾーン・履歴アクセス許可の細分化・更年期関連トラッキング、HomeKit Secure Video 録画への Apple Intelligence 処理（iCloud+ 2TB 以上が必要）、StoreKit のオファーコード引き換えが `VerificationResult` を返す＋ボリューム購入・サブスクリプション Bundles/Suites 対応、MetricKit の `MetalFrameRateMetric`・`MemoryExceptionDiagnostic`・`StateReporting` 連携。

## バージョン一覧

### iOS & iPadOS 27 Beta 7 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27-release-notes
- **要約**: iOS & iPadOS 27 の 7 番目のベータ。リリースノートは 27.0 の累積形式。新機能では SwiftUI の `AsyncImage` の HTTP キャッシュ自動対応、インタラクティブな `Text` 選択と `TextRenderer` 対応、`TabsPickerStyle`/`TextInputBorderShape`、外部ディスプレイ向け `.sceneAccessory`、Game Controller の PlayStation Access コントローラ対応、AudioAccessoryKit の固定空間オーディオ、Media Sharing Extensions、App Intents の Notes スキーマ拡張などが記載。廃止・変更では On Demand Resources 廃止（→Background Assets）、旧 MetricKit API 非推奨（→`MetricManager`）、`FileDocument`/`ReferenceFileDocument` 非推奨（→`Document`）、PencilKit `__PKStrokeRenderState`→`PKStrokeRenderStateReference`、PhotoKit `originalFilename`→nullable な `filename`、`calendar.deleteEvents`→`calendar.deleteEvent` が継続。27.0 のシステムプロセスに対する TLS 要件厳格化（MDM/DDM/構成プロファイル/アプリ配信/ソフトウェア更新）は破壊的変更として要注意。Known Issues として CarPlay・Control Center・Dictation・Core Spotlight 等に残存項目あり。
