## 今回の注目ポイント

- **iOS & iPadOS 27.2 Beta 3 のリリースノートが公開**（前回収集時は「27.2 Beta 2」）。SDK は Xcode 27.2 に同梱される。
- **App Tracking Transparency の新 API 名が変更された**（Beta 3 で解決済みとして記載）。`requestTrackingAuthorization(usingExpandedInterface:additionalInformationAction:completionHandler:)` が `requestTrackingAuthorization(preferExpandedInterface:...)` に、さらに `requestTrackingAuthorizationPreferringExpandedInterface:…` にリネーム。EU 向け拡張プロンプト対応の実装を進めている開発者は API 名の追従が必要。
- **UIKit の新機能**: iOS 27.1 以降、`UIView` の既定のレイアウトマージンがゼロになった。ビューコントローラのビューのサブビューでこれらのマージンを継承するには `preservesSuperviewLayoutMargins` を `true` に設定する。
- Simulator Runtimes・Quest Lab Appointments に新しい既知の問題が追加。

## バージョン一覧

### iOS & iPadOS 27.2 Beta 3 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_2-release-notes
- **要約**: iPhone / iPad 向け iOS & iPadOS 27.2 beta 3 の開発をサポートする SDK のリリースノート。SDK は Xcode 27.2 に同梱される。前回の Beta 2 からの主な差分は以下。
  - **新機能（App Tracking Transparency）**: `AppTrackingTransparency` が EU ユーザー向けの代替の拡張プロンプトと年次ベースでの再プロンプトに対応。代替プロンプトはフランス・ドイツ・イタリア・ポーランド・ルーマニアのユーザーで必須。(179504171)
  - **解決された問題（App Tracking Transparency、Beta 3 で追加）**: 新 API `requestTrackingAuthorization(usingExpandedInterface:additionalInformationAction:completionHandler:)` を `requestTrackingAuthorization(preferExpandedInterface:...)` にリネーム (187149729)。さらに `requestTrackingAuthorization(preferExpandedInterface:...)` を `requestTrackingAuthorizationPreferringExpandedInterface:…` にリネーム (187610745)。
  - **新機能（UIKit、Beta 3 で追加）**: iOS 27.1 以降、`UIView` の既定のレイアウトマージンがゼロになった。ビューコントローラは引き続き自身のビューに `systemMinimumLayoutMargins`（表示コンテキストに応じて変化）を提供する。サブビューでこれを継承するには `preservesSuperviewLayoutMargins` を `true` に設定する。(186294594)
  - **解決された問題（StoreKit Testing in Xcode）**: `SKTestSession.clearTransactions()` 呼び出し後に導入オファーの適格性が即座にリセットされない問題 (183933307 / FB24137836)、`SKTestSession` でストアフロント/ロケールを変更しても `Storefront.updates` に伝播しない問題 (184155259)、`dialogsDisabled` を true にしても購入失敗時にエラーダイアログが表示されることがある問題 (184255116) を修正。
  - **既知の問題（Beta 3 で追加分を含む）**: （Health）Insights タブでパーソナライズド サマリーが期待どおり生成されないことがある (186964423)。（Quest Lab Appointments）ラボ予約がある場合は結果を受け取るまで iOS のアップデートを待つことが推奨される (184530996)。（Shortcuts）Describe a Shortcut が「Something went wrong. Try again later.」エラーで失敗することがある (187499433)。（Simulator Runtimes）ランタイム 27.2 を実行中のシミュレータデバイスのクローンがファイル権限の誤りで失敗することがある (188407822 / FB24939277、回避策あり)。（StoreKit Testing）サブスクリプション バンドルに含まれるサブスクリプションのアプリ内購入で、エラーを投げるべきところ誤ってアンバンドルできてしまう (186018916)。
