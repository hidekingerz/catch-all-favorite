## 今回の注目ポイント

- iOS & iPadOS 26.6 が正式版としてリリースノートを更新（前回は 26.6 RC を記録済み）。Xcode 26.6 同梱の 26.6 SDK 向けで、内容は解決済みの不具合が中心。新規 API の追加や廃止に関する記載はなし。
- HealthKit・Messages・Object Capture・Stickers・StoreKit で複数の不具合が修正。特に StoreKit の Simulator でテスト環境に接続できない問題や、Stickers データ破損でステッカーが作成/表示できなくなる問題（iCloud 同期で他デバイスにも波及）が解消。
- iOS & iPadOS 27 系は今回時点でも「Beta 4」のままで、前回キャッチアップ（27 Beta 4）から変化なし。

## バージョン一覧

### iOS & iPadOS 26.6 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-26_6-release-notes
- **要約**: iOS & iPadOS 26.6 SDK（Xcode 26.6 同梱、Mac App Store で入手可）向けの正式版リリースノート。新機能・廃止 API の記載はなく、解決済みの不具合のみ。HealthKit: 認可画面が表示されない問題、及び時間加重平均の統計クエリで安静時心拍数などが異常に高く返る問題を修正。Messages: HDR スクリーンショット送信時に画像が乱れる問題を修正。Object Capture: キャプチャと再構築が失敗する問題を修正。Stickers: データ破損によりステッカーの作成・表示ができなくなり iCloud 同期で他デバイスにも波及する問題を修正。StoreKit: Simulator 使用時にテスト環境へ正しく接続できずテストアクションが失敗する問題を修正（FB22500243）。
