## 今回の注目ポイント

- **iOS & iPadOS 27.3 Beta 2 のリリースノートが公開**（前回収集時は「27.3 Beta」）。SDK は Xcode 27.3 に同梱される。前回の Beta からいくつかの項目が追加・変更された。
- **App Intents に Siri AI 連携の新機能**: Video スキーマドメインが tvOS / iOS / macOS / visionOS で Siri AI と連携できるようになった (189805051)。
- **StoreKit に破壊的な API 変更**: マルチシートの招待・データ共有同意 API が、サブスクリプショングループ ID ではなく元の取引 ID（original transaction ID）を受け取る形に変更。`multiSeatDataSharingConsentEligibility` インスタンスプロパティは廃止。シンボル欠落によるクラッシュを避けるため最新 SDK で再コンパイルが必要 (191322945)。
- **StoreKit Testing の既知の問題が解決に転じた**: 前回 Beta で既知の問題だった「`SKTestSession` を使うアプリの初回起動時に一部の StoreKit Test API 呼び出しがハングする」問題 (186670057 / FB24651858) が、今回は解決済み（Resolved Issues）に移動。
- **新規セクションが追加**: Apple Video Podcasts in the TV App（192370477）、CoreImage（CIRAWFilter のリソース外部ダウンロード、190766743）、Siri（HomeView の既知の問題、192952891）、SwiftUI（`ScrollEdgeEffectStyle.soft` の解決、188312290）。

## バージョン一覧

### iOS & iPadOS 27.3 Beta 2 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_3-release-notes
- **要約**: iPhone / iPad 向け iOS & iPadOS 27.3 beta 2 の開発をサポートする SDK のリリースノート。SDK は Xcode 27.3 に同梱される。前回の Beta から新機能・解決済み項目・新規セクションが追加された。掲載項目は以下のとおり（★は前回 Beta から新規・変更された項目）。
  - **★ 新機能（App Intents）**: Video スキーマドメインが、tvOS・iOS・macOS・visionOS 上で Siri AI と連携するアプリ向けに利用可能になった (189805051)。
  - **既知の問題（App Intents）**: unlock を要求する `authenticationPolicy` を `AppEntity` またはそのプロパティに定義しても、Siri AI がエンティティ表示前に unlock を要求しないことがある (190573761)。
  - **★ 新機能（Apple Video Podcasts in the TV App、新規セクション）**: Apple Video Podcasts が Apple TV アプリで利用可能になった。お気に入りのビデオポッドキャストのフルエピソードを視聴でき、Apple Podcasts で視聴を中断した位置から続きを再生できる (192370477)。
  - **★ 新機能（CoreImage、新規セクション）**: `CIRAWFilter` が OS に同梱されないリソースに依存するようになった。ダウンロードには `CIRAWFilter` の `downloadresources` / `downloadallresources` メソッドを使う (190766743)。
  - **新機能（Live Caller ID Lookup）**: システムが未使用の評価鍵（evaluation key）をサービスにアップロードしておき、事前アップロード済みの鍵を使い切った場合はクエリにインラインで新しい評価鍵を送る。クエリに評価鍵が含まれる場合、サービスはユーザー識別子から鍵を探すのではなく、その鍵を直接使用しなければならない (187726157)。
  - **廃止・変更（Live Caller ID Lookup）**: サービスの PIR 構成のシャード数は 2 の累乗（256・512・1024・2048 など）である必要があり、それ以外の構成は拒否される。既存の 2 の累乗構成は変更不要 (191651833)。
  - **新機能（NEURLFilter）**: Live Caller ID Lookup と同様のインラインフォールバックで未使用評価鍵を保持。クエリに評価鍵が含まれる場合は直接使用しなければならない (187726173)。
  - **廃止・変更（NEURLFilter）**: (1) ユーザー階層（user tiers）が非サポートになり、`/token-key-for-user-token` エンドポイントは呼ばれず、Privacy Pass トークン発行者ディレクトリの最初の有効な公開鍵が使われる (191651440)。(2) PIR 構成は最大 65,536 シャードかつ 2 の累乗に制限され、超過・非累乗の構成は拒否される (191651462)。(3) 実行時のみの URL 指定は非推奨。サービス URL と Privacy Pass issuer URL はアプリ本体（URL フィルタ拡張ではない）の Info.plist に `NSPIRConfiguration` 辞書（`PIRServerURL` / `PrivacyPassIssuerURL`）で静的宣言する。`PIRServerURL` は `pirServerURL`、`PrivacyPassIssuerURL` は `pirPrivacyPassIssuerURL` に対応し、後者が無い場合は `PIRServerURL` が既定値になる。各値はサーバのホスト名のみを含むこと。実行時にも設定する場合は Info.plist の値と完全一致が必要で、不一致だと無効な構成エラーでフィルタが起動しない (191651632)。
  - **★ 既知の問題（Siri、新規セクション）**: iOS または iPadOS 27.3 beta を実行する iPhone / iPad とペアリングした場合、HomeView 上の Siri AI が正しくセットアップされないことがある (192952891)。
  - **新機能（StoreKit）**: マルチシート サブスクリプションに対応。顧客が自動更新サブスクの複数シートを購入して他者を招待できる。新プロパティ `supportsMultiSeatPurchase`（`Product` / `AdvancedCommerceProduct`）で App Store Connect の設定に基づくサポート可否を確認できる (164581840)。
  - **解決された問題（StoreKit）**: Family Sharing グループの iCloud アカウントでサインイン中に Sandbox で Ask to Buy をテストすると、sandbox の Ask to Buy リクエストの閲覧・承認ができなくなることがある問題を修正 (190639717)。
  - **★ 解決された問題（StoreKit、破壊的変更）**: マルチシートの招待・データ共有同意 API が、サブスクリプショングループ ID ではなく元の取引 ID（original transaction ID）を受け取るようになった。`AppStore.presentMultiSeatInvitationSheet(from:originalTransactionID:)`、`AppStore.presentMultiSeatDataSharingConsentSheet(from:originalTransactionID:)`、`Product.SubscriptionInfo.multiSeatDataSharingConsentEligibility(originalTransactionID:)`、および SwiftUI の `multiSeatInvitationSheet(isPresented:originalTransactionID:onCompletion:)` / `multiSeatDataSharingConsentSheet(isPresented:originalTransactionID:onCompletion:)` 修飾子がサブスクリプション取引の `originalID` を受け取る。`Product.SubscriptionInfo` の `multiSeatDataSharingConsentEligibility` インスタンスプロパティは利用不可になった。シンボル欠落によるクラッシュを避けるため、最新 SDK でアプリを再コンパイルすること (191322945)。
  - **解決された問題（StoreKit Testing in Xcode）**: サブスクリプション バンドルに含まれるサブスクリプションのアプリ内購入で、エラーを投げるべきところ誤ってアンバンドルできてしまう問題を修正 (186018916)。
  - **★ 解決された問題（StoreKit Testing in Xcode）**: `SKTestSession` を使うアプリの初回起動時に、一部の StoreKit Test API 呼び出しがハングする問題を修正（前回 Beta では既知の問題として掲載されていた）(186670057 / FB24651858)。
  - **★ 解決された問題（SwiftUI、新規セクション）**: iOS 26 SDK でビルドしたアプリで、iOS 27 上で実行すると `ScrollEdgeEffectStyle.soft` が `safeAreaBar(edge:)` の上に完全に透明なエッジをレンダリングする問題があった。iOS 27.3 以降では、これらのアプリは iOS 27 のソフトエッジ効果を得られるようになった (188312290)。
