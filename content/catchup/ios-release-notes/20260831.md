## 今回の注目ポイント

- **iOS & iPadOS 27 が Beta 8 に更新**（前回キャッチアップ時点＝Beta 7, 2026-08-24 から進行）。今回の新着は 27 Beta 8 のみ。26 系正式版（26.6）に新規更新はなし。リリースノートは 27.0 の累積形式のため、以下は Beta 8 時点で記載されている開発者向けの主要な変更点。
- Beta 4〜7 から継続している**破壊的変更・必須対応**は引き続き有効: iOS 27.0 SDK 以降でビルドしたアプリは Launch screen キー（`UILaunchScreen` 等）を `Info.plist` に必須化、On Demand Resources / `NSBundleResourceRequest` 廃止→Background Assets、旧 MetricKit API 非推奨→`MetricManager`、`FileDocument`/`ReferenceFileDocument` 非推奨→`Document` プロトコル、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、AirPort Utility の新規ダウンロード終了、**27.0 で一部システムプロセスの TLS（ネットワークセキュリティ）要件厳格化**（MDM/DDM/Automated Device Enrollment・構成プロファイル・アプリ配信・ソフトウェア更新等。サーバが要件を満たさないと接続失敗の可能性）。
- Beta 8 の累積ノートで目立つ開発者向けの追加・変更: **Trust Insights フレームワーク**（Xcode でケイパビリティ宣言、エンタイトルメントとネット接続が必要）、**TextKit の `NSTextTable` 系が OS 27 から UIKit でも利用可能に**、**System が C の `stat`/`lstat`/`fstat`/`fstatat` に対応する Swift API（`Stat` 型・`FilePath.stat()` 等）を提供**、**VideoToolbox の `VTLowLatencySuperResolutionScalerConfiguration` が 1.5x スケール対応・`VTLowLatencyFrameInterpolationConfiguration` が最大 1080p の任意ソース寸法対応**、**Core AI がバックグラウンドでの Neural Engine アクセスを GPU 同様に制限**（バックグラウンド推論には新エンタイトルメント `com.apple.developer.background-tasks.continued-processing.inference` が必要）、**RealityKit の Gaussian Splat Component API は今後のリリースで提供予定**。SwiftUI の `AsyncImage` の HTTP キャッシュ自動対応・インタラクティブな `Text` 選択と `TextRenderer` 対応・`ReadableDocument`/`WritableDocument`/`Document` プロトコル・`TabsPickerStyle`/`TextInputBorderShape`・外部ディスプレイ向け `.sceneAccessory` なども継続して記載。

## バージョン一覧

### iOS & iPadOS 27 Beta 8 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27-release-notes
- **要約**: iOS & iPadOS 27 SDK の 8 番目のベータ（Xcode 27 バンドル、Mac App Store 入手可）。概要は「新機能に対応し、API 変更に対してアプリをテストせよ」で、リリースノートは 27.0 の累積形式。
  - **主な新機能（27.0 累積、Beta 8 時点）**: SwiftUI に `AsyncImage` の HTTP キャッシュ自動対応、`.textSelection(.enabled)` の `Text` のインタラクティブ選択と `TextRenderer` 対応、`@State` のマクロ実装化（初期化式の再評価回避）、`ReadableDocument`/`WritableDocument`/`Document` プロトコルと `DocumentGroup`/`fileExporter` 拡張、`TabsPickerStyle`・`TextInputBorderShape`・`concentricCornerRadii`・`toolbarMinimizationBehavior`（`toolbarMinimizeBehavior` を置換）・外部ディスプレイ向け `.sceneAccessory`。UIKit は 27.0 SDK で Launch screen 必須化、`UINavigationItem.navigationBarMinimization`（旧 `barMinimizeBehavior` を置換）、`UISearchController` のスコープバー挙動変更、`UIScene.extendStateRestoration`/`completeStateRestoration`。App Intents は `notes.createNote`/`notes.updateNote` が `AttributedString` の name を受け取り可能。StoreKit はオファーコード引き換えが `VerificationResult` を返す・ボリューム購入（`Transaction.OwnershipType.assigned` 等）・サブスクリプション Bundles/Suites・Advanced Commerce の `partnerName`/`partnerId`。MetricKit は Swift 版 `MetricManager`・`MemoryExceptionDiagnostic`・`MetalFrameRateMetric`・`CrashDiagnostic.terminationCategory`・`HitchTimeRatio` 型。HealthKit は心拍/サイクリングパワーゾーン・限定/全履歴を選べる権限フロー・更年期状態/閉経後出血のトラッキング。Core AI は Neural Engine 改善とバックグラウンドアクセス制限＋新エンタイトルメント。Game Controller が PlayStation Access コントローラを macOS/iPadOS/iOS でサポート。AudioAccessoryKit（固定空間オーディオ、当面は開発者テスト用）、Media Sharing Extensions、Background Assets のローカライズ済みアセットパック、HomeKit Secure Video 録画への Apple Intelligence 処理（iCloud+ 2TB 以上）、Dictation のオンデバイスモデル精度向上プレビュー。Beta 8 累積で目立つのは **Trust Insights フレームワーク**、**TextKit `NSTextTable` の UIKit 対応**、**System の stat 系 Swift API**、**VideoToolbox の超解像 1.5x／フレーム補間 1080p 対応**、**RealityKit Gaussian Splat Component（今後提供予定）** など。
  - **廃止・変更**: On Demand Resources / `NSBundleResourceRequest` 廃止（→Background Assets）、旧 MetricKit API 非推奨（→`MetricManager`）、`FileDocument`/`ReferenceFileDocument` 非推奨（→`Document`）、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、AirPort Utility の新規ダウンロード終了、27.0 での一部システムプロセスの TLS 要件厳格化（破壊的変更として要注意）。
  - **解決済みの問題（主なもの）**: AirPlay（ホームシアターでの PIN/パスワード必須失敗）、AirPods Max 2 のファームウェアベータ更新、App Intents（Siri でのカスタム画像非表示・`reminders.updateReminder` 失敗・`AppEntity` 10MB 累積上限クラッシュ・`notes.appendText` スキーマ消失）、Apple Wallet の Digital ID が 27.0 Beta 3/4 更新中に期限切れ扱いになる問題、Battery/Power（深放電デバイスの起動不能）、Apple Intelligence Report、Core AI 各種。
  - **既知の問題（主なもの）**: 既存の `@AppEntity(schema: .photos.asset)` 準拠コードが新プロパティ追加により 27 SDK でコンパイルできない場合あり（回避策: 可用性チェック付きで新プロパティを採用）。
