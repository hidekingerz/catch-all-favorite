## 今回の注目ポイント

- **iOS & iPadOS 27.2 Beta 4 のリリースノートが公開**（前回収集時は「27.2 Beta 3」）。SDK は Xcode 27.2 に同梱される。
- 本文内容は Beta 3 から実質的な差分なし。各セクション（App Tracking Transparency / Health / Quest Lab Appointments / Shortcuts / Simulator Runtimes / StoreKit Testing in Xcode / UIKit）の項目・Radar 番号はすべて Beta 3 と同一で、タイトルのベータ番号のみ進んだ。
- 引き続きの主要トピック: App Tracking Transparency の EU 向け拡張プロンプト対応と、新 API が `requestTrackingAuthorizationPreferringExpandedInterface:…` にリネームされた点、UIKit で iOS 27.1 以降 `UIView` の既定レイアウトマージンがゼロになった点。

## バージョン一覧

### iOS & iPadOS 27.2 Beta 4 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_2-release-notes
- **要約**: iPhone / iPad 向け iOS & iPadOS 27.2 beta 4 の開発をサポートする SDK のリリースノート。SDK は Xcode 27.2 に同梱される。前回の Beta 3 からの本文差分はなく、掲載項目は以下のとおり（タイトルが Beta 3 → Beta 4 に更新された）。
  - **新機能（App Tracking Transparency）**: `AppTrackingTransparency` が EU ユーザー向けの代替の拡張プロンプトと年次ベースでの再プロンプトに対応。代替プロンプトはフランス・ドイツ・イタリア・ポーランド・ルーマニアのユーザーで必須。(179504171)
  - **解決された問題（App Tracking Transparency）**: 新 API `requestTrackingAuthorization(usingExpandedInterface:additionalInformationAction:completionHandler:)` を `requestTrackingAuthorization(preferExpandedInterface:...)` にリネーム (187149729)。さらに `requestTrackingAuthorization(preferExpandedInterface:...)` を `requestTrackingAuthorizationPreferringExpandedInterface:…` にリネーム (187610745)。
  - **新機能（UIKit）**: iOS 27.1 以降、`UIView` の既定のレイアウトマージンがゼロになった。ビューコントローラは引き続き自身のビューに `systemMinimumLayoutMargins`（表示コンテキストに応じて変化）を提供する。サブビューでこれを継承するには `preservesSuperviewLayoutMargins` を `true` に設定する。(186294594)
  - **解決された問題（StoreKit Testing in Xcode）**: `SKTestSession.clearTransactions()` 呼び出し後に導入オファーの適格性が即座にリセットされない問題 (183933307 / FB24137836)、`SKTestSession` でストアフロント/ロケールを変更しても `Storefront.updates` に伝播しない問題 (184155259)、`dialogsDisabled` を true にしても購入失敗時にエラーダイアログが表示されることがある問題 (184255116) を修正。
  - **既知の問題**: （Health）Insights タブでパーソナライズド サマリーが期待どおり生成されないことがある (186964423)。（Quest Lab Appointments）ラボ予約がある場合は結果を受け取るまで iOS のアップデートを待つことが推奨される (184530996、回避策: Browse > Lab Results でも結果を確認可能)。（Shortcuts）Describe a Shortcut が「Something went wrong. Try again later.」エラーで失敗することがある (187499433)。（Simulator Runtimes）ランタイム 27.2 を実行中のシミュレータデバイスのクローンがファイル権限の誤りで失敗することがある (188407822 / FB24939277、回避策あり)。（StoreKit Testing）サブスクリプション バンドルに含まれるサブスクリプションのアプリ内購入で、エラーを投げるべきところ誤ってアンバンドルできてしまう (186018916)。
