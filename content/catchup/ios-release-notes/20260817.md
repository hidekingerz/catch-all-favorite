## 今回の注目ポイント

- **iOS & iPadOS 27 が Beta 6 に更新**（前回キャッチアップ時点＝Beta 5, 2026-08-11 から進行）。今回の新着は 27 Beta 6 のみ。26 系の正式版に新規更新はなし。
- Beta 4/5 から継続している**破壊的変更・必須対応**（シーンベースライフサイクル未対応アプリの起動失敗、Launch screen キー必須化、On Demand Resources 廃止→Background Assets、旧 MetricKit API 非推奨→`MetricManager`、`FileDocument`/`ReferenceFileDocument` 非推奨→`Document` プロトコル、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、AirPort Utility の新規ダウンロード終了、MDM/登録/構成プロファイル/アプリ配信/ソフトウェア更新に関わるシステムプロセスの TLS 1.2 以上・ATS 準拠強制）は引き続き有効。
- Beta 6 で目立つのは **SwiftUI の `@State` マクロ実装化**、**`ReadableDocument`/`WritableDocument` プロトコル**、**StoreKit のオファーコード引き換えが `VerificationResult` を返すよう変更＋ボリューム購入・サブスクリプション Bundles/Suites 対応**、**Core AI の Neural Engine 改善＋バックグラウンド推論用エンタイトルメント（`com.apple.developer.background-tasks.continued-processing.inference`）**、**Dictation のオンデバイス精度向上プレビュー**、**HealthKit の心拍/サイクリングパワーゾーン・更年期関連トラッキング**、**HomeKit Secure Video 録画への Apple Intelligence 処理（iCloud+ 2TB 以上が必要）** など。
- 解決済みの問題も広範。特に **Apple Wallet の Digital ID が 27.0 Beta 3/4 更新中に期限切れ扱いになる問題**、**セキュリティ修正（183456836）: ACME 証明書取得・MDM Managed Device Attestation 登録の失敗**、Core AI（モデルロード・推論・AOT コンパイル）、Siri 関連の多数の修正などが入った。既知の問題として Safari のタブバー消失・Dictation の音声編集コマンド不安定・App Intents の `.photos.asset` スキーマ非互換などが残る。

## バージョン一覧

### iOS & iPadOS 27 Beta 6 Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27-release-notes
- **要約**: iOS/iPadOS 27 SDK の Beta 6（Xcode 27 バンドル）。概要は「新機能に対応し、API 変更に対してアプリをテストせよ」。
  - **主な新機能（Beta 6 時点）**: SwiftUI に `@State` マクロ実装・`ReadableDocument`/`WritableDocument` プロトコル・`TabsPickerStyle`・`TextInputBorderShape`・外部ディスプレイアクセサリ対応・ドキュメント進捗レポート。StoreKit はオファーコード引き換えが `VerificationResult` を返すよう変更、ボリューム購入とサブスクリプション Bundles/Suites に対応。MetricKit は Swift 版 `MetricManager` API・`MemoryExceptionDiagnostic`・`MetalFrameRateMetric` を追加。Core AI は Neural Engine 改善とバックグラウンド推論用の新エンタイトルメント。Background Assets はユーザーの優先言語に応じてシステムが配信するローカライズ済みアセットパックに対応。GameController は PlayStation® Access™ コントローラを macOS/iPadOS/iOS でサポート。HealthKit は心拍・サイクリングパワーゾーン、権限フロー更新、更年期状態・閉経後出血のトラッキングを追加。HomeKit Secure Video 録画に Apple Intelligence 処理（iCloud+ 2TB 以上が必要）。Dictation はオンデバイスモデルによる精度向上プレビュー（Keyboard 設定 > Dictation > "Advanced Dictation Preview"）。
  - **廃止・変更（継続）**: On Demand Resources 廃止→Background Assets、旧 MetricKit API（`MXMetricManager`/`MXMetricPayload` 等）非推奨→`MetricManager`、`FileDocument`/`ReferenceFileDocument` 非推奨→`Document` プロトコル、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、PencilKit `__PKStrokeRenderState`→`PKStrokeRenderStateReference`、PhotoKit `originalFilename` の非 null 指定が誤りだったとして nullable な `filename` プロパティを新設、AirPort Utility の新規ダウンロード終了。
  - **解決済みの問題（Beta 6）**: Apple Wallet Digital ID の 27.0 Beta 3/4 更新中の期限切れ問題、Core AI のモデルロード・推論・AOT コンパイル、AirPlay の PIN/パスワード認証（ホームシアター）、AirPods Max 2 のファームウェアベータ更新、App Intents の Siri 内カスタム画像表示・`AppEntity` 10MB 累積サイズ上限クラッシュ、CloudKit `CKShare` の self-demotion、Foundation `URLWithString:` の % 二重エンコード、RealityKit `OpacityComponent` の透過描画、Siri の連絡先解決・メッセージ送信・リマインダー操作、StoreKit のテスト取引・価格処理。**セキュリティ（183456836）: ACME 証明書取得・MDM Managed Device Attestation 登録の失敗を修正**。
  - **既知の問題（Beta 6）**: App Intents の既存 `@AppEntity(schema: .photos.asset)` コードがコンパイルできない場合がある（回避策: 可用性チェック付きで新プロパティを採用）、Core Spotlight の `SpotlightSearchTool`（設定なし）がオンデバイスモデルで失敗、Dictation の音声編集コマンド（"Change X to Y"／削除／Undo/Redo）が不安定、Safari のタブバー消失・Intelligence 機能がアセットダウンロード前に利用可能に見える、Reminders の Messages 連携でタイトル空欄、Shortcuts の一部インテント失敗、Siri の写真選択検出・重複名連絡先解決・通話失敗・Maps 応答の不完全さ・CarPlay での応答遅延など。
