## 今回の注目ポイント

- **iOS & iPadOS 27.2 RC（Release Candidate）のリリースノートが公開**（前回収集時は「27.2 Beta 4」）。SDK は Xcode 27.2 に同梱される。正式リリース直前の RC 段階に進んだ。
- **Health に重要な既知の問題が追加**: 再デザインされた Health アプリは今回の beta には含まれない（前回の beta ではテスト目的でのみ提供）。前の beta からアップデートすると、前 beta の Health データは端末に残り、設定（Settings）から閲覧可能。再デザイン版は今後の iOS beta で再提供予定 (188843443)。
- **Nearby Interaction に新しい既知の問題（新セクション）が追加**: フォアグラウンドアプリで DL-TDoA 構成の `NISession` を実行すると、リソースタイムアウトエラー (`NIErrorCodeResourceUsageTimeout`) で予期せず無効化されることがある (189664070)。
- App Tracking Transparency / UIKit / StoreKit Testing / Simulator / Shortcuts / Quest Lab Appointments の各項目は Beta 4 と同一内容（App Tracking Transparency の EU 向け拡張プロンプト対応と API 名の変更、iOS 27.1 以降の `UIView` 既定レイアウトマージンゼロ化が引き続き主要トピック）。

## バージョン一覧

### iOS & iPadOS 27.2 RC Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27_2-release-notes
- **要約**: iPhone / iPad 向け iOS & iPadOS 27.2 RC の開発をサポートする SDK のリリースノート。SDK は Xcode 27.2 に同梱される。前回の Beta 4 からの差分は、Health と Nearby Interaction の既知の問題が追加された点。掲載項目は以下のとおり。
  - **新機能（App Tracking Transparency）**: `AppTrackingTransparency` が EU ユーザー向けの代替の拡張プロンプトと年次ベースでの再プロンプトに対応。代替プロンプトはフランス・ドイツ・イタリア・ポーランド・ルーマニアのユーザーで必須。(179504171)
  - **解決された問題（App Tracking Transparency）**: 新 API `requestTrackingAuthorization(usingExpandedInterface:additionalInformationAction:completionHandler:)` を `requestTrackingAuthorization(preferExpandedInterface:...)` にリネーム (187149729)。さらに `requestTrackingAuthorizationPreferExpandedInterface:…` を `requestTrackingAuthorizationPreferringExpandedInterface:…` にリネーム (187610745)。
  - **新機能（UIKit）**: iOS 27.1 以降、`UIView` の既定のレイアウトマージンがゼロになった。ビューコントローラは引き続き自身のビューに `systemMinimumLayoutMargins`（表示コンテキストに応じて変化）を提供する。サブビューでこれを継承するには `preservesSuperviewLayoutMargins` を `true` に設定する。(186294594)
  - **解決された問題（StoreKit Testing in Xcode）**: `SKTestSession.clearTransactions()` 呼び出し後に導入オファーの適格性が即座にリセットされない問題 (183933307 / FB24137836)、`SKTestSession` でストアフロント/ロケールを変更しても `Storefront.updates` に伝播しない問題 (184155259)、`dialogsDisabled` を true にしても購入失敗時にエラーダイアログが表示されることがある問題 (184255116) を修正。
  - **既知の問題（Health、新規追加分を含む）**: Insights タブでパーソナライズド サマリーが期待どおり生成されないことがある (186964423)。**再デザインされた Health アプリは今回の beta には含まれず、前回の beta ではテスト目的でのみ提供されていた。前 beta からアップデートすると前 beta の Health データは端末に残り、設定から閲覧可能。再デザイン版は今後の iOS beta で再提供予定 (188843443)。**
  - **既知の問題（Nearby Interaction、新規セクション）**: フォアグラウンドアプリで DL-TDoA 構成の `NISession` を実行すると、リソースタイムアウトエラー (`NIErrorCodeResourceUsageTimeout`) で予期せず無効化されることがある (189664070)。回避策: 同じ DL-TDoA 構成で新しい `NISession` を実行する。
  - **既知の問題（その他、Beta 4 から継続）**: （Quest Lab Appointments）ラボ予約がある場合は結果を受け取るまで iOS のアップデートを待つことが推奨される (184530996、回避策: Browse > Lab Results でも結果を確認可能)。（Shortcuts）Describe a Shortcut が「Something went wrong. Try again later.」エラーで失敗することがある (187499433)。（Simulator）ランタイム 27.2 を実行中のシミュレータデバイスのクローンがファイル権限の誤りで失敗することがある (188407822 / FB24939277、回避策あり)。（StoreKit Testing）サブスクリプション バンドルに含まれるサブスクリプションのアプリ内購入で、エラーを投げるべきところ誤ってアンバンドルできてしまう (186018916)。
