## 今回の注目ポイント

- **iOS & iPadOS 27 が RC（Release Candidate）に到達**（前回キャッチアップ時点＝Beta 8, 2026-08-31 から進行）。今回の新着は 27 RC のみ。26 系正式版（26.6）に新規更新はなし。リリースノートは 27.0 の累積形式のため、以下は RC 時点で記載されている開発者向けの主要な変更点。正式リリース前の最終確認フェーズであり、破壊的変更への対応漏れがないか最終チェックが必要。
- ベータ期間から継続している**破壊的変更・必須対応**は RC でも有効: iOS 27.0 SDK 以降でビルドしたアプリは **シーンベースライフサイクル必須**（未対応だと起動失敗）、**Launch screen キー**（`UILaunchStoryboardName`/`UILaunchScreen` 等）を `Info.plist` に必須化（未対応アプリは 27.0 SDK ビルド受付開始後に App Store でリジェクト）、**On Demand Resources / `NSBundleResourceRequest` 廃止**→Background Assets、**旧 MetricKit API 非推奨**（`MXMetricManager` 等）→`MetricManager`、**`FileDocument`/`ReferenceFileDocument` 非推奨**→`ReadableDocument`/`Document` プロトコル、**`calendar.deleteEvents`→`calendar.deleteEvent` リネーム**、**AirPort Utility の新規ダウンロード終了**、**`canOpenURL:` 非推奨**（検証せず直接オープンして失敗を処理する方式へ）。
- **27.0 でのネットワークセキュリティ（TLS）要件厳格化は要注意の破壊的変更**: MDM/DDM/Automated Device Enrollment・構成プロファイルインストール・アプリインストール・ソフトウェア更新に関わる一部システムプロセスが、最低 TLS 1.2＋ATS 準拠の暗号スイート/証明書を要求。サーバが要件を満たさないと接続失敗の可能性（管理環境向けの監査・診断手順は Apple の関連ドキュメント参照）。
- **RC 時点で目立つ追加・修正**: SwiftUI に `.newDocument` 環境値による「テンプレートから新規」フロー・複数 `WritableDocument` を一括書き出す `fileExporter`・`DocumentReader`/`DocumentWriter` の `@concurrent` 化と `@MainActor` 隔離の整理など Document 系 API が大きく前進。UIKit の iPhone Mirroring／iPad リサイズ関連の解決済み問題が多数追加。StoreKit はトランザクション完了不能などの不具合修正。多数の Siri／Dictation 関連の不具合が解決。Core AI は Neural Engine バックグラウンドアクセス制限＋新エンタイトルメント `com.apple.developer.background-tasks.continued-processing.inference` が引き続き必要。

## バージョン一覧

### iOS & iPadOS 27 RC Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27-release-notes
- **要約**: iOS & iPadOS 27 SDK の Release Candidate（Xcode 27 バンドル、Mac App Store 入手可）。概要は「新機能に対応し、API 変更に対してアプリをテストせよ」で、リリースノートは 27.0 の累積形式。正式版直前の最終ビルドとして、これまでのベータで積み上がった新機能・非推奨・既知の問題が集約されている。
  - **主な新機能（27.0 累積、RC 時点）**: SwiftUI に `AsyncImage` の HTTP キャッシュ自動対応（`URLRequest` の `cachePolicy`・`View.asyncImageURLSession(_:)`）、`.textSelection(.enabled)` の `Text` のインタラクティブ選択と `TextRenderer` 対応、`@State` のマクロ実装化（初期化式の再評価回避、iOS 17 系までバックデプロイ）、`ReadableDocument`/`WritableDocument`/`Document` プロトコルと `DocumentGroup`/`fileExporter`/`\.newDocument` 拡張、`TabsPickerStyle`・`TextInputBorderShape`（`.bordered` テキストフィールドスタイル）・`concentricCornerRadii`・`toolbarMinimizationBehavior`（`toolbarMinimizeBehavior` を置換）・`.toolbarColorScheme(_, for: .statusBar)`・外部ディスプレイ向け `.sceneAccessory`・メニュー項目画像の既定非表示化（`labelStyle(.titleAndIcon)` で明示表示）。UIKit は 27.0 SDK で Launch screen 必須化、シーンベースライフサイクル必須、`UINavigationItem.navigationBarMinimization`（旧 `barMinimizeBehavior` を置換）、`UISearchController` のスコープバー挙動変更、`UIScene.extendStateRestoration`/`completeStateRestoration`、`UIMenuElement.preferredImageVisibility`。App Intents は `notes.createNote`/`notes.updateNote` が `AttributedString` の name を受け取り可能。StoreKit はオファーコード引き換えが `VerificationResult` を返す・ボリューム購入（`Transaction.OwnershipType.assigned` 等）・サブスクリプション Bundles/Suites・Advanced Commerce の `partnerName`/`partnerId`。MetricKit は Swift 版 `MetricManager`（`AsyncStream` で `MetricReport`/`DiagnosticReport`）・`MemoryExceptionDiagnostic`・`MetalFrameRateMetric`・`CrashDiagnostic.terminationCategory`・`HitchTimeRatio` 型。HealthKit は心拍/サイクリングパワーゾーン・限定/全履歴を選べる権限フロー・更年期状態/閉経後出血のトラッキング（新カテゴリタイプ）。Core AI は Neural Engine 改善とバックグラウンドアクセス制限＋新エンタイトルメント。Game Controller が PlayStation Access コントローラを macOS/iPadOS/iOS でサポート。AudioAccessoryKit（固定空間オーディオ、当面は開発者テスト用）、Media Sharing Extensions、Background Assets のローカライズ済みアセットパック、HomeKit Secure Video 録画への Apple Intelligence 処理（iCloud+ 2TB 以上）、Dictation のオンデバイスモデル精度向上プレビュー（「Advanced Dictation Preview」）。**Network Security**: 27.0 で一部システムプロセスの TLS 要件厳格化（MDM/DDM/ADE・構成プロファイル・アプリ配信・ソフトウェア更新。最低 TLS 1.2＋ATS 準拠）。
  - **廃止・変更**: シーンベースライフサイクル必須（未対応で起動失敗）、Launch screen 必須化、On Demand Resources / `NSBundleResourceRequest` 廃止（→Background Assets）、旧 MetricKit API（`MXMetricManager` 等）非推奨（→`MetricManager`）＋`ScrollHitchTimeMetric`/`scrollHitchTime(_:)` 廃止（→`HitchTimeMetric`、再コンパイル必須で欠落シンボルクラッシュ回避）、`FileDocument`/`ReferenceFileDocument` 非推奨（→`Document`）、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、`canOpenURL:` 非推奨、PencilKit `__PKStrokeRenderState`→`PKStrokeRenderStateReference`、PhotoKit `originalFilename`（非 null 誤記）→nullable な `filename`、AirPort Utility の新規ダウンロード終了、27.0 での TLS 要件厳格化（破壊的変更として要注意）。
  - **解決済みの問題（主なもの）**: StoreKit（TestFlight での払い戻し/オファーコード/サブスク管理シート非表示、`Storefront` の不正メタデータ、`SKTestSession.buyProduct()` の失敗、トランザクション完了不能）、UIKit（iPhone Mirroring・iPad のリサイズ/インターフェース向き挙動を多数修正、非推奨ステータスバーアクセサの NaN/null 返却）、SwiftUI（`containerRelativeFrame` の safe-area 計算、`controlSize` 等がシート/ポップオーバーに波及、`fileExporter`＋`fileMover` の同時提示、`@State` の raw identifier コンパイル失敗）、Core AI（`.aimodel`/`.aimodelc` のオンデバイス特殊化失敗・Metal API Validation・カスタム Metal カーネルモデルのロード失敗など多数）、Siri/Dictation（連絡先解決・Maps・リマインダー・CarPlay・メッセージ送信など多数）、Battery（深放電デバイスの起動不能）、Apple Wallet の Digital ID 期限切れ、Files/Photos/Messages/Metal 等。
  - **既知の問題（主なもの）**: 既存の `@AppEntity(schema: .photos.asset)` 準拠コードが新プロパティ追加により 27 SDK でコンパイルできない場合あり（回避策: 可用性チェック付きで新プロパティを採用）。Core Spotlight の `SpotlightSearchTool` をオンデバイス言語モデルで使うとトークン上限超過（回避策: `.focused(...)` の focused guide を使用）。Now Playing の `RemoteMediaSession` が `development` 設定でも常に `production` APNs のプッシュトークンを発行（テストは `production` で実施）。Control Center の Performance Trace ウィジェットでのトレース取得失敗、CarPlay での Siri 応答遅延、Shortcuts の `UnionValue`/`Duration` 関連など。
