## 今回の注目ポイント

- **iOS & iPadOS 27 が RC（Release Candidate）に更新**（前回キャッチアップ時点＝Beta 8, 2026-09-09 から進行）。タイトルが「iOS & iPadOS 27 Beta 8 Release Notes」から「iOS & iPadOS 27 RC Release Notes」へ変わり、正式版が目前。今回の新着は 27 RC のみ。26 系正式版（26.6）に新規更新はなし。
- リリースノートは 27.0 の累積形式のため、Beta 4〜8 から継続している**破壊的変更・必須対応**は RC でも引き続き有効: シーンベースライフサイクル未対応アプリの起動失敗、iOS 27.0 SDK 以降でビルドしたアプリは Launch screen キー（`UILaunchScreen` 等）を `Info.plist` に必須化、On Demand Resources（`NSBundleResourceRequest`）廃止→Background Assets、旧 MetricKit API（`MXMetricManager` 等）非推奨→`MetricManager`、`FileDocument`/`ReferenceFileDocument` 非推奨→`Document` プロトコル、`calendar.deleteEvents`→`calendar.deleteEvent` リネーム、AirPort Utility の新規ダウンロード終了。
- **ネットワークセキュリティ**: 27.0 で MDM/DDM/Automated Device Enrollment・構成プロファイル・アプリ配信・ソフトウェア更新に関わる一部システムプロセスが TLS 1.2 以上・ATS 準拠を強制（サーバが要件を満たさないと接続失敗の可能性）。正式版リリース前に対応済みか要確認。

## バージョン一覧

### iOS & iPadOS 27 RC Release Notes
- **URL**: https://developer.apple.com/documentation/ios-ipados-release-notes/ios-ipados-27-release-notes
- **要約**: iOS & iPadOS 27 の Release Candidate（Xcode 27 バンドル、Mac App Store 入手可）。概要は「新機能に対応し、API 変更に対してアプリをテストせよ」で、リリースノートは 27.0 の累積形式。**破壊的変更・必須対応**は Beta 期から継続（シーンベースライフサイクル未対応アプリの起動失敗、Launch screen キー必須化、On Demand Resources 廃止→Background Assets、旧 MetricKit API 非推奨→`MetricManager`、`FileDocument`/`ReferenceFileDocument` 非推奨→`Document`、`calendar.deleteEvents`→`calendar.deleteEvent`、AirPort Utility 新規ダウンロード終了、27.0 システムプロセスの TLS 要件厳格化）。**新機能**（継続記載）: App Intents の Notes スキーマ拡張（`notes.createNote`/`notes.updateNote` の `name` パラメータに `AttributedString` を渡せる）、Background Assets のローカライズ済みアセットパック、Core AI の Neural Engine 改善（バックグラウンドアクセス制限・新エンタイトルメント `com.apple.developer.background-tasks.continued-processing.inference`・1GB 超モデル読込高速化・メモリ計上をアプリプロセスへ）、AudioAccessoryKit の固定空間オーディオ（開発者テスト向け）など。**RC で目立つ解決済み（Resolved Issues）**: AirPlay to Home Theaters の PIN/パスワード時の失敗、App Intents の各種不具合（Siri でのカスタム画像未表示・"Set" 型パラメータの既定値未適用・`reminders.updateReminder` 呼び出し失敗・AppEntity の 10MB 上限クラッシュ・`notes.appendText` スキーマ消失）、Apple Wallet の Digital ID 期限切れ、Camera のポートレートぼかし描画不具合、CarPlay の複数不具合（`CPNavigationSession`/`CPMapPanel`/ステアリング操作/Spatial Audio 後の無音）、CloudKit の `CKShare` 自己降格無効、深放電バッテリでの起動不能、Core AI の各種推論不具合（`AIModelCache` ポリシー・`InferenceFunction` のブロッキング・FP8/パレット化重み・動的形状/制御フロー）など。**既知の問題（Known Issues）**: 27 SDK で `@AppEntity(schema: .photos.asset)` 準拠エンティティがコンパイル不可になる可能性（新プロパティ追加のため、可用性チェックで対応）、CarPlay での Siri 応答遅延、Control Center の Performance Trace（`PowerProfiler`/`Lookback`）トレース取得失敗など。
