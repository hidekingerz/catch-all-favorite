## 今回の注目ポイント

最新の OS リリース（iOS 27 / iPadOS 27 / macOS 27 / tvOS 27 / visionOS 27 / watchOS 27）向けの App Store 提出受付が開始された。ビルドには Xcode 27 Release Candidate と最新 SDK を使用する。2027年4月以降は各プラットフォームの最新 SDK でのビルドが必須となるほか、macOS 27 は Apple シリコン専用（Intel Mac / Rosetta 非対応）となる点に注意が必要。アプリを提出予定のデベロッパは早めに対応方針を確認しておきたい。

## 記事一覧

### 最新のOSリリースに向けたApp Storeの提出受付を開始
- **URL**: https://developer.apple.com/jp/news/?id=k1mtkt1k
- **公開日**: 2026-09-09
- **要約**: iOS 27・iPadOS 27・macOS 27・tvOS 27・visionOS 27・watchOS 27 向けアプリの App Store 提出が可能になった。ビルドには Xcode 27 Release Candidate と最新 SDK を使用する。2027年4月以降は各プラットフォームの最新 SDK でのビルドが必須。macOS 27 は Apple シリコン専用（macOS 26 が Intel Mac / Rosetta をサポートする最後のリリース）となり、Intel 版アプリを継続する場合はビルドアーキテクチャを arm64 のみに設定して再提出する必要がある。あわせて Time Allowances に伴う年齢レーティングのソーシャルメディア関連質問への回答や、新しいプロダクトページ用アセットの提供予定にも言及されている。
