## 今回の注目ポイント

iOS / iPadOS / macOS / visionOS 27.3 のベータ公開に合わせ、Siri AI の Developer Preview がすべての開発者に解放された。App Intents を使ってアプリのコンテンツやアクションを Siri AI に直接統合でき、春には App Store への提出が開始される予定。あわせて 27.3 系ベータ一式（iOS・iPadOS・macOS・tvOS・visionOS・watchOS）と Xcode 27.3 が提供開始された。Apple Intelligence 対応アプリを開発する開発者は早期に試して対応を検討したい。

## 記事一覧

### Siri AI is now open to all developers
- **URL**: https://developer.apple.com/jp/news/?id=gdk2umrf
- **公開日**: 2026-11-03
- **要約**: 本日より iOS 27.3 / iPadOS 27.3 / macOS 27.3 / visionOS 27.3 の各ベータで、すべての開発者がアプリを Siri AI と統合できる Developer Preview が開始された。App Intents を使ってアプリのコンテンツ・アクションを Siri AI に直接取り込め、パーソナルコンテキスト理解・画面認識・自然言語などの新機能を活用できる。複数アクションを1つの体験にまとめる「skills」や、既存スキーマに収まらないエンティティを Spotlight セマンティックインデックスから提示する機能も導入。Apple 製アプリ（Calendar、Mail、Maps、Messages、Photos、Safari など）でも展開が始まっている。顧客への提供は数か月後、App Store への提出は春に開始予定。新 API のドキュメントは appintents/siri-ai-developer-preview で公開。11月4〜5日には Apple Intelligence Group Labs も開催される。なお Siri AI はベータ時点で EU（iOS・iPadOS・watchOS）では利用不可、13歳未満は対象外。

### Get ready with the latest beta releases
- **URL**: https://developer.apple.com/jp/news/?id=6gpufove
- **公開日**: 2026-11-03
- **要約**: iOS 27.3 / iPadOS 27.3 / macOS 27.3 / tvOS 27.3 / visionOS 27.3 / watchOS 27.3 のベータ版が公開された。これらのリリースでアプリが期待どおり動作するか確認し、最新 SDK の機能を活用するために Xcode 27.3 でビルド・テストを行うよう案内されている。ダウンロードとリリースノート、ベータ OS のテスト方法、フィードバック送信先へのリンクが提供されている。
