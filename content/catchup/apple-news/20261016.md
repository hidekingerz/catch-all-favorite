## 今回の注目ポイント

**App Review Guidelines（App Review ガイドライン）が改訂**された。今回の改訂は、既存の App Store 保護を強化・拡張して **非合意の性的画像（nonconsensual intimate imagery）** と **bait-and-switch（審査時には隠し、承認後に機能を追加する手口）** に対抗することが柱。ユーザー生成コンテンツを扱うアプリには、AI 生成を含む非合意の性的画像のフィルタリング・通報手段・悪質アカウントのブロック機能を義務づけ、実在人物の性的画像を無断生成する「nudification」アプリを明確に禁止する。審査時にアプリの目的を偽り承認後に有害機能を明かす行為は、新ガイドライン **2.5.19（Hidden, dormant, or undocumented features）** で明示的に禁止され、違反アプリは App Store と Apple Developer Program から排除され得る。同日公開の2記事（ガイドライン更新の告知と、その背景を詳説する記事）をまとめて収録する。

## 記事一覧

### Updated App Review Guidelines are now available
- **URL**: https://developer.apple.com/jp/news/?id=92th7e5i
- **公開日**: 2026-10-16
- **要約**: 新機能・ポリシー更新・明確化に対応するため App Review ガイドラインを改訂。主な変更は次のとおり。**Before You Submit / After You Submit**: 追加ドキュメントへのリンクを追加。**1.2**: 本ガイドラインが対象とするアプリの内容・種別を明確化し、適切なセーフガードを実装しない、または通知後に違反を是正しない場合は Developer Code of Conduct 違反となり得ると明記。**2.3.14（新設）**: クリエイティブアセットに関する条項。**2.5.19（新設）**: 隠された／休眠中／未記載の機能に関する長年のポリシーを明確化（従来はガイドライン 2.3.1 に含まれていた内容）。**3.1.1(a)**: Music Streaming Services Entitlements の箇条書きを削除し StoreKit External Purchase Link Entitlements に統合、許可された宛先へのリンク提供が可能と明確化。**5**: 人身売買や児童搾取を助長するアプリは App Store から削除し代替配信もブロックすると明確化。翻訳版は1か月以内に Apple Developer サイトで提供予定。あわせて、審査時に機能を隠し承認後に追加する bait-and-switch は禁止で、該当アプリの削除や Developer Program 資格の終了があり得ること、ユーザー生成コンテンツを扱うアプリには非合意の性的画像（AI 生成含む）のフィルタ・通報・ブロックが求められること、実在人物の性的画像を無断生成する「nudification」アプリが禁止であることを明記。Apple は昨年、安全性に問題のある15万件超のアプリを排除し、不正・悪用により19.3万件超の開発者アカウントを停止したとしている。

### Strengthening App Review Guidelines against nonconsensual intimate imagery and bait-and-switch apps
- **URL**: https://developer.apple.com/jp/news/?id=vvzx6cul
- **公開日**: 2026-10-16
- **要約**: 上記ガイドライン改訂の背景を詳説する記事。ポルノ素材は従来から禁止されているが、今回これに実在人物の性的画像を無断生成する「nudification」アプリなど、ヌードや性的画像を生成するアプリが明示的に含まれることを説明。隠された／未記載の機能を含むアプリ（審査時に目的を偽り、承認後に有害機能を明かすものを含む）も禁止。**ガイドライン 1.2（ユーザー生成コンテンツ）**: コンテンツモデレーション要件が AI 生成を含む非合意の性的画像を明示的に対象とし、不適切コンテンツのフィルタリング・通報手段・悪質アカウントのブロックを義務づけ。適切なセーフガードを実装しない／通知後に是正しない開発者は Developer Code of Conduct 違反と App Store からの削除のリスクを負う。**ガイドライン 2.5.19（隠された／休眠中／未記載の機能）**: 審査時にアプリを偽り承認後に変更する（提出版に無い機能を追加する等）行為を禁じる新設ガイドライン。違反アプリは App Store と Apple Developer Program から排除され得る（従来はガイドライン 2.3.1 の一部）。**セクション5**: 人身売買や児童搾取（児童性的虐待素材を含む）を助長するアプリは App Store から削除し代替配信もブロック。Apple は昨年、安全性に問題のある15万件超のアプリが顧客に届くのを防ぎ、不正・悪用により19.3万件超の開発者アカウントを停止したと説明し、有害コンテンツを承認後まで隠す組織的な手口に対し検出ツールの改善を続けるとしている。
