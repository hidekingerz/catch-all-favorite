## 今回の注目ポイント

2026年11月12日付で **HomeView Software Version 27.2** が公開された。対象は Apple HomeView（ホーム用デバイス）。9件の CVE に対処しており、11月9日に iOS / macOS 等へ一斉配信された脆弱性群（CVE-2026-113960 番台）とおおむね共通するコンポーネント（AirPlay・App Intents・Bluetooth・brotli・CoreUtils・Messages・rapportd）を修正している。Bluetooth 経由のペアリングコード試行回数（レート制限）バイパス、ユーザー操作なしでのペアリング、メモリ破損（use-after-free／領域外書き込み）、iMessage グループチャットへの不正参加・過去メッセージの閲覧などが含まれる。いずれも悪用が確認されている旨の記載はない。HomeView デバイスを利用している場合は早めの更新が推奨される。

## リリース一覧

### HomeView Software Version 27.2
- **公開日**: 2026-11-12
- **対象**: Apple HomeView
- **詳細**: https://support.apple.com/ja-jp/149851
- **要約**: Apple HomeView 向けのセキュリティアップデート。9件の CVE に対処する。主な内容は以下のとおり。
  - **AirPlay**（CVE-2026-113968）: Bluetooth 経由の近接攻撃者がペアリングコード試行のレート制限をバイパスできる問題。
  - **App Intents**（CVE-2026-113963）: 認可の不備により、アプリが機微なユーザーデータにアクセスできる問題。
  - **Bluetooth**（CVE-2026-113970）: Bluetooth 経由の近接攻撃者がプロセスメモリを破損できる問題（use-after-free）。
  - **brotli**（CVE-2026-111497）: 細工された入力の処理によりメモリ破損（領域外書き込み）が発生し得る問題。
  - **CoreUtils**（CVE-2026-113965）: 悪意ある Bluetooth デバイスがユーザー操作なしでペアリングできる問題。
  - **CoreUtils**（CVE-2026-113964）: 近接攻撃者がペアリングコードのレート制限をバイパスし、ユーザー操作なしでペアリングできる問題。
  - **Messages**（CVE-2026-113961）: 遠隔の攻撃者が iMessage グループチャットに参加してそのメッセージを受信できる問題。
  - **Messages**（CVE-2026-113960）: iMessage グループに追加されたユーザーが、参加前に送信されたメッセージにアクセスできる問題。
  - **rapportd**（CVE-2026-113969）: 同一ネットワーク上の攻撃者が AirPlay のペアリングコード試行のレート制限をバイパスできる問題。
