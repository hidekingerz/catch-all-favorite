> 取得日: 2026-08-07
> ソース: [Apple セキュリティリリース](https://support.apple.com/ja-jp/100100)

## 今回の注目ポイント

- 2026年8月6日に、macOS 向けの臨時（アウトオブバンド）セキュリティアップデートとして macOS Tahoe 26.6.1・macOS Sequoia 15.7.9・macOS Sonoma 14.8.9 の3件が同時公開された。
- 3件はいずれも Screen Sharing の認証バイパス脆弱性 CVE-2026-65400 のみを修正するピンポイントな更新。ネットワーク上の攻撃者が有効な認証情報なしに Screen Sharing に認証できる可能性があった。状態管理の改善で対処されている。
- 現行の Tahoe だけでなく、旧 OS の Sequoia・Sonoma にも同時に修正が提供されている。
- 取得した範囲では、実環境で悪用された（actively exploited）と明記された記述は確認されなかった。

## リリース一覧

### macOS Tahoe 26.6.1
- **公開日**: 2026-08-06
- **対象**: macOS Tahoe
- **詳細**: https://support.apple.com/ja-jp/148170
- **要約**: Screen Sharing の認証バイパス脆弱性 CVE-2026-65400 を修正する単一 CVE の臨時アップデート。ネットワーク上の攻撃者が有効な認証情報なしに Screen Sharing に認証できる可能性があった問題を、状態管理の改善で対処。報告: Alfredo Pesoli 氏（@__rev）via Bynario Atlas。実環境での悪用は明記されていない。

### macOS Sequoia 15.7.9
- **公開日**: 2026-08-06
- **対象**: macOS Sequoia
- **詳細**: https://support.apple.com/ja-jp/148171
- **要約**: 旧 OS（Sequoia）向けに、macOS Tahoe 26.6.1 と同じ Screen Sharing の認証バイパス脆弱性 CVE-2026-65400 を修正。ネットワーク上の攻撃者による認証情報なしの Screen Sharing 認証を防ぐ。状態管理の改善で対処。報告: Alfredo Pesoli 氏（@__rev）via Bynario Atlas。実環境での悪用は明記されていない。

### macOS Sonoma 14.8.9
- **公開日**: 2026-08-06
- **対象**: macOS Sonoma
- **詳細**: https://support.apple.com/ja-jp/148172
- **要約**: 旧 OS（Sonoma）向けに、Screen Sharing の認証バイパス脆弱性 CVE-2026-65400 を修正。ネットワーク上の攻撃者が有効な認証情報なしに Screen Sharing に認証できる可能性があった問題を状態管理の改善で対処。報告: Alfredo Pesoli 氏（@__rev）via Bynario Atlas。実環境での悪用は明記されていない。
