# ブラウザと HTTP の会話についていく

> 想定読者: フロントエンドを学んだことがない新人と、エンジニア志望の人。短いコードを読めて、ターミナルでコマンドを 1 行実行できる
> 省いたもの: 規格書の番号、各社の対応状況、歴史、攻撃の手法、ブラウザ内部の細かい段階、保存用 API の使い方
> 所要時間: 5 章で、読むのに約 45 分、手を動かして約 25 分
> 検証方法: 本文に載せた出力は、すべて `checks.json` のコマンドで作り直して照合している

この本は、フロントエンドを学んだことがない人に、職場でよく出る 5 つの言い回しが何の話なのかを伝えます。

元にしたのは、このリポジトリの 5 本の技術調査レポートです（[HTTP/1.1](../../content/research/http/http1.md)、[HTTP/2](../../content/research/http/http2.md)、[HTTP/3](../../content/research/http/http3.md)、[ブラウザの仕組み](../../content/research/browser/internals.md)、[ブラウザのストレージ](../../content/research/browser/storage.md)）。

レポートは経験者向けに書かれています。この本は、レポートを読む前の人が、動く例を 1 つずつ実行して確かめながら読む入口です。

## 一枚で

| 職場で聞く言い回し | 何の話か | 章 |

| 「メインスレッドが詰まっている」 | 1 つの長い処理が順番を占有して、クリックへの反応と画面の更新が待たされている | [3 章](03-main-thread.md) |

| 「Cookie に入れる？ localStorage に入れる？」 | そのデータを、サーバにも毎回届けるかどうかを決めている | [5 章](05-storage.md) |

## 動かす準備

Node.js（22 以上）が必要です。ターミナルで `node -v` と打って、`v22` 以上の番号が出れば入っています。出なければ、先輩に入れ方を聞いてください。

ターミナルでこの本のフォルダ（この README.md があるフォルダ）に移動して、次の 2 行を 1 回だけ実行します。

```sh
npm install
npx playwright install chromium
```

1 行目は、例が使う道具を取ってきます。2 行目は、例が使うブラウザ（Chromium）を取ってきます。ふだん使っているブラウザには影響しません。

各章の例は、`node examples/01-page-load.mjs` のように 1 行で実行できます。手元に小さなサーバを立てるだけで、外部とは通信しません。

→ 最初の章: [1 章](01-quickstart.md)
